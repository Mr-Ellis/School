A1.1.7 – Secondary Memory

📌 Learning Objective

By the end of this lesson, you will be able to:

  • Describe what separates internal from external secondary storage — that the distinction is location and connection, not what the device stores
  • Describe the three internal types (HDD, SSD, eMMC), giving for each the technology it uses, one or two defining characteristics, and a typical use
  • Describe the external types (external HDD and SSD, optical drive, flash drive, memory card, NAS) in the same terms: technology, characteristic, use

🎯 IB Command Term: Describe

Describe – "Give a detailed account."

Naming a device is not describing it. This lesson builds the skill of providing a detailed account for each storage type.

🔑 Key Terms

TermDefinition
Secondary storageNon-volatile storage that holds data whether the machine is on or off
Internal storageFitted inside the computer case, connected directly to the motherboard
External storageConnected from outside the case through an interface such as USB or a network
InterfaceThe connection through which an external device links to the computer, e.g., USB
Flash memoryStorage with no moving parts, used by SSDs, eMMC, flash drives, and memory cards
NAS (Network Attached Storage)A storage device connected to a network so many machines can reach it
