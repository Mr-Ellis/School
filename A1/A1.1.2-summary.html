A1.1.2 – GPU Architecture

📌 Learning Objective

By the end of this lesson, you will be able to:

  • Explain the role and architecture of a GPU
  • Compare GPUs with CPUs in terms of design and use cases
  • Discuss how GPUs accelerate machine learning and graphics

🎯 IB Command Term: Explain

Explain – "Give a detailed account including reasons or causes."

🔑 Key Terms

TermDefinition
GPUGraphics Processing Unit – a specialised processor originally designed for rendering graphics, now used for parallel processing.
CUDA CoresNVIDIA's parallel processing cores that handle many tasks simultaneously.
Stream ProcessorsAMD's equivalent to CUDA cores for parallel computation.
VRAMVideo RAM – dedicated memory on the GPU for storing textures and frame buffers.
Parallel ProcessingPerforming many operations simultaneously, which is the key strength of GPUs.
