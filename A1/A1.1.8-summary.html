A1.1.8 – Data Compression

📌 Learning Objective

By the end of this lesson, you will be able to:

  • Describe the concept of compression and why it is used (storage space, transmission time, bandwidth)
  • Describe the difference between lossy and lossless compression methods, including when each is appropriate
  • Describe how Run-Length Encoding (RLE) and transform coding work, giving for each the technology, a defining characteristic, and a typical use

🎯 IB Command Term: Describe

Describe – "Give a detailed account."

Simply naming a compression method (e.g., "JPEG") is not describing it. This lesson builds the skill of providing a detailed account of how compression works, what it achieves, and the trade-offs involved.

🔑 Key Terms

TermDefinition
CompressionThe process of reducing the size of data to save storage space or transmission bandwidth.
Lossless compressionA compression method where all original data is retained, allowing the exact reconstruction of the original file without any loss of quality.
Lossy compressionA compression method where some original data is permanently removed, leading to a smaller file size but a loss of quality.
Run-length encoding (RLE)A lossless compression technique that replaces sequences of identical data values with a count and the single value.
Transform codingA lossy compression technique that converts data into a different domain (e.g., frequency domain) to remove less important information.
RedundancyData that is repeated or unnecessary; compression works by removing this.

💡 Why Compression?

Compression is a fundamental technique in computer science. It works by removing redundancy, either reversibly or irreversibly, depending on the method used.

The goal is to reduce:
  • File size (e.g., MB to KB) — saves storage space
  • Bandwidth usage during transmission — faster downloads and streaming
  • Storage requirements — more files fit on a disk

Compression is essential in areas such as multimedia (images, audio, video), data transmission, file storage, and archival.

🔁 Run-Length Encoding (RLE) – Lossless

Run-Length Encoding is a simple lossless compression method used when data contains consecutive repeated values (runs). It replaces repeated elements with a single value and a count.

How it works

  • Scan the data for consecutive identical values.
  • Replace each run with a count followed by the single value.
Example 1 — Text Original: AAAAABBBCCDAA
Compressed: 5A3B2C1D2A
Example 2 — Binary Original binary string: 00000011110000
Compressed: 6×0, 4×1, 4×0 → represented as (0,6)(1,4)(0,4)
Best for: Data with long repeated sequences — simple images (e.g., black-and-white bitmaps), text with repeated characters, icons.

Limitations: Inefficient on data with high variability (e.g., random data or noisy signals) — it can actually increase file size if there are few runs.

🎵 Transform Coding – Lossy

Transform coding is the basis of most modern lossy compression algorithms, especially for images and audio. It removes data that is considered redundant or imperceptible to human senses.

How it works

  1. Transform the data from the time/spatial domain to the frequency domain (e.g., apply the Discrete Cosine Transform (DCT) in JPEG images).
  2. Quantize the frequency components (round or remove small values).
  3. Encode the quantized values using entropy coding (e.g., Huffman).
Example in JPEG • An image is divided into 8×8 blocks.
• Each block is transformed using DCT to get frequency coefficients.
• Coefficients representing fine details (high-frequency) are often quantized to zero.
• The result is high compression with acceptable loss of visual quality.
Best for: Images (JPEG), audio (MP3), video (MPEG, H.264).

Trade-offs: Compression ratio vs. perceptual quality — loss of fine detail and possible visible artifacts at high compression.

✅ Conclusion

Compression is an important tool in managing digital data efficiently. The distinction between lossless and lossy compression determines whether original data can be perfectly reconstructed. Run-Length Encoding offers a simple method for lossless scenarios, while transform coding underpins powerful lossy formats like JPEG and MP3. Understanding when and how to use each method enables better design of storage systems, transmission protocols, and multimedia applications.
