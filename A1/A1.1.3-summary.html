🔑 Key Terms (HL)

TermDefinition
GPGPUGeneral-Purpose computing on Graphics Processing Units – using GPUs for non-graphics tasks.
SIMDSingle Instruction, Multiple Data – a parallel processing architecture where one instruction operates on multiple data elements.
SM (Streaming Multiprocessor)A unit within a GPU that contains multiple CUDA cores and shared memory.
Memory BandwidthThe rate at which data can be read from or written to GPU memory.
Tensor CoresSpecialised cores in NVIDIA GPUs designed for matrix multiplication, accelerating AI workloads.
