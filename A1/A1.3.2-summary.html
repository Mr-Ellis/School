💡 The Big Idea — System Integrity

An operating system's functions are the concrete services that put its resource-management role into practice. Where the role (A1.3.1) is to abstract hardware and arbitrate resources, the functions (A1.3.2) are the specialised subsystems that do the day-to-day work.

Their overarching purpose is to maintain system integrity:

System integrity – the state where a computer system operates correctly and securely, free from unauthorised changes or corruption. The OS ensures its own code, its data, and running applications' code remain correct, consistent and protected from accidental corruption or malicious interference.

Without these functions, one malfunctioning driver or runaway process could destabilise the entire system.

📊 The Nine Functions

The IB syllabus groups OS functions into nine broad areas. Each one manages a different resource or provides a different service.

🧠 Memory Management Allocates RAM to processes; manages virtual memory
📁 File System Organises files and directories; controls access
🖨️ Device Management Controls hardware via drivers; handles I/O
⏱️ Scheduling Decides which process runs next, and for how long
🔒 Security Authentication, encryption, malware protection
📊 Accounting Tracks resource usage; quotas and billing
🖥️ GUI Windows, icons, menus, pointers for user interaction
📦 Virtualisation Runs multiple VMs on one physical machine
🌐 Networking Manages connections and data communication

🔍 Function in Detail

For each function, the exam expects you to say what the OS is actually doing — not just name it.

1. Memory Management

The OS controls and coordinates the computer's primary memory (RAM). It ensures memory is allocated efficiently to processes, maintains system stability, and protects memory areas from unauthorised access.

When you open an application, the OS:

  1. Locates the application on the storage device (HDD or SSD)
  2. Reads the executable file (.exe on Windows, .app on Mac)
  3. Allocates the necessary memory space for code, data and resources
  4. Ensures the application has enough space without interfering with other processes

If applications need more memory than is available in RAM, the OS uses virtual memory — allocating space on the HDD or SSD to act as RAM. Reading from storage is much slower than RAM, but by switching higher-priority processes into RAM and lower-priority ones into virtual memory, the OS keeps the system running.

💡 Analogy

Think of memory management as organising books on a bookshelf. The OS allocates each book (process) its own space on the shelf (memory). Just as you wouldn't let books overlap, the OS ensures each process has its own protected area.

2. File Management

The OS provides a structured way to manage files and directories on storage devices, ensuring system stability and security. It employs a hierarchical file system — files organised into directories (folders), which can contain further directories, forming a tree-like structure.

Set file operations include:

  • Creating new files and directories
  • Reading and writing data to files
  • Deleting files
  • Renaming files
  • Moving or copying files and directories

The OS enforces naming rules so no two files in the same directory have the same name. Files often have extensions (like .jpg or .exe) to indicate file type.

One important maintenance task is defragmentation — reorganising fragmented data on an HDD so files are stored in contiguous blocks, improving access speed and overall performance.

3. Device Management

The OS controls and coordinates hardware components — printers, disk drives, display screens, keyboards, network interfaces — through device drivers: specialised software that allows the OS to communicate with and control hardware by providing necessary instructions and protocols.

The OS handles I/O using three key techniques:

TechniqueWhat it does
BufferingTemporarily stores data in memory while it's transferred between two devices, managing differences in data-flow rates
CachingStores frequently accessed data in a high-speed area to reduce access time
SpoolingQueues data or tasks (e.g. for printers) so they process sequentially, letting the system work on other tasks meanwhile

Modern OSes use Plug and Play (PnP) — the OS automatically detects, configures and installs drivers for new hardware without manual setup.

4. Scheduling

The OS manages the execution of multiple processes by determining which process runs at any given time. The scheduler allocates CPU time to processes, ensuring efficient and fair use of system resources.

This is crucial for multitasking environments — implementing various scheduling algorithms to optimise performance, reduce wait times and maintain system stability. (Details are covered in A1.3.3.)

5. Security

The OS protects the integrity, confidentiality and availability of information and resources. It has mechanisms to safeguard against threats, prevent unauthorised access, and ensure users and applications can operate securely.

AspectWhat the OS does
User authenticationRequires credentials — username/password, biometric data or security tokens — to log in. Based on user settings, grants or prevents access to files, folders and applications. Allows multiple users with different credentials (administrator vs standard user).
EncryptionProvides tools and frameworks for encrypting files, communication channels and devices. Even if data is intercepted, it cannot be read without the decryption key.
Auditing and monitoringTracks all system activities — logins, file access, errors, administrator actions — in a log. Used for auditing, detecting suspicious activity, and identifying issues.
Malware protectionDetects and prevents malware infections and intruders using antivirus software, firewalls and intrusion detection systems (IDS). Protects against viruses, worms and trojans.

6. Accounting

The OS tracks resource consumption by users and processes, providing data for performance analysis, cost allocation and resource optimisation. Key aspects:

  • Resource usage tracking — CPU time, memory, disk space, network volume used by each process/user
  • Process accounting — process ID, user ID, execution time, start/end times, resource consumption
  • User accounting — cost allocation, quota management (disk quotas, memory quotas)
  • Performance monitoring — identifying bottlenecks, underutilisation and trends
  • Auditing and reporting — compliance, security analysis, resource management decisions
  • Billing and chargeback — usage-based billing (e.g. cloud computing), chargeback to departments

7. Graphical User Interface (GUI)

The OS provides a user-friendly environment for interacting with the computer using visual elements: windows (display application contents), icons (graphical representations of applications and files), menus (lists of commands), pointers (cursor controlled by input device).

Key GUI responsibilities:

  • Application management — task switching (Alt+Tab), window management (snapping, tiling), desktop environment
  • File and system management — File Explorer, system settings, drag-and-drop
  • Accessibility — screen readers, high-contrast themes, keyboard shortcuts for users with disabilities
  • Visual feedback — progress bars, notifications, tooltips
  • Customisation — themes, wallpapers, widgets

8. Virtualisation

The OS allows multiple virtual machines (VMs) to run on a single physical machine. Each VM operates independently with its own OS and applications. The OS manages this through a hypervisor, which allocates CPU time, memory and storage to each VM.

Benefits: isolation between VMs, snapshots and backups, live migrations, disaster recovery, dynamic scaling in cloud environments.

9. Networking

The OS manages and facilitates network communication. It establishes and maintains network connections, manages network interfaces and protocols, configures settings, assigns IP addresses via DHCP, and handles underlying hardware like NICs (network interface cards).

It implements networking protocols such as TCP/IP — governing how data is packetised, addressed, transmitted, routed and received. It ensures data integrity through error checking, flow control and congestion avoidance, and supports higher-level protocols like HTTP, FTP.

💻 Worked Example — Opening an Application

What happens when you double-click a Word document?

  1. File system — locates the document by name and maps it to physical blocks on the disk
  2. Memory management — allocates a private address space; loads Word's code and the document into RAM
  3. Scheduling — gives the Word process CPU time, alongside other running processes
  4. Security — checks that your user account has permission to read the file
  5. GUI — renders the window, menus and document on screen
  6. Device management — handles keyboard and mouse input via drivers
  7. Accounting — logs the CPU time and memory the process consumes

Seven of the nine functions are involved in a single everyday action. This is why "system integrity" matters: all seven must cooperate correctly or the experience breaks.
