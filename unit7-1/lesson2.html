🕵️ Making Programming Easy: Plan Your Code Like a Detective!

Imagine you're a detective solving a mystery. Before you catch the culprit, you need a plan: What clues will you look for? What steps will you take?

Programming works the same way! Before writing code, you need a clear plan.

🗺️ Flowcharts: Your Program's Treasure Map

A flowchart is like a treasure map or a game plan for your program. It's a picture that shows the steps your computer will follow, using simple symbols:

Start/Stop
Start/Stop: The beginning and end of the program.
Process
Process: Things the computer does, like adding numbers.
Input/Output
Input/Output: Asking the user for info or showing results.

Example: Adding Two Numbers

  1. Start
  2. Ask the user for the first number
  3. Ask the user for the second number
  4. Add the two numbers
  5. Show the result
  6. End

🐍 Turning a Flowchart into Python Code

Once your flowchart is ready, you turn it into Python — a language computers understand. Think of it like turning a recipe diagram into real cooking steps.

# Adding two numbers with casting number1 = int(input("Enter the first number: ")) number2 = int(input("Enter the second number: ")) total = number1 + number2 print("The sum is:", total)
Tip: int() makes sure the computer treats what you typed as a number, not text! This is called casting.

🔍 Predict Before You Test

Before running your code, guess the result. If you enter 15 and 20, what will the program show? This helps you check if your plan makes sense.

📦 Data Types & Casting

In Python, we work with different data types. Choosing the right one is important!

Common Data Types

  • String — text, like "Maryam" or "001256" (leading zeros are preserved).
  • Integer — whole numbers, like 13 or 2026.
  • Float (Real) — decimal numbers, like 145.98 or 1.76.

Casting (Converting Types)

Use these functions to cast input to the right type:

  • str() → converts to string
  • int() → converts to integer
  • float() → converts to float (real)
# Examples of casting age = int(input("Enter your age: ")) # integer height = float(input("Enter height: ")) # float city = input("Enter city: ") # string (no casting needed)
