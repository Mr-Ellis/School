1 Data Types

Data TypeWhat it storesExample
StringText — letters, numbers, symbols (always in quotes)"Hello", "city", "April"
IntegerWhole numbers (positive or negative, no decimal point)15, -5, 3
Real / FloatDecimal numbers3.14, 1.75, -0.5
Remember: In Python, the real data type is referred to as float. Integers can be positive or negative — not just positive.

Q: Which data type would store a decimal number like 3.14?

A: Real / Float.

2 Choosing the Right Data Type

When you see a variable name, think about what kind of data it would sensibly hold:

VariableSensible typeWhy
cityStringIt's a name made of letters
monthStringMonth names are text (e.g. "April")
house numberIntegerWhole numbers
costReal/FloatMoney often has decimals (e.g. 4.99)
school stageIntegerYear group is a whole number
temperatureReal/FloatTemperatures have decimals (e.g. 21.5)
Tip: If it's a label, name, or category → String. If it's a count of whole things → Integer. If it can have a decimal point → Real/Float.

Q: What data type would the variable cost most likely be?

A: Real / Float (prices usually have decimals).

3 Python Commands

CommandWhat it does
print()Displays information on the screen
input()Asks the user for information (returns a string)
int()Casts a variable to an integer
float()Casts a variable to a real/float
str()Casts a variable to a string
Important: input() is for getting data in. print() is for showing data out. Don't mix them up!

Variables

  • Variable names cannot have spaces — use underscores instead (e.g. first_name).
  • Variables can be used to store data and reuse it later.
  • You can join strings and variables together in a print() using a comma.

Q: Which command displays information on the screen?

A: print().

4 Flowchart Symbols

SymbolNameWhat it shows
⬭TerminatorStart or end of the flowchart
▱Input/OutputInformation being entered or displayed
▭ProcessSomething needs to happen / a calculation
◇DecisionA yes/no question to determine what to do next
▯▯Sub-routineJump into a mini-program, then return
Remember: The sub-routine symbol has double vertical lines on the left and right edges. It means the flowchart is jumping into a mini-program and coming back.

Q: Which flowchart symbol is used to check a condition and decide what to do?

A: Decision (diamond).

6 BIDMAS — Order of Operations

Python follows the same order of operations as maths. BIDMAS tells you which part to work out first:

  • Brackets
  • Indices (powers)
  • Division
  • Multiplication
  • Addition
  • Subtraction

Worked example

3 + 4 * 5   →  multiplication first: 4 × 5 = 20, then 3 + 20 = 23
5 * (8 + 6) →  brackets first: 8 +
