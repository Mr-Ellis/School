📋 Array and List Challenge Levels

STEP 01
Create a List
Declare a one-dimensional list and print it.
STEP 02
Access Elements
Access and print specific elements using indices.
STEP 03
Modify Elements
Change elements in a list using assignment.
STEP 04
Add to a List
Use .append() and .insert() to add elements.
STEP 05
Remove from a List
Use .remove() and del to remove elements.
STEP 06
Traverse a List
Loop through a list and print each element.
STEP 07
List Length
Use len() to find the number of elements.
STEP 08
Search a List
Implement linear search to find an element.
STEP 09
2D Lists
Create a 2D list and access elements with two indices.
STEP 10
Build a Program
Build a short program that uses a dynamic list with add, remove, and traverse operations.
