Representing Sound
Lesson 5 · Sampling, Sample Rate, Bit Depth

Learning Objectives

  • Understand why sound must be converted from analogue to digital
  • Explain what sampling is and why it is necessary
  • Define sample rate and bit depth and explain how they affect quality and file size
  • Calculate the file size of a sound file using the correct formula
💡 Key Fact: Sound is naturally analogue (continuous). Computers can only store digital (discrete) data. To store sound, we must convert it by sampling — measuring the wave at regular intervals.

🔊 Analogue vs Digital

Sound travels as a continuous wave of pressure. A microphone converts that wave into a continuous electrical signal — this is analogue. But computers can only store 1s and 0s, so the wave must be converted into digital form.

The process is called analogue-to-digital conversion (ADC), and it happens by sampling.

Each red dot is a sample — a measurement of the wave's amplitude at that instant.

📏 Sampling — Two Key Decisions

When a sound is sampled, two decisions must be made. Each affects both the quality and the file size.

Term Definition Effect of increasing
Sample Rate The number of samples taken per second, measured in Hertz (Hz). Higher quality, captures higher frequencies, larger file size.
Bit Depth
(Sample Resolution)		 The number of bits used to represent each sample's amplitude. Greater dynamic range, more accurate volume levels, larger file size.
🔑 The Trade-off: Higher sample rate and higher bit depth both mean better quality but bigger files. Choosing the right settings is about balancing quality against storage and transmission cost.

🧮 Calculating Sound File Size

For the exam, you must be able to calculate the size of a sound file. Use this formula:

File Size (bits) = Sample Rate (Hz) × Bit Depth (bits) × Time (seconds)

To convert the result into Bytes, divide by 8.

📝 Worked Example: A 10-second recording at 44,100 Hz with a 16-bit depth.
44,100 × 16 × 10 = 7,056,000 bits
7,056,000 ÷ 8 = 882,000 bytes (≈ 882 KB)

🧮 Class Activity – Sound File Size Calculator

Work through these tasks in pairs, using a calculator:

  1. A 30-second clip at 22,050 Hz with 8-bit depth — what is the file size in bits?
  2. A 5-second clip at 44,100 Hz with 16-bit depth — what is the file size in bytes?
  3. Which is larger and why?
Reveal answers

1. 22,050 × 8 × 30 = 5,292,000 bits

2. 44,100 × 16 × 5 = 3,528,000 bits ÷ 8 = 441,000 bytes

3. Question 2 has a higher sample rate and bit depth, but is shorter (5s vs 30s). Question 1 is larger overall because of the longer duration.
