★ What moderators frequently criticise

These recurring comments appeared across the moderated exemplars. Read them before you write.

❌ "The testing strategy was effective."
A generic statement. Explain why the testing demonstrates correctness, reliability or efficiency.
❌ Functionality is claimed but not shown.
If a feature is not demonstrated in the video, moderators may not accept that it works.
❌ Only normal testing.
Strong submissions include normal, abnormal and extreme tests.
❌ Description instead of evaluation.
"I used a Trie because it stores words" is description. "A Trie was selected instead of a list because… however it increases memory usage…" is evaluation.
❌ Partial functionality demonstrated.
Every success criterion needs to be shown working — not just the ones that happen to work easily.

→ The rule high-scoring students follow

For every major technique, answer every question below. Missing evaluation and testing justification are two of the most common reasons projects lose marks.

  • What is the technique?
  • How is it used?
  • Why was it chosen?
  • What alternative was considered?
  • What limitation exists?
  • Why is it still appropriate? (this is evaluation)
  • How was it tested?
  • Why were those tests effective?
  • What does the testing not prove?

2 Structure for each technique

Use this exact structure for every technique. Point F is evaluation — that is what the top band rewards.

A
What is the technique?
“A Trie is a tree-based data structure where each node stores a character. Words with common prefixes share branches, allowing efficient prefix searching.”
B
How is it used in my solution?
“In my solution, the Trie stores all dictionary words and is used to generate autocomplete suggestions from user-entered prefixes.”
C
Why did I choose it?
“I chose a Trie because autocomplete requires many prefix searches. A Trie can find matching prefixes without searching every stored word.”
D
What alternative could I have used?
“An alternative would have been storing all words in a list and checking every word individually.”
E
What is a limitation?
“A Trie uses more memory because each character requires a separate node.”
F
Why is my choice still appropriate? (evaluation)
“Although memory usage is higher, the increased search speed makes the Trie more appropriate for autocomplete functionality.”
G
How did I test it?
“The Trie was tested using normal, abnormal and extreme input data.”
H
Why was the testing effective?
“The tests demonstrated that correct suggestions were generated for valid prefixes, invalid inputs were handled safely and large data sets could still be processed successfully.”
I
What does the testing NOT prove?
“The testing demonstrates that the Trie performs correctly with the current dataset but does not guarantee the same performance if millions of words were added.”
