Section A — Programming Concepts (B2.1)

18 marks

1. A program is being written to manage a student's grades. The following code snippet is used to get a user's input and display a message:

name = input("What is your name? ")
print("Welcome, " + name)

(a) **State** the data type of the variable name. [1]

(b) The program crashes when the user enters a number, for example, "123". **Explain** why this happens. [2]

(c) **Explain** the difference between local scope and global scope, using an example from the provided code. [3]

2. A program is written to process a student's email address, for example, "sophia.jones@school.com".

(a) **Describe** one string manipulation operation that could be used to extract the username "sophia.jones". [2]

(b) The following code is written to check if an email address is valid (contains an '@' symbol). Identify and fix the error in the code. [2]

email = "student@example.com"
if email.find("@") = -1:
    print("Invalid email")

(c) **Outline** why strings are described as "immutable" in Python. [2]

3. The following Python code is designed to calculate the total of a shopping list, but it contains an error.

prices = [10, 20, 5]
total = 0
for price in prices:
    total = total + price
print("Total: " + total)

(a) **Describe** the error that will occur when the code is run. [2]

(b) **Explain** how a try-except block can be used to handle this type of error gracefully. [3]

4. This question is about debugging.

(a) **Describe** the difference between a syntax error, a runtime error, and a logic error. [3]

(b) The following code is intended to print the numbers 1 to 5, but it contains a logic error. **Describe** the error and how to fix it. [2]

for i in range(1, 5):
    print(i)

Section B — Data Structures (B2.2)

18 marks

5. A shopping website stores products that are frequently added and removed by users.

(a) **Explain** why a dynamic data structure (like a Python list) would be more suitable than a static data structure (like a fixed-size array) for this scenario. [4]

(b) **Compare** static and dynamic data structures with reference to **memory allocation** and **performance**. [3]

6. The following code is used to store the scores of students:

scores = [85, 92, 78]
scores.append(95)

(a) **State** what the .append() method does in Python. [1]

(b) **Describe** how a `for` loop could be used to traverse the `scores` list and print each score. [2]

(c) **Explain** the difference between a 1D list and a 2D list, giving one example of where a 2D list would be useful. [3]

7. A stack and a queue are both abstract data structures.

(a) **Describe** the LIFO principle as applied to a stack. [2]

(b) **Describe** the FIFO principle as applied to a queue. [2]

(c) **Explain** why a stack would be appropriate for implementing an "undo" feature in a text editor. [3]
