Section A — Programming Concepts (B2.1)

18 marks

1. A program stores information about a student. The following code is used:

student_name = "Amira"
age = 16
height = 1.72
is_enrolled = True

(a) State the data type of each of the four variables. [4]

(b) Explain why height must be stored as a float rather than an integer. [2]

2. The following code is used:

def greet():
    name = "Alice"
    print("Hello", name)

greet()
print(name)

(a) Explain why the final line print(name) raises a NameError. [3]

(b) Describe one change that would allow the value of name to be printed outside the function. [2]

3. A program is written to process a student's email address, for example, "amira.khan@school.com".

(a) Describe how slicing could be used to extract the username "amira.khan". [2]

(b) The following code is intended to check whether an email address contains an @ symbol. Identify and fix the error. [2]

email = "student@example.com"
if email.find("@") = -1:
    print("Invalid email")

(c) Outline why strings are described as immutable in Python. [2]

4. The following code is intended to calculate the total of a shopping list, but it contains an error.

prices = [10, 20, 5]
total = 0
for price in prices:
    total = total + price
print("Total: " + total)

(a) Describe the error that will occur when the code is run. [2]

(b) Explain how a try-except block can be used to handle this type of error gracefully. [3]
