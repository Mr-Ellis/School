9Function defined with def count_letter(word, letter): (1). Initialises a counter to 0 (1). Loops through each character in word (1). Compares each character to letter and increments the counter when they match (1). Returns the counter (1).
def count_letter(word, letter):
    count = 0
    for char in word:
        if char == letter:
            count = count + 1
    return count
