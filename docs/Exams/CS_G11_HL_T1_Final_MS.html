Performance: static has faster access (O(1)) due to contiguous memory; dynamic is slower (O(n)) due to traversal and pointer overhead (1).

11 Function defined with def find_max(numbers): (1). Handles empty list by returning None (1). Initialises a variable to the first element (1). Loops and updates the variable when a larger value is found (1). Returns the variable (1).
def find_max(numbers):
    if len(numbers) == 0:
        return None
    max_value = numbers[0]
    for num in numbers:
        if num > max_value:
            max_value = num
    return max_value

def count_letter(word, letter):
    count = 0
    for char in word:
        if char == letter:
            count = count + 1
    return count
