Section A — Data Representation and Computer Logic (A1.2)

28 marks

1. A digital thermometer stores temperature readings as 8-bit two's complement integers.

(a) State the range of values that can be stored in an 8-bit two's complement integer. [1]

(b) The thermometer records a temperature of −18 °C. Construct the 8-bit two's complement representation of −18. Show your working. [3]

(c) The thermometer stores a humidity value as an 8-bit unsigned integer. The current value is 220. Calculate the stored value after 45 is subtracted, assuming the result is kept as an 8-bit unsigned integer. [2]

(d) Explain why BCD would be preferred to pure binary for storing a shop price, even though BCD uses more bits per digit. [2]

2. A wildlife photographer captures an uncompressed image and a short voice memo.

(a) The image is 640 × 480 pixels with a colour depth of 8 bits. Calculate the file size in KiB. Show every stage of your working. [3]

Working

(b) The voice memo is recorded in mono at 8000 Hz with a bit depth of 16 bits for 5 seconds. Calculate the file size in bytes. Show every stage of your working. [3]

Working

(c) Outline one difference between lossy and lossless compression. [2]

3. A server-room alarm system has three inputs: D (door open), M (motion detected), P (mains power active). The alarm A must sound when:

(D AND M) OR (NOT P)

(a) Construct a truth table for this system, with columns for D, M, P and A. [4]

DMPA

(b) Derive the Boolean expression for A from the specification above. [2]

(c) Construct a logic diagram using AND, OR and NOT gates to implement the expression in part (b). Label all inputs and the output. [3]

(d) Describe the purpose of a logic gate, using the AND gate as your example. Your answer should say what the gate does to its inputs and why that behaviour is useful in a computer. [3]

[Total Section A: 28 marks]

Section B — Network Fundamentals (A2.1)

43 marks

4. A school has a main building containing the server room, and a sports hall 350 metres away. Staff also need secure remote access from home.

(a) Define the term protocol. [2]

(b) Compare a LAN and a WAN in terms of geographic scope, ownership and transmission media. Use the school scenario to illustrate each point. [5]

(c) Explain how a VPN provides both security and anonymity for staff working from home. [2]

(d) The school uses a client–server model. Describe one advantage and one disadvantage of this model compared with a peer-to-peer network for the school. [2]

(e) The sports hall uses edge computing for IoT fitness trackers that monitor students' heart rates during PE. Justify this choice with reference to latency and bandwidth. [2]

5. The school network uses a hub, a switch, a router, a firewall and a wireless access point.

(a) Distinguish between a switch and a router in terms of the layer at which each operates and the addressing information each uses to forward data. [3]

(b) Explain why a hub is considered unsuitable for a modern school network. Refer to network efficiency and security. [3]

(c) The firewall blocks incoming traffic on port 80 but allows traffic on port 443. Explain what this policy suggests about the school's security stance, referring to HTTP and HTTPS. [2]

(d) A student's laptop joins the school Wi-Fi. Describe the role of DHCP in this process, including the four stages of the DORA cycle. [4]

(e) The school's live video-lesson system performs poorly. Suggest whether TCP or UDP is more appropriate for this application. Justify your answer with reference to latency and reliability. [2]

6. HL Only The network administrator is troubleshooting a connectivity failure between the sports hall and the main building.

(a) Describe the four layers of the TCP/IP model and the primary function of each. [4]

(b) Explain the process of encapsulation as data travels from an application on a student's laptop, through the network, to a server in the main building. Refer to each layer of the TCP/IP model. [4]

(c) Analyse how the layered structure of the TCP/IP model simplifies fault diagnosis for the administrator. [2]

7. A start-up is choosing between cloud computing and edge computing for a network of security cameras that must detect intruders in real time.

(a) Describe one benefit and one limitation of cloud computing for this start-up. [2]

(b) Explain why edge computing is more appropriate than cloud computing for real-time intruder detection, even though edge devices have less processing power. [2]

8. Describe the function of the Network Interface Card (NIC) in a device connected to a school network. [2]

[Total Section B: 43 marks]

Section C — Anchor Topics (A1.1, A1.3, A1.4)

18 marks

9. A computer has a Program Counter (PC), a Memory Address Register (MAR) and a Memory Data Register (MDR).

(a) State the purpose of the PC. [1]

(b) Describe the role of the MAR and MDR during the fetch stage. [3]

(c) Outline one difference between the address bus and the data bus. [2]

10. A laptop runs an operating system and several applications at once.

(a) Explain why the operating system must schedule processes rather than allowing each process to run until it finishes. [2]

(b) Outline one difference between polling and interrupts. [2]

(c) State one resource, other than the CPU, that the operating system must manage. [1]

(d) Explain one way the operating system can prevent deadlock from occurring. [2]

11. HL Only A student writes a program and runs it on the laptop.

(a) Outline one function of the ALU during program execution. [2]

(b) Explain why RAM is described as volatile, and why this matters when the laptop loses power. [2]

(c) Explain why compiled code generally executes faster than interpreted code. [1]
