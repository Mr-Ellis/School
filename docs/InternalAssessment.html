A

📋 Criterion A Problem Specification

4 marks · 300 words

Describe the problem, its requirements, and the computational context.

  • Describe the problem scenario & measurable requirements
  • State appropriate success criteria (measurable)
  • Explain the choice of computational context
Tools Guide
B

📐 Criterion B Planning

4 marks · 150 words

Decompose the problem and create a plan addressing the success criteria.

  • Construct a reasonable decomposition (diagrams)
  • Construct a plan (GANTT/AGILE) that addresses success criteria
  • Plan must be consistent with Criterion A
Tools draw.io
C

🧩 Criterion C System Overview

6 marks · 150 words

Create a complete system model and algorithms, with a testing strategy.

  • Complete system model (diagrams, UI, connections)
  • Algorithms for components (pseudocode/flowcharts)
  • Describe a testing strategy aligned with success criteria
Tools draw.io
D

💻 Criterion D Development

12 marks · 1,000 words

Build a fully functional product using appropriate techniques and justify your choices.

  • Fully functional product (video evidence required)
  • Use appropriate techniques (loops, data structures, libraries)
  • Evaluate and justify implementation choices & testing strategy
Tools Python Tutor GitHub
E

📄 Criterion E Evaluation

4 marks · 400 words

Evaluate your product against success criteria and justify future improvements.

  • Evaluate the extent to which success criteria were met
  • Justify improvements to the product
  • Must be consistent with Criterion A
