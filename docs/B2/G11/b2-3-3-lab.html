🧪 Coding Challenges

Work through these challenges in order. Each one focuses on a different aspect of looping. Write your code in the Python Code Lab above.

1 Fix the Broken Counted Loop

The following code is supposed to print the numbers 1 to 5, but it prints 1 to 4. Find the bug and fix it.

for i in range(1, 5):
    print(i)

What to do: Change the range so that 5 is included. Remember that range(start, stop) stops before stop.

✅ Success criteria: The output is exactly 1, 2, 3, 4, 5.

2 Fix the Infinite Loop

The following code is meant to print "Hello" five times, but it never stops. Find the bug and fix it.

i = 0
while i < 5:
    print("Hello")

What to do: Add the missing line inside the loop that updates i. Test it in the IDE — if it hangs, you haven't fixed it yet.

✅ Success criteria: "Hello" is printed exactly 5 times and the program finishes.

3 Countdown with a While Loop

Write a program that asks the user for a starting number and counts down to 1, then prints "Blast off!".

Hint: Use a while loop and subtract 1 from the counter each time. Make sure the loop stops when the counter reaches 0.

✅ Success criteria: Entering 5 prints 5, 4, 3, 2, 1, then "Blast off!". Entering 1 prints 1 then "Blast off!".

4 Input Validation with a While Loop

Write a program that keeps asking the user for a grade between 0 and 100 until they enter a valid number, then prints the grade.

Hint: Start with an invalid value (e.g. grade = -1) so the loop runs at least once. Use or in the condition to catch values that are too low or too high.

⚠️ Watch out: The condition grade < 0 or grade > 100 is correct here — it is true when the grade is outside the valid range. Think carefully about why this one works but the "always true" example from the theory lesson does not.

✅ Success criteria: Entering 150 keeps asking; entering -5 keeps asking; entering 75 stops and prints 75.

5 Nested Loops — Star Triangle

Write a program using nested loops that prints a right-angled triangle of stars with 5 rows, like this:

*
**
***
****
*****

Hint: The outer loop controls the rows. The inner loop controls how many stars are printed on each row — and its range depends on the outer loop variable. Use print("*", end="") to stay on the same line, then print() after the inner loop to start a new row.

📖 Need help? Read the Nested Loops reference before you start. It shows the same pattern built step by step.

✅ Success criteria: Row 1 has 1 star, row 2 has 2 stars, … row 5 has 5 stars, and each row starts on a new line.

6 Nested Loops — Multiplication Table

Write a program using nested loops that prints a 5 × 5 multiplication table. Each row should show the products for one number, from 1 × 1 up to 5 × 5.

Hint: Use two loops both running from 1 to 5. The inner loop prints i * j for each pair. Use end=" " to keep the row on one line, and print() after the inner loop to move to the next row.

✅ Success criteria: The output has 5 rows and 5 columns, and every product from 1 × 1 to 5 × 5 appears exactly once.

7 Trace the Nested Loop

Without running the code, work out how many times "Hello" is printed. Fill in the trace table, then check your answer by running it in the IDE with the Step button.

for i in range(3):
    for j in range(2):
        print("Hello")

Trace table:

Outer i Inner j Prints "Hello"?
00Yes
01Yes
10Yes
11Yes
20Yes
21Yes

✅ Success criteria: "Hello" is printed 6 times — because the inner loop runs 2 times for each of the 3 outer iterations (3 × 2 = 6).
