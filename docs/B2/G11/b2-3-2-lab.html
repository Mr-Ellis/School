1 Fix the Broken Selection

The following code is supposed to print "Pass" if the score is 50 or above and "Fail" otherwise, but the branches are in the wrong order and one condition is always true. Copy it into the IDE, fix it, and test it with scores of 30, 50, and 90.

score = int(input("Enter score: "))
if score > 50:
    print("Fail")
else:
    print("Pass")
What to do: Fix the comparison so that 50 counts as a pass, and swap the branches so the output is correct. Then test all three scores.
✅ Success criteria: 30 → "Fail", 50 → "Pass", 90 → "Pass".

2 Fix the Wrong Branch Order

The following code is meant to award grades A–F, but "A" can never be printed. Find the bug and fix it.

grade = int(input("Enter grade: "))
if grade >= 60:
    print("D")
elif grade >= 70:
    print("C")
elif grade >= 80:
    print("B")
elif grade >= 90:
    print("A")
else:
    print("F")
What to do: Reorder the elif branches so that the highest threshold is checked first. Test with 95, 85, 75, and 65.
✅ Success criteria: 95 → "A", 85 → "B", 75 → "C", 65 → "D".

3 Range Check with and

Write a Python program that asks the user for a number and prints "In range" if it is between 10 and 20 (inclusive), otherwise prints "Out of range".

⚠️ Watch out: Use and, not or. A condition like x >= 10 or x <= 20 is always true! Ask yourself: does the number need to satisfy both limits at once?
✅ Success criteria: 5 → "Out of range", 10 → "In range", 15 → "In range", 20 → "In range", 25 → "Out of range".

1. If Statements 2. Multiple Conditions 3. Pattern Matching

1 If Statements

The if statement is the basic building block of all conditional logic. It executes a block of code only when its condition evaluates to True. If the condition is False, the block is skipped entirely and the program continues after it.

  • Simple if — run code only when a single condition is true. No else is needed.
  • if / else — choose between two alternative paths. Exactly one branch always runs.
  • Truthiness — conditions do not have to be comparisons. A non-empty string or a non-zero number is True; 0, "", and None are False.
age = 18
has_license = True

# Simple if — only runs when the condition is True
if age >= 18:
    print("You are old enough to vote!")

# if / else — exactly one branch runs
if age >= 18 and has_license:
    print("You can drive!")
else:
    print("You need a license to drive.")
💡 Try it: Copy the code above into the Python Code Lab. Run it once with age = 18 and once with age = 15. Notice that the first if simply does nothing when the condition is false — there is no output at all.

2 Multiple Conditions

elif (short for "else if") lets you check several conditions in sequence and handle multiple mutually exclusive options. Python checks each condition in order, top to bottom, and runs the first block whose condition is True. Once a branch runs, the rest of the chain is skipped.

  • Order matters — always check the most specific or highest threshold first. If you check >= 60 before >= 90, an A can never be awarded.
  • Only one branch runs — even if several conditions are true, only the first matching block executes.
  • The else is optional — but if you include it, it catches every case not already handled.
  • Logical operators — combine comparisons with and, or, and not to build richer conditions.
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"

print(f"Your grade is: {grade}")
💡 Try it: Copy the code into the Python Code Lab and change score to 95, 85, 75, and 65. Predict the grade before you run it. Then try moving the >= 70 check to the top and see what breaks — this is exactly the bug in Challenge 2.

3 Pattern Matching

Pattern matching (introduced in Python 3.10) is a modern, switch-like statement for making decisions based on the shape or structure of data, not just simple equality. It uses the match and case keywords and is especially powerful when you need to branch on many possible values or on the structure of a list, tuple, or dictionary.

  • match / case — compare a value against several patterns, top to bottom.
  • Wildcard case _: — the default branch, like else. It matches anything and must come last.
  • Structural patterns — match against sequences (e.g. [x, y]) or capture parts of the data.
  • Cleaner than long elif chains — when checking a single value against many fixed options, match reads more clearly.
command = "start"

match command:
    case "start":
        print("Starting the system...")
    case "stop":
        print("Stopping the system...")
    case "pause":
        print("Pausing the system...")
    case _:
        print("Unknown command")
💡 Try it: Copy the code into the Python Code Lab. Change command to "stop", then "pause", then "reboot". Notice how the wildcard case _: catches anything that doesn't match the earlier patterns. This is the modern alternative to a long if / elif / else chain.
