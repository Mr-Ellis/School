2. Analyse the following code. Describe the outcome of each of the three calls to safe_divide, and explain the role of the finally block.
def safe_divide(a, b):
    try:
        result = a / b
        return result
    except ZeroDivisionError:
        print("Cannot divide by zero")
        return None
    except TypeError:
        print("Invalid input type")
        return None
    finally:
        print("Calculation complete")

x = safe_divide(10, 2)
y = safe_divide(10, 0)
z = safe_divide("10", 2)
