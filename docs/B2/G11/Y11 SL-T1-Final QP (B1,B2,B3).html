Section A — Programming Fundamentals (22 marks)

1. Define the terms variable and constant, and explain one advantage of using a constant instead of a variable.[3]
2. Explain the difference between a syntax error, a runtime error and a logic error. Give one example of each.[5]
3. Describe string concatenation and string slicing, giving one example of each.[3]
4. Analyse the following code and identify two distinct errors. Explain how each should be fixed.
total = 0
marks = [72, 85, 90]
for i in range(4):
    total = total + marks[i]
average = total / len(marks)
print("Average: " + average)
5. Explain how using the wrong data type can cause a bug in a program. Use a specific example in your answer.[3]
6. State the output of the following code and justify your answer by tracing the execution.
n = 5
total = 0
while n > 0:
    total = total + n
    n = n - 1
print(total)

Section B — Data Structures (24 marks)

7. Compare static and dynamic data structures by giving four differences.[4]
8. Explain what happens during push and pop operations on a stack. Include what occurs when the stack is full and when it is empty.[4]
9. Explain what happens during enqueue and dequeue operations on a queue. Include what occurs when the queue is full and when it is empty.[4]
10. Discuss the advantages and disadvantages of using a circular queue instead of a linear array-based queue.[5]

Section C — Programming Constructs (24 marks)

13. Write a Python if–elif–else statement that takes a variable height and prints: “Too short” if height < 120, “Supervised only” if 120 <= height <= 140, and “Unrestricted” if height > 140.[4]
14. Explain the difference between a for loop and a while loop. Justify which is more appropriate for a program that repeatedly asks for a password until the correct one is entered.[4]
15. Describe what modularisation means in programming and justify why it is important in a large program.[5]
16. Explain the difference between local and global scope. Describe what happens when a function assigns to a variable without using the global keyword.[4]
17. Write a Python function called convert_temp that takes a Celsius temperature as a parameter and returns the Fahrenheit equivalent (F = C × 9/5 + 32).[4]
18. Describe two benefits of using functions in a program.[3]
