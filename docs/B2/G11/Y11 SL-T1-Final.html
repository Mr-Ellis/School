Section A — B.2.1 Programming Fundamentals (25 marks)

1. A library app stores each book’s title, the number of copies in stock, and whether the book is currently on loan. State the most appropriate data type for each of the three values and justify each choice.[3]
2. A programmer writes the following code inside a function called check_out:
copies_left = copies_left - 1
The variable copies_left is declared outside all functions. Explain why this line may cause a problem and how it can be corrected.[3]
3. A student ID is stored as the string "2027-JS-014". Describe the steps needed to extract the year ("2027") and the initials ("JS") from this ID. You may refer to character positions, which start at 0.[4]
4. A program asks the user to enter the number of tickets they want to buy. The input is stored as a string and then converted to an integer. Explain why exception handling is suitable for this conversion.[3]
5. The following code is intended to calculate the average of three test scores:
total = score1 + score2 + score3
average = total / 2
print(average)
(a) Identify the type of error in this code.[1]
(b) Describe how a trace table could help a programmer locate this error.[2]
6. A program contains the following lines:
x = 10
y = "5"
result = x + y
(a) State the type of exception that will be raised.[1]
(b) Describe how a try–except block could be used to handle this exception gracefully.[3]
7. A programmer wants to test whether a variable age contains a whole number between 1 and 120. Describe one debugging technique that would help confirm the program behaves correctly for boundary values such as 1 and 120.[3]

Section B — B.2.2 Data Structures (25 marks)

8. A school timetable stores a fixed set of 30 lesson slots. The number of slots never changes during the year. Explain why a static data structure is more appropriate than a dynamic one for this timetable.[3]
9. A warehouse stores item quantities in a 2D list. The list has 3 rows (aisles) and 4 columns (shelves).
(a) State how many individual integer values the list can hold.[1]
(b) Describe how a nested loop could be used to calculate the total quantity of all items in the warehouse.[3]
10. A music player uses a stack to implement the “undo” feature for playlist edits. The user adds three songs: "Song A", then "Song B", then "Song C".
(a) Describe the state of the stack after all three songs have been added.[2]
(b) The user then presses “undo” once. State which song is removed and explain why the stack is the correct structure for this feature.[3]
11. A delivery company uses a queue to manage parcels waiting to be loaded onto vans. Parcels arrive in this order: P1, P2, P3, P4.
(a) Describe the state of the queue after P1 and P2 have been dequeued (loaded).[2]
(b) Explain why a queue rather than a stack is the appropriate structure for loading parcels onto vans.[3]
12. A programmer is choosing between a static array and a linked list for storing a list of student names that will grow and shrink throughout the year as students join and leave. Describe one advantage and one disadvantage of each choice in this scenario.[4]

Section C — B.2.3 Programming Constructs (20 marks)

13. The following steps are intended to calculate a student’s grade from a test score, but they are in the wrong order:
1. Print "Grade: " + grade
2. If score >= 70 then set grade = "A"
3. Read score
4. Otherwise set grade = "B"
Rearrange the steps into a correct sequence and explain why the original order would produce incorrect output.[3]
14. A vending machine accepts coins and dispenses an item only if the total inserted is at least the item price and the item is in stock.
(a) Construct a nested if statement (in pseudocode or a language of your choice) that implements this logic.[4]
(b) Explain why a single if statement using and would also work, and state one reason a programmer might still prefer the nested version.[3]
15. A program must ask the user to enter a positive whole number. It should keep asking until a valid number is entered.
(a) State whether a for loop or a while loop is more suitable, and justify your answer.[2]
(b) Write pseudocode (or code) for the loop. Include a condition that rejects zero and negative numbers.[4]
16. The function below is intended to return the smaller of two numbers, but it contains a logic error.
function smaller(a, b)
  if a > b then
    return a
  else
    return b
  end if
end function
(a) Identify the logic error.[1]
(b) Describe how you would use a trace table to confirm the error before fixing it.[3]
