📖 Lesson Content

The Big Idea

Think of a stack of plates in a cafeteria. You add a new plate to the top, and you take a plate from the top. You would never pull a plate from the middle of the stack—that would be messy and inefficient. This "Last In, First Out" (LIFO) principle is the core of a fundamental data structure in Computer Science: the Stack.

A stack is an abstract data structure that works on the LIFO (Last In, First Out) or FILO (First In, Last Out) principle. This means the last element added to the stack is the first one to be removed. Only the top element is accessible at any time.

Key Concepts

1. LIFO Principle

Imagine a stack of coins. If you want to add a coin, you put it on top. If you want to take a coin, you take it from the top. The coin that was placed last is the first one to be taken out. This is the essence of LIFO.

2. Core Operations

Stacks are defined by a small set of essential operations:

  • Push: Adding an item to the top of the stack.
  • Pop: Removing the item from the top of the stack.
  • Peek (or Top): Looking at the top item without removing it.
  • isEmpty: Checking if the stack is empty.
  • isFull: Checking if the stack is full (for a static, array-based stack).

📌 Important: A stack pointer (often called topIndex or top) is a variable used to keep track of the index of the topmost element in the stack. It is crucial for all operations.

Stack Operations in Detail

1. Push (Adding an Item)

To push an item, the stack pointer is incremented (moved to the next free slot), and the new value is placed at that position. If the stack is already full, attempting to push causes an overflow error.


# Python - Push operation (simplified)
def push(stack, value):
    if len(stack) == MAX_SIZE:
        print("Stack Overflow!")
    else:
        stack.append(value)
        print(f"Pushed: {value}")

2. Pop (Removing an Item)

To pop an item, the value at the top of the stack is returned, and the stack pointer is decremented. If the stack is empty, attempting to pop causes an underflow error.


# Python - Pop operation (simplified)
def pop(stack):
    if len(stack) == 0:
        print("Stack Underflow!")
        return None
    else:
        return stack.pop()

3. Peek (Looking at the Top)

This operation returns the value of the top element without changing the stack. It's useful for checking what's next without committing to a pop.


# Python - Peek operation (simplified)
def peek(stack):
    if len(stack) > 0:
        return stack[-1]
    else:
        return None

4. isEmpty and isFull

These are boolean checks to prevent errors. isEmpty checks if the stack pointer is at -1 (or 0, depending on implementation). isFull checks if the stack pointer has reached the maximum size of the array.

🔑 Key Principle: A stack can be implemented as a static data structure (using an array with a fixed size) or as a dynamic data structure (using a linked list, which can grow and shrink as needed).

Uses of Stacks

Stacks are incredibly useful in computer science for managing data in a specific order. Here are some key applications:

  • Interrupt Handling: When the CPU is interrupted, the current state (variables, return address) is pushed onto a stack. After the interrupt is handled, the state is popped to resume the previous task.
  • Recursion: When a function calls itself, the return addresses and parameters are stored on a stack to help "unwind" the recursive calls correctly.
  • Undo Feature: In games or text editors, each action is pushed onto a stack. The "Undo" command pops the last action, reverting the state.
  • Browser Back Button: Opening a new page pushes the URL onto a stack. Pressing "Back" pops the current URL to go to the previous one.
  • Evaluating Arithmetic Expressions: Stacks are used to convert and evaluate expressions, especially in Reverse Polish Notation (RPN).

Key Terms

TermDefinition
StackAn abstract data structure that works on the LIFO principle.
LIFOLast In, First Out. The last element inserted is the first one removed.
PushA method for inserting an element at the top of a stack.
PopA method for deleting the element from the top of a stack.
PeekLooking at the top element without removing it.
Stack PointerA variable (e.g., topIndex) that tracks the position of the top element.
OverflowAn error that occurs when trying to push onto a full stack.
UnderflowAn error that occurs when trying to pop from an empty stack.

⚠️ Common Errors:

  • Stack Overflow: Forgetting to check if a static stack is full before pushing.
  • Stack Underflow: Forgetting to check if a stack is empty before popping.
  • Losing Data: Not storing the popped value if it's needed later.
