1 Create Your First Function

Write a function called greet_user that takes one parameter, name, and returns a greeting string like "Hello, Alice! Welcome to Python!".

What to do: Use def to define the function, add a docstring, and use return to send the greeting back. Then call the function three times with different names and print the results.

✅ Success criteria: The output shows a personalised greeting for each name you pass in.

def greet_user(name):
    """Returns a personalised greeting."""
    return f"Hello, {name}! Welcome to Python!"

print(greet_user("Alice"))
print(greet_user("Bob"))
print(greet_user("Charlie"))

2 Fix the Missing Return

The following function calculates the area of a rectangle but does not return the result, so room_area is None. Fix it.

def calculate_area(length, width):
    area = length * width

room_area = calculate_area(12, 10)
print(room_area)

What to do: Add the missing return statement inside the function. Test it with the arguments 12 and 10 — the output should be 120.

✅ Success criteria: calculate_area(12, 10) returns 120, and printing room_area shows 120, not None.

def calculate_area(length, width):
    area = length * width
    return area

room_area = calculate_area(12, 10)
print(room_area)

3 Temperature Converter

Write a function called convert_temperature that takes a Celsius value as a parameter and returns the Fahrenheit equivalent. Use the formula: fahrenheit = (celsius * 9/5) + 32.

Hint: Call the function with 25 and print the result. The output should be 77.0.

✅ Success criteria: convert_temperature(25) returns 77.0. Test with 0 to get 32.0.

def convert_temperature(celsius):
    fahrenheit = (celsius * 9/5) + 32
    return fahrenheit

print(convert_temperature(25))
print(convert_temperature(0))

4 Grade Calculator with Return

Write a function called get_grade that takes a numeric score and returns a letter grade based on this scale: 90+ = "A", 80–89 = "B", 70–79 = "C", otherwise "F".

Hint: Use if, elif, and else inside the function, with a return in each branch. Test it with 85 (should return "B") and 92 (should return "A").

✅ Success criteria: get_grade(85) returns "B", get_grade(92) returns "A", and get_grade(65) returns "F".

def get_grade(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 70:
        return "C"
    else:
        return "F"

print(get_grade(85))
print(get_grade(92))
print(get_grade(65))

5 Local vs Global Scope

Run the following code and explain why it raises a NameError. Then fix it so it prints both lines without error.

def greet():
    name = "Alice"
    print("Hello", name)

greet()
print(name)

What to do: The variable name is local to greet() and cannot be accessed outside. To fix it, either move the print inside the function, or return the name and print it outside.

✅ Success criteria: The program runs without error and prints "Hello Alice" followed by "Alice".

Solution (Returning the value):

def greet():
    name = "Alice"
    print("Hello", name)
    return name

name = greet()
print(name)

6 Modular Payroll System

Break the following task into three separate functions and then call them in order:

  • calculate_gross(hours, rate) — returns hours * rate.
  • calculate_deductions(gross) — returns 20% of gross.
  • print_payslip(name, gross, deductions) — prints the employee's name, gross pay, deductions, and net pay.

Hint: Each function should do one job. In print_payslip, calculate net pay as gross - deductions.

✅ Success criteria: Calling the functions with hours=40, rate=15, name="Sam" produces a correctly formatted payslip showing gross 600, deductions 120, and net 480.

def calculate_gross(hours, rate):
    return hours * rate

def calculate_deductions(gross):
    return gross * 0.20

def print_payslip(name, gross, deductions):
    net_pay = gross - deductions
    print(f"Employee: {name}")
    print(f"Gross Pay: ${gross:.2f}")
    print(f"Deductions: ${deductions:.2f}")
    print(f"Net Pay: ${net_pay:.2f}")

gross = calculate_gross(40, 15)
deductions = calculate_deductions(gross)
print_payslip("Sam", gross, deductions)

7 Even Number Checker

Write a function called is_even that takes a number and returns True if it is even, and False otherwise.

Hint: Use the modulo operator %. A number is even if number % 2 == 0.

✅ Success criteria: is_even(42) returns True, is_even(7) returns False, and is_even(0) returns True.

def is_even(number):
    return number % 2 == 0

print(is_even(42))
print(is_even(7))
print(is_even(0))

💡 Key Takeaway

"Functions are the building blocks of organised, reusable code. Define them once, call them many times, pass in different arguments, and return results. Keep variables local to avoid unintended side effects, and break larger programs into small, focused functions. Modular design makes code easier to read, test, and maintain."
