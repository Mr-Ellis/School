The Big Idea

In programming, a substring is a contiguous sequence of characters within a string. Mastery of substring manipulation is fundamental to many tasks in software development—from parsing user input to handling file paths, processing text data, and implementing algorithms.

To construct programs that extract and manipulate substrings means to:

  • Identify relevant sections of a string based on indices or patterns,
  • Modify those substrings (e.g. replace, capitalize, reverse),
  • Combine substrings to form new strings.

Key Concepts

1. Substring Extraction (Slicing)

The ability to select a portion of a string using character positions (indices).


# Python - String indices
name = "MacKenty"
sub = name[0:3]    # 'Mac'
sub2 = name[3:]     # 'Kenty'
sub3 = name[-3:]    # 'nty' (negative indices count from end)

print(sub)          # Output: Mac
▶ Output: Mac

📌 Remember: Python strings are 0-indexed (first character is at index 0). Slicing [start:end] includes start but excludes end.

2. Concatenation

Combining strings together, possibly using extracted substrings.


greeting = "Hello"
name = "Bill"
full = greeting + ", " + name + "!"
print(full)           # Output: Hello, Bill!
▶ Output: Hello, Bill!

3. Replacement & Alteration

Changing parts of a string: transforming case, trimming, or replacing substrings.


message = "Hello, World!"
print(message.lower())             # "hello, world!"
print(message.replace("World", "IB"))  # "Hello, IB!"
▶ Output: hello, world!
▶ Output: Hello, IB!

🔑 Key Principle: Strings are immutable in Python. Methods like .replace() and .lower() return a new string; they do not modify the original.

Practical Worked Examples

📧 Example 1: Masking an Email Address


email = "student@example.com"
at_index = email.index("@")
masked = email[0] + "***" + email[at_index:]
print(masked)   # s***@example.com
▶ Output: s***@example.com

📎 Example 2: Extracting a File Extension


filename = "report.pdf"
dot_index = filename.rfind(".")  # Find last '.'
extension = filename[dot_index+1:]
print(extension)   # pdf
▶ Output: pdf

🔄 Example 3: Reversing Words in a Sentence


sentence = "IB Computer Science"
words = sentence.split(" ")          # ['IB', 'Computer', 'Science']
reversed_sentence = " ".join(words[::-1])
print(reversed_sentence)   # "Science Computer IB"
▶ Output: Science Computer IB

📝 Example 4: Extracting Username from Email


email = "user123@gmail.com"
at_index = email.find('@')
username = email[:at_index]        # "user123"
domain = email[at_index+1:]        # "gmail.com"
print(username, domain)
▶ Output: user123 gmail.com

Key Terms

TermDefinition
SubstringA contiguous sequence of characters within a larger string.
ConcatenationThe operation of joining two or more strings together (using + in Python).
SlicingExtracting a portion of a string using indices [start:end].
ImmutableA property of strings in Python; they cannot be changed in place. Operations return new strings.
IndexThe position of a character in a string (starting from 0).
ReplaceA method that substitutes all occurrences of a substring with another.
SplitA method that divides a string into a list of substrings based on a delimiter.

⚠️ Common Errors:

  • Off-by-one errors: Slicing [start:end] excludes the end index.
  • Immutable strings: Methods like .replace() return a new string; assign the result to a variable.
  • Out-of-bounds access: Always check that your indices are within the string length.
