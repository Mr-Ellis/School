🔍 Explore PRIMMDebug

📖 Lesson Content

The PRIMMDebug Approach

PRIMMDebug is a reflective approach to teaching debugging that follows five stages:

  • Predict: Look at the code and predict what it will do.
  • Run: Execute the code and observe the actual output.
  • Investigate: Use debugging techniques to find the cause of any errors.
  • Modify: Make changes to fix the errors.
  • Make: Build something new using what you've learned.

This framework encourages a systematic, reflective approach to debugging that builds confidence and deeper understanding.

Key Debugging Strategies

Remember these core techniques from the theory lesson:

TechniqueWhen to Use
Trace TablesTrack variables through loops and conditionals
Print StatementsQuickly inspect values and flow
Breakpoint DebuggingInteractive inspection in an IDE
Step-by-Step ExecutionFollow logic precisely, especially in nested functions

📌 The PRIMM Process in Action:

For each bug you encounter:

  1. Predict what the code should do.
  2. Run it to see what it actually does.
  3. Investigate using print statements, trace tables, or the debugger.
  4. Modify the code to fix the issue.
  5. Make notes on what you learned.

🔍 Task 2: Investigate

🕵️ Investigate the Bugs
Use debugging techniques to find and fix the errors in the code below. Document your investigation process.

Buggy Program 1:


# This program should calculate the average of three numbers
num1 = input("Enter first number: ")
num2 = input("Enter second number: ")
num3 = input("Enter third number: ")

average = (num1 + num2 + num3) / 3
print("The average is", average)

Buggy Program 2:


# This program should count down from 5 to 1
count = 5
while count > 1:
    print(count)

Buggy Program 3:


# This program should ask the user for their age and double it
age = input("Enter your age: ")
double_age = age * 2
print("Your age doubled is", double_age)

Investigation Steps:

  1. For each program, predict what it should do.
  2. Run the code to see what it actually does.
  3. Use print statements to inspect variable values.
  4. Create a trace table for the loop in Program 2.
  5. Modify the code to fix all errors.
  6. Make notes on each bug you found and how you fixed it.

🛠️ Task 3: Modify & Make

🔧 Modify and Extend
Now that you've fixed the bugs, extend the programs with new functionality.

Extension 1:

  • Modify the average calculator to handle four numbers.
  • Add error handling for non-numeric inputs.

Extension 2:

  • Modify the countdown to ask the user for the starting number.
  • Add a message like "Liftoff!" when the countdown reaches 0.

Extension 3:

  • Create a new program that asks the user for five names and stores them in a list.
  • Print each name with a greeting.
  • Debug any issues that arise.

⭐ Challenge: Debugging a Real-World Scenario

🚀 The Grade Calculator

Your school needs a program to calculate the final grade for a student. The program should:

  1. Ask for five test scores (out of 100).
  2. Calculate the average score.
  3. Assign a letter grade: A (90+), B (80-89), C (70-79), D (60-69), F (below 60).
  4. Display the average and the letter grade.

Your task:

  • Write the code for this program.
  • Then, intentionally introduce three different bugs (e.g., off-by-one error, type error, logic error).
  • Swap your buggy code with a partner.
  • Use the PRIMMDebug approach to find and fix your partner's bugs.
  • Document your debugging process using trace tables, print statements, and notes.
