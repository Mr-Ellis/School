1. Sequence

The Big Idea

A program is ultimately a sequence of instructions that the computer executes one by one. The order of these instructions is critical: changing it can alter the logic, behaviour, or outcome of a program entirely. Understanding how to organise instructions correctly and intentionally is essential to writing software that works as expected.

💡 Think of a recipe. If you add the flour after baking the cake, the result is ruined. The order of steps matters just as much as the steps themselves.

Why instruction order matters

The sequence of code instructions determines program behaviour. A program may be syntactically valid but functionally incorrect if instructions are placed in the wrong order.

Example 1: Incorrect order produces incorrect output

# Version 1 — correct order
print("Welcome")
name = input("What is your name? ")

# Version 2 — wrong order
name = input("What is your name? ")
print("Welcome")

In Version 1, the user is greeted before being asked for their name. In Version 2, they are asked for their name before being greeted — which feels abrupt and confusing. Both are syntactically valid, but only one meets the program objective of a friendly welcome.

Example 2: Using a variable before it exists

# Python — runtime error
print(x)          # NameError: name 'x' is not defined
x = 10

# Correct order
x = 10
print(x)

In Python, you cannot use a variable before assigning it a value. This raises a NameError at runtime. (In Java, the equivalent mistake is a compile-time error, because the compiler checks that variables are initialised before use.)

Example 3: Control flow and indentation

total = 0
for i in range(5):
    total += i
print("Done")
print(total)

If print("Done") were placed inside the loop (indented), it would execute 5 times, not once. Indentation in Python determines whether a line is inside or outside a loop.

⚠️ Common sequencing errors:
  • Premature execution: using a variable before it has been assigned.
  • Late execution: printing a result before the calculation is complete.
  • Skipped or repeated execution: placing a statement inside or outside a loop incorrectly.
  • Infinite loops: forgetting to update a loop variable so the condition never becomes false.
📝 Exam tip: Use trace tables to track the value of each variable after every line. This is the most reliable way to catch sequencing errors before you run the code.

Key terms

TermDefinition
SequenceThe order in which instructions are executed, one after another.
Trace tableA table that records the value of each variable after each line of code, used to verify execution order.
Stepwise refinementBreaking a problem into smaller, ordered steps before coding.
InitialisationAssigning an initial value to a variable before it is used.

2. Selection

The Big Idea

Selection structures allow a program to make decisions — to choose different paths of execution based on conditions. At runtime, these decisions determine which blocks of code will be executed and which will be skipped. This is a critical component of control flow, allowing programs to behave differently under different inputs, states, or environments.

💡 Think of a fork in a road. A selection structure is the signpost: if you want the scenic route, turn left; else, turn right. The program checks the condition and takes exactly one path.

Types of selection structures

A. Single selection (if)

Executes a block only if a condition is true.

if score > 90:
    print("Excellent")

B. Double selection (if-else)

Executes one block if the condition is true, another if false.

if score >= 60:
    print("Pass")
else:
    print("Fail")

C. Multiple selection (if-elif-else)

Allows multiple mutually exclusive conditions to be evaluated in sequence.

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("Fail")
🔑 Key Principle: Python evaluates elif branches top to bottom and stops at the first true condition. Always order conditions from most specific / highest threshold to lowest. If you put score >= 70 before score >= 90, a score of 95 would match >= 70 first and print "C".

Boolean and relational operators

Selection structures evaluate Boolean expressions, composed using comparison operators and logical operators.

Operator TypePythonUse
Relational<, <=, >, >=, ==, !=Compare values
Logicaland, or, notCombine or invert conditions

Worked example: Range check

if x >= 10 and x <= 20:
    print("In range")
else:
    print("Out of range")
⚠️ Common logic error: Using or when you need and. The condition x >= 10 or x <= 20 is always true for any number, because every number is either ≥ 10, ≤ 20, or both. Use and to check that a value lies between two limits.

Nested selection

Placing one selection structure inside another allows more complex decisions. Use nested selection only when the logic genuinely requires it; otherwise, simplify with elif or combined conditions.

if age >= 18:
    if has_permission:
        print("Access granted")
    else:
        print("Permission required")
else:
    print("Too young")

Common selection errors

  • Assignment vs comparison: using = instead of == in a condition.
  • Wrong branch order: checking a lower threshold before a higher one, making the higher branch unreachable.
  • Always-true conditions: using or when and is needed for a range check.
  • Missing else branch: leaving a path through the logic with no instruction.
  • Redundant conditions: adding unnecessary checks that make the code harder to read.
📝 Exam tip: When writing selection code, trace through it with sample values — one below the threshold, one exactly on the threshold, and one above. This catches off-by-one errors and wrong branch order.

Key terms

TermDefinition
SelectionA control structure that chooses which block of code to execute based on a condition.
ConditionA Boolean expression that evaluates to True or False.
BranchOne possible path through a selection structure.
Boolean expressionAn expression that produces a True/False result, often using relational and logical operators.
Nested selectionA selection structure placed inside another selection structure.

3. Looping

The Big Idea

Looping structures allow us to execute a block of code multiple times, often with changing conditions or counters. Instead of writing the same instructions repeatedly, loops enable efficient, concise, and flexible repetition of actions — a core concept in all computational processes.

💡 Think of a loop as a treadmill: a counted loop is like setting the treadmill to run for exactly 5 kilometres; a conditional loop is like running until your heart rate reaches a target — you don't know in advance how long that will take.

Types of loops

A. Counted loops (definite iteration) — for

Executes a fixed number of times, often using a loop control variable.

for i in range(5):
    print("Iteration:", i)

Used when the number of iterations is known ahead of time. The loop variable i controls how many times the loop runs.

B. Conditional loops (indefinite iteration) — while

Repeats until a condition becomes false. Used when the number of repetitions is not known in advance.

password = ""
while password != "open123":
    password = input("Enter password: ")
🔑 Key Principle: Use a for loop when you know how many times to repeat (e.g. iterating over 10 items, or range(n)). Use a while loop when the number of repetitions depends on a condition that may change unpredictably (e.g. keep asking for input until it is valid).

Loop control keywords

KeywordEffect
breakExits the loop immediately.
continueSkips the rest of the current iteration and moves to the next one.

These are most useful inside if statements within the loop.

Sentinel-controlled loops

A sentinel value is a special input that signals the loop should stop. It is commonly used when the number of iterations is not known in advance.

total = 0
num = int(input("Enter number (-1 to quit): "))
while num != -1:
    total += num
    num = int(input("Enter number (-1 to quit): "))
print("Total:", total)

Nested loops

A loop placed inside another loop. The inner loop runs completely for each iteration of the outer loop. Nested loops are useful for processing grids, generating patterns, and working with 2D structures.

for i in range(3):
    for j in range(2):
        print("Hello")

This prints "Hello" 6 times (3 outer iterations × 2 inner iterations).

Common loop errors

ErrorWhat it looks likeFix
Infinite loopwhile i < 5: with no update to iUpdate the loop variable inside the body (e.g. i += 1).
Off-by-one errorfor i in range(1, 5): when you meant 1–5Remember range(start, stop) excludes stop. Use range(1, 6).
Missing initialisationUsing a counter before assigning it a starting valueInitialise counters to 0 and accumulators before the loop.
Faulty condition logicwhile x > 0 or x < 10: (always true)Use and for range checks: while x > 0 and x < 10:.
⚠️ Infinite loop first aid: If your program hangs, press Ctrl + C in the terminal (or the stop button in your IDE). Then look for the loop whose condition never becomes false — the culprit is almost always a missing or misplaced update to the control variable.

Key terms

TermDefinition
IterationOne single pass through the body of a loop.
Counted loopA loop that repeats a fixed, known number of times (e.g. for).
Conditional loopA loop that repeats while a condition remains true (e.g. while).
Sentinel valueA special input value that signals the loop should stop.
Infinite loopA loop whose condition never becomes false, so it never terminates.
Off-by-one errorA loop that runs one time too many or too few because a boundary value is wrong.

4. Functions & Modularization

The Big Idea

Modularization is the principle of breaking down a program into independent, reusable components, each responsible for a specific task. These components are typically implemented as functions, which accept inputs (parameters), perform a task, and optionally return a result. Functions enable code that is easier to read, easier to maintain, and less error-prone. Modularization also supports testing, debugging, and collaborative development by isolating functionality into clear, well-defined blocks.

💡 Think of a function like a recipe: you write it once, and you can follow it many times to produce the same dish. You can also swap ingredients (parameters) to get variations. Modularization is like organising a cookbook into chapters — each recipe (function) is self-contained, easy to find, and easy to change without rewriting the whole book.

Functions: reusable blocks of code

A function is a named block of code that performs a specific task. Functions can:

  • Be defined once and called many times.
  • Take parameters (inputs).
  • Return values (outputs).
  • Encapsulate behaviour, making programs modular and easier to reason about.
def add(a, b):
    return a + b

result = add(5, 3)
print(result)  # Output: 8

Functions vs procedures

AspectFunctionProcedure
Returns a value?YesNo (or returns None)
Typical useCalculate and return a resultPerform an action (e.g. print, update)
Pythondef with returndef without return (returns None)
🔑 Key Principle: Functions eliminate duplication (DRY — Don't Repeat Yourself). If you need to change the logic, you change it in one place rather than many. Functions also make code easier to test: you can test the function in isolation with known inputs and expected outputs.

Modularization: structuring programs into logical components

Modularization refers to organizing code into separate, logically distinct units, usually through functions, classes and methods, or modules and packages.

Benefits of a modular program

BenefitExplanation
Easier to testEach module can be tested independently.
Easier to maintainBugs are easier to isolate and fix.
Easier to extendNew features can be added without rewriting existing code.
Easier to reuseFunctions or modules can be imported into other projects.
🔍 High cohesion, low coupling: Good modular design aims for high cohesion (each module focuses on a single, well-defined task) and low coupling (modules depend on each other as little as possible). This makes modules easier to understand, test, and replace.

Scope: local vs global

Scope defines the visibility and lifetime of variables — where they can be accessed and modified.

Local scope

A variable declared inside a function is local to that function and cannot be accessed from outside.

def greet():
    name = "Alice"  # local to greet()
    print("Hello", name)

greet()
# print(name)  # Error: name is not defined

Global scope

A variable defined outside all functions (in the main body) is global and accessible across multiple functions.

name = "Bob"  # global

def greet():
    print("Hello", name)

greet()  # Accesses global 'name'
⚠️ Modifying globals inside functions: In Python, if you assign to a global variable inside a function without declaring it global, Python creates a new local variable instead. To modify a global, you must use the global keyword.
📝 Exam tip: Local scope is usually safer than global scope. Local variables are isolated: changes inside one function cannot accidentally affect another function. This reduces side effects and makes behaviour easier to predict. Keep variables local unless they genuinely need to be shared.

Parameters and arguments

Parameters are the names listed in a function definition. Arguments are the actual values supplied when the function is called.

def greet(name):        # 'name' is a parameter
    print("Hello", name)

greet("Alice")          # "Alice" is an argument

Common function errors

  • Missing return: the function calculates a result but does not send it back, so the caller receives None.
  • Scope mistake: trying to access a local variable from outside the function.
  • Forgetting to call the function: defining it but never using it.
  • Wrong number of arguments: calling a function with too many or too few values.
✅ Quick checklist before writing a function:
  1. Does this function do exactly one thing?
  2. Are all inputs passed as parameters?
  3. Does it return a value if it is meant to be a function (rather than a procedure)?
  4. Is the name descriptive?
  5. Have I tested it with normal, edge, and invalid inputs?

Key terms

TermDefinition
FunctionA named block of code that performs a task and returns a value.
ProcedureA named block that performs an action but does not return a value.
ParameterThe name listed in a function definition that receives a value.
ArgumentThe actual value supplied when a function is called.
returnThe keyword that sends a value back from a function.
Local scopeA variable accessible only inside the function where it is declared.
Global scopeA variable defined outside all functions and accessible across them.
ModularizationBreaking a program into independent, reusable components.

5. Exam Technique

Understanding command words

Command wordWhat to do
State / Give / NameA short answer — often one word or phrase. No explanation.
DescribeSay what happens or what something is. More detail than "state," but no need for reasons.
ExplainSay how or why. Give reasons and make connections.
DistinguishMake clear the differences between two things.
Complete / TraceFill in the blank, or work through the code step by step.

Reading the mark allocation

  • 1 mark: one short answer.
  • 2 marks: two distinct points, OR one point with a clear explanation.
  • 3 marks: three distinct points, OR one point developed through three stages.
  • 4+ marks: multiple developed points — don't try to answer in one sentence.

Common mistakes to avoid

  • Confusing sequence (order of instructions) with selection (choosing a path) and looping (repeating).
  • Using = instead of == in a condition.
  • Putting elif branches in the wrong order (lowest threshold first).
  • Forgetting to update a while loop variable (infinite loop).
  • Forgetting that range(start, stop) excludes stop.
  • Writing a function that calculates a value but forgets to return it.
  • Trying to access a local variable from outside its function.

How to tackle a programming exam question

  1. Read the question carefully. Identify whether it's about sequence, selection, looping, or functions.
  2. Look at the mark allocation. It tells you how many points the examiner wants.
  3. For "explain" questions, use a two-part structure: what happens + why it happens.
  4. For code-writing questions, if unsure, write a plan first, then code.
  5. For trace questions, work through the code step by step, updating the state after each line.

6. Practice Questions

Now test yourself. Try each question without looking back at the notes. Write your answer first, then click Show answer ▼ to check. None of these questions are the same as the ones in the exam — they test the same skills on different scenarios.

Question 1

Explain why the order of instructions matters in a program. Give one example of a sequencing error and explain its consequence. (3 marks)

The order of instructions determines the program's behaviour. If instructions are misordered, the program may produce incorrect output or crash.

Example: using a variable before assigning it a value. print(x) before x = 10 raises a NameError in Python because x does not exist yet. The consequence is that the program terminates with an error instead of printing 10.

Question 2

Trace the following code and state the final value of total. (2 marks)

total = 0
for i in range(1, 5):
    total = total + i
print(total)

The loop runs for i = 1, 2, 3, 4 (range excludes 5).

total becomes: 0 + 1 = 1 → 1 + 2 = 3 → 3 + 3 = 6 → 6 + 4 = 10.

Final value: 10.

Question 3

Write a Python if-elif-else statement that prints "Hot" if the temperature is 30 or above, "Warm" if it is between 20 and 29, and "Cool" otherwise. (3 marks)

if temperature >= 30:
    print("Hot")
elif temperature >= 20:
    print("Warm")
else:
    print("Cool")

Note: the conditions are ordered from highest to lowest. If temperature >= 20 were checked first, a temperature of 35 would print "Warm" instead of "Hot".

Question 4

Explain the difference between a for loop and a while loop, and give one scenario where each is the better choice. (4 marks)

A for loop is used when the number of iterations is known in advance (count-controlled). A while loop is used when the number of iterations depends on a condition that may change unpredictably (condition-controlled).

For loop scenario: iterating over a list of 10 students to print their names.

While loop scenario: repeatedly asking for a password until the correct one is entered.

Question 5

Identify and fix the error in the following loop:

i = 0
while i < 5:
    print("Hello")

(2 marks)

Error: the loop variable i is never updated, so the condition i < 5 is always true. This creates an infinite loop.

Fix: add i += 1 inside the loop body.

i = 0
while i < 5:
    print("Hello")
    i += 1

Question 6

Define the term function and state one benefit of using functions in a program. (2 marks)

A function is a named block of code that performs a specific task and can be called multiple times.

Benefit (any one): it avoids code duplication; it makes the program easier to test and debug; it improves readability by giving a name to a logical operation; it allows code to be reused across different parts of a program.

Question 7

Explain the difference between local scope and global scope, using examples. (3 marks)

Local scope: a variable declared inside a function is only visible within that function. Example: def greet(): name = "Alice" — name cannot be used outside greet().

Global scope: a variable defined outside all functions is visible across the whole program. Example: name = "Bob" at the top level can be read inside any function.

Question 8

Write a Python function called calculate_area(length, width) that returns the area of a rectangle. Then call it with length = 5 and width = 3 and print the result. (4 marks)

def calculate_area(length, width):
    return length * width

result = calculate_area(5, 3)
print(result)  # Output: 15

Marks: 1 for correct function header with two parameters; 1 for returning the product; 1 for calling the function with arguments 5 and 3; 1 for printing the returned value.

Question 9

A programmer writes the following code:

x = 5
if x > 3 or x < 10:
    print("Condition true")

Explain why this condition is always true, and rewrite it so that it is only true when x is between 3 and 10 (exclusive). (3 marks)

The condition uses or, which is true when either side is true. Every number satisfies at least one of “x > 3” or “x < 10” (e.g. 15 satisfies the first, 1 satisfies the second), so the condition is always true.

Corrected: if x > 3 and x < 10: — this is true only for values strictly between 3 and 10.

Question 10

Explain two benefits of modularization for a large software project. (3 marks)

Any two of:

  • Easier maintenance — bugs are isolated to a single module, so fixing one part does not require understanding the whole program.
  • Easier testing — each module can be unit-tested independently with known inputs.
  • Reusability — well-designed modules can be imported into other projects.
  • Collaboration — different developers can work on separate modules with clear boundaries, reducing conflicts.

Question 11

Trace the following code and state the output. (2 marks)

count = 0
for i in range(3):
    for j in range(2):
        count += 1
print(count)

The outer loop runs 3 times. For each outer iteration, the inner loop runs 2 times. So the inner loop body executes 3 × 2 = 6 times.

Output: 6

Question 12

A function is written as follows:

def add(a, b):
    a + b

result = add(2, 3)
print(result)

Explain why result is None, and fix the function. (2 marks)

The function calculates a + b but does not return the value. In Python, a function without a return statement returns None by default.

Fix: add return a + b.

def add(a, b):
    return a + b

Question 13

Describe the difference between a sentinel-controlled loop and a count-controlled loop. (3 marks)

A count-controlled loop repeats a fixed number of times, known in advance (e.g. for i in range(5)).

A sentinel-controlled loop repeats until a special input value (the sentinel) is encountered; the number of iterations is not known in advance (e.g. while num != -1).

Question 14

Explain why range(1, 5) prints 1, 2, 3, 4 and not 1, 2, 3, 4, 5. (2 marks)

In Python, range(start, stop) generates numbers from start up to but not including stop. So range(1, 5) stops before 5.

To include 5, you would write range(1, 6).

Question 15

A student writes the following selection code:

if score >= 70:
    print("C")
elif score >= 80:
    print("B")
elif score >= 90:
    print("A")

Explain why a score of 95 would print "C" instead of "A", and fix the code. (3 marks)

Python evaluates elif branches top to bottom and stops at the first true condition. A score of 95 satisfies score >= 70 first, so it prints "C" and never reaches the score >= 90 branch.

Fix: reorder the conditions from highest threshold to lowest:

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
