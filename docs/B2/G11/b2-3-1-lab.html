🧪 Coding Challenges

Work through these challenges in order. Each one focuses on a different aspect of sequencing. Write your code in the Python Code Lab above.

1 Fix the Broken Sequence

The following code is supposed to ask for two numbers and print their sum, but the instructions are in the wrong order. Copy it into the IDE, fix the order, and run it.

print("Sum:", total)
a = int(input("Enter first number: "))
total = a + b
b = int(input("Enter second number: "))
What to do: Rearrange the lines so the program works correctly. Use the IDE's Step button to trace execution.
✅ Success criteria: The program asks for two numbers, adds them, and prints the correct sum.

2 Fix the Infinite Loop

The following code is meant to count from 1 to 5, but it runs forever. Find the bug and fix it.

i = 1
while i <= 5:
    print(i)
What to do: Add the missing line so the loop terminates after printing 5.
✅ Success criteria: The program prints 1, 2, 3, 4, 5 and then stops.

3 Write a Greeting Program

Write a Python program that:

  1. Asks the user for their name.
  2. Asks the user for their favourite colour.
  3. Prints a personalised greeting that includes both.
Example output: 
What is your name? Alex
What is your favourite colour? Blue
Hello Alex! Blue is a great colour.
✅ Success criteria: Input is collected before it is used, and the greeting appears after both inputs.

5 Build a Homework Reminder

Write a Python program that:

  1. Creates an empty list called homework_list.
  2. Asks the user how many homework assignments they have.
  3. Uses a loop to collect each assignment's name.
  4. Prints a reminder header, then lists each assignment on its own line.
  5. Ends with a motivational message.
Example output: 
How many homework assignments do you have? 3
Enter homework #1: Maths
Enter homework #2: Physics
Enter homework #3: English

Here are your homework assignments for today:
- Maths
- Physics
- English

Good luck! Remember to finish your homework on time!
✅ Success criteria:
  • The list is created before any items are added.
  • The reminder header prints after all inputs are collected.
  • The motivational message prints after the list.
