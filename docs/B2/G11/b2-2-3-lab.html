🧪 Part 1: Practical Stack Activity

🐍 Build a Stack in Python
Before you choose your path, you must complete this practical activity. You will write a Python program that implements a stack using a list, with push, pop, peek, and isEmpty functions.

Step 1: Set Up Your Stack

Open the Python Copy tool and write the following code to create an empty stack:


# Initialize the stack
my_stack = []
print("Stack created:", my_stack)
▶ Output: Stack created: []

Step 2: Write the Push Function

The push function adds an item to the top of the stack. Add this code below your stack:


def push(stack, item):
    stack.append(item)
    print(f"Pushed: {item}")

Step 3: Write the Pop Function

The pop function removes and returns the top item. Add this code:


def pop(stack):
    if len(stack) == 0:
        print("Stack Underflow!")
        return None
    else:
        return stack.pop()

Step 4: Write the Peek Function

The peek function returns the top item without removing it. Add this code:


def peek(stack):
    if len(stack) > 0:
        return stack[-1]
    else:
        print("Stack is empty!")
        return None

Step 5: Write the isEmpty Function

The isEmpty function checks if the stack has no elements. Add this code:


def isEmpty(stack):
    return len(stack) == 0

Step 6: Test Your Stack

Now test your stack by pushing and popping items. Add this code at the bottom of your program:


# Test the stack
push(my_stack, "A")
push(my_stack, "B")
push(my_stack, "C")

print("Top item:", peek(my_stack))
print("Popped:", pop(my_stack))
print("Popped:", pop(my_stack))
print("Is empty?", isEmpty(my_stack))
print("Popped:", pop(my_stack))
print("Is empty?", isEmpty(my_stack))
▶ Expected Output:
Pushed: A
Pushed: B
Pushed: C
Top item: C
Popped: C
Popped: B
Is empty? False
Popped: A
Is empty? True

✅ Checkpoint: Before moving on, make sure your program runs and produces the expected output. If you see errors, check your indentation and function names. Ask your teacher for help if you get stuck.
