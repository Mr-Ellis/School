The Big Idea

Arrays and lists are foundational data structures that allow us to store, organize, and manipulate collections of data in a single variable. Whether we're dealing with a simple set of values (e.g. test scores) or more complex data grids (e.g. a chessboard), using arrays and lists allows a program to efficiently access, update, and manage multiple elements.

To construct programs that apply arrays and lists means to:

  • Declare and initialize one-dimensional (1D) and two-dimensional (2D) arrays/lists,
  • Access and modify elements using indices,
  • Add and remove elements from dynamic lists,
  • Traverse arrays and lists using loops.

Key Concepts

1. One-Dimensional Arrays and Lists

An array is an ordered collection of elements that all share the same data type. Each element sits at a numbered position called an index. In most languages — and in IGCSE pseudocode — indexing starts at 0.


# Python - 1D List
numbers = [10, 20, 30]     # Declaration and initialization
numbers[0] = 15            # Modify
print(numbers[0])          # Access
▶ Output: 15

📌 Remember: Indexing starts at 0 in both Java and Python. The main difference is mutability and resizing: Java arrays are fixed-size, while Python lists are dynamic.

2. Two-Dimensional Arrays and Lists

A 2D array (or list of lists) is a grid-like structure where each element is accessed using two indices: row and column.


# Python - 2D List (Matrix)
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
print(matrix[0][0])  # Output: 1
▶ Output: 1

3. Dynamic Lists in Python

Python lists are inherently dynamic and provide built-in methods for flexible manipulation.


names = []
names.append("Alice")
names.append("Bob")
names.remove("Alice")
print(names[0])  # Outputs: "Bob"
▶ Output: Bob

🔑 Key Principle: Python lists are mutable and dynamic. You can add, remove, and change elements after the list is created. Java arrays are fixed-size; Java ArrayList is the dynamic alternative.

Practical Worked Examples

📊 Example 1: Calculating the Average of a List


scores = [90, 80, 70]
total = 0
for score in scores:
    total = total + score
average = total / len(scores)
print(average)   # Output: 80.0
▶ Output: 80.0

🔍 Example 2: Linear Search in a List


numbers = [73, 99, 37, 49, 38]
target = 37
found = False
for i in range(len(numbers)):
    if numbers[i] == target:
        found = True
        print("Found at index", i)
        break
if not found:
    print("Not found")
▶ Output: Found at index 2

🛒 Example 3: Shopping List Manager


shopping_list = []
# Add items
shopping_list.append("apples")
shopping_list.append("bananas")
shopping_list.insert(1, "oranges")
# Traverse
for item in shopping_list:
    print(item)
# Remove
shopping_list.remove("bananas")
del shopping_list[0]
print("Final list:", shopping_list)
▶ Output:
apples
oranges
bananas
Final list: ['oranges']

🎮 Example 4: 2D List (Tic-Tac-Toe Board)


board = [
    ["X", "O", "X"],
    ["O", "X", "O"],
    ["O", "X", "X"]
]
for row in board:
    for cell in row:
        print(cell, end=" ")
    print()
▶ Output:
X O X
O X O
O X X

Key Terms

TermDefinition
ArrayAn ordered collection of elements of the same data type, with a fixed size in languages like Java.
ListA dynamic, resizable collection of elements (Python's built-in list).
ElementOne value inside an array or list.
IndexThe position of an element in an array or list (starting from 0).
LengthHow many elements an array or list holds.
TraversalVisiting each element in an array or list, typically using a loop.
2D Array/ListA grid-like structure (array of arrays / list of lists) accessed with two indices.
DynamicAble to grow or shrink in size at runtime (e.g. Python lists, Java ArrayList).

⚠️ Common Errors:

  • Out-of-bounds access: Accessing an index that doesn't exist (e.g. list[10] in a list of size 3).
  • Removing items during traversal: Modifying a list while iterating over it can cause errors.
  • Confusing 1D with 2D logic: Forgetting to use nested loops when dealing with 2D structures.
  • Assuming fixed size: Trying to assign to an index that hasn't been created in a dynamic list.
