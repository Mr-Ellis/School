📖 Lesson Content

The Big Idea

In programming, looping structures allow us to execute a block of code multiple times, often with changing conditions or counters. Instead of writing the same instructions repeatedly, loops enable efficient, concise, and flexible repetition of actions—a core concept in all computational processes.

There are two broad categories of loops: counted loops (repeat a specific number of times) and conditional loops (repeat while a condition remains true). Effective use of loops—especially with conditional logic—allows programs to process data sets, interact with users, and perform algorithmic operations in a scalable way.

📚 Further reading: Course companion pages 366–370.

💡 Think of a loop as a treadmill: a counted loop is like setting the treadmill to run for exactly 5 kilometres; a conditional loop is like running until your heart rate reaches a target — you don’t know in advance how long that will take.

1. Types of Loops

A. Counted Loops (Definite Iteration)

Counted loops execute a fixed number of times, often using a loop control variable. In Python these are for loops.

for i in range(5):
    print("Iteration:", i)

Commonly used when the number of iterations is known ahead of time. The loop variable i controls how many times the loop runs.

B. Conditional Loops (Indefinite Iteration)

Conditional loops repeat until a condition becomes false. These are used when the number of repetitions is not known in advance. In Python these are while loops.

password = ""
while password != "open123":
    password = input("Enter password: ")

C. Loop Variants and Their Use Cases

Loop TypeSyntax FormBest Use Case
for loopCount-controlledWhen the number of iterations is known

💡 Think about it: Use a for loop when you know how many times to repeat (e.g. iterating over 10 items, or range(n)). Use a while loop when the number of repetitions depends on a condition that may change unpredictably (e.g. keep asking for input until it is valid). If you can express the repetition with a counter that stops at a known value, a for loop is usually clearer.

2. Conditional Statements Within Loops

Inside a loop, if, elif, and else can be used to modify control flow, such as filtering values, breaking loops, or skipping iterations.

Example: Filtering Odd Numbers (Python)

for i in range(10):
    if i % 2 == 0:
        continue  # Skip even numbers
    print(i)

Why are range and len different constructs? range(10) generates a sequence of numbers (0–9) directly, so the loop variable i takes each numeric value in turn. len(numbers), on the other hand, returns a single integer — the count of items in a collection. Wrapping it as range(len(numbers)) produces the indices 0, 1, 2 … up to the last valid index, so that numbers[i] can be used to access each element by position. In short: range creates a numeric sequence for iteration; len measures a collection’s size and is only used inside range to build that sequence.

Example: Early Exit on Match

for i in range(len(numbers)):
    if numbers[i] == target:
        print("Found!")
        break

Here range(len(numbers)) lets the loop visit every valid index of the list. The break exits immediately once the target is found, so no unnecessary iterations occur.

🔍 Loop control keywords:
  • break — exits the loop immediately.
  • continue — skips the rest of the current iteration and moves to the next one.
  • These are most useful inside if statements within the loop.

3. Boolean and Relational Conditions in Loops

Loops often rely on relational and Boolean logic for continuation or branching.

Python Example

while age < 18 or not has_permission:
    print("Access denied.")
    # request age or permission
Operator TypeExamplesUse
Relational<, <=, >, >=, ==, !=Compare values
Booleanand, or, not (Python)Combine or invert relational expressions to form compound conditions
⚠️ Watch the logic! In a loop condition, while x > 0 or x < 10: is always true — the loop will never stop. Why? The condition joins two tests with or, which is true if either side is true. For any number x, at least one of “x > 0” or “x < 10” will hold: if x is 15, the first part is true; if x is 3, the second is true; if x is 7, both are true. There is no value of x that makes both sides false at once, so the loop can never exit. Use and when checking that a value lies within a range — e.g. while x > 0 and x < 10: is only true for values strictly between 0 and 10.

4. Program Design Using Looping Structures

The goal is to repeat actions efficiently while maintaining clear, correct control flow.

Example: Accumulate Input Until Sentinel Value (Python)

total = 0
num = int(input("Enter number (-1 to quit): "))
while num != -1:
    total += num
    num = int(input("Enter number (-1 to quit): "))
print("Total:", total)

Example: Count-Controlled Sum (Python)

total = 0
for i in range(1, 11):
    total += i
print("Sum 1 to 10 =", total)
💡 Think about it: Use a while loop that keeps repeating until valid data is entered. For example: 
grade = -1
while grade < 0 or grade > 100:
    grade = int(input("Enter grade (0-100): "))
This is called input validation — a very common use of conditional loops.

5. Best Practices for Loops

Practice Description
Initialise before the loop Set any counter, accumulator, or flag before the loop begins. In Python, a for loop variable is initialised automatically by range()for i in range(1, 10): print(i) when you wanted 1–10 The loop runs one too few or one too many times; the final value is missing or an extra iteration appears. Remember range(start, stop) excludes stop. Use range(1, 11) for 1–10.
Missing initialisation while count < 5: with no count = 0 beforehand NameError in Python, or the loop behaves unpredictably if a stale value is reused. Initialise the control variable and any accumulator before the loop.
Faulty condition logic while x > 0 or x < 10: Loop never exits because the compound condition is always true. Use and for range checks: while x > 0 and x < 10:.
Update on only one path Counter incremented inside an if branch that is sometimes skipped Loop hangs on the iterations where the branch is not taken. Ensure the control variable changes on every path through the body.
Modifying a list while iterating for item in items: items.remove(item) Items are skipped or the loop misbehaves as indices shift. Iterate over a copy (for item in items[:]:) or build a new list.
⚠️ Debugging tip: If a loop misbehaves, add a print() of the control variable at the top of the body to trace its values. If the same value repeats forever, you have found your infinite loop.

✏️ Practice & Consolidation

Try It Yourself

Work through these tasks in your Python environment. They build from simple counted loops to combined conditional logic.

Task 1 — Countdown

Write a for loop that prints the numbers 10 down to 1, then prints "Liftoff!".

for i in range(10, 0, -1):
    print(i)
print("Liftoff!")

range(10, 0, -1) starts at 10, stops before 0, and steps down by 1.

Task 2 — Sum Until Zero

Ask the user for numbers repeatedly and add them to a running total. Stop when the user enters 0, then print the total.

total = 0
num = int(input("Enter a number (0 to stop): "))
while num != 0:
    total += num
    num = int(input("Enter a number (0 to stop): "))
print("Total:", total)

This is a sentinel-controlled loop — 0 is the sentinel value.

Task 3 — Input Validation

Keep asking for a test score until the user enters a value between 0 and 100 inclusive. Then print the accepted score.

score = -1
while score < 0 or score > 100:
    score = int(input("Enter score (0-100): "))
print("Accepted score:", score)

The initial -1 guarantees the loop runs at least once. Note the use of or here — the loop continues while the value is outside the valid range.

Task 4 — Filter with continue

Print only the odd numbers from 1 to 20 using a loop and continue.

for i in range(1, 21):
    if i % 2 == 0:
        continue
    print(i)

Even numbers are skipped; only odd numbers reach the print.

Task 5 — Early Exit with break

Search a list of names for "Ada". Print "Found!" and stop searching as soon as it appears.

names = ["Grace", "Alan", "Ada", "Linus"]
for name in names:
    if name == "Ada":
        print("Found!")
        break

break exits the loop immediately, so "Linus" is never checked.
