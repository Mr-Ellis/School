📖 Lesson Content

The Big Idea

In programming, looping structures allow us to execute a block of code multiple times, often with changing conditions or counters. Instead of writing the same instructions repeatedly, loops enable efficient, concise, and flexible repetition of actions—a core concept in all computational processes.

There are two broad categories of loops: counted loops (repeat a specific number of times) and conditional loops (repeat while a condition remains true). Effective use of loops—especially with conditional logic—allows programs to process data sets, interact with users, and perform algorithmic operations in a scalable way.

📚 Further reading: Course companion pages 366–370.

💡 Think of a loop as a treadmill: a counted loop is like setting the treadmill to run for exactly 5 kilometres; a conditional loop is like running until your heart rate reaches a target — you don’t know in advance how long that will take.

1. Types of Loops

A. Counted Loops (Definite Iteration)

Counted loops execute a fixed number of times, often using a loop control variable. In Python these are for loops.

for i in range(5):
    print("Iteration:", i)

Commonly used when the number of iterations is known ahead of time. The loop variable i controls how many times the loop runs.

B. Conditional Loops (Indefinite Iteration)

Conditional loops repeat until a condition becomes false. These are used when the number of repetitions is not known in advance. In Python these are while loops.

password = ""
while password != "open123":
    password = input("Enter password: ")

C. Loop Variants and Their Use Cases

Loop TypeSyntax FormBest Use Case
for loopCount-controlledWhen the number of iterations is known
while loopCondition-controlledWhen looping until a condition changes
do-while (Java only)Executes at least onceWhen the body must run before the condition is checked
💡 Think about it: Use a for loop when you know how many times to repeat (e.g. iterating over 10 items, or range(n)). Use a while loop when the number of repetitions depends on a condition that may change unpredictably (e.g. keep asking for input until it is valid). If you can express the repetition with a counter that stops at a known value, a for loop is usually clearer.

2. Conditional Statements Within Loops

Inside a loop, if, elif, and else can be used to modify control flow, such as filtering values, breaking loops, or skipping iterations.

Example: Filtering Odd Numbers (Python)

for i in range(10):
    if i % 2 == 0:
        continue  # Skip even numbers
    print(i)

Example: Early Exit on Match

for i in range(len(numbers)):
    if numbers[i] == target:
        print("Found!")
        break
🔍 Loop control keywords:
  • break — exits the loop immediately.
  • continue — skips the rest of the current iteration and moves to the next one.
  • These are most useful inside if statements within the loop.

3. Boolean and Relational Conditions in Loops

Loops often rely on relational and Boolean logic for continuation or branching.

Python Example

while age < 18 or not has_permission:
    print("Access denied.")
    # request age or permission
Operator TypeExamplesUse
Relational<, <=, >, >=, ==, !=Compare values

⚠️ Watch the logic! In a loop condition, while x > 0 or x < 10: is always true — the loop will never stop. Use and when checking that a value lies within a range.

4. Program Design Using Looping Structures

The goal is to repeat actions efficiently while maintaining clear, correct control flow.

Example: Accumulate Input Until Sentinel Value (Python)

total = 0
num = int(input("Enter number (-1 to quit): "))
while num != -1:
    total += num
    num = int(input("Enter number (-1 to quit): "))
print("Total:", total)

Example: Count-Controlled Sum (Python)

total = 0
for i in range(1, 11):
    total += i
print("Sum 1 to 10 =", total)
💡 Think about it: Use a while loop that keeps repeating until valid data is entered. For example: 
grade = -1
while grade < 0 or grade > 100:
    grade = int(input("Enter grade (0-100): "))
This is called input validation — a very common use of conditional loops.

5. Best Practices for Loops

PracticeDescription
Practice Description
Initialise before the loop Set any counter, accumulator, or flag before the loop begins. In Python, a for loop variable is initialised automatically by range(), but a while loop variable must be set manually.
Update the loop control variable Every while loop must change the variable used in its condition, otherwise it runs forever. Place the update at the end of the body (or wherever the logic requires) and check that it is reachable.
Choose the right loop type Use for when the number of repetitions is known; use while when it depends on a condition. Mixing them up makes code harder to read and more error-prone.
Keep the loop body focused Each iteration should do one clear job. If the body grows long, consider extracting it into a function.
Avoid deep nesting Nested loops multiply the number of iterations (an O(n²) pattern). Only nest when the problem genuinely requires it, and comment the purpose of each level.
Use break and continue sparingly They are useful for early exit and filtering, but overuse makes control flow hard to trace. Prefer a clear condition where possible.
Comment non-obvious conditions Explain why a loop stops, especially for sentinel values or compound Boolean conditions.
Test boundary values Check the first and last iterations, empty input, and the sentinel value itself to catch off-by-one errors.
📝 Quick checklist before running a loop:
  1. Is the loop variable initialised?
  2. Does the condition eventually become false?
  3. Is the variable updated on every path through the body?
  4. Are the boundaries correct (start, stop, step)?
  5. Does the loop do what the objective requires?

6. Common Loop Errors and How to Fix Them

The following mistakes appear again and again in student code. Learn to recognise them before you run your program.

Error What it looks like Symptom Fix
Infinite loop while i < 5: print("Hi") Program never terminates; fans spin up. Update i inside the body (e.g. i += 1).
Off-by-one error for i in range(1, 5) when 1–5 is intended One too few or too many iterations. Remember range(start, stop) excludes stop. Use range(1, 6) for 1–5.
Missing initialisation while total < 100: with no prior total = 0 NameError (Python) or unpredictable behaviour. Initialise counters and accumulators before the loop.
Faulty condition logic while x > 0 or x < 10: Always-true condition → infinite loop. Use and for range checks: while x > 0 and x < 10:.
Update in the wrong place i += 1 before a continue that skips it Some iterations never advance → infinite loop. Ensure the update is reached on every path, or restructure the logic.
Accidental semicolon / indentation A stray line outside the loop body Only part of the intended body repeats. Check indentation carefully in Python; keep the body consistent.
⚠️ Debugging tip: If a loop misbehaves, add a temporary print() at the top of the body to show the loop variable and condition values on each pass. Remove it once the loop is correct.
