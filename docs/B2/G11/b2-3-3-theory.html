The Big Idea

In programming, looping structures allow us to execute a block of code multiple times, often with changing conditions or counters. Instead of writing the same instructions repeatedly, loops enable efficient, concise, and flexible repetition of actions—a core concept in all computational processes.

There are two broad categories of loops: counted loops (repeat a specific number of times) and conditional loops (repeat while a condition remains true). Effective use of loops—especially with conditional logic—allows programs to process data sets, interact with users, and perform algorithmic operations in a scalable way.

📚 Further reading: Course companion pages 366–370.

💡 Think of a loop as a treadmill: a counted loop is like setting the treadmill to run for exactly 5 kilometres; a conditional loop is like running until your heart rate reaches a target — you don't know in advance how long that will take.

1. Types of Loops

A. Counted Loops (Definite Iteration)

Counted loops execute a fixed number of times, often using a loop control variable.

for i in range(5):
    print("Iteration:", i)

Commonly used when the number of iterations is known ahead of time. The loop variable i controls how many times the loop runs. In most languages these are for loops — here is the equivalent Java:

for (int i = 0; i < 5; i++) {
    System.out.println("Iteration: " + i);
}

B. Conditional Loops (Indefinite Iteration)

Conditional loops repeat until a condition becomes false. These are used when the number of repetitions is not known in advance.

password = ""
while password != "open123":
    password = input("Enter password: ")

The same idea in Java:

Scanner sc = new Scanner(System.in);
String password = "";
while (!password.equals("open123")) {
    System.out.print("Enter password: ");
    password = sc.nextLine();
}

C. Loop Variants and Their Use Cases

Loop TypeSyntax FormBest Use Case
for loopCount-controlledWhen the number of iterations is known
while loopCondition-controlledWhen looping until a condition changes
do-while (Java only)Executes at least onceWhen the body must run before the condition is checked

Java do-while example — the body runs once before the condition is tested, so the user is always prompted at least once:

int num;
do {
    num = scanner.nextInt();
} while (num <= 0);
💡 Think about it: Use a for loop when you know how many times to repeat (e.g. iterating over 10 items, or range(n)). Use a while loop when the number of repetitions depends on a condition that may change unpredictably (e.g. keep asking for input until it is valid). If you can express the repetition with a counter that stops at a known value, a for loop is usually clearer.

2. Conditional Statements Within Loops

Inside a loop, if, elif, else can be used to modify control flow, such as filtering values, breaking loops, or skipping iterations.

Example: Filtering Odd Numbers

for i in range(10):
    if i % 2 == 0:
        continue  # Skip even numbers
    print(i)

Why are range and len different constructs? range(10) generates a sequence of numbers (0–9) directly, so the loop variable i takes each numeric value in turn. len(numbers), on the other hand, returns a single integer — the count of items in a collection. Wrapping it as range(len(numbers)) produces the indices 0, 1, 2 … up to the last valid index, so that numbers[i] can be used to access each element by position. In short: range creates a numeric sequence for iteration; len measures a collection's size and is only used inside range to build that sequence.

Example: Early Exit on Match

for i in range(len(numbers)):
    if numbers[i] == target:
        print("Found!")
        break

Here range(len(numbers)) lets the loop visit every valid index of the list. The break exits immediately once the target is found, so no unnecessary iterations occur.

🔍 Loop control keywords:
  • break — exits the loop immediately.
  • continue — skips the rest of the current iteration and moves to the next one.
  • These are most useful inside if statements within the loop.

3. Boolean and Relational Conditions in Loops

Loops often rely on relational and Boolean logic for continuation or branching.

Python Example

while age < 18 or not has_permission:
    print("Access denied.")
    # request age or permission

Java Example

while (score >= 0 && score <= 100) {
    System.out.println("Valid score");
    // get new input
}
Operator TypePythonJavaUse
Relational<, <=, >, >=, ==, !=<, <=, >, >=, ==, !=Compare values
Booleanand, or, not&&, ||, !Combine or invert relational expressions to form compound conditions
⚠️ Watch the logic! In a loop condition, while x > 0 or x < 10: is always true, so unless something inside the loop changes x in a way you didn't intend, the loop will never exit. Why? The condition joins two tests with or, which is true if either side is true. For any number x, at least one of "x > 0" or "x < 10" will hold: if x is 15, the first part is true; if x is 3, the second is true; if x is 7, both are true. There is no value of x that makes both sides false at once, so the condition can never become false. Use and when checking that a value lies within a range — e.g. while x > 0 and x < 10: is only true for values strictly between 0 and 10.

4. Program Design Using Looping Structures

The goal is to repeat actions efficiently while maintaining clear, correct control flow.

Example: Accumulate Input Until Sentinel Value

total = 0
num = int(input("Enter number (-1 to quit): "))
while num != -1:
    total += num
    num = int(input("Enter number (-1 to quit): "))
print("Total:", total)

This pattern is called a sentinel-controlled loop — the sentinel value -1 signals "stop".

Example: Count-Controlled Sum

total = 0
for i in range(1, 11):
    total += i
print("Sum 1 to 10 =", total)
💡 Think about it: Use a while loop that keeps repeating until valid data is entered. For example: 
grade = -1
while grade < 0 or grade > 100:
    grade = int(input("Enter grade (0-100): "))
This is called input validation — a very common use of conditional loops.

5. Common Errors and Best Practices

Mistake Example / Description Effect How to Avoid
Infinite loop Forgetting to update the control variable, or while True: with no break Program hangs; the condition never becomes false. Update the control variable inside the loop; ensure every path can reach the exit condition.
Off-by-one error for i in range(1, 5): when you meant to include 5, or range(0, n) when you needed range(1, n+1) One too few or too many iterations; missing or extra data processed. Remember that range(start, stop) excludes stop. Use range(1, 6) to get 1–5.
Missing initialisation Using a counter or accumulator before assigning it a starting value NameError in Python, or unpredictable results in Java. Initialise counters to 0 and accumulators (e.g. total) before the loop.
Faulty condition logic Using or when and is needed (see the warning box in Section 3) Loop never exits, or exits too early. Test the condition with sample values; use and for ranges, or for alternatives.
Updating the wrong variable Incrementing Incrementing j instead of i, or updating a copy rather than the loop variable Condition never changes; infinite loop or wrong results. Double-check that the variable in the condition is the one being updated.
Modifying a list while iterating Removing items from a list inside a for loop over that same list Items are skipped or an error is raised. Iterate over a copy (for x in list[:]:) or build a new list.
✅ Best practices:
  • Give loop variables meaningful names (i, j are fine for simple counters; index, attempt, student are clearer for larger programs).
  • Keep the loop body focused — if it grows too long, extract it into a function.
  • Always make sure the loop condition can eventually become false.
  • Use for when the count is known, while when it isn't.
  • Test loops with zero iterations, one iteration, and many iterations to catch edge cases.
