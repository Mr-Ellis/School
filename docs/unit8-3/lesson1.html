💻 All About Software

Software is the programs that run on a computing device. There are two main types:

Systems Software

Runs the device and helps everything else work. The main example is the operating system (OS) — like Windows, macOS, Linux, Android or iOS.

The OS starts when you turn the device on and acts as the link between the hardware and the applications.

Applications Software

Programs that help you complete a specific task. Examples include web browsers, word processors, games, and simulators.

Some applications are general-purpose (like a word processor) and some are for a specific purpose (like a flight simulator).

🛠️ Utility Programs

Utility programs are also part of systems software. They are extra tools that keep your device running smoothly. Examples include:

  • Antivirus — protects against harmful software.
  • Firewall — blocks unauthorised access.
  • Backup — saves copies of files.
  • Compression — reduces file size.

🔤 Using Binary to Store Text

Computers only understand 1s and 0s (binary). ASCII (American Standard Code for Information Interchange) gives each character its own unique binary pattern.

  • The letter A = 01000001 in ASCII.
  • The letter a = 01100001 in ASCII.
  • ASCII makes sure all computers can share text, no matter the brand.
Important: The ASCII code for the number character "0" is 00110000. This is different from the binary number 0, which is 00000000. The ASCII code represents the character, not the value.

🔢 Using Binary to Store Numbers

Our normal number system is denary (base 10) — it uses digits 0–9. Computers use binary (base 2) — they use only 0 and 1.

Place values:

  • Denary → Ones, Tens, Hundreds, Thousands (×10 each time)
  • Binary → 1, 2, 4, 8, 16, 32, 64, 128 (×2 each time)

Example: Binary 1011 = (1 × 8) + (0 × 4) + (1 × 2) + (1 × 1) = 11 in denary.

⚡ Quick Recap

  • Operating System = manages hardware and provides a user interface (Windows, iOS, Android).
  • Utility Program = maintains the device (antivirus, firewall, backup, compression).
  • Application Software = helps the user complete a specific task (Word, Chrome, games).
  • ASCII = a code that gives each character a unique binary pattern (A = 01000001).
  • Binary = base 2, using place values 1, 2, 4, 8, 16, 32, 64, 128.
  • Denary = base 10, our normal number system (0–9).
