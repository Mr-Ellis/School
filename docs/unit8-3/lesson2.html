🔢 Binary Basics

Computers store all data as 1s and 0s — this is called binary. Each binary digit is called a bit.

Inside a computer, transistors act like tiny switches:

  • ON = 1
  • OFF = 0
Did you know? A modern computer chip can contain billions of transistors — each one is a tiny switch that can be ON or OFF.

🔄 Converting Denary to Binary

There are two main methods to convert a denary (decimal) number into binary.

Method 1: Division-by-2

Divide the number by 2 repeatedly and record the remainder (0 or 1) at each step. The first remainder is the LSB and the last remainder is the MSB. Read the binary result from bottom to top.

Example: Convert 94 to binary
  • 94 ÷ 2 = 47 remainder 0 (LSB)
  • 47 ÷ 2 = 23 remainder 1
  • 23 ÷ 2 = 11 remainder 1
  • 11 ÷ 2 = 5 remainder 1
  • 5 ÷ 2 = 2 remainder 1
  • 2 ÷ 2 = 1 remainder 0
  • 1 ÷ 2 = 0 remainder 1 (MSB)

Reading from bottom to top: 01011110

Method 2: Place-Value

Write the place-value headings from left to right: 128, 64, 32, 16, 8, 4, 2, 1. Start from the left (128) and work your way right. At each step, ask: "Can I subtract this place value from my number?" If yes, write 1 and subtract it. If no, write 0 and move on.

Example: Convert 94 to binary using place-value
128 64 32 16 8 4 2 1
0 1 0 1 1 1 1 0

Step-by-step:

  • Start with 94.
  • Can we subtract 128? No → write 0.
  • Can we subtract 64? Yes → write 1. 94 − 64 = 30.
  • Can we subtract 32? No → write 0.
  • Can we subtract 16? Yes → write 1. 30 − 16 = 14.
  • Can we subtract 8? Yes → write 1. 14 − 8 = 6.
  • Can we subtract 4? Yes → write 1. 6 − 4 = 2.
  • Can we subtract 2? Yes → write 1. 2 − 2 = 0.
  • Can we subtract 1? No → write 0.

Result: 01011110 (same as Method 1!)

Important: Always write your answers as 8-bit numbers (e.g., 00001010).

💻 Inside the Computer: Transistors

Millions of transistors store binary data. They use electrical signals to represent ON/OFF states. Binary digits combine to represent numbers, text, and images.

What is a transistor? A transistor is a tiny electronic switch that can be either ON (1) or OFF (0). Modern processors contain billions of them!

🧠 Logic Gates

Logic gates are the building blocks of digital circuits. They take binary inputs and produce a binary output based on a specific rule.

NOT Gate

Reverses the input. If input is 1, output is 0. If input is 0, output is 1.

AND Gate

Outputs 1 only if both inputs are 1.

OR Gate

Outputs 1 if at least one input is 1.

⚡ Quick Recap

  • Binary = computers store data as 1s and 0s.
  • Bit = a single binary digit.
  • Division-by-2 = divide by 2, record remainders, read bottom to top.
  • Place-value = subtract largest possible place value, place 1 or 0.
  • MSB = Most Significant Bit (leftmost). LSB = Least Significant Bit (rightmost).
  • NOT = reverses input. AND = both inputs must be 1. OR = at least one input must be 1.
