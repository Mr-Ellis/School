📦 Auto‑PY‑to‑EXE student guide

Packaging Tkinter, CustomTkinter, and PyQt projects with resource folders auto‑py‑to‑exe on PyPI →

This guide shows you how to use Auto‑PY‑to‑EXE to turn your Python GUI project — including resource folders — into a standalone .exe file. The steps are almost identical whether you used Tkinter, CustomTkinter, or PyQt.

1

Install Auto‑PY‑to‑EXE

Open the command prompt (CMD) and type:

pip install auto-py-to-exe

Once installed, launch it:

auto-py-to-exe

A window will open with the interface. (If you have multiple Python versions, you can also use python -m auto_py_to_exe.)

2

Select your main script

At the top of the interface, in the “Script Location” box, click “Browse” and select your main program file (usually main.py or app.py).

When selected correctly, the input box border will turn blue.

3

Choose the packaging mode

Under the “Onefile” option, choose based on your project type:

Your project typeChoose
Single .py file, no external resources✅ Check “Onefile” (produces a single .exe)
Multi‑file project or has resource folders❌ Leave unchecked (produces a folder — more reliable)
💡 Recommendation: If your project contains an assets/ folder, theme files (like CustomTkinter .json themes), or images, do not check Onefile. Packaging as a folder is more reliable, and double‑clicking the .exe inside still runs normally.
4

Hide the console window (important)

Under the “Console Window” option, select “Window Based (hide the console)”.

This makes your program run without the black command‑line window — only your GUI appears. This is required for Tkinter, CustomTkinter, and PyQt projects.

5

Add resource folders (the most important step)

This is where things most often go wrong. If your project has folders like assets/, images/, or themes/, you must add them here manually — otherwise the packaged exe won’t find them.

In the “Additional Files” section, click “Add Folder”:

  1. Select the resource folder in your project (e.g. assets)
  2. Set the destination path to the same name (e.g. assets)
📁 Example: If your image is at assets/logo.png, add the assets folder and set the destination to assets. This way, the exe will find it in the right place at runtime.
⚠️ CustomTkinter users: If your program uses a custom theme .json file, make sure the folder containing that file is also added.
6

Fix resource paths in your code (must do!)

Adding folders alone is not enough. After packaging, the program runs from a temporary directory, so relative paths will fail. You must add a resource_path function to your code and replace every place that loads a resource.

Add this to the top of your main script:

import sys
import os

def resource_path(relative_path):
    """Get the absolute path to a resource, compatible with dev and packaged exe"""
    if hasattr(sys, '_MEIPASS'):
        return os.path.join(sys._MEIPASS, relative_path)
    return os.path.join(os.path.abspath("."), relative_path)

Then update your loading code:

# ❌ Wrong (won't be found after packaging)
image = tk.PhotoImage(file="assets/logo.png")

# ✅ Correct
image = tk.PhotoImage(file=resource_path("assets/logo.png"))

Same idea for CustomTkinter themes:

# ❌ Wrong
customtkinter.set_default_color_theme("assets/myTheme.json")

# ✅ Correct
customtkinter.set_default_color_theme(resource_path("assets/myTheme.json"))

Use the same approach for loading images/icons in PyQt.

🚨 If you skip this step, the exe will throw FileNotFoundError or crash immediately.
7

Set an icon (optional)

In the “Icon” section, select your .ico file. Note it must be .ico format — you cannot use a .png directly.

8

Click Convert

Click the big “CONVERT .PY TO EXE” button at the bottom.

When it finishes, find the result in the output/ folder:

  • If you checked Onefile: you get a single .exe file
  • If you didn’t check Onefile: you get a folder — double‑click the .exe inside to run

🔧 Framework‑specific notes

FrameworkSpecial notes
TkinterBasically nothing extra needed — just follow the steps above
CustomTkinterIf you use a custom .json theme, make sure the folder containing the theme file is added in Additional Files
PyQt / PySideUsually auto‑detected, but if you get a missing module error, add it manually under Advanced → Hidden Imports (e.g. PyQt5.QtSvg)

✅ Quick checklist

  • The main script runs correctly
  • Onefile choice matches your project (leave unchecked if you have resource folders)
  • Console Window is set to Window Based
  • All resource folders are added in Additional Files
  • Every place that loads a resource uses the resource_path() function
  • After packaging, test the exe on another computer

💡 Troubleshooting tip: If the exe crashes or throws errors, rebuild without --windowed and run it from the command line to see the exact error message.
