3 Testing evidence

The write-up already says “51 core checks passed”. The work now is to explain what those checks prove, and to add extreme testing, which is currently missing entirely. Run each test, record the expected and actual result, and tick it once you have evidence (video or screenshot).

Normal, abnormal, boundary and extreme testing are four different things. Normal tests show the program works when used correctly. Abnormal tests confirm that invalid input is rejected safely. Boundary tests check the decision thresholds. Extreme testing is separate: it confirms that valid input at the edge of the program's limits — large datasets, long inputs and repeated runs — is still handled correctly and without unacceptable performance. A report with only abnormal and boundary tests has not shown that the program holds up under load.
