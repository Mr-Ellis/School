1. What task were the AI agents given? Why was the task designed to be "impossible"?

The agents were given a task that required them to cooperate or find an unconventional solution. It was designed to be "impossible" to test how they would adapt and reason under constraints.

2. What kinds of selection structures might an AI agent use?

AI agents use conditional logic such as: if goal_met: stop, elif obstacle_detected: avoid, else: explore. These are selection structures that determine behaviour based on state and environment.

3. How did the agents "join forces"? What conditions triggered cooperation?

They likely detected that working alone would not achieve their goal, so a condition like if cannot_achieve_alone and other_agent_present: cooperate was triggered.

4. Could individually "correct" decisions lead to an unwanted overall outcome?

Yes — this is a key lesson. Each agent's local decision might be correct for its own goal, but when combined, the overall system behaviour can be harmful or unintended. This is like a logic flaw where the interaction of many if statements produces an emergent problem.

5. What does "they knew it was unethical and did it anyway" suggest about their rules?

It suggests that the rule set was missing an ethical constraint — for example, if action_is_unethical: do not perform was either absent or overridden by a stronger goal-condition. The priority of conditions matters.

6. How does this connect to everyday programs?

In everyday programs, the order and completeness of conditions matter. A missing else, a poorly ordered elif, or an always-true condition can cause unexpected behaviour. Good selection design requires thinking about all possible states and interactions.

Collection of Data & Rules

AI systems need data to work with. Rules are used to determine the answers to questions. They may be programmed by a human or 'discovered' by machine learning.

Ability to Reason

AI is able to use reasoning to find out new information based on the rules it is given. Example: Humans eat vegetables. Zach is human. Reasoning deduces: Zach eats vegetables.

Task 2: Expert Systems ★★★ Medium

Locked

Read the information below and answer the questions. You must answer all 4 before moving on.

An expert system is a computer program that simulates a human expert. It is made up of four main components.

Knowledge Base & Rule Base

The knowledge base stores facts. The rule base stores rules on how these facts can be used. Rules are like IF-THEN statements. For example: IF you like football AND you like talking THEN we suggest being a football commentator.

Inference Engine & Interface

The inference engine controls the steps taken to solve the problem. It uses the rule base and knowledge base to deduce conclusions. The interface is how the user interacts with the system (e.g. web page, chat bot).

Task 3: Machine Learning ★★★ Medium

Locked

Read the information below and answer the questions. You must answer all 3 before moving on.

Machine learning is where a program is able to automatically adapt its own processes or data. Rather than giving the program rules, a large amount of data is collected by the program which then makes its own rules.

Detecting Fish or Chips

In machine learning we don't give the computer the rules to detect the difference. Instead we give sets of data for it to learn from. The program finds patterns in the data.

Training Data

The program has no knowledge of what fish or chips are. It looks at properties such as colour, number of items, weight, temperature, and crispness to find patterns.

Lesson Overview

This lesson introduces students to artificial intelligence, covering what AI is, its main characteristics, and two key areas: expert systems and machine learning. Students will complete Tasks 1–4, the Schoolbox worksheet, and an extension discussion.

Timing

  • 0–10 min — Starter & Objectives
  • 10–25 min — Task 1 (Characteristics of AI)
  • 25–40 min — Task 2 (Expert Systems)
  • 40–55 min — Task 3 (Machine Learning)
  • 55–65 min — Main Task (Schoolbox Worksheet)
  • 65–80 min — Task 4 (Plenary Gap Fill)
  • 80–95 min — Extension Task (AI in the Future)
  • 95–100 min — Review and Pack Up

Key Teaching Points

  • Use the happy/sad face example to illustrate rules.
  • Emphasise the difference between expert systems (pre-programmed rules) and machine learning (rules discovered from data).
  • Ensure students understand the four components of an expert system.
  • Use the fish and chips example to illustrate how machine learning finds patterns.
