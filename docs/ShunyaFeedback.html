2. How to Write Each Technique

Aim for 100 words per technique, using the same five-point structure:

  1. What the technique is
  2. Where in your code it appears
  3. Why you chose it
  4. What benefit it gives the user
  5. What limitation it has

Point five is what most students skip. It is also what turns a description into an evaluation, which is what the top band requires.

5. Required Code Changes

5.1 SC3 — Broaden yes/no matching

The current get_yes_no_value() only accepts the exact strings in YES_VALUES and NO_VALUES. A user typing "Y" or "no " with a trailing space is rejected. Strip the input first and accept single-letter versions case-insensitively. Add a message when the input does not match any valid form instead of silently returning the default.

5.2 SC7 — Explicit threshold check

Add a threshold constant near the top of the file:

STRESS_ALERT_THRESHOLD = 7.0

In maximum_score_trend(), after computing hourly_scores[peak_hour], compare it against the threshold and change the message accordingly. This makes SC7 measurable and removes the ambiguity of the current "recommended" wording.

5.3 SC8 — Timing evidence

import time
start = time.perf_counter()
# run submit_answers() equivalent
elapsed = time.perf_counter() - start
print(f"Test completed in {elapsed:.4f}s")

Record the result and show it in the video. SC8 is now provable.

5.4 SC3 — Corrupt file handling

Both get_latest_score() and maximum_score_trend() currently return quietly when the JSON is corrupted. Replace the silent return 0.0 with an explicit message:

QMessageBox.warning(self, "Data error", "Score history file is corrupted. Starting fresh.")

5.5 Question text consistency

Q6 in Questioneer.json reads "How much do you feel mentally exhausted?" while the GUI label reads "How do you feel mentally exhausted?" — align these so the user and the data file match.

7. Splash Screen

A splash screen supports SC1 (guides the user before they begin), and provides a screenshot for the Criterion C wireframe. Keep it short.

7.1 Where to add it

In StartWindow.__init__, after the UI is loaded, call self.show_splash() once. Add a "How to use" button if you want the option to re-display it.

7.2 The splash function

def show_splash(self) -> None:
    QMessageBox.information(
        self,
        "Welcome to Stress Manager",
        "Take a short questionnaire to measure your stress level.\n\n"
        "QUICK START\n"
        "  1. Press 'Start test'.\n"
        "  2. Answer all 10 questions.\n"
        "  3. Receive a score out of 10.\n"
        "  4. Take a recommended break.\n\n"
        "Your results are saved automatically so you can track\n"
        "your stress over time."
    )

8.4 Immediate priority

The most urgent item is SC7. maximum_score_trend() currently detects the peak hour and displays a message, but does not compare the average against a threshold. Adding a threshold constant makes SC7 measurable and gives you a clean test case for the video. The broaden-yes/no fix for SC3 is the second priority.
