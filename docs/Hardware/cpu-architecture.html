🏗️ 3.1.1 The Components of a CPU

The Central Processing Unit (CPU) is the hardware that executes software instructions. It is made up of several key parts that work together to process data.

1. The Control Unit (CU)
Think of the CU as the manager of the CPU.
• It sends control signals to other parts of the computer to tell them what to do.
• It manages the flow of data so that instructions happen in the correct order.
2. The Arithmetic Logic Unit (ALU)
The ALU is the calculator. It handles two types of operations:
• Arithmetic: Addition, subtraction, multiplication, and division.
• Logic: Comparisons such as "Is A greater than B?" and logical gates like AND, OR, and NOT.

📋 3. The Registers (Internal Memory)

Registers are super-fast, tiny storage locations inside the CPU. For your exam, you need to know these four:

  • Program Counter (PC): The "Address Pointer." It always holds the address of the very next instruction to be processed.
  • Memory Address Register (MAR): Holds the address of the data currently being read or written.
  • Memory Data Register (MDR): Holds the actual data or instruction that was just fetched from memory.
  • Accumulator (ACC): The "Storage Bin." It holds the result of whatever calculation the ALU just finished.

🚌 How they work together: The "Buses"

Data doesn't just float around; it travels on "highways" called Buses:

Address Bus

Carries signals relating to addresses between the CPU and Memory. (It only goes one way).

Unidirectional
Data Bus

Sends the actual data and instructions between the CPU and Memory. (This goes both ways).

Bidirectional
Control Bus

Carries command signals from the Control Unit to all other components.

Bidirectional
💡 Study Tip for the Exam:
Common Mistake: Students often confuse the MAR and the MDR.
The MAR is the "Map" (where the data is).
The MDR is the "Box" (what is actually inside).
