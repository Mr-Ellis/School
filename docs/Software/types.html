📂 System Software vs Application Software

🖥️ System Software

Provides the services that the computer requires. It enables the computer or device to work, or helps to maintain the good working order of the computer.

Examples: Operating systems (Windows, macOS), utility software (antivirus, disk defragmenter)

📱 Application Software

Provides services that the user requires. Apps on smartphones and tablets get their name from "application software".

Examples: Word processors, spreadsheets, social media apps, video players, accountancy programs

🧠 Important: Software that comes pre-installed (like iMovie on a Mac) is still application software – it provides services for the user, not the computer itself.

🔧 Utility Software

Utility software helps in configuring and maintaining the computer or device. Examples include:

📦 Compression

Reduces file size for storage or transmission

.zip, .rar files

💾 Backup

Creates copies of data to prevent loss

External drives, cloud backup

🧹 Disk Clean-up

Removes temporary and unnecessary files

Deletes cache, temp files

🔄 Disk Defragmenter

Reorganises files into contiguous locations

Improves access speed on HDDs

🛡️ Antivirus

Scans for and removes malware

Real-time protection, scans downloads

⚠️ Note: Disk defragmentation is not required for SSDs – it can cause unnecessary writes that degrade the drive.

🔁 Plenary – Software Categories

Click to reveal suggested answers
  • System vs Application: System software provides the services the computer requires (e.g., OS, utilities). Application software provides services the user requires (e.g., word processor, games).
  • Operating system: Manages hardware, runs programs, handles files, provides a user interface.
  • Utility software examples: Antivirus – protects against malware; Disk defragmenter – reorganises files; Backup – creates copies of data for safety.
