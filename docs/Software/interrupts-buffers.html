⚡ What is an Interrupt?

🔔 Definition

An interrupt is a signal to the processor that a high-priority event requires immediate attention. The processor stops what it is doing and handles the interrupt.

🔄 Fetch-Execute Cycle

During the fetch-execute cycle, the processor checks for interrupts. If an interrupt is detected, the CPU completes the current instruction, saves its state, and jumps to an interrupt service routine (ISR).

📋 Types of Interrupts

Hardware interrupts – from devices like keyboards, mice, printers.
Software interrupts – from programs or system calls.
Timer interrupts – from internal system timers.

💾 Buffers and Their Role

📦 What is a Buffer?

A buffer is a temporary storage area in memory that holds data during transfer between devices or between a device and the processor.

⚡ Why Buffers are Important

Buffers allow devices with different speeds to communicate efficiently. For example, a printer is slower than the CPU. The buffer stores data and sends it to the printer at its own speed, freeing the CPU to do other tasks.

🔄 How Buffers Work

Data is written to the buffer. The CPU doesn't wait for the device; it continues processing. The device reads data from the buffer when it's ready. This improves overall system performance.
