Lesson 2 · Operating Systems
Year 10 · Software · Role and functions of an operating system

Learning Objectives

  • Describe the role and basic functions of an operating system
  • Understand how hardware, firmware and an operating system are required to run applications software
  • Explain key functions: managing files, providing an interface, managing peripherals and drivers, managing memory, multitasking, providing a platform for applications, system security, and managing user accounts
💡 Key Fact: An operating system is responsible for managing the hardware and software in a computer, providing a platform for applications, and handling user interaction.

⚙️ Key Functions of an Operating System

📁 Managing Files

Organises, stores, and retrieves files on storage devices. Provides a file system for saving, copying, renaming, and deleting files.

🖥️ Providing an Interface

Allows users to communicate with the computer through GUI (WIMP), menu-driven, command line (CLI), voice-activated, or real-time interfaces.

🔌 Managing Peripherals & Drivers

Controls peripheral devices (keyboard, mouse, printer, etc.) using device drivers that allow the OS to communicate with hardware.

🧠 Managing Memory

Keeps track of where programs and data are stored in RAM, ensuring programs do not overwrite each other's memory space.

🔄 Managing Multitasking

Allows multiple programs to run simultaneously by rapidly switching between them, giving each program time on the CPU.

📦 Platform for Running Applications

Provides a platform for software to run on, handling memory management, file saving, and CPU time allocation.

🔒 Providing System Security

Protects the computer system through user authentication (username/password, PIN, biometrics) and access rights.

👤 Managing User Accounts

Manages multiple user accounts, controlling access to files, programs, and system settings based on user permissions.

🖱️ Types of User Interface

🖼️ GUI (WIMP)

Windows, Icons, Menus, Pointers. Most common interface for desktop computers.

📋 Menu-Driven

Users select options from menus. Common in settings, music players, and TVs.

⌨️ Command Line (CLI)

Text-based interface where users type commands. Faster for experienced users, uses less resources.

🎤 Voice-Activated

Users speak commands. Used by assistants like Siri, Alexa, and Google Assistant.

💡 WIMP Interface: Windows are used to show each program. Icons represent key functions. Menus provide options. Pointers (cursors) allow interaction.
