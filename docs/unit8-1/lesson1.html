🚀 Get started!

Think of a network like a group of friends passing notes to each other — except the notes are digital, and the friends are devices like phones, laptops, and printers. Networks help these devices talk, share, and work together!

Warm up: Complete 8.1.1 Worksheet 1 to assign each device a valid IP address. Remember, each number in an IPv4 address must be between 1 and 255, separated by full stops.

📶 Types of Networks

There are different kinds of networks, each with its own job:

  • PAN (Personal Area Network): Super small! Connects things like your smartwatch to your phone using Bluetooth.
  • LAN (Local Area Network): Found in homes and schools. Connects computers, printers, and more using cables or Wi-Fi.
  • WAN (Wide Area Network): Huge! Connects LANs across cities or countries. The Internet is the biggest WAN!
Quick Check: A smart watch uses a PAN. Can you explain why? (It connects over a very short distance, often using Bluetooth.)

🔌 Wired vs. 📡 Wireless Connections

Networks can be wired or wireless:

Wired Networks

  • Ethernet (Copper): Fast and cheap, but can get interference.
  • Fiber-Optic: Super fast and reliable, but more expensive.

Wireless Networks

  • Wi-Fi: Used in homes and schools.
  • Bluetooth: Great for short distances (like headphones).
  • Cellular (3G/4G/5G): Used by phones to connect anywhere.
Tip: Wireless is flexible, but wired is often faster and more secure.

🧩 Network Hardware

These are the tools that make networks work:

  • Switches: Send data to the right device.
  • Routers: Connect different networks and give devices IP addresses.
  • Access Points: Boost Wi-Fi signals.
  • Cables: Used for wired connections.

🛡️ Network Security

Just like locking your front door, networks need protection:

  • Firewalls: Block bad traffic.
  • Antivirus & Anti-spyware: Stop harmful software.
  • Encryption: Scrambles data so only the right people can read it.
Security Tip: Use strong passwords and keep your software updated!

🤔 Why Do We Network Devices?

Networking devices brings many advantages, but also some disadvantages.

✅ Advantages
  • Devices such as printers and scanners can be shared.
  • Software licences can be shared (cheaper).
  • Files can be accessed by all users on the network.
  • Users can communicate with each other.
  • Users can share an internet connection.
❌ Disadvantages
  • Networking hardware can be very expensive.
  • Managing a network is complicated and requires skilled people.
  • If the file server stops working, nobody can access files.
  • Viruses can spread to all devices if one gets infected.
