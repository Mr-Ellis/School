4. Transmitting Data

Binary & ASCII

  • Computers use binary (0s and 1s).
  • A bit is the smallest piece of data.
  • ASCII turns letters, numbers and symbols into binary.
    e.g. 'A' = 01000001, 'B' = 01000010, 'C' = 01000011

Serial vs Parallel

SerialParallel
How it sendsOne bit at a time8 bits (a byte) at once
WiresOneMultiple
SpeedSlowerFaster
Best forLong distances, wirelessShort distances (inside a computer)

Transmission errors

Caused by interference, power surges, or long distances. Bits can flip from 0 to 1 (or vice versa).

5. Error Detection & Correction

Echo checking

  1. Sender transmits data to receiver.
  2. Receiver sends the data back to the sender.
  3. Sender compares the returned data with the original.
  4. If they match, transmission is successful.
  5. If they don't match, the data is sent again.

Limitations: doesn't show where the error happened; uses extra data (whole message sent back), which slows things down.

ARQ – Automatic Repeat reQuest

  1. Sender sends data to receiver.
  2. Receiver checks and sends back an acknowledgement:
    • Positive (ACK): data arrived correctly – no resend.
    • Negative (NAK): data arrived with errors – sender must resend.
  3. If no reply arrives in time (timeout), sender resends the data.
Why ARQ is better: only a small acknowledgement is sent back, not the whole message. Uses less data, faster, and timeout triggers automatic resend.

6. Security Threats

ThreatWhat it is
VirusBad software that spreads and damages files or systems
RansomwareLocks your files and asks for money to unlock them
SpywareSecretly collects your personal info without permission

MeasureWhat it does

Anti‑spywareScans for and removes adware and trojans; informs the user.

Antivirus details: uses databases of code; quarantines harmful files; must be kept up to date.
Firewall details: keeps networks safe by limiting access; prevents unauthorised users; examines data against rules.

8. Operating Systems

What an OS does:

  • Manages hardware and software
  • Manages files and folders
  • Controls memory (RAM)
  • Communicates with hardware (keyboards, printers, etc.)
  • Provides a user interface
  • Manages user accounts
  • Has built‑in tools to keep devices safe

User interfaces

  • Command Line: type text commands (DOS, Terminal)
  • GUI: click icons and menus (Windows, Mac)
  • Speech: talk to the device (Siri, Alexa)

Network OS (NOS): used on servers; manages many devices, installs updates, controls access, includes utility software.

Operating systems are required on smartphones and portable technology. They do manage user accounts and hardware/software.

9. Advantages & Disadvantages of Networks

✅ Advantages

  • Users can share an internet connection
  • Users can share devices such as printers and scanners
  • Users can communicate with each other
  • Users can share software licences (often cheaper)
  • Files can be accessed by all users on the network

❌ Disadvantages

  • Networking hardware can be very expensive
  • Managing a network can be complicated and requires skilled people
  • If the file server stops working, nobody can access files
  • Viruses can spread to all devices if one gets infected
