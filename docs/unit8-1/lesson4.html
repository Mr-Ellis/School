🔄 Quick Recap: Why Do We Need Error Checking?

When computers send data across a network, it's really important that the information arrives correctly. You've already learned about echo checks, where the data is sent back to the sender to check for mistakes.

But there's a problem: Echo checks can take up a lot of time and use extra data. There must be a better way!

🔁 What is ARQ?

ARQ stands for Automatic Repeat reQuest. It's a way for computers to check if data has been received correctly — without sending the whole message back.

How ARQ Works

  1. The sender sends the data.
  2. The receiver checks the data and sends back a message:
    • If the data is correct, it sends a positive acknowledgement.
    • If the data is wrong, it sends a negative acknowledgement.
  3. If the sender doesn't get a reply in time (called a timeout), it sends the data again.

This helps make sure that the data is accurate, even if the network isn't perfect.

Acknowledgements

Positive Acknowledgement

Data arrived correctly. No need to resend. This is often called ACK.

Negative Acknowledgement

Data arrived with errors. The sender must resend. This is often called NAK.

⚖️ ARQ vs Echo Check

Feature Echo Check ARQ
What gets sent back? The entire message is echoed back to the sender Just a short acknowledgement (ACK or NAK)
Data usage High — the whole message goes back Low — only a small signal goes back
Speed Slower — lots of data to send Faster — small acknowledgements
What if data is lost? Sender compares and resends if mismatched Timeout triggers automatic resend
Key idea: ARQ is more efficient than echo checking because it only sends small acknowledgements back, not the whole message.

a) How firewalls protect a network

Firewalls keep networks safe by limiting the access that devices have to networks. They prevent unauthorised users from accessing a network. Firewalls examine all the data entering and leaving a network to check that it does not break any rules. If something breaks one of the network rules, the action will not be completed and the user will be notified.

b) How antivirus and anti-spyware protect data

Antivirus software prevents viruses from opening and infecting files on computers. It performs real-time scans of chunks of data coming into a device to detect whether it has been infected. If it detects a file as harmful, it quarantines the file and lets the user know a virus has been detected. The user can then decide whether to delete the file.

Anti-spyware works in a similar way. It regularly scans for files that could be troublesome — such as adware and trojans. When it detects threats, it removes them from the system and informs the user.
