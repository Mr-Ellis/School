📡 Transmitting Data in Networks

Let's explore how computers send messages to each other — and how they keep those messages safe and accurate!

🔢 Binary Data: The Language of Computers

  • Computers don't speak English — they speak binary, a language made of just 0s and 1s.
  • Each number is called a bit, and it's the smallest piece of data.
  • Everything you see on a screen — text, pictures, videos — is made from bits!

🔤 ASCII: Turning Letters into Binary

ASCII is a special code that turns letters, numbers, and symbols into binary. Each character has its own binary number.

CharacterBinary
'A'01000001
'B'01000010
'C'01000011

This is how your keyboard talks to your computer!

🚚 How Data Travels: Serial vs. Parallel

Serial Transmission

  • Sends one bit at a time through a single wire or channel.
  • Slower, but great for long distances and wireless communication.

Parallel Transmission

  • Sends 8 bits (a byte) at once using multiple wires.
  • Much faster, but only works well over short distances (like inside a computer).

⚠️ Transmission Errors: What Can Go Wrong?

Sometimes data gets messed up while traveling. Here's why:

  • Interference from other signals or devices
  • Power surges that mess with the signal
  • Long distances that weaken the signal

This can flip bits from 0 to 1 or vice versa — like sending the wrong message!

🔍 Error Detection: Echo Checking

To make sure data arrives safely, networks use echo checking:

  1. The receiver sends the data back to the sender.
  2. The sender compares it with the original.
    • If it matches, all good!
    • If it doesn't, the data is sent again.
Note: Echo checking doesn't show where the error happened, and it uses extra data, which can slow things down.

🛡️ Network Security Threats

Viruses

Bad software that spreads and damages files or systems.

Ransomware

Locks your files and asks for money to unlock them.

Spyware

Secretly collects your personal info without permission.

Social Engineering

Tricks people into giving away passwords or private info.

🔓 Password Cracking & Cyber Attacks

Brute Force Attack: Tries every possible password until it finds the right one.

Weak passwords (like "1234" or "password") are easy to crack!
