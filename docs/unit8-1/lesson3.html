⚙️ Operating Systems (OS)

The operating system is the most important software on a computer. It manages everything!

  • Manages files and folders — organises your data.
  • Controls memory (RAM) — decides what runs and when.
  • Communicates with hardware — works with keyboards, printers, etc.
  • Provides user interface — lets you interact with the device.

Types of User Interfaces

  • Command Line: Type text commands (e.g., DOS, Terminal).
  • GUI (Graphical User Interface): Click icons and menus (e.g., Windows, Mac).
  • Speech: Talk to the device (e.g., Siri, Alexa).

Network OS (NOS)

Used on servers to manage many devices. It helps install updates, control access, and includes utility software for safety.

🧩 Network Hardware

Server

Provides services like file sharing, printing, email, and websites.

NIC

Network Interface Controller — connects a device to the network. Has a unique MAC address.

Switch

Connects devices and sends data to the correct one using MAC addresses.

WAP

Wireless Access Point — lets devices connect using Wi-Fi.

Router

Connects networks and finds the best path for data.

All-in-One

Combines router, switch, and WAP. Common in homes.

🛡️ Keeping It Safe — Utility Software

Antivirus

Scans for viruses, quarantines or deletes them. Needs regular updates.

Anti-spyware

Finds and removes hidden software like adware and trojans.

Ransomware Protection

Stops software that locks files and demands payment.

Firewall

Controls what data enters or leaves a network.

🔥 Firewalls

  • Hardware firewalls — built into routers.
  • Software firewalls — installed on individual devices.
  • They block harmful data and follow rules set by network administrators.
  • Rules can block websites, unknown devices, or dangerous files.
Did you know? A firewall works like a security guard at a building entrance — it checks who and what is allowed in and out!
