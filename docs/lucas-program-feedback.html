🔍 On Pattern Detection

Simple approach for SC5:

  • Repeating chars: check for aaa, 111 using a loop or regex
  • Sequences: check against a list like "abc", "123", "qwerty"
  • Dictionary words: check if the password contains any word from a small wordlist
💡 Tip: Python's re module makes repeating-character detection easy. For example, re.search(r'(.)\1{2,}', pwd) finds any character repeated 3+ times.

📁 CSV / Database Question — Yes, Use CSV

Yes, a CSV is the better choice. Reasons:

  • Simpler — Python's csv module is built-in, no external database needed.
  • Portable — Mr. Aloof can open it in Excel to inspect or update breached passwords.
  • Offline-friendly — aligns with your "zero keystroke transmission" constraint.
  • Easy to justify in Criterion C — you can show the file structure and explain the lookup algorithm.

Suggested approach

  1. Create breached_passwords.csv with one column of plain-text breached passwords (or pre-hashed values).
  2. At startup, load them into a Python set:
import csv, hashlib

def load_breached_hashes(path="breached_passwords.csv"):
    hashes = set()
    with open(path, newline='', encoding='utf-8') as f:
        reader = csv.reader(f)
        for row in reader:
            if row:
                hashes.add(hashlib.sha256(row[0].strip().encode()).hexdigest())
    return hashes
  1. On each keypress, hash the input and check if hash in breached_hashes.
  2. Show a red banner if found, green if not.
Why store hashes instead of plain text? SC3 says passwords should never be stored in plain text — storing the breached list as hashes is consistent with that. It's also faster to compare hashes than to hash every entry on every keypress.

If you want to keep it simpler, store plain text in the CSV and hash on load — still defensible.

🏗️ OOP Refactor — Why and How

Your current code has one class doing everything: UI, math, state. For Criterion D, you want to show modularity and separation of concerns. Splitting into multiple classes makes testing easier and demonstrates stronger OOP.

Example AnalysisResult

from dataclasses import dataclass

@dataclass
class AnalysisResult:
    length: int
    pool: int
    pool_details: str
    entropy: float
    crack_time: str
    tier: int
    tier_name: str
    hash: str
    is_breached: bool
    patterns: list[str]
    advice: list[str]
    latency_ms: float
