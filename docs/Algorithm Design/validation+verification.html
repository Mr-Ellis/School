🤔 Starter: The Preposterous Age

Look at this simple program:

INPUT age
OUTPUT "You are", age, "years old"

What is output if the user enters 5, 15, or 215?

Think: What is the problem with this program? How could it be fixed?

The program will happily output "You are 215 years old" — which is clearly impossible. The program doesn't check that the input is reasonable. This is where validation comes in.

🛡️ Types of Validation

Validation is checking an input to see that it is realistic or conforms to a set of rules. It does not guarantee the data is correct — only that it is sensible.

Validation Check Meaning Example
Range check Check that a value is between two values An age must be between 0 and 120
Length check Check the length of input is a given number of characters Password length is at least 8 characters
Type check Check if a value is the correct data type An integer is a whole number
Presence check Check if a value is present or not "y" (present) vs "" (not present)
Format check Check the input matches a format Rooms are letter, number
Check digit A digit added to the end of a number to check it is valid Barcode numbers, credit card numbers

Presence Check

Sometimes validation simply requires that a data item is present (has been entered). For example, a required field in a form.

Consent ← FALSE
WHILE NOT Consent DO
  OUTPUT "Do you agree with the terms and conditions?"
  INPUT Response
  IF Response = 'y' THEN
    Consent ← TRUE
    OUTPUT "Thank you for your consent"
  ELSE
    OUTPUT "Sorry, you must consent to use the program"
  ENDIF
ENDWHILE

Length Check

These checks are useful when a certain number of characters is required — such as for a password.

ValidNameLength ← FALSE
Name ← ""
WHILE NOT ValidNameLength DO
  INPUT Name
  IF LENGTH(Name) >= 8 THEN
    ValidNameLength ← TRUE
  ENDIF
ENDWHILE

Range Check

For numbers, we can validate that they are part of a particular range. Remember: the input will first need to be converted to a number.

ValidAge ← FALSE
Age ← 0
WHILE NOT ValidAge DO
  INPUT Age
  IF Age >= 0 AND Age <= 120 THEN
    ValidAge ← TRUE
  ENDIF
ENDWHILE

Type Check

A type check makes sure the data a user enters contains the correct data type. The pseudocode uses a function called Type that checks if a variable is of a certain data type (similar to Python's isinstance).

INPUT Length
IF Type(Length, Integer) THEN
  OUTPUT "Valid number"
ELSE
  OUTPUT "Invalid - not an integer"
ENDIF

Format Check

A string can be checked to see that it has the format that is required. Useful functions include:

Function Meaning
isalpha()Contains letters
isalnum()Contains letters or numbers
isdigit()Contains digits
isnumeric()Contains a number
isupper()Is in uppercase
islower()Is in lowercase
INPUT Username
IF Username.isalpha():
  OUTPUT "Valid - all letters"
ENDIF
Note: Regular expressions are usually used to check formats in real programming languages, but they are beyond the scope of this specification.

Check Digits

A check digit is a digit added to the end of a number and used to check that the number is valid. This has many uses including credit card numbers and barcode numbers.

Example: The number 48371294 has its check digit calculated by adding each digit, then taking the final digit of the total.

4 + 8 + 3 + 7 + 1 + 2 + 9 + 4 = 38
Check digit = 8

Once the data is input, the check digit is generated. If it doesn't match the number, the number isn't valid.

Important: A simple check digit (summing digits) will not detect a transposition error (e.g., entering 48 instead of 84). More complex algorithms like the EAN-13 barcode system will detect transposition errors. This is why they are used for barcodes and credit cards.

✅ Verification: Double-Checking Data

Validation only checks that data entered is reasonable (and valid). It doesn't check it is correct.

Verification, by contrast, is interested in the data being correct. The two techniques you need to know are:

  • Double-entry check: Entering the data twice and comparing both entries to see if they match (e.g., entering a password twice when signing up).
  • Visual check: The user checks data already entered and confirms it is correct (e.g., reviewing an order before clicking "Place Order").
Key Difference: Validation = "Is this data sensible?"  |  Verification = "Is this data correct?"

Challenge Yourself: Write a Validation Program

Instructions:

  1. Write a pseudocode program that asks the user to enter a username.
  2. The username must be all letters (use isalpha()).
  3. If the input is invalid, the program should display an error message and keep asking until a valid username is entered.
  4. Extension: Once a valid username is entered, ask for a PIN that must be exactly 4 digits long and contain only digits (use isdigit() and LENGTH()).

Self-Check: Compare your solution

Once you've written your program, click below to reveal a possible solution.

Username validation:
ValidUsername ← FALSE
Username ← ""
WHILE NOT ValidUsername DO
  OUTPUT "Enter username (letters only):"
  INPUT Username
  IF Username.isalpha() THEN
    ValidUsername ← TRUE
    OUTPUT "Valid username"
  ELSE
    OUTPUT "Invalid username - letters only please"
  ENDIF
ENDWHILE

Extension - PIN validation:
ValidPIN ← FALSE
PIN ← ""
WHILE NOT ValidPIN DO
  OUTPUT "Enter a 4-digit PIN:"
  INPUT PIN
  IF LENGTH(PIN) = 4 AND PIN.isdigit() THEN
    ValidPIN ← TRUE
    OUTPUT "PIN accepted"
  ELSE
    OUTPUT "Invalid PIN - must be exactly 4 digits"
  ENDIF
ENDWHILE
