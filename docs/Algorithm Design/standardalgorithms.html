🔢 Counting and Totalling

Counting and totalling are among the simplest and most common algorithms.

Counting

Use a FOR loop to count from 1 to 10:

FOR i ← 1 TO 10
  OUTPUT i
NEXT i

To count in twos (even numbers), use STEP:

FOR i ← 2 TO 10 STEP 2
  OUTPUT i
NEXT i

This outputs: 2, 4, 6, 8, 10.

Totalling

To find the total of a set of values, keep a running total:

Total ← 0
WHILE SushiDetected
  Total ← Total + Price
ENDWHILE

Finding Maximum, Minimum, and Average

  • Maximum: Start with Max ← 0 (or a very small number). If a value is greater than Max, update Max.
  • Minimum: Start with Min ← a very large number (e.g., 10000). If a value is less than Min, update Min. Alternatively, use a "First" flag to handle the first item correctly.
  • Average: Total ÷ Count.
Robust Minimum Algorithm (using a First flag):
Min ← 0
First ← TRUE
WHILE MoreItems
  INPUT Item
  IF First THEN
    Min ← Item
    First ← FALSE
  ELSE
    IF Item < Min THEN
      Min ← Item
    ENDIF
  ENDIF
ENDWHILE

🔎 Linear Search

A linear search checks each item in turn until it finds the target. It works on sorted and unsorted lists.

Numbers ← [5, 1, 9, 8, 7, 6, 4, 10]
INPUT SearchItem
Found ← FALSE
FOR i ← 1 TO LENGTH(Numbers)
  IF Numbers[i] = SearchItem THEN
    OUTPUT "SearchItem found"
    Found ← TRUE
  ENDIF
NEXT i
IF NOT Found THEN
  OUTPUT "SearchItem not found"
ENDIF

Key points: The loop runs through every item. The Found flag tracks whether the item was found. If the item is not in the list, the flag remains FALSE and the "not found" message is output.

🔄 Bubble Sort

Bubble sort repeatedly compares adjacent items and swaps them if they are in the wrong order. After each pass, the largest remaining item "bubbles" to the end.

How It Works

  • Start at the leftmost item.
  • Compare it with the next item. If the next item is smaller, swap them.
  • Move to the next pair and repeat.
  • At the end of one pass, the largest item is in the correct place.
  • Repeat for the remaining items until the list is sorted.

Python Example (from your resources)

userName = ["Carl", "Tamsin", "Eric", "Zoe", "Alan", "Mark"]
numItems = 6
while numItems > 1:
    for count in range(5):
        if userName[count] > userName[count+1]:
            temp = userName[count]
            userName[count] = userName[count+1]
            userName[count+1] = temp
    numItems = numItems - 1
print(userName)
