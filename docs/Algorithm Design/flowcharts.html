🔍 What is a Flowchart?

A flowchart is a visual way to show an algorithm. It uses standard symbols joined by arrows to show the order of steps. Think of it like a recipe for a computer — it shows exactly what to do, step by step.

Example: Even a bread-making algorithm can be shown as a flowchart. You add flour, add water, mix, check if the mixture is too dry or too wet, and keep adjusting until it's just right.

🔣 The Flowchart Symbols

Flowcharts use a standard set of symbols. You need to know each symbol and what it means.

Terminator
Start and end of the algorithm
Input/Output
Data coming in or results going out
Process
A calculation or assignment
Decision
A question with Yes/No exits
Sub-routine
Runs a mini-program
Flow Line
Shows direction of flow

🧠 Trace the Flowchart

Being able to read a flowchart and predict its output is a key skill. Try these exercises.

Trace 1: What is the output?
START → INPUT age → Is age > 18? → YES: OUTPUT "Adult" → END
                                → NO: OUTPUT "Child" → END

If the user inputs 18, what is the output?

Trace 2: What is the output?
START → count = 0 → count = count + 1 → OUTPUT count → Is count < 3? → YES: go back to count = count + 1
                                                            → NO: END

What numbers does this algorithm output?

📦 Subprograms in Flowcharts

You need to know how subprograms are drawn in flowcharts. These represent procedures and functions in programming languages.

  • A process box with double lines either side is used for function/procedure calls.
  • The terminator (start/end) symbols are used for the function name (and parameters) and the return value.
  • The dotted arrows show how data is passed from the calling statement to the subprogram (function).
Example: The findVAT function takes a value n, multiplies it by 0.2 to calculate VAT, and returns the result. The main program calls it using total < total + findVAT(total).
