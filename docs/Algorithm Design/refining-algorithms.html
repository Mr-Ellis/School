🔤 Starter: Palindrome Checker

A word is a palindrome if it reads the same forwards and backwards. RACECAR is an example.

Think about how a word is stored in a string — each character is at an index, just like an array:

R A C E C A R

Create an algorithm using pseudocode to find if a word is a palindrome.

Hint: Compare the first character with the last, the second with the second-to-last, and so on. If any pair doesn't match, it's not a palindrome.
Predict: What is the output for "RACECAR"?

Will the algorithm output TRUE or FALSE for the word "RACECAR"?

🚴 Main Task: Cycle Race (Fastest Time)

A cycle race has around 10 competitors. At the end of the race, each competitor's time (in seconds) is entered into a program. The program automatically calculates the fastest time.

Work in a pair to create an algorithm for the program using pseudocode.

Think about: How do you find the minimum value in a list? How do you handle the first input? How does the program know when to stop?

Self-Check: Compare your algorithm

Once you've written your pseudocode, click below to reveal a possible solution.

fastestTime ← 0
firstInput ← TRUE
moreTimes ← TRUE

WHILE moreTimes DO
  INPUT time
  IF time = -1 THEN
    moreTimes ← FALSE
  ELSE
    IF firstInput THEN
      fastestTime ← time
      firstInput ← FALSE
    ELSE
      IF time < fastestTime THEN
        fastestTime ← time
      ENDIF
    ENDIF
  ENDIF
ENDWHILE

OUTPUT fastestTime

🐛 Debugging: Miles to km/h Convertor

The following Python code is for a MPH (miles per hour) to km/h (kilometres per hour) convertor. The program should only accept miles between 0 and 100.

miles = -1
valid = Flse
while not valid:
  mph = float(input("Enter number of miles per hour: "))
  if mph >= 0 or mph <= 100:
    valid = True
    kmph = 1.609 * mph
    print(kmph, "km/h)

Identify the three errors in the program.

  • Error 1: Flse should be False (syntax error — spelling).
  • Error 2: or should be and (logical error — the condition mph >= 0 or mph <= 100 is always true).
  • Error 3: Missing closing quote in "km/h) (syntax error).

Self-Check: Compare your corrected code

Once you've fixed the errors, click below to reveal the corrected program.

miles = -1
valid = False
while not valid:
  mph = float(input("Enter number of miles per hour: "))
  if mph >= 0 and mph <= 100:
    valid = True
    kmph = 1.609 * mph
    print(kmph, "km/h")

Challenge Yourself: Space Shuttle Countdown

Instructions:

  1. Create a countdown for a space shuttle launch from 10 to 0.
  2. The procedure time.sleep(seconds) will pause a program for a number of seconds.
  3. Write an algorithm as a flowchart, pseudocode, or program code to produce the countdown.
  4. After the countdown reaches 0, output "Liftoff!".

Self-Check: Compare your solution

Once you've written your algorithm, click below to reveal a possible solution.

Pseudocode:
FOR i ← 10 TO 1 STEP -1
  OUTPUT i
  time.sleep(1)
NEXT i
OUTPUT "Liftoff!"

Python:
import time
for i in range(10, 0, -1):
    print(i)
    time.sleep(1)
print("Liftoff!")
