🔢 Data Types and Boolean Operators

Before writing pseudocode, you need to understand the basic data types and how to compare values.

Primitive Data Types

  • INTEGER – a whole number (e.g., 1475, 0, -5)
  • REAL – a number with a decimal point (e.g., 56.75, 6.0, -2.456)
  • BOOLEAN – either TRUE or FALSE
  • CHAR – a single character (e.g., 'a', 'K', '4', '@')
  • STRING – a sequence of characters (e.g., "Jo Hobson", "123")

Boolean Operators

These operators compare two values and produce a TRUE or FALSE result:

  • > greater than
  • >= greater than or equal to
  • < less than
  • <= less than or equal to
  • = equal to
  • <> not equal to
Quick Check: Evaluate each expression:
35 >= 5 * 7 → True
'A' < 'B' → True
100 > 10^2 → False

📝 Introducing Pseudocode

Pseudocode is a structured English description of an algorithm. It focuses on logic, not syntax, and is written in a consistent style. You do not need to memorise exact syntax, but you should be clear and consistent.

Sequence

Statements are executed one after another, in order.

MealCost ← 4.00
DrinkCost ← 2.00
Total ← MealCost + DrinkCost

Selection (IF Statements)

Selection allows the program to branch based on a condition.

INPUT FruitAndVegEaten
IF FruitAndVegEaten >= 5
THEN
  OUTPUT "That's healthy"
ELSE
  OUTPUT "Eat more fruit & veg"
ENDIF

Switch/Case Statement

When there are several possible options, CASE OF is often clearer.

CASE OF OptionChosen
  1 : OUTPUT "You chose option 1"
  2 : OUTPUT "You chose option 2"
  3 : OUTPUT "You chose option 3"
  OTHERWISE : OUTPUT "Invalid choice"
ENDCASE

Assignment

Use the arrow ← to assign a value to a variable.

Total ← 0
Cost ← Adult * 2 + Child * 3
Counter ← Counter + 1

Input and Output

Use INPUT to receive data and OUTPUT to display it.

OUTPUT "How old are you?"
INPUT age

🧠 Trace the Pseudocode

Read the pseudocode and predict the output.

Trace 1: What is the final value of Total?

FOR Count ← 1 TO 4
  Total ← Total + Count
