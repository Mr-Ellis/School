Section 1: Data Packets & Packet Switching (Questions 1–22)
1Why is a large file broken down into packets before it is sent across a network?
  • Because packets are always encrypted
  • Because the file is too large to send in one piece
  • Because packets are faster than binary
  • Because routers cannot read large files
Answer: B — A large file is too big to send through a network in one piece, so it is split into packets.
2Which three sections make up every data packet?
  • Header, payload, trailer
  • Address, body, signature
  • Start, middle, end bits
  • Source, router, destination
Answer: A — Every packet contains a header, payload and trailer.
3Which of the following is NOT a component of the packet header?
  • Destination address
  • Originating (source) address
  • Packet number
  • Checksum
Answer: D — The checksum is in the trailer, not the header.
4What is the purpose of the destination address in a packet header?
  • To identify the computer or server the packet is being sent to
  • To identify the computer the packet came from
  • To show the order of the packet in the file
  • To check the packet for errors
Answer: A — The destination address identifies where the packet is going.
5What is the originating address also known as?
  • The destination address
  • The source address
  • The packet number
  • The checksum
Answer: B — The originating address is also called the source address.
6Why does a packet header include a packet number?
  • To count how many packets were sent
  • To determine the packet's place in the overall order so packets can be reordered
  • To show which router sent the packet
  • To calculate the checksum
Answer: B — The packet number lets the receiver reassemble packets in order.
7What is the payload of a packet?
  • The destination address
  • The actual data being sent — the fragments of the original file
  • The end-of-packet marker
  • The error-checking data
Answer: B — The payload is the actual contents being sent.
8What does the trailer of a packet contain?
  • The destination address and packet number
  • The payload only
  • An end-of-packet marker and error-checking data such as a checksum or CRC
  • The originating address
Answer: C — The trailer ends the packet and holds error-checking data.
9What is packet switching?
  • The process of encrypting packets before sending them
  • The process of sending data through a network by breaking it into packets and routing them independently
  • The process of storing packets on a server
  • The process of converting packets into binary
Answer: B — Packet switching sends data through a network in packets.
10In packet switching, what is the first step?
  • Reorder the packets
  • Break the data down into packets
  • Send the packets to the nearest router
  • Calculate the checksum
Answer: B — The file is first split into fragments.
11What do routers do during packet switching?
  • They store the packets permanently
  • They read the destination address and forward the packet to a closer router
  • They encrypt every packet
  • They reorder the packets before sending them on
Answer: B — Routers forward packets towards their destination.
12Why might packets arrive at the destination out of order?
  • Because routers deliberately scramble them
  • Because each packet can take a different route through the network, and some routes are faster than others
  • Because the sender sends them in the wrong order
  • Because the payload is encrypted
Answer: B — Different routes and timings can reorder packets.
13How does the destination computer reassemble packets into the correct order?
  • By using the destination address
  • By using the packet number
  • By using the checksum
  • By using the originating address
Answer: B — The packet number restores the correct sequence.
14What is the role of a server in a packet-switched network?
  • It directs packets between networks
  • It stores data and responds to requests from clients
  • It allows wireless devices to connect
  • It encrypts all data
Answer: B — Servers store data and respond to client requests.
15What is the role of a router in a network?
  • It stores web pages
  • It directs packets between networks, choosing the best route to the destination
  • It converts analogue signals to digital
  • It provides power to client devices
Answer: B — Routers choose the best route for packets.
16Which of the following is a client device?
  • A web server
  • A router
  • A smartphone
  • A Wi-Fi access point
Answer: C — Smartphones are client devices.
17What does a Wi-Fi access point and router allow?
  • It stores all network data permanently
  • It allows wireless devices to connect to the network and routes traffic between the LAN and the internet
  • It converts binary to denary
  • It encrypts all wireless traffic
Answer: B — It connects wireless devices and routes traffic.
18In the postal analogy, what does the address on a parcel represent in a data packet?
  • The payload
  • The header (destination address)
  • The trailer
  • The packet number
Answer: B — The address works like the header.
19Why is packet switching described as efficient and resilient?
  • Because all packets take the same route
  • Because packets can take different routes, so if one route is busy or fails, packets can still get through
  • Because packets are never lost
  • Because it uses no routers
Answer: B — Alternative routes make the network resilient.
20Which of the following is a common misconception about packets?
  • Packets contain a header, payload, and trailer
  • Packets always arrive in the order they were sent
  • Packets can take different routes
  • Packets contain a packet number
Answer: B — Packets can arrive out of order, so reordering is essential.
21A checksum is commonly replaced in real networks by which more reliable error check?
  • Parity bit
  • Cyclic redundancy check (CRC)
  • Check digit
  • Echo check
Answer: B — CRC is more reliable and commonly used.
22If a packet never arrives at the destination, what is this most likely to lead to?
  • The file is automatically complete
  • Retransmission of the missing packet
  • The network shuts down
  • The packet number is reused
Answer: B — A missing packet is retransmitted.
Section 2: Serial & Parallel Transmission (Questions 23–40)
23How many bits are sent at a time in serial transmission?
  • One bit at a time over a single wire
  • Four bits at a time
  • Eight bits at a time
  • All bits simultaneously
Answer: A — Serial sends one bit at a time over one wire.
24How does parallel transmission send data?
  • One bit at a time over a single wire
  • Multiple wires are used so many bits may be sent at the same time
  • Using radio waves only
  • By encrypting each bit
Answer: B — Multiple wires send many bits at once.
25What is crosstalk?
  • When signals arrive at slightly different times
  • When a signal on one wire creates a disturbance in another wire
  • When a packet is lost
  • When data is encrypted
Answer: B — Crosstalk is interference between wires.
26What is skew?
  • When signals arrive at slightly different times because each wire has slightly different properties
  • When a signal is too weak
  • When data is sent in one direction only
  • When packets are reordered
Answer: A — Skew is timing differences between wires.
27Which problem affects parallel transmission but NOT serial transmission?
  • Crosstalk and skew
  • Encryption
  • Packet loss
  • Checksums
Answer: A — Parallel suffers from crosstalk and skew.
28Why are serial cables cheaper to make than parallel cables?
  • Because they are made of plastic
  • Because they only need one wire, so they are smaller and use less material
  • Because they are shorter
  • Because they don't need connectors
Answer: B — One wire makes serial cheaper.
29Which of the following is an example of serial transmission?
  • Older PATA/IDE hard drive cables
  • USB
  • Parallel printer cables
  • CPU-to-RAM connections
Answer: B — USB is serial.
30Which of the following is an example of parallel transmission?
  • USB
  • Ethernet
  • Older PATA/IDE hard drive cables
  • Broadband internet
Answer: C — PATA/IDE cables are parallel.
31Why has parallel transmission largely been replaced by serial transmission for external cables?
  • Because serial avoids crosstalk and skew, and modern processors are fast enough to handle high serial speeds
  • Because parallel cannot send data
  • Because serial is always slower
  • Because parallel cables are too short
Answer: A — Serial avoids crosstalk/skew and is fast enough.
32Where is parallel transmission still commonly used inside a computer?
  • Between the CPU and RAM
  • Between the keyboard and computer
  • Between the computer and a printer
  • Over broadband internet
Answer: A — CPU-to-RAM is parallel.
33Historically, serial transmission was slower than parallel. Why is this no longer true?
  • Because modern processors are fast enough to handle high serial speeds
  • Because serial now uses crosstalk
  • Because parallel cables were banned
  • Because serial sends multiple bits at once
Answer: A — Faster processors enable high serial speeds.
34A serial, simplex cable sends data how?
  • Multiple bits at a time in both directions
  • One bit at a time in one direction only
  • One bit at a time in both directions simultaneously
  • Multiple bits at a time in one direction
Answer: B — Serial = one bit at a time; simplex = one direction.
35Which transmission method is used by SATA hard drives?
  • Serial
  • Parallel
  • Simplex only
  • Half-duplex only
Answer: A — SATA is serial.
36Which transmission method suffers from skew?
  • Serial
  • Optical fibre
  • Parallel
  • Wireless
Answer: C — Skew affects parallel transmission.
37Why does parallel transmission need thicker cables?
  • Because it uses higher voltage
  • Because it needs many more wires
  • Because it is encrypted
  • Because it is wireless
Answer: B — More wires make parallel cables thicker.
38Which is an advantage of serial over parallel over long distances?
  • It avoids crosstalk and skew
  • It sends multiple bits at once
  • It is always cheaper per bit
  • It uses no connectors
Answer: A — Serial is reliable over long distances.
39A parallel, full-duplex cable sends data how?
  • One bit at a time in one direction
  • One bit at a time in both directions
  • Multiple bits at a time in one direction
  • Multiple bits at a time in both directions simultaneously
Answer: D — Parallel = many bits; full-duplex = both directions at once.
40Which statement about serial transmission is correct?
  • It always uses multiple wires
  • It sends one bit at a time over a single wire
  • It suffers from crosstalk
  • It cannot be used over long distances
Answer: B — Serial sends one bit at a time over one wire.
Section 3: Simplex, Half-Duplex, Full-Duplex & USB (Questions 41–52)
41What type of transmission is used by a keyboard sending data to a computer?
  • Simplex
  • Half-duplex
  • Full-duplex
  • Parallel
Answer: A — A keyboard sends one way only (simplex).
42What type of transmission is used by walkie-talkies?
  • Simplex
  • Half-duplex
  • Full-duplex
  • Parallel
Answer: B — Walkie-talkies are half-duplex.
43Which transmission allows data to travel in both directions simultaneously?
  • Simplex
  • Half-duplex
  • Full-duplex
  • Serial
Answer: C — Full-duplex sends both ways at once.
44How many cables (or fibres) does a full-duplex connection require?
  • One
  • Two
  • Four
  • Eight
Answer: B — Full-duplex needs two connections.
45Which is a disadvantage of simplex transmission?
  • It cannot send and receive
  • It requires two cables
  • It is the most expensive
  • It is the fastest
Answer: A — Simplex travels one way only.
46Which is an advantage of half-duplex?
  • Data can travel both ways simultaneously
  • Both devices can send and receive
  • It needs no cables
  • It is always faster than full-duplex
Answer: B — Half-duplex allows both devices to send and receive, one at a time.
47What does USB stand for?
  • Universal System Bus
  • Unified Serial Bridge
  • Universal Serial Bus
  • Universal Serial Bridge
Answer: C — Universal Serial Bus.
48What is the maximum recommended length for a USB connection before a hub is needed?
  • 1 metre
  • 5 metres
  • 10 metres
  • 50 metres
Answer: B — USB cables should be no longer than 5 m before a hub.
49Why is USB not used for internal devices such as the CPU and hard drive?
  • It is not fast enough
  • It is too expensive
  • It cannot be hot-swapped
  • It uses too much power
Answer: A — Internal devices need much higher speeds (e.g. DDR4 RAM).
50What term describes the ability to plug in or remove a USB cable whilst the device is turned on?
  • Plug-and-play
  • Warm-swappable
  • Cold-swappable
  • Hot-swappable
Answer: D — USB is hot-swappable.
51Which is a benefit of USB?
  • It requires screws to attach
  • No screws needed — simple connector
  • It only works with one device type
  • It is slower than older serial ports
Answer: B — USB uses a simple connector with no screws.
52Which analogy matches full-duplex?
  • Cars sent along a one-way road, one car at a time
  • Cars travel in both directions, but only one direction at a time
  • Cars travel in both directions at the same time
  • A motorway with 8 lanes, multiple cars at the same time
Answer: C — Full-duplex = both directions at once.
Section 4: Error Detection (Questions 53–72)
53What can interference during transmission cause?
  • Data loss only
  • Data gain only
  • Data change only
  • Data loss, gain, or change
Answer: D — Interference can lose, add, or change bits.
54In a parity check, what do the sender and receiver agree?
  • The checksum algorithm
  • Whether to use even or odd parity
  • The packet number
  • The encryption key
Answer: B — They agree on even or odd parity.
55For even parity, the number of 1s including the parity bit must be…
  • Even
  • Odd
  • Zero
  • Always 8
Answer: A — Even parity means an even number of 1s.
56What is a limitation of a single parity check?
  • It cannot detect one changed bit
  • It cannot be used with bytes
  • It cannot detect an even number of bit changes
  • It requires a checksum
Answer: C — Two bit flips keep the parity the same.
57What can a parity block check do that a single parity check cannot?
  • Encrypt the data
  • Locate a single-bit error
  • Compress the data
  • Send an acknowledgement
Answer: B — The crossing row and column pinpoint the error.
58How does a checksum detect errors?
  • The recalculated checksum does not match the one sent
  • The parity bit is wrong
  • The packet number is missing
  • The data is echoed back
Answer: A — The receiver recalculates and compares.
59In an echo check, what does the receiver do?
  • Recalculates the checksum
  • Adds a parity bit
  • Sends an ACK
  • Sends a copy of the data back to the sender
Answer: D — The receiver echoes the data back.
60What is a limitation of an echo check?
  • It cannot detect errors
  • Every piece of data is sent twice
  • It requires encryption
  • It only works with parity
Answer: B — Sending twice takes more time and bandwidth.
61What is a check digit?
  • A bit added to each byte
  • A number sent with the data
  • An extra digit calculated from the other digits
  • A packet number
Answer: C — A check digit is calculated from the other digits.
62Which errors are check digits designed to catch?
  • Typing one digit incorrectly, swapping digits, missing/extra digits
  • Only transmission interference
  • Only encrypted data errors
  • Only packet loss
Answer: A — Check digits catch common data entry errors.
63Where are check digits used?
  • In USB cables
  • In routers
  • In parity blocks
  • In ISBNs and barcodes
Answer: D — ISBNs and barcodes use check digits.
64What is the purpose of a check digit in a number such as a barcode or ISBN?
  • To encrypt the number so it cannot be read
  • To detect errors made when the number is entered or transmitted
  • To show which country the product comes from
  • To count how many digits the number contains
Answer: B — A check digit is calculated from the other digits so that a mistyped or swapped digit can be detected.
65Which type of data entry error is a check digit designed to catch?
  • A number being sent over a wireless connection
  • Two digits being typed the wrong way round (a transposition error)
  • A file being compressed before it is stored
  • A packet arriving out of order
Answer: B — Check digits catch typing mistakes such as a wrong digit, a transposition error (45 instead of 54), or a missing/extra digit.
66What does ARQ stand for?
  • Automatic Repeat Query
  • Automatic Retransmission Queue
  • Applied Repeat Query
  • Automatic Request Query
Answer: A — Automatic Repeat Query.
67What does the receiver send if a packet is correct?
  • A NACK
  • A positive acknowledgement (ACK)
  • A checksum
  • A parity bit
Answer: B — A correct packet gets an ACK.
68What does the receiver send if a packet has an error?
  • An ACK
  • A checksum
  • A negative acknowledgement (NACK)
  • A parity block
Answer: C — An error triggers a NACK.
69What happens if the sender receives no acknowledgement before the timeout?
  • It stops sending
  • It sends the next packet
  • It encrypts the packet
  • It resends the packet automatically
Answer: D — A timeout causes automatic retransmission.
70Which error detection method can automatically recover from an error?
  • Parity check
  • ARQ
  • Echo check
  • Check digit
Answer: B — ARQ retransmits automatically.
71Which method is used for data entry rather than transmission?
  • Check digit
  • Parity check
  • Checksum
  • ARQ
Answer: A — Check digits are for data entry.
72Which method pinpoints the location of a single-bit error?
  • Parity check
  • Checksum
  • Parity block check
  • Echo check
Answer: C — The parity block check locates the bit.
Section 5: Encryption (Questions 73–85)
73What is plaintext?
  • The original, readable data before encryption
  • The scrambled data after encryption
  • The encryption key
  • The private key
Answer: A — Plaintext is readable data before encryption.
74What is ciphertext?
  • The original readable data
  • The scrambled data produced after encryption
  • The public key
  • The checksum
Answer: B — Ciphertext is the encrypted, scrambled data.
75What is the purpose of encryption?
  • To speed up transmission
  • To compress data
  • To keep data confidential while it is transmitted
  • To detect errors
Answer: C — Encryption keeps transmitted data confidential.
76Does encryption stop data being intercepted?
  • Yes, completely
  • No — it makes intercepted data unreadable
  • Only for wireless data
  • Only for text data
Answer: B — Encryption scrambles data but does not prevent interception.
77In symmetric encryption, how many keys are used?
  • One key, used to encrypt and decrypt
  • Two keys: public and private
  • Three keys
  • No keys
Answer: A — Symmetric uses one shared key.
78What is the main weakness of symmetric encryption?
  • It is too slow
  • It cannot encrypt data
  • It requires two keys
  • The key distribution problem — the shared key could be intercepted
Answer: D — Sharing the key safely is difficult.
79In asymmetric encryption, which key encrypts data?
  • The shared key
  • The public key
  • The private key
  • The session key
Answer: B — The public key encrypts.
80In asymmetric encryption, which key decrypts data?
  • The public key
  • The shared key
  • The private key
  • The session key
Answer: C — The private key decrypts.
81Why is a public key safe to share?
  • It can only encrypt, not decrypt
  • It is too long to copy
  • It changes every second
  • It is encrypted itself
Answer: A — The public key cannot decrypt anything.
82Why does asymmetric encryption solve the key distribution problem?
  • Because keys are never used
  • Because the private key is never sent anywhere
  • Because the public key is secret
  • Because it is faster than symmetric
Answer: B — The private key never leaves its owner.
83Which protocol uses asymmetric encryption for secure websites?
  • FTP
  • SMTP
  • HTTPS
  • HTTP
Answer: C — HTTPS uses asymmetric encryption.
84Why is symmetric encryption often used for the bulk of data after an asymmetric key exchange?
  • It is faster
  • It is more secure
  • It needs no key
  • It cannot be intercepted
Answer: A — Symmetric encryption is faster.
85Which statement about symmetric vs asymmetric is correct?
  • Symmetric uses two keys; asymmetric uses one
  • Asymmetric is always faster than symmetric
  • Both use exactly the same key type
  • Symmetric is faster; asymmetric solves key sharing
Answer: D — Symmetric is faster; asymmetric solves key distribution.
