A1.1 Revision Guide: Computer Architecture

This revision guide covers the fundamental hardware components of a computer system, how they communicate, and how data is managed and stored.

1. The CPU (Central Processing Unit)

The CPU is the "brain" of the computer. It processes instructions and manages the flow of data. It consists of three main parts:

  • The Control Unit (CU): Directs the flow of data between the components and decodes instructions.
  • The Arithmetic Logic Unit (ALU): Performs mathematical calculations (add, subtract) and logical operations (AND, OR, NOT).
  • Registers: Tiny, ultra-fast memory locations inside the CPU.
Key Registers to Know:
• Program Counter (PC): Holds the memory address of the next instruction.
• Memory Address Register (MAR): Holds the address of the data currently being fetched.
• Memory Data Register (MDR): Holds the actual data fetched from memory.
• Accumulator (ACC): Stores the result of calculations from the ALU.
• Current Instruction Register (CIR): Holds the instruction currently being decoded and executed.

The Fetch-Decode-Execute Cycle (FDE)

The CPU repeats this cycle billions of times a second:

  1. Fetch: The address in the PC is copied to the MAR. The instruction at that address is fetched into the MDR, then copied to the CIR. The PC increments to point to the next instruction.
  2. Decode: The Control Unit decodes the instruction in the CIR to determine what needs to be done.
  3. Execute: The instruction is carried out. This might involve the ALU doing a calculation, or reading/writing data to memory.

2. GPU Architecture (Graphics Processing Unit)

While a CPU has a few, highly complex cores designed for sequential tasks, a GPU has thousands of simpler cores designed to work in parallel.

  • Purpose: To handle the massive mathematical calculations required for rendering images, video, and 3D graphics.
  • Parallel Processing: Because a GPU has thousands of cores, it can process many pieces of data at the exact same time (e.g., calculating the colour of every pixel on a 4K screen simultaneously).

3. Memory (RAM & ROM)

Memory is split into Primary (direct CPU access) and Secondary (long-term storage).

Feature RAM (Random Access Memory) ROM (Read-Only Memory)
Volatility Volatile (loses data when power is off) Non-volatile (keeps data without power)
Read/Write Read and Write (changes constantly) Read-only (cannot be changed by user)
Purpose Stores currently running programs and open files. Stores the BIOS / boot-up instructions.

Cache Memory

Cache is an extremely fast type of memory built into or very close to the CPU. It stores frequently used instructions to reduce the need to fetch them from the slower RAM.

4. Secondary Storage

Secondary storage is non-volatile long-term storage for files, software, and the OS.

  • Magnetic (HDD): Uses spinning disks and magnetic heads. Cheap, high capacity, but slow and easily damaged.
  • Solid State (SSD): Uses flash memory (no moving parts). Extremely fast, silent, and durable, but more expensive than HDDs.
  • Optical: Uses lasers (CD, DVD, Blu-ray). Used for media distribution.

5. Data Compression

Compression reduces the file size to save storage space and speed up transmission.

  • Lossless Compression (e.g., ZIP, PNG): Reduces file size by finding patterns and storing them more efficiently. All original data is preserved, so the file can be perfectly restored.
  • Lossy Compression (e.g., MP3, JPEG): Permanently removes data that the human eye or ear is unlikely to notice. It results in much smaller files but the original quality cannot be recovered.
Exam Tip: If an exam question asks why a file should use lossless compression, the answer is usually because the data must remain perfectly intact (e.g., a text document, or a medical scan). Lossy is best for media where slight quality loss is acceptable (e.g., streaming music).

6. Cloud Computing

Cloud computing is the delivery of computing services (storage, servers, software) over the internet.

  • Advantages: Accessible from anywhere, scalable (pay for what you use), no need to maintain physical hardware.
  • Disadvantages: Relies heavily on a stable internet connection, potential security/privacy risks, ongoing subscription costs.

7. Pipelining (HL Only)

A technique used in CPUs to improve performance. Instead of waiting for one instruction to completely finish the FDE cycle before starting the next, the CPU begins fetching the next instruction while decoding the current one. This dramatically speeds up processing time.
