🔑 Key Terms (quick)

ALU – arithmetic & logic CU – decodes, controls PC – next instruction address IR – current instruction MAR – address (where) MDR – data (what) AC – ALU results Address bus → one way Data bus ↔ two way Control bus ↔ signals

📋 Component Reference (from eBook)

ComponentFunction
ALUArithmetic (add, sub, mul, div) and logical (AND, OR, NOT, comparisons).
Control Unit (CU)Fetches & decodes instructions; sends control signals. Processes no data itself.
Program Counter (PC)Holds address of next instruction to fetch.
Instruction Register (IR)Holds instruction currently being decoded & executed.
Memory Address Register (MAR)Holds memory address about to be accessed (where).
Memory Data Register (MDR)Holds data read from / written to memory (what).
Accumulator (AC)Holds intermediate results of ALU operations.
Address BusCarries addresses CPU → memory. One direction.
Data BusCarries data between CPU and memory. Both directions.
Control BusCarries control/timing signals between CU and components.
Single-coreOne core; one instruction stream at a time.
Multi-coreSeveral cores on one chip; threads run in parallel.
Co-processorSpecialist (GPU, FPU) offloads specific work from main CPU.
