A1.1.1 – CPU Architecture

📌 Learning Objective

By the end of this lesson, you will be able to:

  • Describe the functions and interactions of the main CPU components
  • Identify the roles of the ALU, CU, registers, and buses
  • Explain the difference between single-core, multi-core and co-processors
  • Draw and label a diagram showing the relationship between CPU components

🎯 IB Command Term: Describe

Describe – "Give a detailed account. For each component: state what it is, what it holds or does, and how it connects to the other components."

🔑 Key Terms

ComponentFunction
ALUPerforms arithmetic (add, subtract, multiply, divide) and logical operations (AND, OR, NOT, comparisons).
Control Unit (CU)Fetches and decodes instructions; sends control signals directing other components. Processes no data itself.
Program Counter (PC)Holds the address of the next instruction to be fetched.
Instruction Register (IR)Holds the instruction currently being decoded and executed.
Memory Address Register (MAR)Holds the memory address about to be accessed (where).
Memory Data Register (MDR)Holds the data read from or being written to memory (what).
Accumulator (AC)Holds intermediate results of ALU operations.
Address BusCarries addresses from CPU to memory. One direction.
Data BusCarries data between CPU and memory. Both directions.
Control BusCarries control and timing signals between CU and other components.
Single-coreOne core; one instruction stream at a time.
Multi-coreSeveral cores on one chip; threads run in parallel.
Co-processorSpecialist (GPU, FPU) that offloads specific work from the main CPU.

📌 EXAM TIP: When drawing the diagram, the directions of the buses are easy marks to gain or lose. The address bus arrow points one way only (CPU → RAM). The data bus and control bus arrows point both ways. A diagram with three identical double-headed arrows tells the examiner you have memorised a shape, not understood the system.
