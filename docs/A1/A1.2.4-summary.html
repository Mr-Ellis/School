A1.2.4 – Construct and Analyse Truth Tables

📌 Learning Objective

By the end of this lesson, you will be able to:

  • Construct a truth table for any logic circuit or Boolean expression
  • Work out how many rows a truth table needs using the \(2^n\) rule
  • Use intermediate columns to break a multi-gate circuit into manageable steps
  • Analyse a completed truth table to describe what a circuit does

🎯 IB Command Term: Construct

Construct – “To build or make by fitting together separate parts.”

In this context, constructing means systematically building the table: counting the inputs, listing every combination, adding columns for intermediate signals, and only then working out the final output. Skipping steps is how mistakes creep in.

🔑 Key Terms

TermDefinition
Truth tableA table that lists every possible combination of inputs to a logic circuit and the output that each combination produces.
Input combinationOne specific pattern of 0s and 1s on the input lines. With two inputs there are four combinations; with three there are eight.
RowOne line of the truth table, representing one input combination and its corresponding output.
Intermediate columnA column added partway across the table to record the output of an inner gate before the final output is calculated.
Boolean expressionA way of writing a logic rule using operators such as AND, OR and NOT — for example, \(Q = (A \text{ AND } B) \text{ OR NOT } C\).
\(2^n\) ruleFor \(n\) inputs, a truth table needs \(2^n\) rows, because each input can be either 0 or 1.

📊 What a Truth Table Actually Does

A truth table is the complete answer for a logic circuit. If you know the truth table, you know exactly what the circuit outputs for every possible input—there is nothing left to discover[reference:0]. That is why exam questions ask you to construct one: it proves you understand the circuit, not just that you can name the gates inside it.

The table has two parts:

  • Input columns on the left — one column per input variable (A, B, C, …).
  • Output column on the right — the final result. If the circuit produces more than one output (like a half adder’s Sum and Carry), there will be more than one output column.
The one rule you must never break

A truth table must include every possible input combination — including the all-zero row[reference:1]. If a row is missing, the table is incomplete and cannot be used to analyse the circuit.

🔢 Step 1: Work Out How Many Rows You Need

Each input can be either 0 or 1. So the number of possible combinations doubles each time you add another input:

Number of inputs (\(n\))CalculationRows needed
1\(2^1\)2
2\(2^2\)4
3\(2^3\)8
4\(2^4\)16

This is called the \(2^n\) rule, and you will see it stated in almost every textbook[reference:3]. For three inputs, for example, there are eight combinations: 000, 001, 010, 011, 100, 101, 110, 111.

A pattern to make the listing easy

When you list the input combinations, the rightmost column alternates every row (0, 1, 0, 1…), the next column alternates every two rows (0, 0, 1, 1…), and the next every four rows (0, 0, 0, 0, 1, 1, 1, 1…). Following this pattern guarantees you cover every combination without repeats.

🧮 Worked Example 1: A Simple Two-Input Circuit

Suppose a circuit has inputs A and B, and the output Q is produced by an AND gate whose output then goes through a NOT gate. In Boolean notation: \(Q = \text{NOT}(A \text{ AND } B)\).

Step 1 — Count the inputs and draw the skeleton

There are two inputs, so we need \(2^2 = 4\) rows. Draw the table with columns for A, B, and Q:

ABQ
00
01
10
11

Step 2 — Add an intermediate column

Q is not produced by a single gate—it is produced by an AND gate followed by a NOT. Trying to work out Q directly is where mistakes happen. Instead, add a column for the AND gate’s output, which we will call X:

ABX (A AND B)Q (NOT X)
00
01
10
11

Step 3 — Fill the intermediate column first

Work through the AND gate row by row. X is 1 only when both A and B are 1:

ABX (A AND B)Q (NOT X)
000
010
100
111

Step 4 — Apply the NOT gate to finish

Now invert every value in the X column to get Q:

ABX (A AND B)Q (NOT X)
0001
0101
1001
1110

That is the complete truth table. If you recognise the output column 1, 1, 1, 0, you have just built a NAND gate out of an AND and a NOT—which is exactly what a NAND gate is internally.

Why the intermediate column matters

If you tried to jump straight from A and B to Q, you would be doing two mental operations at once. The intermediate column lets you check each gate separately, so an error is easy to spot and fix[reference:5].

🧮 Worked Example 2: A Three-Input Circuit

Now a harder one. The Boolean expression is:

\(Q = (A \text{ AND } B) \text{ OR } (\text{NOT } C)\)

Step 1 — Count the inputs

There are three inputs (A, B, C), so we need \(2^3 = 8\) rows.

Step 2 — Identify the intermediate parts

The expression has two bracketed parts that are combined by the final OR. So we need two intermediate columns:

  • X = A AND B
  • Y = NOT C

Then the final output is Q = X OR Y.

Step 3 — Build the skeleton and fill the inputs

Use the alternation pattern for the inputs: C alternates every row, B every two rows, A every four rows.

ABCX (A AND B)Y (NOT C)Q (X OR Y)
000
001
010
011
100
101
110
111

Step 4 — Fill X and Y

X = A AND B: 1 only when A and B are both 1 (the bottom two rows).

Y = NOT C: the opposite of C in every row.

ABCX (A AND B)Y (NOT C)Q (X OR Y)
00001
00100
01001
01100
10001
10100
11011
11110

Step 5 — Apply the final OR

Q is 1 whenever either X or Y is 1:

ABCX (A AND B)Y (NOT C)Q (X OR Y)
000011
001000
010011
011000
100011
101000
110111
111101

Now you can analyse the table. Look at the Q column: the only row where Q is 0 is when A=0, B=0, C=1. Every other combination produces a 1. That tells you something useful about the circuit: it outputs 0 only when both A and B are off and C is on.

🔌 Building a Table From a Circuit Diagram

Exam questions often give you a circuit diagram rather than a Boolean expression. The method is the same, but you have to work out the intermediate signals by tracing the wires:

1
Label every gate’s output. Give each gate output a name (X, Y, Z…) and add a column for it. This is exactly the same idea as the intermediate columns above.
2
Work left to right. Fill in the columns for gates closest to the inputs first. A gate cannot be evaluated until the signals feeding into it have been worked out.
3
Finish with the output gate. The last column is the circuit’s actual output. If the final gate is an AND gate, the output can only be 1 when every input to that gate is 1[reference:7].

⚠️ Common Mistakes to Avoid

Where marks are usually lost
  • Too few rows. Three inputs need eight rows, not six or seven. Use \(2^n\) before you draw anything.
  • Repeating an input combination. Every row must be different. Follow the alternation pattern to avoid duplicates.
  • Jumping straight to the output. With more than one gate, always add an intermediate column. It is worth marks and it prevents errors[reference:8].
  • Forgetting the all-zero row. 000 is a valid input combination and must be included[reference:9].
  • Inverting the wrong thing. NOT binds to whatever is immediately to its right. In NOT A AND B, the NOT applies only to A, not to the whole expression.
