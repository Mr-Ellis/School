💡 The Big Idea — System Integrity

An OS's functions are the concrete services that put its resource-management role into practice. Their overarching purpose is to maintain system integrity:

System integrity – the state where a computer system operates correctly and securely, free from unauthorised changes or corruption.

Without these functions, one malfunctioning driver or runaway process could destabilise the entire system.

🧠 Memory Management Manages RAM and virtual memory
Allocates memory space for each process, protects processes from each other, and uses virtual memory to extend apparent RAM capacity when physical memory runs out.

📁 File System Organises files and directories
Provides a hierarchical structure for storing and retrieving data. Handles creation, reading, writing, renaming, moving and deleting files. Enforces naming rules and permissions. Performs defragmentation on HDDs.

🖨️ Device Management Controls hardware via drivers
Uses device drivers to communicate with hardware (printers, keyboards, network cards). Manages I/O using buffering, caching and spooling. Supports Plug and Play for automatic device setup.

⏱️ Scheduling Decides which process runs next
The scheduler allocates CPU time to processes, ensuring efficient and fair use. Crucial for multitasking — implements algorithms like FCFS, round robin, priority and multilevel queue. Covered in detail in A1.3.3.

🔒 Security Protects data and resources
Authenticates users (passwords, biometrics, tokens), enforces access control, encrypts files and communications, audits system activity, and protects against malware (viruses, worms, trojans).

📊 Accounting Tracks resource usage
Monitors CPU, memory, disk and network usage by users and processes. Supports quotas, performance monitoring, auditing, and billing on shared or cloud systems.

🖥️ GUI User-friendly visual interface
Provides windows, icons, menus and pointers (WIMP). Handles application management (task switching, window snapping), file management (File Explorer), accessibility (screen readers), visual feedback and customisation.

📦 Virtualisation Runs multiple VMs on one machine
Uses a hypervisor to run multiple virtual machines on a single physical machine. Each VM has its own OS. Benefits: isolation, snapshots, live migration, disaster recovery, cloud scaling.

Establishes and maintains network connections, configures network interfaces, assigns IP addresses via DHCP, and implements protocols like TCP/IP. Handles error checking, flow control and congestion avoidance.

🔄 Device Management — Flip the Cards

The OS uses three key I/O techniques to handle data flow between devices. Click each card to flip it.

📥 Buffering Click to flip
Temporarily stores data in memory while it is transferred between two devices. Manages differences in data-flow rates (e.g. slow printer vs fast CPU).
⚡ Caching Click to flip
Stores frequently accessed data in a high-speed storage area (cache) to reduce access time and improve overall system performance.
📄 Spooling Click to flip
Queues data or tasks (typically for printers) so they process sequentially at their own pace, letting the system work on other tasks meanwhile.

🔍 Scenario Explorer — Which Functions Are at Work?

For each scenario, click the question to reveal the functions involved.

📄 Printing a 50-page document
  • Device management — the print job is spooled so the CPU can do other work while the printer processes pages at its own pace.
  • File system — reads the document from disk to send to the printer.
  • Scheduling — gives the print process a share of CPU time alongside other tasks.
  • Memory management — buffers pages of the document in RAM before sending.
  • Security — checks that the user has permission to print.
💾 Plugging in a new USB drive and copying files to it
  • Device management — Plug and Play detects the USB drive and loads the appropriate driver automatically.
  • File system — reads the drive's file table, allows copying files to it, and enforces naming rules.
  • Memory management — buffers file data during transfer.
  • Security — may enforce permission checks on both source and destination.
🎬 Running out of RAM while editing a video
  • Memory management — swaps less-active pages out to disk as virtual memory, keeping the most-needed pages in RAM.
  • Scheduling — prioritises the video editor so its pages stay in RAM.
  • File system — the swap file on disk is managed by the file system.
  • Accounting — logs the memory usage, which is why Task Manager can show you which process is hogging RAM.

Effect: the editor slows down noticeably — RAM is much faster than disk, so virtual memory is a fallback, not a substitute.

🔐 Logging in to a school computer and opening a network drive
  • Security — authenticates your credentials and applies your access permissions.
  • Networking — establishes the connection to the network drive and handles file transfer over TCP/IP.
  • File system — mounts the network drive as if it were a local folder.
  • Accounting — logs your login event and resource usage for auditing.
  • GUI — renders the login screen and displays the network drive in File Explorer.
