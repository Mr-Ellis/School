💡 The Big Idea — What Is a Control System?

A control system is a set of components that work together to manage, command, direct or regulate the behaviour of another system or device so that it achieves a desired outcome.

A control system takes an input (from a sensor), processes it against a target value (the set point), and produces an output (via an actuator) to bring the system back to the desired state. Feedback continuously updates the controller so it can adjust in real time.

🧩 The Core Components

Click any card to reveal the role of that component.

🧠 Controller Click to flip
Role: The "brain" of the system. It receives input from sensors, compares it against the set point, and decides what action to take.

Example: The thermostat chip that decides whether to turn heating on or off.
📡 Sensor Click to flip
Role: Detects a physical quantity (temperature, light, motion, pressure) and sends that data to the controller.

Example: A temperature sensor in a thermostat, or a PIR motion sensor in a security light.
⚙️ Actuator Click to flip
Role: Carries out the controller's decision by physically changing something in the system — moving a part, opening a valve, switching a current.

Example: A motor that opens a door, or a relay that switches on a heating element.
🔁 Transducer Click to flip
Role: Converts one form of energy into another — often a physical quantity into an electrical signal (or vice versa) so the controller can read it or the actuator can act on it.

Example: A microphone (sound → electrical) or a speaker (electrical → sound).
🔄 Feedback Loop Click to flip
Role: Continuously feeds the current state of the system back to the controller so it can compare with the set point and adjust. This is what makes a system closed-loop.

Example: The thermostat re-reading the room temperature every few seconds.
🎯 Set Point Click to flip
Role: The target value the system is trying to achieve or maintain (e.g. 21 °C, 60% soil moisture).

Example: The temperature you dial into a thermostat, or the flow rate a traffic controller is aiming for.

🛠️ Open-Loop vs Closed-Loop

Feature Open-Loop Closed-Loop
Feedback? No — the controller never checks the result. Yes — the output is measured and fed back.
Accuracy Lower — any error or disturbance goes uncorrected. Higher — the system self-corrects.
Complexity Simple and cheap. More complex (needs sensors + feedback logic).
Example A toastie maker that runs for a fixed time. A thermostat, cruise control, irrigation system.
Best for Simple, predictable tasks where the environment doesn't change much. Complex, dynamic environments with disturbances.

🏠 Real-World Applications

Click any card to see how each system uses the components. These are the systems you need to know for the exam.

🌡️ Home Thermostat Click to flip
Sensor: Temperature sensor continuously monitors the room.
Controller: Compares the current temperature to the set point.
Actuator: Switches the heating or cooling on/off.
Feedback: Sensor re-reads the temperature after each change.
Type: Closed-loop.
🛗 Automatic Elevator Click to flip
Sensors: Position sensors, floor-request buttons, door-status sensors.
Controller: Decides whether to move up/down, stop, or open doors.
Actuators: The motor that moves the elevator and the door mechanism.
Feedback: Position and speed sensors keep the controller updated in real time.
Type: Closed-loop.
🚗 Autonomous Vehicle Click to flip
Sensors: Cameras, LiDAR, radar, GPS — gather data about obstacles, road and traffic.
Controller: AI algorithms decide speed, direction and braking.
Actuators: Steering, throttle and brakes.
Transducers: Convert sensor readings into signals and controller commands into physical actions.
Feedback: Continuous re-scanning of the environment.
Type: Closed-loop.
🧺 Washing Machine Click to flip
Sensors: Water-level, load-size and cycle-progress sensors.
Controller: Decides when to fill, agitate, drain and spin.
Actuators: Water inlet valve, drum motor, drain pump.
Feedback: Water-level sensor tells the controller when to stop filling; load sensor adjusts spin intensity.
Type: Closed-loop.
🚦 Traffic Signals Click to flip
Sensors: Vehicle-detection loops, pedestrian buttons, sometimes cameras.
Controller: Determines timing and sequence of red/amber/green.
Actuators: The lights themselves.
Feedback: Sensors report current traffic, so the controller can extend a green light or trigger a pedestrian crossing.
Type: Closed-loop.
💧 Irrigation System Click to flip
Sensors: Soil-moisture, weather and time-of-day sensors.
Controller: Decides when and how much water to deliver.
Actuators: Water pumps and valves.
Feedback: Moisture sensors update the controller — water stops when the desired level is reached.
Type: Closed-loop.
🔐 Home Security Click to flip
Sensors: Door/window contacts, motion detectors, cameras.
Controller: Assesses whether there's a threat and decides the response.
Actuators: Sirens, door locks, cameras, notifications to the owner.
Feedback: Sensors continuously report the state of the home so the controller can react instantly.
Type: Closed-loop.
🚪 Automatic Doors Click to flip
Sensors: Infrared motion detectors or pressure mats.
Controller: Decides when to open or close the doors.
Actuators: The motor that moves the door.
Feedback: Sensors keep checking for presence — doors close only when no one is detected.
Type: Closed-loop.
