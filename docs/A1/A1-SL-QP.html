Instructions to Students
Answer all questions. Write your answers in the spaces provided. The number of marks is shown in brackets [ ] after each question or part. No calculators permitted. Section C contains longer-response questions — plan your answer before writing.

Section A — CPU, GPU and Primary Memory (24 marks)

1. Describe the difference in function between the instruction register (IR) and the memory data register (MDR). [4]

2. Explain why ROM rather than RAM is used to store the instructions a computer needs at startup. [2]

3. A computer has a small amount of cache memory.

(a) Explain the difference between a cache hit and a cache miss. [2]

(b) Explain why a higher cache hit rate improves system performance. [2]

4. Describe how the architecture of a GPU makes it suitable for training a machine learning model. [3]

5. A video game is being rendered. Explain why a GPU renders a frame faster than a CPU could, even though each GPU core is simpler than a CPU core. [3]

6. Explain how the CPU and GPU divide and coordinate their work when training a machine learning model. [4]

7. Describe the role of the address bus and the data bus during the fetch stage. [2]

8. Describe the steps the CPU performs during the fetch stage of the fetch–decode–execute cycle. [4]

9. Outline what happens during the decode stage. [2]

Section B — Secondary Memory, Compression and Cloud (20 marks)

10. Describe two differences between internal and external secondary memory storage. [2]

11. Describe the characteristics of an SSD and state one reason it is preferred to an HDD for storing an operating system. [3]

12. Outline one difference between lossy compression methods and lossless compression methods. [2]

13. Apply run-length encoding to the string AAAAAABBBBCCD. State the encoded string and the number of characters before and after encoding. [3]

14. A student records a podcast and saves it as an MP3 file. Describe how transform coding reduces the size of the audio file. [4]

15. Describe what is meant by platform as a service (PaaS). [2]

16. A start-up is deciding between SaaS and IaaS for its new customer-booking system. Describe one advantage and one disadvantage of each model in this scenario. [4]

Section C — Operating Systems (16 marks)

17. Compare first-come first-served and round robin scheduling. [4]

18. Evaluate the use of polling and interrupt handling for taking input from a keyboard on a battery-powered laptop. [6]

19. A system has multiple processes running. Explain one way the operating system can prevent deadlock from occurring. [3]

20. Describe how an operating system manages memory using paging, and explain one benefit of this approach. [3]
