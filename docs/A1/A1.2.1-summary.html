A1.2.1 – Data Representation 1

📌 Learning Objective

By the end of this lesson, you will be able to:

  • Describe the principal methods of representing data — binary, hexadecimal, octal, and ASCII/Unicode
  • Explain why computers use binary rather than denary
  • Convert between binary, denary, hexadecimal, and octal
  • Describe how characters are represented, and why Unicode extends ASCII

🎯 IB Command Term: Describe

Describe – "Give a detailed account."

Naming the four methods is not describing them. This lesson builds the skill of giving a detailed account of what each method is, which base it uses, and where and why it is used.

🔑 Key Terms

TermDefinition
BitA single binary digit — 0 or 1
Nibble4 bits; corresponds to exactly one hexadecimal digit
Byte8 bits; the standard unit of storage
BinaryBase-2 representation, using only the digits 0 and 1
DenaryBase-10 representation, using digits 0–9 (the human default)
HexadecimalBase-16 representation, using 0–9 and A–F
OctalBase-8 representation, using digits 0–7
ASCIIA 7-bit character code representing 128 characters
UnicodeAn extended character encoding covering the world's scripts and symbols

📊 The Principal Methods of Representation

MethodBaseDigits usedWhy it is used
Binary20, 1Matches the two physical states of a transistor (on / off)
Octal80–7Compact shorthand for binary — 1 octal digit = 3 bits
Hexadecimal160–9, A–FCompact shorthand for binary — 1 hex digit = 1 nibble. Used for colours, memory addresses, MAC addresses
ASCII—7-bit codesStandard character encoding for English / Latin text
Unicode—UTF-8 / UTF-16Represents all world languages, symbols and emoji

Why computers use binary

A processor is built from transistors, each of which has two stable electrical states — effectively on and off. Two states map naturally onto two digits, so base 2 is all the hardware needs to distinguish.

Denary is not technically superior — it is a historical accident of humans having ten fingers. Any base can be converted into any other, which is why hexadecimal and octal are simply human-friendly shorthand for the underlying binary.
