Why computers use binary

A processor is built from transistors, each of which has two stable electrical states — effectively on and off. Two states map naturally onto two digits, so base 2 is all the hardware needs to distinguish.

Denary is not technically superior — it is a historical accident of humans having ten fingers. Any base can be converted into any other, which is why hexadecimal and octal are simply human-friendly shorthand for the underlying binary.

Worked methods

Binary → Denary: add the place values where a 1 appears.

Place value1286432168421
Bit00101010
 
00101010  →  32 + 8 + 2  =  42

Denary → Binary: subtract the largest place value that fits, then repeat with the remainder.

42 → 32 (remainder 10) → 8 (remainder 2) → 2 (remainder 0)
   = 00101010

Binary → Hexadecimal: group the bits in fours from the right.

1010 1100  →  A    C  →  AC

Binary → Octal: group the bits in threes from the right.

101 010  →  5   2  →  52

Hexadecimal → Denary: multiply each digit by its place value (16⁰, 16¹, 16² …).

2A = (2 × 16) + (10 × 1) = 32 + 10 = 42

Computers use binary because their processors are built from transistors, which have only two stable states — on and off — so two digits are all the hardware needs to distinguish. Binary uses only the digits 0 and 1, with each position representing a power of two.

Hexadecimal is base 16 and uses the digits 0–9 plus A–F. It is used because it is a compact shorthand for binary: one hex digit represents exactly one nibble (4 bits), so long binary strings become shorter and less error-prone to read. It is commonly used for colour codes, memory addresses and MAC addresses.

Octal is base 8 and uses the digits 0–7. It is useful because one octal digit represents exactly 3 bits, giving a compact notation historically used in early computing and still used for file permissions in Unix-like systems.

Characters are represented using ASCII, which is a 7-bit code covering 128 characters including the English alphabet, digits and punctuation. Unicode is needed because ASCII cannot represent the world's other scripts, symbols or emoji; Unicode is a superset that assigns a unique code point to every character, allowing text in any language to be stored and exchanged.

💡 Key Takeaway

Computers store everything as binary because their hardware has exactly two stable states. Denary, hexadecimal and octal are all just different ways of writing down the same underlying bits — chosen for human convenience, not machine necessity. Characters are no different: ASCII and Unicode assign numbers to letters, and those numbers are stored in binary like everything else.
