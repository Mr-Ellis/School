A1.2.5 – Construct Logic Diagrams

📌 Learning Objective

By the end of this lesson, you will be able to:

  • Construct a logic diagram from a Boolean expression
  • Use the standard symbols for AND, OR, NOT, NAND, NOR, XOR and XNOR
  • Apply the four drawing rules to keep a diagram clean and correct
  • Read a logic diagram back into a Boolean expression
  • Translate a written requirement into inputs, gates and an output

🎯 IB Command Term: Construct

Construct – “To build or make by fitting together separate parts.”

In this context, constructing means turning an abstract Boolean expression into a physical circuit drawing. Every operator in the expression becomes one gate symbol, wired in the order the operators apply. The diagram is not decoration—it is the specification for the hardware.

🔑 Key Terms

TermDefinition
Logic diagramA drawing that shows how logic gates are connected to implement a Boolean expression or a written requirement.
Gate symbolThe standard shape used to represent a particular logic gate. Using the correct shape is part of the mark scheme.
InputA signal entering the circuit from the left. Inputs are usually labelled A, B, C, …
OutputThe final signal leaving the circuit on the right. Usually labelled Q.
Intermediate signalA signal produced by one gate and fed into another. It may be labelled (X, Y, Z…) to make the diagram easier to read.
Fan-outWhen one wire branches to feed several gates. The same value travels down every branch.
BubbleThe small circle on the output of a gate symbol. It means “invert this output”—that is how NAND, NOR and XNOR are drawn.

💡 The Big Idea: From Expression to Circuit

A Boolean expression is a set of instructions. A logic diagram is those instructions turned into a circuit. The translation is mechanical: one operator becomes one gate, and the order of operations tells you how to wire them together.

The syllabus requires you to know seven gates. Any finite Boolean function can be built from these seven, and in practice most real chips use only NAND or NOR because each is functionally complete on its own.

The most useful habit

Count the operators in the expression before you draw anything. If the expression has three operators, your finished diagram must have three gates. If it has four, you need four gates. Counting first catches dropped or duplicated operations immediately.

🔌 The Seven Standard Gate Symbols

Every gate has a fixed shape. A diagram drawn with invented shapes earns no marks, even if the wiring is correct. Learn the shapes.

AND

Flat back, rounded front
A · B

OR

Curved back, pointed front
A + B

NOT

Triangle with an output bubble
NOT A (or A with a bar)

NAND

AND shape plus output bubble
NOT (A · B)

NOR

OR shape plus output bubble
NOT (A + B)

XOR

OR shape with an extra curved line
A ⊕ B

XNOR

XOR shape plus output bubble
NOT (A ⊕ B)
The bubble sits on the output

A bubble on the output of a gate means “invert the result”—that is how NAND, NOR and XNOR are drawn. A bubble on an input line means “invert this input before the gate acts”, which is a different circuit. Do not confuse the two.

📐 The Four Rules for Drawing a Diagram

These rules keep the diagram readable and prevent wiring errors.

1
Identify and label the inputs and output first.
Inputs go on the left (A, B, C…). The output goes on the right (Q). Label them before drawing a single gate.
2
Work outward from the innermost bracket.
The gate for the deepest bracket is drawn first, because its output feeds the next gate outward.
3
Let the logic flow left to right.
Every wire carries a value forward. Wires should not double back on themselves.
4
Give each gate exactly one output.
That output may branch to feed several later gates (fan-out). Every branch carries the same value. A gate never has two outputs.

🧮 Worked Example 1: A Two-Gate Diagram

Construct a logic diagram for:

Q = (A AND B) OR C

Step 1 — Count the operators

There are two operators: AND and OR. So the finished diagram needs exactly two gates.

Step 2 — Identify the innermost bracket

The bracket (A AND B) is computed first. Its result feeds the OR gate.

Step 3 — Draw the gates left to right

  • Draw an AND gate on the left. Wire inputs A and B into it.
  • Draw an OR gate to its right. Wire the AND gate’s output into one input of the OR gate.
  • Wire input C directly into the other input of the OR gate.
  • The OR gate’s output is Q.
What the diagram looks like
  A ──┐
      ├──[ AND ]──┐
  B ──┘           ├──[ OR ]── Q
  C ──────────────┘

The AND gate’s output branches into the OR gate. C goes straight into the other OR input. Two gates, three inputs, one output.

🧮 Worked Example 2: A Three-Gate Diagram with NOT

Construct a logic diagram for:

Q = (A OR B) AND (NOT C)

Step 1 — Count the operators

There are three operators: OR, NOT and AND. The diagram needs three gates.

Step 2 — Identify the innermost parts

Two bracketed parts must be computed before the final AND:

  • (A OR B)
  • (NOT C)

Step 3 — Draw outward from the brackets

  • Draw an OR gate for A and B.
  • Draw a NOT gate for C.
  • Draw an AND gate to the right. Wire the OR output and the NOT output into its two inputs.
  • The AND gate’s output is Q.
What the diagram looks like
  A ──┐
      ├──[ OR ]────┐
  B ──┘            ├──[ AND ]── Q
  C ──[ NOT ]──────┘

Notice that the OR gate and the NOT gate are drawn side by side. They are independent, so their order does not matter—but both must be finished before the AND gate can combine them.

🗣️ Constructing From a Written Requirement

Exam questions sometimes give you a sentence rather than an expression. Translate the sentence into Boolean first, then draw.

Requirement: “A security alarm sounds only when the motion sensor and the door sensor are both triggered, but not when the system is disabled.”

1
Name the inputs. M = motion sensor, D = door sensor, S = system disabled.
2
Name the output. A = alarm.
3
Translate the words. “Both triggered” means AND. “Not disabled” means NOT S. The alarm requires both conditions, so the two parts are joined by another AND.
A = (M AND D) AND (NOT S)
4
Draw. An AND gate for M and D, a NOT gate for S, and a final AND gate combining the two results.

📖 Reading a Diagram Back Into an Expression

The same skill works in reverse. Work from the output gate backwards:

  • Find the gate that produces Q. Write its operator.
  • Look at what feeds that gate. Each input becomes a bracketed expression.
  • Trace each input back to its source. If it comes from another gate, write that operator inside the bracket.
  • Repeat until every input is a single letter.
Example

If the final gate is an AND, and its upper input comes from an OR of A and B, while its lower input comes from a NOT of C, then:

Q = (A OR B) AND (NOT C)

✨ The Magic Trick: Simplifying Circuits

You do not need to learn complicated Boolean algebra. There is only one visual trick you need to know, and it lets you change the shape of a circuit without changing what it does.

It is called De Morgan's Law, but it is easier to remember as the "Push the Bubble" rule.

1
If you have a NAND gate (an AND gate with a bubble on the output), you can push that bubble through the gate.
The gate changes from AND to OR, and the bubble splits and pops up on the two input lines.
2
The exact same trick works for a NOR gate.
Push the output bubble through the gate. The gate changes from OR to AND, and bubbles appear on the inputs.
Why does this matter?

If you are building a circuit and you have run out of AND gates, but you have plenty of OR gates and NOT gates, you can use this trick to rebuild the exact same circuit using different parts. The logic stays exactly the same—the truth table does not change.

NOT (A AND B)  =  (NOT A) OR (NOT B)

Open Logicly in a new tab and build each diagram below. Use toggle switches for inputs and a light bulb for the output, so you can test the circuit as you go.

Lab 1 — Two-gate circuit

  1. Build the diagram for Q = (A AND B) OR C.
  2. Test all eight input combinations. Write down the truth table as you go.
  3. Check: Q should be 1 whenever C is 1, and also when A and B are both 1.
Check: If your Q is not 1 when C is 1, the wire from C is not reaching the OR gate. If Q is not 1 when A and B are both 1, the AND gate output is not wired into the OR gate.

Lab 2 — Three-gate circuit with NOT

  1. Build the diagram for Q = (A OR B) AND (NOT C).
  2. Test all eight input combinations.
  3. Analyse: describe in one sentence the exact condition that makes Q equal 1.
Think: Q is 1 only when the OR gate outputs 1 and C is 0. That means at least one of A or B must be 1, and C must be 0. If both A and B are 0, Q is 0 no matter what C is.

Lab 3 — Build from a requirement

  1. Translate this requirement into Boolean: “The light turns on if the switch is on and the sensor is not blocked.”
  2. Build the diagram in Logicly.
  3. Test it. Then reverse the requirement: draw a second circuit where the light turns on if the switch is on or the sensor is blocked. Compare the two truth tables.
Compare: The first circuit is an AND with a NOT. The second is an OR. Only the AND version requires both conditions simultaneously.

⚠️ Common Mistakes to Avoid

Where marks are usually lost
  • Invented gate shapes. Use the standard symbols. A box with “AND” written inside is not an AND gate.
  • Wrong bubble placement. The bubble goes on the output. A bubble on an input changes the meaning.
  • Too many or too few gates. Count the operators first. Three operators means three gates.
  • Gates in the wrong order. Work outward from the innermost bracket. The bracket is drawn first.
  • Two outputs from one gate. A gate has one output that may branch. It never has two separate outputs.
  • Wires that double back. Logic flows left to right. If a wire loops backwards, the diagram is wrong.
