A1.2 Revision Guide: Data Representation & Logic

This revision guide covers how computers represent numbers, text, images, and sound using binary, the fundamental logic gates that process this data, and how to construct truth tables and logic diagrams.

1. Data Representation 1 (A1.2.1)

Computers use binary (base-2) because transistors have two stable states: on (1) and off (0). Every other number system is either a human-friendly shorthand or a standard for encoding characters.

MethodBaseDigits UsedWhy It Is Used
Binary20, 1Matches the physical on/off states of a transistor.
Denary100–9Human default (because we have ten fingers).
Hexadecimal160–9, A–FCompact shorthand for binary. 1 hex digit = 1 nibble (4 bits). Used for colours, memory addresses, MAC addresses.
Octal80–7Compact shorthand for binary. 1 octal digit = 3 bits.
ASCII—7-bit codesStandard character encoding for English/Latin text (128 characters).
Unicode—UTF-8 / UTF-16Represents all world languages, symbols, and emoji.
Key Terms:
• Bit: A single binary digit (0 or 1).
• Nibble: 4 bits (one hex digit).
• Byte: 8 bits (standard unit of storage).

2. How Binary Is Used to Store Data (A1.2.2)

All data is just an ordered sequence of bits. A file type is not a different kind of storage—it is a different encoding (a rule for interpreting those bits).

Units of Storage

bit (1 or 0) → ÷ 8 → Byte (8 bits) → ÷ 1024 → KiB (1024 bytes) → ÷ 1024 → MiB (1024 KiB)

Note: IB exams normally expect the 1024 ladder (KiB, MiB), not the 1000 ladder (KB, MB).

Integers: Unsigned, Signed, and BCD

TypeHow It WorksRange (8-bit)
UnsignedAll bits are used for magnitude.0 to 255
Two’s Complement (Signed)Most significant bit (MSB) has a negative place value.−128 to +127
BCDStores each decimal digit separately in 4 bits.Two digits per byte.
Why BCD? Ordinary binary cannot represent some decimal fractions exactly (e.g., 0.1 becomes a repeating fraction). BCD stores digits 0–9 exactly, which is why financial systems use it for money.

Storing 47 in BCD: Digit 4 = 0100, Digit 7 = 0111. Joined: 0100 0111 (one byte, two digits).

⚡ Calculating File Sizes (Crucial for Exams)

You must be able to calculate the uncompressed file size for images, audio, and video. Always remember to convert your final answer from bits to Bytes (÷ 8) and then to KiB / MiB (÷ 1024).

1. Images

Formula:
Total Bits = Width (pixels) × Height (pixels) × Colour Depth (bits per pixel)
Worked Example: Calculate the size of a 1920 × 1080 image with a 24-bit colour depth.

Step 1 (Pixels): 1920 × 1080 = 2,073,600 pixels
Step 2 (Bits): 2,073,600 × 24 = 49,766,400 bits
Step 3 (Bytes): 49,766,400 ÷ 8 = 6,220,800 bytes
Step 4 (KiB): 6,220,800 ÷ 1024 = 6,075 KiB
Step 5 (MiB): 6,075 ÷ 1024 ≈ 5.93 MiB

2. Audio

Formula:
Total Bits = Sample Rate (Hz) × Bit Depth × Channels × Duration (seconds)
Worked Example: Calculate the size of 60 seconds of CD-quality stereo audio.
(CD audio = 44,100 Hz, 16-bit depth, 2 channels)

Step 1 (Bits per second): 44,100 × 16 × 2 = 1,411,200 bits/sec
Step 2 (Total Bits): 1,411,200 × 60 = 84,672,000 bits
Step 3 (Bytes): 84,672,000 ÷ 8 = 10,584,000 bytes
Step 4 (KiB): 10,584,000 ÷ 1024 = 10,335.9 KiB
Step 5 (MiB): 10,335.9 ÷ 1024 ≈ 10.09 MiB

3. Video

Formula:
Total Bits = Width × Height × Colour Depth × Frame Rate (fps) × Duration (seconds)
Worked Example: Calculate 10 seconds of uncompressed 1080p video at 30fps.
(1920 × 1080, 24-bit colour)

Step 1 (Bits per frame): 1920 × 1080 × 24 = 49,766,400 bits
Step 2 (Bits per second): 49,766,400 × 30fps = 1,492,992,000 bits/sec
Step 3 (Total Bits): 1,492,992,000 × 10s = 14,929,920,000 bits
Step 4 (Convert to MiB): (14,929,920,000 ÷ 8) ÷ 1024 ÷ 1024 ≈ 1,780 MiB (or 1.78 GiB)
⚠️ Calculation Tips:
1. Read the units. The question might ask for the answer in Bytes, KiB, or MiB.
2. Stereo means 2 channels. Mono means 1 channel.
3. Check the colour depth. If it gives you "8-bit colour", that's 1 byte per pixel. If it gives you "24-bit RGB", that's 3 bytes per pixel.

3. Logic Gates (A1.2.3)

A logic gate is a small group of transistors that takes binary inputs and makes a binary decision. Gates are the bridge between Boolean algebra and physical hardware.

GateRuleQuestion It AnswersTruth Table (A, B → Q)
ANDOutput is 1 only when both inputs are 1.“Are both inputs on?”00→0, 01→0, 10→0, 11→1
OROutput is 1 when at least one input is 1.“Is either input on?”00→0, 01→1, 10→1, 11→1
NOTOutput is the opposite of the input.“Is the input off?”0→1, 1→0
NANDOutput is 1 unless both inputs are 1.“Is either input off?”00→1, 01→1, 10→1, 11→0
NOROutput is 1 only when both inputs are 0.“Are both inputs off?”00→1, 01→0, 10→0, 11→0
XOROutput is 1 when the inputs are different.“Are the inputs different?”00→0, 01→1, 10→1, 11→0
Functional Completeness: NAND and NOR are called universal gates because any other gate can be built using only NAND gates, or only NOR gates. This is why real chip designers favour them.

4. Truth Tables (A1.2.4)

A truth table lists every possible combination of inputs and the output each one produces. It is the complete specification for a logic circuit.

⚠️ The Golden Rule: A truth table must include the all-zero row. If a row is missing, the table is incomplete and cannot be used to analyse the circuit.

The 2^n Rule

For n inputs, a truth table needs 2^n rows, because each input can be either 0 or 1.

5. Logic Diagrams (A1.2.5)

A logic diagram turns an abstract Boolean expression into a physical circuit drawing. One operator becomes one gate.

Boolean Algebra Symbols

SymbolMeaning
A · BAND (the dot means AND)
A + BOR (the plus means OR)
NOT ANOT (sometimes written as A' or with a bar over the A)
A ⊕ BXOR (the circle with a cross means exclusive OR)

The Four Drawing Rules

  1. Label inputs and outputs first. Inputs on the left (A, B, C…), output on the right (Q).
  2. Work outward from the innermost bracket. The gate for the deepest bracket is drawn first.
  3. Logic flows left to right. Wires should not double back.
  4. One output per gate. That output may branch (fan-out) to feed several later gates.

Worked Example

Q = (A AND B) OR C

A ──┐
    ├──[ AND ]──┐
B ──┘         ├──[ OR ]── Q
C ──────────────┘

The AND gate’s output branches into the OR gate. C goes straight into the other OR input. Two gates, three inputs, one output.

Constructing From a Written Requirement

Requirement: “A security alarm sounds only when the motion sensor AND the door sensor are both triggered, but NOT when the system is disabled.”

  1. Name the inputs: M = motion sensor, D = door sensor, S = system disabled.
  2. Name the output: A = alarm.
  3. Translate the words: A = (M AND D) AND (NOT S).
  4. Draw: An AND gate for M and D, a NOT gate for S, and a final AND gate combining the two results.
⚠️ Common Mistakes to Avoid:
• Invented gate shapes: Use the standard symbols. A box with “AND” written inside is not an AND gate.
• Wrong bubble placement: The bubble goes on the output to invert the result (NAND, NOR, XNOR). A bubble on an input changes the circuit entirely.
• Too many or too few gates: Count the operators in the expression first. Three operators means three gates.
• Wires that double back: Logic must flow left to right.

6. The Magic Trick: Simplifying Circuits (De Morgan’s Law)

You do not need complicated Boolean algebra to change the shape of a circuit without changing what it does. There is one visual trick:

The “Push the Bubble” Rule:
• A NAND gate does the exact same job as an OR gate with NOT inputs.
• A NOR gate does the exact same job as an AND gate with NOT inputs.

NOT (A AND B)  =  (NOT A) OR (NOT B)

Why does this matter? If you are building a circuit and you have run out of NAND gates, but you have plenty of OR and NOT gates, you can use this trick to rebuild the exact same circuit using different parts. The truth table stays exactly the same—the logic does not change, only the picture changes.
