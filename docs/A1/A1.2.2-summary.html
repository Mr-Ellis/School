A1.2.2 – How Binary Is Used to Store Data

📌 Learning Objective

By the end of this lesson, you will be able to:

  • Explain how binary encoding is the foundation of all data storage, and how it impacts storage and retrieval
  • Explain the mechanisms used to store integers, characters, strings, images, audio, and video in binary form
  • Distinguish between storage format and interpretation—the same bits can mean different things under different encodings
  • Calculate the storage requirements for common data types, converting bits all the way to a final unit (bytes, KiB, MiB)

🎯 IB Command Term: Explain

Explain – “Give a detailed account including reasons or causes.”

Describing that images are stored as pixels is not enough. This lesson builds the skill of explaining why a particular encoding is used, how it represents the data, and what consequences it has for storage size, quality, and retrieval.

🔑 Key Terms

TermDefinition
BitThe smallest addressable unit of data—a single 0 or 1.
Byte8 bits; the standard unit of storage. Can represent 256 distinct values.
EncodingAn agreed rule that maps a pattern of bits to a meaning (e.g., “01000001” ↔ ‘A’). Without encoding, bits are meaningless noise.
Unsigned integerAn integer that uses every bit for magnitude. An 8-bit unsigned integer holds 0 to 255.
Two’s complementThe signed integer scheme used by real hardware. The most significant bit has a negative place value.
Binary-coded decimal (BCD)Stores each decimal digit separately in 4 bits. Used in financial systems to keep money amounts exact.
PixelA single dot in a digital image. Each pixel’s colour is stored as a binary value.
Sampling rateHow many audio samples are taken per second (Hz). CD audio uses 44,100 Hz.
Bit depthThe number of bits used per audio sample. CD audio uses 16 bits per sample.
FrameA single still image in a video. Video is a sequence of frames played back rapidly.

📊 The Fundamentals of Binary Encoding

Every datum in a computer—whether it looks to us like a number, a paragraph, a photograph, or a song—is ultimately just an ordered sequence of bits (0s and 1s). A transistor has only two stable states (on/off), so binary is the natural language of hardware.

The critical idea is that a file type is not a different kind of storage—it is a different agreed rule for reading the same 1s and 0s. That rule is called an encoding. Change the encoding, and the same bit pattern means something entirely different: a number, a letter, a colour, or a sound.

ConceptWhat it meansWhy it matters for storage & retrieval
Bit0 or 1.Everything else is built from bits.
Byte8 bits.File sizes, memory addresses, and buses are byte-oriented.
Encoding ruleAgreed mapping between bit patterns and abstractions.Without the rule, the bits are meaningless noise.
MetadataExtra bits describing the payload (type, length, checksums).Guarantees correct decoding and integrity on retrieval.

Impact on storage and retrieval

  • Capacity: Higher-precision encoding (e.g., 24-bit colour vs 8-bit) multiplies the space required.
  • Throughput: Wider buses move more bits per clock, affecting how fast data can be retrieved.
  • Latency: Compressed encodings trade space efficiency for extra CPU time during decoding.
  • Compatibility: Interoperability depends on all parties agreeing on the same binary layout (endianness, character set, container format).
  • Correct retrieval: If the encoding is known, binary data can be accurately reconstructed. If it is incorrect or unknown, data may be misinterpreted or corrupted.

🔢 Integers: Unsigned, Signed, and BCD

Unsigned integers

Unsigned integers use every bit for magnitude. An 8-bit unsigned integer holds the values 0 to 255 (256 possible patterns, counting from 0).

Example: 0011 0101₂ = 32 + 16 + 4 + 1 = 53₁₀.

Signed integers: two’s complement

Signed integers must give up one bit to record the sign. The scheme real processors use is two’s complement. The most significant bit carries a negative place value, while the remaining bits carry their normal positive values.

  • In 4 bits, the MSB is worth −8, so 1011 = −8 + 2 + 1 = −5.
  • 4 bits cover −8 to +7; 8 bits cover −128 to +127.
  • To negate a number: flip every bit, then add 1. (13 = 00001101 → flip → 11110010 → +1 → 11110011 = −13).
  • Two’s complement is used because the same adder circuit handles addition and subtraction with no extra gates.

Sign and magnitude (for contrast)

In sign and magnitude, the MSB is a flag (0 = positive, 1 = negative) and is not added to the total. The same pattern 1011 means −5 in two’s complement but −3 in sign and magnitude. Sign and magnitude produces two representations of zero (0000 and 1000) and needs separate circuits for addition and subtraction, which is why hardware does not use it.

Binary-coded decimal (BCD) and fixed point

BCD stores each decimal digit separately in 4 bits. So 1001 0011 reads as 9 then 3, giving 93. Money amounts that cannot be written exactly in ordinary binary stay exact in BCD, which is why financial systems use it. The cost is wasted space: 4 bits can hold 16 values, but BCD uses only 10.

Fixed point places the binary point at an agreed position, so bits to the left are the integer part and bits to the right are the fractional part.

🔤 Characters and Strings

Characters are stored as binary codes. Each character is assigned a unique binary value, allowing text to be stored and processed. A string is simply a sequence of characters, so it is stored as a sequence of binary codes.

EncodingWhat it providesStorage layout notes
ASCII7-bit code for English letters and symbols. 'A' = 0x41 = 0100 0001₂.Legacy text remains readable in UTF-8 because ASCII bytes stay unchanged.
Unicode (UTF-8)Assigns a code-point to every written symbol worldwide. UTF-8 encodes those points in 1–4 bytes.Length-prefixed ([len][data…]) allows fast random access; null-terminated ([data…][0]) is C-style and requires re-scanning for length.

🖼️ Images

A digital image is a grid of pixels. Each pixel’s colour or brightness is stored as a binary value. In a raw bitmap, a header records width, height, and bit-depth, followed by the pixel data.

RGB colour

A common scheme uses 24 bits per pixel: 8 bits red, 8 bits green, 8 bits blue. A 1920 × 1080 RGB image therefore needs the following. Work down the ladder until you reach a sensible unit:

1920 × 1080 image at 24 bits per pixel
Pixels1920 × 1080 = 2,073,600 pixels
Bits2,073,600 × 24 = 49,766,400 bits
÷ 8 → Bytes49,766,400 ÷ 8 = 6,220,800 bytes
÷ 1024 → KiB6,220,800 ÷ 1024 = 6,075 KiB
÷ 1024 → MiB6,075 ÷ 1024 = ≈ 5.93 MiB

Quality vs size

More pixels (higher resolution) increases detail. More bits per pixel increases colour accuracy. Both increase the storage required. Compressed formats (PNG, JPEG) convert blocks of pixels into frequency coefficients and entropy-code them, dramatically shrinking size at the cost of CPU time (and for JPEG, some quality).

🎵 Audio

Analogue sound is a continuous wave. To store it in binary, the waveform is sampled at regular intervals and each sample is quantised into a fixed-width binary integer. This is Pulse-Code Modulation (PCM).

ParameterMeaningCD audio value
Sampling rate (fₛ)Samples taken per second. Determines temporal resolution.44,100 Hz
Bit depth (b)Bits per sample. Determines quantisation resolution and signal-to-noise ratio.16 bits
Channels (c)Independent audio streams (mono = 1, stereo = 2).2

Bit rate for CD audio

First work out the number of bits produced each second, then convert to a rate you can compare with file sizes:

CD-quality stereo (44,100 Hz, 16-bit, 2 channels)
Bits per second44,100 × 16 × 2 = 1,411,200 bits/s
÷ 8 → Bytes/s1,411,200 ÷ 8 = 176,400 bytes/s
÷ 1024 → KiB/s176,400 ÷ 1024 = ≈ 172.3 KiB/s

Samples are stored interleaved (L₀, R₀, L₁, R₁, …) to maintain sample-accurate alignment.

Quality vs size

More samples improve accuracy; more bits per sample improve precision. Higher quality requires more storage. Compressed codecs (MP3, AAC, Opus) transform blocks to frequency space and psycho-acoustically quantise, reaching 90%+ savings by removing masked or inaudible components.

🎬 Video

A video file is a container plus one or more streams. The video stream is a sequence of frames (bitmaps), and audio is usually stored alongside.

Frame types and compression

  • I-frames are self-contained (like a still image).
  • P/B-frames store only the differences from other frames.
  • A codec (H.264, AV1) orchestrates block transforms, motion vectors, and entropy coding to compress the stream.

The binary stream is timestamped so the playback engine reconstructs each frame in order and at the correct rate (e.g., 30 fps ≈ one frame every 33 ms).

Why video files are large: many frames must be stored, audio data is included, and higher quality increases requirements.
