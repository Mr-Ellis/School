Section A — CPU, GPU and Primary Memory (20 marks)

1. Describe the difference in function between the instruction register (IR) and the memory data register (MDR).[4]
2. Explain why ROM rather than RAM is used to store the instructions a computer needs at startup.[2]
3. Explain the difference between a cache hit and a cache miss, and why a higher hit rate improves performance.[3]
4. Describe how the architecture of a GPU makes it suitable for training a machine learning model.[3]
5. Explain how the CPU and GPU divide and coordinate their work when training a machine learning model.[4]
6. Describe the steps the CPU performs during the fetch stage of the fetch–decode–execute cycle.[4]

Section B — Pipelining (12 marks)

7. Outline what happens at the decode and write-back stages of the instruction pipeline.[2]
8. Describe how pipelining in a multi-core processor improves overall system performance.[4]
9. A processor has a 4-stage pipeline. Explain why a branch instruction can reduce the performance benefit of pipelining, and describe one technique a processor can use to reduce this problem.[4]
10. Explain why increasing the number of pipeline stages does not always improve performance.[2]

Section C — Secondary Memory, Compression and Cloud (18 marks)

11. Describe two differences between internal and external secondary memory storage.[2]
12. Describe the characteristics of an SSD and state one reason it is preferred to an HDD for storing an operating system.[3]
13. Apply run-length encoding to the string AAAAAABBBBCCD. State the encoded string and the number of characters before and after encoding.[3]
14. A student records a podcast and saves it as an MP3 file. Describe how transform coding reduces the size of the audio file.[4]
15. Describe what is meant by platform as a service (PaaS).[2]
16. A start-up is deciding between SaaS and IaaS for its new customer-booking system. Describe one advantage and one disadvantage of each model in this scenario.[4]

Section D — Operating Systems, Control, Compilers (15 marks)

17. Compare first-come first-served and round robin scheduling.[4]
18. Evaluate the use of polling and interrupt handling for taking input from a keyboard on a battery-powered laptop.[6]
19. Explain how deadlock can arise when two processes share resources.[4]
20. A greenhouse uses a closed-loop system to hold its temperature at 24°C. Explain how the components work together to maintain this temperature, and why a closed-loop design is used rather than open-loop.[4]
21. Explain why compiled code generally executes faster than interpreted code.[2]
