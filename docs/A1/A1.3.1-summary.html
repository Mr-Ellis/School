🤔 Think First — What Makes Your Computer Work? 5 min

Brainstorm: When you open a Word document, listen to music, and browse the web at the same time — what is actually making all of that work?

You have a bare CPU, some RAM, a disk and a keyboard. No operating system. You want to run a word processor. What problems would you hit immediately?

  • Where would the word processor store your document?
  • How would two programs share the CPU?
  • How would the word processor know which printer is attached?
  • How would you stop a buggy program overwriting another program's memory?

Write two problems on your whiteboard. Hold it up.

Discovery: Every problem you wrote down is something the operating system handles. The OS exists because raw hardware is unusable by ordinary programs.

💡 What Is an Operating System? 5 min

An operating system (OS) is the fundamental software that manages computer hardware and software resources and provides common services for computer programs. It acts as an intermediary between the user and the hardware, ensuring efficient and secure operation of the system.

Some of the most famous modern operating systems:

Device typeOperating systems
Larger computers / laptopsMicrosoft Windows, Apple macOS, Linux
Smaller portable devicesAndroid, iOS

Useful analogies for the OS role:

  • Restaurant manager — doesn't cook the food (that's the CPU) but coordinates orders, staff, and customers so the kitchen works efficiently.
  • Traffic controller — doesn't drive the cars (those are the processes) but ensures they all move safely and fairly through shared space.

📊 The Two Big Ideas — Connected 8 min

The exam-critical framing: The two ideas are connected, not parallel.

The OS manages the system's resources (the what) — the processor, main memory and storage are all finite, and several programs want them at the same time.

It does this by abstracting the hardware (the how) — programs ask the OS to open a file, and the OS translates that request into whatever the specific hardware needs.

The result: the same program runs on a machine with a completely different disk, because the messy, device-specific part is the OS's problem, not the program's.

Abstraction — how the OS hides complexity

The OS hides hardware complexity. A program that wants to read a file does not issue the precise electrical commands a specific disk controller expects. It asks the OS to open a file, and the OS translates that into whatever the hardware needs.

APPLICATIONS Word processor · browser · games · media player
⬇ asks the OS for services   |   ⬆ returns results
OPERATING SYSTEM Memory management · process management · I/O management · file system · user interface · security
⬇ translates requests   |   ⬆ returns data
HARDWARE CPU · memory · storage · I/O devices · network

Why it matters: Programs are written once against a simple, uniform interface instead of against every possible piece of hardware.

Resource management — what the OS coordinates

The OS allocates limited resources to competing demands. Without OS decisions, two programs writing to the same memory or the same file would corrupt each other within seconds.

ResourceWhat the OS doesWhy it matters
CPU management Allocates CPU time to processes; schedules; handles context switching Ensures efficient execution; enables multitasking
Memory management Handles allocation and de-allocation; manages virtual memory; enforces protection Extends apparent memory capacity; stops one program corrupting another
Storage management Organises data on storage devices; controls access; manages file system Reliable data storage and retrieval by name, independent of physical location
Device management Loads drivers; provides interfaces; coordinates hardware devices Same read/write calls work for files, pipes, sockets, printers, keyboards

📋 The OS Role in Detail — Reference Table reference

Use this as your reference for the detailed description the exam expects. Naming each responsibility is not enough — say what it does.

ResponsibilityWhat it does
Processor managementCreates, schedules, suspends and terminates processes and threads. Implements context switching and enforces privilege separation.
Memory managementMaintains page tables, performs paging/segmentation, enforces protection, handles allocation and de-allocation. Provides virtual memory to extend apparent capacity.
I/O and device managementLoads device drivers, mediates direct memory access (DMA), buffers asynchronous I/O, exposes uniform I/O abstractions.
File-system and secondary-storage managementImplements naming, directories, metadata, journaling, caching and quota enforcement.
Network stackImplements protocol layers (e.g. TCP/IP) in software, integrates sockets with the generic I/O interface, applies firewall and QoS rules.
Security and access controlAuthenticates principals, enforces discretionary/mandatory access-control models, addresses encryption and auditing.
Virtualisation & isolationMay act as a hypervisor (type 1) or host for containers; isolates guests or namespaces while multiplexing physical hardware.
User interface subsystemProvides command-line shells, window servers or system libraries so that application UI code need not address GPUs directly.

✍️ Independent Proof 8 min

Silent, individual. Write a full answer:

"Describe the role of an operating system in a computer system. [4 marks]"

📝 Sentence frame:

"The operating system is ___ that ___. Its primary role is to ___ and ___. It manages ___ by ___. For example, it manages ___ by ___. Without an OS, ___ would ___."

📌 Click to see a model answer

The operating system is the fundamental software that manages computer hardware and software resources and provides common services for programs, acting as an intermediary between the user and the hardware [1].

Its role is to abstract hardware complexities and manage system resources [1]. It hides the intricate details of physical components so that programs can use simple, uniform interfaces instead of issuing device-specific commands — the same program therefore runs on any machine without being rewritten [1].

For example, it manages CPU time by scheduling processes and performing context switches, and it manages memory by allocating and de-allocating space, enforcing protection between processes and providing virtual memory [1].

Without an operating system, two programs could overwrite each other's memory or the same file, and ordinary users would need to understand every hardware detail to run a program.

💡 Key Takeaway: "The operating system exists to do two connected things: manage resources so that competing programs share the CPU, memory, storage and devices safely, and abstract the hardware so programs can use simple, uniform interfaces instead of device-specific commands. The abstraction is how the OS manages resources; the resource management is what it does. Everything else — from drawing windows to encrypting network traffic — serves those two roles."
