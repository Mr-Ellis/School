🕵️ Plan Your Code Like a Detective

Before writing any code, you need a plan. Just like a detective gathers clues before solving a mystery, programmers plan their steps before typing a single line of code.

🗺️ Flowcharts: Your Program's Treasure Map

A flowchart is a visual diagram that shows the steps your program will follow. It's like a treasure map for your code!

Start/Stop
Start / Stop Beginning and end of the program.
Process
Process An action or calculation (e.g., adding numbers).
Input/Output
Input / Output Asking the user for info, or showing results.
✧
Decision A yes/no question (e.g., "Is age ≥ 13?").
Tip: Flowcharts help you think through your program before you write any code. This saves time and prevents mistakes!

💡 Worked Example: From Flowchart to Code

Here's how a simple flowchart becomes Python code:

Flowchart steps:

  1. Start
  2. Ask for first number
  3. Ask for second number
  4. Add them together
  5. Show the result
  6. End
# Python code
num1 = int(input("First: "))
num2 = int(input("Second: "))
total = num1 + num2
print("Sum:", total)

📦 Data Types & Casting

In Python, we need to tell the computer what type of data we're using:

  • String — text like "hello"
  • Integer — whole numbers like 7
  • Float — decimal numbers like 3.14

Use int() for whole numbers, float() for decimals, and str() for text.
