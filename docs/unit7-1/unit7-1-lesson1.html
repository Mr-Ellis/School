🚀 Get started!

Think of programming like using a super-smart calculator. You type in instructions (like numbers and operations), and Python helps you get the answers!

You'll use something called IDLE, which is like a notebook where you write, test, and run your Python programs. It's easy to use and great for beginners.

Tip: You can add comments to your code using the # symbol. These are notes that help you (and others) understand what your code is doing.

🔢 Data Types in Python

In Python, you'll work with different data types:

  • Integers — whole numbers like 5
  • Floats — decimal numbers like 3.14
  • Strings — text like "Hello"

Each type helps you store and use different kinds of information in your programs.

🖥️ Writing Basic Python Programs

Let's start coding!

  • Use print() to show messages on the screen.
  • Use input() to ask the user for information.
# Example: greet the user name = input("What's your name? ") print("Hi " + name + "!")

➕ Doing Calculations & Fixing Mistakes

Python can do math! Use symbols like:

  • + for addition
  • - for subtraction
  • * for multiplication
  • / for division
Be careful! If you make a mistake in your code (like using the wrong symbol), Python will show an error. That's totally normal — it's how you learn!

Try this: Solve 7 + 3 * 2 + 5. Python follows math rules (order of operations), so think carefully!

🛠️ Debugging (Fixing Your Code)

Sometimes your code won't work the way you expect. That's okay!

Your job is to find and fix errors. Use comments (#) to explain what each part of your code does and why something might not be working.

🔄 Understanding How Programs Work

Programs follow a step-by-step path. This is called the program flow.

To plan your program, you can use flowcharts — simple diagrams that show what happens first, next, and last.
