1 Data Types

Data TypeWhat it storesExample
StringText — letters, numbers, symbols (always in quotes)"Hello", "city", "April"
IntegerWhole numbers15, -5, 3
Real / FloatNumbers with a decimal point3.14, 1.75, -0.5
Think carefully: Can an integer be negative? Can a float have no decimal places? These are the kinds of details worth double-checking.

Q: Which data type would store a decimal number like 3.14?

A: Real / Float.

2 Choosing the Right Data Type

When you see a variable name, ask: what kind of data would sensibly go in here?

VariableSensible typeWhy
cityStringIt's a name made of letters
monthStringMonth names are text (e.g. "April")
house numberIntegerWhole numbers
costReal / FloatMoney often has decimals (e.g. 4.99)
school stageIntegerYear group is a whole number
temperatureReal / FloatTemperatures often have decimals
Tip: If it's a label or name → String. If it's a count of whole things → Integer. If it can have a decimal point → Real / Float.

Q: What data type would the variable cost most likely be?

A: Real / Float (prices usually have decimals).

3 Python Commands & Variables

CommandWhat it does
print()Displays information on the screen
input()Asks the user for information (returns a string)
int()Casts a variable to an integer
float()Casts a variable to a real / float
str()Casts a variable to a string
Watch out: input() gets data in. print() shows data out. Don't mix them up.

Variable rules

  • Variable names cannot contain spaces — use underscores instead.
  • Variables store data so you can reuse it later.
  • You can join strings and variables in a print() using a comma.

Joining strings and variables

name = "Samira"
print("Hello", name)          # comma: works with any data type
print("Hello " + name)          # plus: only works with strings

Both lines above will run. But if name held a number, only the comma version would work — using + with a number would cause an error.

Q: Which command displays information on the screen?

A: print().

6 BIDMAS — Order of Operations

Python follows the same order of operations as maths. BIDMAS tells you which part to work out first:

  • Brackets
  • Indices (powers)
  • Division
  • Multiplication
  • Addition
  • Subtraction

Worked examples

7 + 3 * 2       →  multiply first: 3 × 2 = 6, then 7 + 6 = 13
(7 + 3) * 2       →  brackets first: 7 + 3 = 10, then 10 × 2 = 20
20 / 4 + 3       →  divide first: 20 ÷ 4 = 5, then 5 + 3 = 8
Tip: Work through the expression in BIDMAS order — don't just go left to right.

Q: What is 2 + 3 * 4?

A: 14 (multiply first: 3 × 4 = 12, then add 2).

7 Predicting Output

Read the code line by line. Work out what each variable holds, then what gets printed.

Example 1 — simple print

print("Hello, how are you?")

Output: Hello, how are you?

Example 2 — numbers added together

num1 = 12
num2 = 8
total = num1 + num2
print(total)

Output: 20

Example 3 — string and number with a comma

age = 13
month = "September"
print("You are", age, "and were born in", month)

Output: You are 13 and were born in September

The comma adds a space automatically between each item.

Example 4 — string with plus

name = "Afzal"
print("Nice to meet you " + name)

Output: Nice to meet you Afzal

With +, you must add your own space — otherwise it would print Nice to meet youAfzal.

Key skill: Trace the value of each variable. Watch for commas (add spaces) and + (needs your own spaces).

Q: What does this print? print("Total:", 5 + 3)

A: Total: 8 — the comma adds a space, and 5 + 3 is worked out first.

8 Spotting Errors in Code

These are the most common mistakes in Python code. Train your eye to spot them.

MistakeBroken codeFixed code
Missing quotes around text print(Hello World) print("Hello World")
Missing closing bracket print("Hello" print("Hello")
Forgetting to cast input age = input("Age: ")
then using age as a number		 age = int(input("Age: "))
Using + with a number print("Age: " + 13) print("Age:", 13) or print("Age: " + str(13))
Wrong operator total = price + quantity (meant to multiply) total = price * quantity
Wrong variable name used print(total) when the variable is cost print(cost)
Missing int() around input num = input("Number: ")
result = num * 2 (repeats string)		 num = int(input("Number: "))
Reading code for errors: Check quotes, brackets, casting, operators, and variable names — in that order.

Q: What's wrong with print("Hello"?

A: Missing closing bracket. It should be print("Hello").

9 Program Flow & Planning

Programs follow a step-by-step path — this is called program flow. Before writing code, plan the steps.

Typical order for a simple program

  1. Start
  2. Ask for input
  3. Process / calculate
  4. Display output
  5. End

Test plans

A test plan lists inputs and the expected output. It helps you check your program works before you hand it in.

InputExpected output
5, 38 (if the program adds them)
10, 220 (if the program multiplies them)
Why plan? Planning with a flowchart or a test plan saves time and catches mistakes before you write a single line of code.

Q: What is a test plan used for?

A: To check a program gives the correct output for given inputs.

10 Selection (IF / ELSE)

Selection lets a program make a decision. In Python we use if, elif, and else.

if score > 100:
    print("Well done!")
else:
    print("Try again!")
Indentation matters! The code inside an if or else block must be indented (usually 4 spaces or one tab).

In a flowchart

Selection is shown using the decision diamond, with two arrows coming out (one for yes, one for no).

Q: Which Python keyword is used when the if condition is not met?

A: else.

11 Sub-routines (Functions)

A sub-routine (also called a function) is a mini-program inside a bigger program. It helps break big tasks into smaller, easier parts.

Why use them?

  • Keeps code neat — organised into manageable chunks.
  • Reusable — use them multiple times instead of rewriting code.
  • Easy to fix — makes debugging easier.

Defining and calling a sub-routine

def greet():
    print("Hello from a subroutine!")

greet()

Output: Hello from a subroutine!

The def keyword defines the sub-routine. You then call it by writing its name followed by brackets.

Sub-routines with parameters

def add(num1, num2):
    return num1 + num2

The return keyword sends a value back to the main program.

In a flowchart: sub-routines use the double-edged rectangle symbol.

Q: Which Python keyword defines a sub-routine?

A: def.

12 Summary — Common Errors Checklist

When reading or writing code, run through this checklist:

Syntax checks

  • All strings wrapped in " " or ' '
  • All brackets opened are closed
  • No spaces in variable names
  • Indentation inside if / else blocks

Logic checks

  • Used int() or float() when needed
  • Used the correct operator (e.g. * not +)
  • Used the correct variable name
  • BIDMAS applied correctly
Reminder: Reading code carefully is a skill. Slow down, trace each line, and check the checklist.
