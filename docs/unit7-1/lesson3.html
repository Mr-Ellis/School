🔢 BIDMAS – The Order of Maths in Python

Python follows the same order of operations as mathematics. BIDMAS helps you remember:

  • Brackets
  • Indices (powers like 2³)
  • Division
  • Multiplication
  • Addition
  • Subtraction
Example: 3 + 4 * 5 → Python does 4 × 5 first, then adds 3 → 23.
5 * (8 + 6) → brackets first → 5 × 14 → 70.

🐞 Debugging & Test Plans

Errors (bugs) are normal! Here are common mistakes and how to fix them:

Forgetting brackets or quotation marks → add them
Using the wrong variable name → check spelling
Not casting data types (input() returns a string) → use int() or float()
Using + instead of * (or vice versa) → check the operator

A test plan helps you check if your program gives the right answers. For example, if a program should add two numbers but instead multiplies them, a test plan will catch it.

🤔 Making Choices with IF Statements

Selection (IF, THEN, ELSE) allows your program to make decisions. Python uses:

if score > 100: print("Well done!") else: print("Try again!")
