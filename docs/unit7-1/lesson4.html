🧩 What Are Sub-routines?

A sub-routine is like a mini-program inside a bigger program. It helps break big tasks into smaller, easier parts.

Keeps code neat

They organise your code into manageable chunks.

Reusable

You can use them multiple times instead of rewriting code.

Easy to fix

They make your program easier to debug and understand.

Example

A calculator with separate sub-routines for addition and subtraction.

In Scratch vs Python

Scratch

Use broadcast to run a sub-routine like "addition" or "subtraction".

Python

Use functions (defined with def) to do the same thing.

# Python sub-routine example def add(): total = number1 + number2 print("The total is:", total)

🗺️ Sub-routines in Flowcharts

Sub-routines have their own special symbol in flowcharts — a rectangle with double lines on the sides.

addition
Sub-routine Runs a mini-program
?
Decision Yes/No question
OUTPUT
Input/Output Show results or ask for data
Remember: Sub-routines help avoid repeating code and keep flowcharts tidy. When a flowchart reaches a sub-routine symbol, it jumps to that mini-program and then returns.

💡 Worked Example: Calculator with Sub-routines

Here's how a calculator program uses sub-routines for addition and subtraction:

Main program:

  1. Start
  2. INPUT number1, number2, operation
  3. Is operation == 1? → addition
  4. Is operation == 2? → subtract
  5. Else → "Enter a valid number"
  6. Stop

Sub-routines:

addition: total = number1 + number2 → OUTPUT "The total is:" + total

subtract: total = number1 - number2 → OUTPUT "The subtraction answer is:" + total
