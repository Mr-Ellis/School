🧩 What Are Sub-routines?

A sub-routine is like a mini-program inside a bigger program. It helps break big tasks into smaller, easier parts.

Keeps code neat

They organise your code into manageable chunks.

Reusable

You can use them multiple times instead of rewriting code.

Easy to fix

They make your program easier to debug and understand.

Challenge: Random Questions Game

Instructions:

  1. Open PictoBlox or another Python IDE.
  2. Copy the text from ChallengeYourself.txt into your IDE.
  3. Finish the program by asking the user:
    • What is your name?
    • What is your favourite colour?
    • How many days are in a week?
    • How many seconds are in an hour?
    • What is your favourite hobby?
    • How many days are in a year?
  4. Print a message that includes all the answers.
  5. Add up the numbers to create a star number and show it at the end.
