Section 1: Binary Systems (Questions 1–15)
1Why do computers use binary?
  • Because binary is easier for humans to read
  • Because computers are made of transistors that have two states: on and off
  • Because binary allows for more colours than denary
  • Because binary uses ten digits like the denary system
Answer: B — Transistors have two states, ON (1) and OFF (0).
2How many bits are in one byte?
  • 4
  • 8
  • 16
  • 1024
Answer: B — A byte is 8 bits.
3What is the denary value of the binary number 10110101?
  • 169
  • 181
  • 197
  • 203
Answer: B — 128 + 32 + 16 + 4 + 1 = 181.
4Convert the denary number 42 to binary.
  • 00101010
  • 00101100
  • 01010100
  • 00100110
Answer: A — 42 = 32 + 8 + 2 = 00101010.
5What is the smallest unit of data in a computer?
  • A byte
  • A bit
  • A nibble
  • A kilobyte
Answer: B — A bit (binary digit) is a single 1 or 0.
6What is the largest denary number that can be represented with 8 bits?
  • 128
  • 255
  • 256
  • 1024
Answer: B — 2^8 − 1 = 255.
7Which of the following is the binary representation of the denary number 100?
  • 01100100
  • 01101000
  • 01010100
  • 01100010
Answer: A — 64 + 32 + 4 = 100 = 01100100.
8How many different values can be represented with 4 bits?
  • 4
  • 8
  • 16
  • 32
Answer: C — 2^4 = 16 different values.
9What is the denary value of the binary number 11111111?
  • 127
  • 128
  • 255
  • 256
Answer: C — 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = 255.
10Which term describes half a byte (4 bits)?
  • A bit
  • A nibble
  • A word
  • A kilobyte
Answer: B — A nibble is 4 bits (half a byte).
11What is the denary value of the binary number 00111001?
  • 45
  • 57
  • 63
  • 71
Answer: B — 32 + 16 + 8 + 1 = 57.
12How many bytes are in a kibibyte (KiB)?
  • 1000
  • 1024
  • 2048
  • 512
Answer: B — A kibibyte is 2^10 = 1024 bytes.
13The number of bytes in a mebibyte can be written as 2^x. What is the value of x?
  • 10
  • 15
  • 20
  • 24
Answer: C — A mebibyte is 2^20 bytes.
14Which of the following is the binary representation of the denary number 200?
  • 11001000
  • 11010000
  • 10101000
  • 11100000
Answer: A — 128 + 64 + 8 = 200 = 11001000.
15What is the denary value of the binary number 01011010?
  • 86
  • 90
  • 94
  • 98
Answer: B — 64 + 16 + 8 + 2 = 90.
Section 2: Hexadecimal (Questions 16–30)
16What is hexadecimal base?
  • Base 2
  • Base 8
  • Base 10
  • Base 16
Answer: D — Hexadecimal is base-16.
17In hexadecimal, what denary value does the letter F represent?
  • 10
  • 14
  • 15
  • 16
Answer: C — F = 15.
18Convert the hexadecimal number 2A to denary.
  • 32
  • 40
  • 42
  • 44
Answer: C — (2 × 16) + 10 = 42.
19Convert the denary number 27 to hexadecimal.
  • 1A
  • 1B
  • 1C
  • 27
Answer: B — 27 ÷ 16 = 1 remainder 11 (B) → 1B.
20Convert the binary number 11100101 to hexadecimal.
  • E5
  • D5
  • E3
  • F5
Answer: A — 1110 = E, 0101 = 5 → E5.
21Why is hexadecimal often used in computing instead of binary?
  • It is easier to read and less error-prone
  • It allows more colours than binary
  • It uses fewer bits per value than binary
  • It is faster for the CPU to process
Answer: A — Hex is more compact and easier to read than binary.
22What is the largest denary number that can be represented with two hex digits?
  • 15
  • 255
  • 256
  • 1024
Answer: B — FF = 255.
23Convert the hexadecimal number 3C to binary.
  • 0011 1100
  • 0011 1010
  • 0100 1100
  • 0011 1110
Answer: A — 3 = 0011, C = 1100 → 0011 1100.
24Convert the denary number 42 to hexadecimal.
  • 2A
  • 2B
  • 2C
  • 3A
Answer: A — 42 ÷ 16 = 2 remainder 10 (A) → 2A.
25What is the denary value of the hexadecimal number 7F?
  • 112
  • 127
  • 128
  • 255
Answer: B — (7 × 16) + 15 = 127.
26Which of the following is the hexadecimal equivalent of the binary number 10101111?
  • AF
  • BF
  • 9F
  • AE
Answer: A — 1010 = A, 1111 = F → AF.
27In hexadecimal, what comes after 19?
  • 20
  • 1A
  • 1B
  • 21
Answer: B — After 19 comes 1A.
28What is the denary value of the hexadecimal number FF?
  • 15
  • 128
  • 255
  • 256
Answer: C — (15 × 16) + 15 = 255.
29Which of the following is the binary equivalent of the hexadecimal number A5?
  • 1010 0101
  • 1010 0110
  • 1011 0101
  • 1001 0101
Answer: A — A = 1010, 5 = 0101 → 1010 0101.
30Convert the denary number 200 to hexadecimal.
  • C8
  • B8
  • D8
  • CA
Answer: A — 200 ÷ 16 = 12 remainder 8 → C8.
Section 3: Binary Shifts & Two's Complement (Questions 31–45)
31What is the effect of a logical left shift by one place on a binary number?
  • Divides by 2
  • Multiplies by 2
  • Adds 2
  • Subtracts 2
Answer: B — A left shift multiplies by 2.
32What is the effect of a logical right shift by one place on a binary number?
  • Multiplies by 2
  • Divides by 2
  • Adds 2
  • Subtracts 2
Answer: B — A right shift divides by 2.
33Perform a left shift by one place on the binary number 00111100.
  • 01111000
  • 00011110
  • 01111100
  • 00111100
Answer: A — 00111100 → 01111000.
34Perform a right shift by one place on the binary number 01011010.
  • 00101101
  • 10110100
  • 00101010
  • 01011010
Answer: A — 01011010 → 00101101.
35What is 45 in binary, then right shifted by one place?
  • 22
  • 23
  • 45
  • 90
Answer: A — 45 ÷ 2 = 22.5, but binary cannot store 0.5, so it becomes 22.
36What is the effect of a right shift on an odd number?
  • It is rounded up
  • It is rounded down (loss of precision)
  • It stays the same
  • It becomes negative
Answer: B — The fractional part is lost, so it rounds down.
37What is two's complement used for?
  • Converting denary to binary
  • Representing negative integers in binary
  • Adding binary numbers
  • Compressing binary data
Answer: B — Two's complement represents negative integers.
38What is -15 in 8-bit two's complement?
  • 11110000
  • 11110001
  • 10001111
  • 00001111
Answer: B — 15 = 00001111, invert = 11110000, add 1 = 11110001.
39What is the denary value of the two's complement number 11111011?
  • -5
  • -4
  • -3
  • -1
Answer: A — Invert: 00000100, add 1: 00000101 = 5, so the value is -5.
40What is the range of values that can be represented with 8-bit two's complement?
  • 0 to 255
  • -127 to 127
  • -128 to 127
  • -128 to 128
Answer: C — The range is -128 to 127.
41Perform a left shift by two places on the binary number 00001111.
  • 00111100
  • 00011110
  • 11110000
  • 00001111
Answer: A — 00001111 << 2 = 00111100.
42What is the denary value of 00001111 after a left shift by two places?
  • 15
  • 30
  • 60
  • 120
Answer: C — 15 × 4 = 60.
43What happens to the bits shifted off the end of a binary register?
  • They are stored in a separate register
  • They are lost
  • They wrap around to the other end
  • They are added to the result
Answer: B — Bits shifted off the end are discarded (lost).
44What is -1 in 8-bit two's complement?
  • 10000000
  • 11111111
  • 00000001
  • 11111110
Answer: B — 1 = 00000001, invert = 11111110, add 1 = 11111111.
45What is the denary value of the two's complement number 10000000?
  • -128
  • -127
  • 0
  • 128
Answer: A — The most negative value in 8-bit two's complement is -128.
Section 4: Character Sets (Questions 46–60)
46What is a character set?
  • A set of binary numbers used for arithmetic
  • A defined list of characters recognised by a computer, each with a unique binary code
  • A group of fonts used for displaying text
  • A compression method for text files
Answer: B — A character set maps characters to unique binary codes.
47How many bits does standard ASCII use per character?
  • 4
  • 7
  • 8
  • 16
Answer: B — Standard ASCII uses 7 bits per character.
48How many characters can standard 7-bit ASCII represent?
  • 64
  • 128
  • 256
  • 512
Answer: B — 2^7 = 128 characters.
49What is one limitation of the ASCII character set?
  • It cannot represent numbers
  • It cannot represent characters from other alphabets such as Arabic or Chinese
  • It uses too many bits per character
  • It is not compatible with modern computers
Answer: B — ASCII cannot represent non-Latin alphabets.
50What character set was designed to overcome the limitations of ASCII?
  • Extended ASCII
  • Unicode
  • EBCDIC
  • BCD
Answer: B — Unicode overcomes ASCII's limitations.
51How many bits does Unicode typically use?
  • 7
  • 8
  • 8, 16, or 32
  • 64
Answer: C — Unicode can use 8, 16, or 32 bits.
52How many characters can 16-bit Unicode represent?
  • 128
  • 256
  • 65,536
  • 1,024
Answer: C — 2^16 = 65,536 characters.
53Which of the following is a limitation of the ASCII character set?
  • It can only represent the English alphabet and a few symbols
  • It cannot represent numbers
  • It uses 16 bits per character
  • It cannot be used on modern computers
Answer: A — ASCII was designed for English and doesn't cover other alphabets.
54If 'A' is represented by 65 in denary, what is 'C'?
  • 66
  • 67
  • 68
  • 69
Answer: B — A = 65, B = 66, C = 67.
55How many bytes are needed to store the message "Hello" in 8-bit extended ASCII?
  • 4
  • 5
  • 6
  • 8
Answer: B — 5 characters = 5 bytes.
56Extended ASCII uses 8 bits. How many characters can it represent?
  • 128
  • 256
  • 512
  • 1,024
Answer: B — 2^8 = 256 characters.
57Why can't you perform arithmetic directly on ASCII values of digits?
  • Because ASCII only stores letters
  • Because the ASCII code for '7' is different from the numeric binary value 7
  • Because ASCII values are too large
  • Because computers cannot add ASCII values
Answer: B — '7' in ASCII is 00110111 (55 denary), not 00000111 (7 denary).
58Which of the following statements about ASCII is correct?
  • Every character (including space and punctuation) has its own unique binary code
  • Only letters have binary codes; spaces and punctuation are ignored
  • All characters use the same binary code
  • ASCII codes can only be used for numbers, not text
Answer: A — Every character in a character set, including space, has its own unique binary code.
59Which character set includes emojis?
  • ASCII
  • Extended ASCII
  • Unicode
  • BCD
Answer: C — Unicode includes emojis and symbols from many languages.
60How many bits are needed to represent 256 different characters?
  • 7
  • 8
  • 16
  • 32
Answer: B — 2^8 = 256, so 8 bits.
Section 5: Representing Sound (Questions 61–75)
61What is the name of the process where an analogue sound wave is measured at regular intervals to convert it into digital data?
  • Modulation
  • Sampling
  • Amplification
  • Compression
Answer: B — Sampling is the process of measuring a sound wave at regular intervals (each measurement is a sample).
62What is the sample rate?
  • The number of bits used to represent each sample
  • The number of samples taken per second
  • The total duration of the recording
  • The frequency of the sound wave
Answer: B — Sample rate is the number of samples per second (measured in Hz).
63Which of the following best describes sample resolution?
  • The number of samples taken per second
  • The number of bits used to store the value of each sample
  • The length of time the recording lasts
  • The volume (amplitude) of the sound wave
Answer: B — Sample resolution (bit depth) is the number of bits per sample. Sample rate is the number of samples per second — don't mix them up!
64What effect does increasing the sample rate have on the sound file?
  • It decreases the file size and improves quality
  • It increases the file size and improves quality
  • It decreases the file size and reduces quality
  • It has no effect on file size or quality
Answer: B — More samples per second = better quality but larger file.
65What effect does increasing the sample resolution have on the sound file?
  • It decreases the file size and improves quality
  • It increases the file size and improves accuracy of each sample
  • It decreases the file size and reduces quality
  • It has no effect on file size or quality
Answer: B — More bits per sample = more accurate samples, but larger file.
66Which formula correctly calculates the file size of an uncompressed sound file?
  • File size = sample rate × duration × sample resolution
  • File size = sample rate × sample resolution ÷ duration
  • File size = duration × sample resolution ÷ sample rate
  • File size = sample rate + duration + sample resolution
Answer: A — File size = sample rate × duration × sample resolution.
67A sound is recorded for 2 seconds at a sample rate of 1,000 Hz with a resolution of 8 bits. What is the file size in bits?
  • 2,000 bits
  • 8,000 bits
  • 16,000 bits
  • 32,000 bits
Answer: C — 1,000 × 2 × 8 = 16,000 bits.
68A sound is recorded for 2 seconds at a sample rate of 1,000 Hz with a resolution of 8 bits. What is the file size in bytes?
  • 500 bytes
  • 1,000 bytes
  • 2,000 bytes
  • 4,000 bytes
Answer: C — 16,000 bits ÷ 8 = 2,000 bytes.
69What is the typical hearing range for humans?
  • 20 Hz to 20,000 Hz
  • 0 Hz to 10,000 Hz
  • 100 Hz to 100,000 Hz
  • 1 Hz to 1,000 Hz
Answer: A — Human hearing range is roughly 20 Hz to 20,000 Hz.
70Which device converts analogue sound signals into digital data?
  • DAC (Digital-to-Analogue Converter)
  • ADC (Analogue-to-Digital Converter)
  • Amplifier
  • Speaker
Answer: B — An ADC converts analogue to digital.
71Which device converts digital data back into an analogue sound signal?
  • ADC (Analogue-to-Digital Converter)
  • DAC (Digital-to-Analogue Converter)
  • Microphone
  • Amplifier
Answer: B — A DAC converts digital back to analogue.
72What happens to the quality of a sound recording if the sample rate is too low?
  • The sound is more accurate
  • The sound is less accurate and may miss high frequencies
  • The sound file is larger
  • The sound is unchanged
Answer: B — A low sample rate misses detail and high frequencies.
73Which of the following is a lossy audio file format?
  • FLAC
  • WAV
  • MP3
  • ALAC
Answer: C — MP3 is lossy; FLAC, WAV, and ALAC are lossless.
74What is the main advantage of lossless audio compression?
  • It produces much smaller files than lossy compression
  • It preserves the original audio exactly
  • It is faster to stream
  • It requires less storage space than lossy
Answer: B — Lossless preserves the original audio exactly.
75If a sound file has a sample rate of 500 Hz, how many samples are taken in 4 seconds?
  • 500
  • 1,000
  • 2,000
  • 4,000
Answer: C — 500 × 4 = 2,000 samples.
Section 6: Representing Images (Questions 76–88)
76What is a pixel?
  • A type of image file format
  • The smallest unit of a digital image
  • A colour code used in HTML
  • A compression algorithm for images
Answer: B — A pixel is the smallest unit of a digital image.
77What is the resolution of an image?
  • The number of colours in the image
  • The number of pixels in the image (width × height)
  • The file size of the image
  • The number of bits per pixel
Answer: B — Resolution is the number of pixels in the image.
78What is colour depth?
  • The number of pixels in the image
  • The number of bits used to represent the colour of a single pixel
  • The physical size of the image on screen
  • The file format of the image
Answer: B — Colour depth is the number of bits per pixel.
79How many colours can be represented with a 1-bit colour depth?
  • 1
  • 2
  • 4
  • 8
Answer: B — 2^1 = 2 colours (black and white).
80How many colours can be represented with a 24-bit colour depth?
  • 256
  • 65,536
  • 16.7 million
  • 1 billion
Answer: C — 2^24 ≈ 16.7 million colours.
81What is the formula for calculating the file size of an uncompressed image?
  • Width × Height × Colour Depth
  • Width + Height + Colour Depth
  • Width × Height ÷ Colour Depth
  • Colour Depth ÷ (Width × Height)
Answer: A — File size = width × height × colour depth.
82An image is 10 × 10 pixels with 8-bit colour depth. What is its file size in bits?
  • 100 bits
  • 800 bits
  • 1,000 bits
  • 8,000 bits
Answer: B — 10 × 10 × 8 = 800 bits.
83An image is 10 × 10 pixels with 8-bit colour depth. What is its file size in bytes?
  • 10 bytes
  • 100 bytes
  • 800 bytes
  • 1,000 bytes
Answer: B — 800 bits ÷ 8 = 100 bytes.
84What effect does increasing the colour depth have on the image file size?
  • It decreases the file size
  • It increases the file size
  • It has no effect on file size
  • It halves the file size
Answer: B — More bits per pixel = larger file.
85What effect does reducing the resolution have on an image?
  • The image becomes sharper
  • The image loses fine detail and may appear blurred
  • The image gains more colours
  • The image file size increases
Answer: B — Fewer pixels = less detail, blurrier image.
86What is metadata in an image file?
  • The pixel data itself
  • Data about the data — such as width, height, colour depth, and format
  • The compression algorithm used
  • The colour palette of the image
Answer: B — Metadata is data about the data.
87Which of the following is a lossless image format?
  • JPEG
  • PNG
  • MP3
  • MP4
Answer: B — PNG is lossless; JPEG is lossy.
88What does RLE stand for?
  • Run Length Encoding
  • Random Loss Encoding
  • Reduced Loss Encoding
  • Real Loss Encoding
Answer: A — RLE = Run Length Encoding.
Section 7: Compression (Questions 89–100)
89What is compression?
  • The process of increasing file size for better quality
  • The process of reducing file size using algorithms
  • The process of converting files to binary
  • The process of encrypting files
Answer: B — Compression reduces file size.
90What is decompression?
  • The process of compressing a file further
  • The process of restoring compressed data to a usable format
  • The process of deleting compressed files
  • The process of copying compressed files
Answer: B — Decompression restores compressed data.
91What is the main difference between lossy and lossless compression?
  • Lossy reduces file size; lossless does not
  • Lossy permanently removes some data; lossless does not
  • Lossless is faster than lossy
  • Lossy is used only for text files
Answer: B — Lossy removes data permanently; lossless preserves all data.
92Which of the following file formats uses lossy compression?
  • PNG
  • JPEG
  • ZIP
  • FLAC
Answer: B — JPEG is lossy; PNG, ZIP, and FLAC are lossless.
93Which of the following file formats uses lossless compression?
  • MP3
  • MP4
  • PNG
  • JPEG
Answer: C — PNG is lossless; MP3, MP4, and JPEG are lossy.
94How does Run Length Encoding (RLE) compress data?
  • By removing every other bit
  • By recording frequency/data pairs for runs of identical values
  • By converting binary to hexadecimal
  • By randomly discarding data
Answer: B — RLE records how many times a value repeats, then the value.
95Using RLE, how would the row 11110000 be encoded (where 1 = white, 0 = black)?
  • 4 1 4 0
  • 1 4 0 4
  • 8 1 0
  • 4 0 4 1
Answer: A — Four 1s, then four 0s → 4 1 4 0.
96What is a digital artefact in the context of lossy compression?
  • A type of file format
  • A small visual mistake introduced by lossy compression
  • A compression algorithm
  • A type of metadata
Answer: B — Digital artefacts are small mistakes from lossy compression.
97Why is lossy compression unsuitable for compressing a computer program?
  • It would make the program run faster
  • A single missing character could stop the program from running
  • It would increase the file size
  • It would change the programming language
Answer: B — Program code must be exact; missing data breaks it.
98What is the effect of reducing the sample rate of an audio file?
  • It increases the file size and quality
  • It decreases the file size and permanently loses some sound data
  • It has no effect on the file
  • It increases the number of bits per sample
Answer: B — Lower sample rate = smaller file but permanently lost data.
99Which of the following is a benefit of compression?
  • Increased bandwidth required
  • Longer transmission time
  • Less storage space required
  • More data usage on mobile contracts
Answer: C — Compression reduces storage space needed.
100Which of the following is true about lossless compression?
  • It permanently removes some data
  • It restores the original data exactly
  • It is used only for video files
  • It always produces smaller files than lossy compression
Answer: B — Lossless restores the original exactly.
