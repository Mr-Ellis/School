🖥️ Why Build a GUI for Your IA?

Important: The course does not explicitly teach GUI creation. But for your Internal Assessment, the strongest projects include a graphical user interface built with classes and OOP.

Choosing a GUI over a command-line interface gives you a clear edge in the IA criteria:

AspectCLI ProjectGUI Project (with OOP)
ComplexityLimited to text I/OEvent handling, widgets, layout, multiple classes
OOP IntegrationOften proceduralNatural fit — windows, frames, widgets as classes
User ExperienceFunctional but plainProfessional, intuitive, demonstrable
IA CriteriaHarder to show complexityEasier to justify modularity and design
Portfolio ValueLess impressiveStrong showcase piece

🔑 Key Insight: A GUI built with classes and OOP naturally demonstrates decomposition, modularity, and complexity — all highly valued in the IA.

ComponentPurposeCommon IA Use

Entry / Text BoxesUser inputForms, search bars
FramesGroup widgetsOrganise layout

Listboxes / TablesDisplay dataRecords, search results

✅ IA GUI Checklist

  • GUI built using classes and OOP
  • Multiple windows or frames (login → main → settings)
  • Input validation and error handling
  • Data persistence (file I/O or database)
  • At least one complex algorithm
  • Clean, modular code with comments
  • Professional-looking interface
  • Documentation explaining class structure
  • Video demonstration of the working app
