🏗️ The "Invisible" Barcode Scanner

Your complete guide to building the physical prototype, the GitHub webpage, and nailing the 2-minute pitch.

1 Set Up GitHub & Your Webpage

You will use GitHub Pages to host your interactive webpage for free.

  1. Create a GitHub Account: Go to github.com and sign up using your school email. Choose a professional username (e.g., isr-barcode-team).
  2. Create a New Repository: Click the + icon (top right) > New repository. Name it barcode-scanner-hackathon. Set it to Public, check "Add a README file", and click Create repository.
  3. Create the File: Click Add file > Create new file. Name it exactly index.html (This is crucial; GitHub Pages looks for this file).
  4. Paste the Code: Copy the complete code from Phase 2 below and paste it into the new file. Click Commit changes.
  5. Turn on GitHub Pages: Go to the Settings tab of your repository. On the left sidebar, click Pages. Under "Build and deployment", set the Source to Deploy from a branch, set the Branch to main (or master) and the folder to / (root). Click Save.
  6. Wait 1-2 minutes, refresh the page, and you will see a green box with your live URL (e.g., https://your-username.github.io/barcode-scanner-hackathon/).

    <script>
        // 1. Generate a random-looking barcode on the screen
        const barcodeDisplay = document.getElementById('barcode-display');
        const barWidths = [4, 2, 6, 2, 4, 8, 2, 4, 2, 6, 4, 2, 8, 2, 4, 6, 2, 4, 2, 8, 2, 4, 6, 2, 4, 2, 8, 4, 2, 6];
        
        barWidths.forEach(width => {
            const bar = document.createElement('div');
            bar.className = 'bar';
            bar.style.width = width + 'px';
            barcodeDisplay.appendChild(bar);
        });

        // 2. The Scanning Logic
        let isScanning = false;

        function startScan() {
            if (isScanning) return;
            isScanning = true;

            const scanner = document.getElementById('scanner');
            const binaryDisplay = document.getElementById('binary-display');
            const resultDisplay = document.getElementById('result-display');
            const scanBtn = document.getElementById('scanBtn');

            // Reset UI
            scanner.classList.add('scanning');
            resultDisplay.classList.remove('show');
            binaryDisplay.innerHTML = '';
            scanBtn.innerText = "Scanning...";
            
            let binaryString = "";
            let iterations = 0;
            
            // Simulate reading the light levels (1s and 0s)
            const interval = setInterval(() => {
                // Randomly generate 1 or 0 to simulate the black/white reflection
                const bit = Math.random() > 0.5 ? "1" : "0";
                binaryString += bit;
                
                // Keep the display looking neat
                if (binaryString.length > 16) {
                    binaryString = binaryString.slice(1);
                }
                
                binaryDisplay.innerText = binaryString;
                iterations++;

                // Stop after 1.5 seconds (when the laser animation finishes)
                if (iterations > 30) {
                    clearInterval(interval);
                    scanner.classList.remove('scanning');
                    scanBtn.innerText = "Scan Complete";
                    
                    // Show the final result
                    setTimeout(() => {
                        resultDisplay.classList.add('show');
                        scanBtn.innerText = "Scan Again";
                        isScanning = false;
                    }, 300);
                }
            }, 50); // Update every 50ms
        }
    </script>

4 The 2-Minute Pitch (What to say)

When you present to the judges, do not just show the code. Tell a story:

  • 0:00 - 0:20 (The Hook): "Every day, we scan items at the grocery store without thinking. But how does a machine read a piece of paper? Today, we are going to show you the invisible science behind the barcode."
  • 0:20 - 0:50 (The Mechanism): "A barcode scanner is just a light sensor. Black bars absorb light, and white gaps reflect it. By sliding our physical Micro:bit over a printed barcode, we are capturing that exact reflection."
  • 0:50 - 1:20 (The Demo): "Watch the screen. As I physically slide the Micro:bit (Input), the webpage translates the light changes into binary 1s and 0s (Output). This is exactly how the computer reads the price."
  • 1:20 - 1:40 (The Aha Moment): "The 'magic' is that the webpage is reacting in real-time to the physical world. Analog light becomes digital data instantly."
  • 1:40 - 2:00 (Conclusion): "By understanding these invisible mechanisms, we understand the technology we use every day. Thank you."

5 Connecting the Physical Micro:bit

To connect the physical Micro:bit to your webpage, you will use MakeCode and the Web Serial feature. If you get stuck on this part, ask Mr. Ellis for help!

  1. MakeCode Code: Write a simple program in MakeCode that continuously sends the light level to the serial port: serial.writeValue("light", input.lightLevel()).
  2. Plug it in: Connect the Micro:bit to the laptop running the webpage via USB.
  3. The Integration: Instead of just clicking a "Start Scan" button, modify the JavaScript in your index.html to listen for the serial data. When the light level drops (simulating the black bar of the barcode), trigger the laser animation and output a "1". When the light level is high, output a "0".
