🏗️ The "Invisible" Barcode Scanner

Your complete guide to building the physical prototype, the GitHub webpage, and nailing the 2-minute pitch.

⚠️ CRITICAL DESIGN REQUIREMENT

Your webpage must work perfectly on its own. The judges will look at your webpage before or after they see your physical Micro:bit. If the webpage requires the Micro:bit to be plugged in just to show the animation, you will fail the "One Rule."

Your webpage needs a "Demo Mode" (a simple button click that runs the animation). The physical Micro:bit is a bonus that triggers the same animation when connected.

1 Set Up GitHub & Your Webpage

You will use GitHub Pages to host your interactive webpage for free.

  1. Create a GitHub Account: Go to github.com and sign up using your school email. Choose a professional username (e.g., isr-barcode-team).
  2. Create a New Repository: Click the + icon (top right) > New repository. Name it barcode-scanner-hackathon. Set it to Public, check "Add a README file", and click Create repository.
  3. Create the File: Click Add file > Create new file. Name it exactly index.html (This is crucial; GitHub Pages looks for this file).
  4. Paste the Code: Copy the complete code from Phase 2 below and paste it into the new file. Click Commit changes.
  5. Turn on GitHub Pages: Go to the Settings tab of your repository. On the left sidebar, click Pages. Under "Build and deployment", set the Source to Deploy from a branch, set the Branch to main (or master) and the folder to / (root). Click Save.
  6. Wait 1-2 minutes, refresh the page, and you will see a green box with your live URL (e.g., https://your-username.github.io/barcode-scanner-hackathon/).

    <script>
        let isScanning = false;
        const leds = document.querySelectorAll('.led');
        const lightFill = document.getElementById('light-fill');
        const binaryDisplay = document.getElementById('binary-display');
        const resultDisplay = document.getElementById('result-display');
        const scanner = document.getElementById('scanner');
        const scanBtn = document.getElementById('scanBtn');
        const statusText = document.getElementById('status-text');

        function startScan() {
            if (isScanning) return;
            isScanning = true;

            // Reset UI
            scanner.classList.add('scanning');
            resultDisplay.classList.remove('show');
            binaryDisplay.innerHTML = '';
            scanBtn.innerText = "Scanning...";
            statusText.innerText = "Processing data...";
            
            let binaryString = "";
            let iterations = 0;
            
            // Simulate reading the light levels (1s and 0s)
            const interval = setInterval(() => {
                // 1. INPUT: Randomly simulate light level (0-100)
                const lightLevel = Math.random() * 100;
                
                // Update Light Meter
                lightFill.style.width = lightLevel + "%";
                
                // Update LEDs (turn some red based on light level)
                leds.forEach(led => {
                    if (Math.random() > 0.5) {
                        led.classList.add('active');
                    } else {
                        led.classList.remove('active');
                    }
                });

                // 2. PROCESS: Convert to binary (High light = 1, Low light = 0)
                const bit = lightLevel > 50 ? "1" : "0";
                binaryString += bit;
                
                if (binaryString.length > 16) {
                    binaryString = binaryString.slice(1);
                }
                
                binaryDisplay.innerText = binaryString;
                iterations++;

                // 3. OUTPUT: Stop and reveal
                if (iterations > 30) {
                    clearInterval(interval);
                    scanner.classList.remove('scanning');
                    scanBtn.innerText = "Scan Complete";
                    
                    setTimeout(() => {
                        resultDisplay.classList.add('show');
                        scanBtn.innerText = "Scan Again";
                        statusText.innerText = "Scan complete. Ready for next input.";
                        // Reset visuals
                        lightFill.style.width = "0%";
                        leds.forEach(led => led.classList.remove('active'));
                        isScanning = false;
                    }, 300);
                }
            }, 50);
        }
    </script>

4 The 2-Minute Pitch (What to say)

When you present to the judges, use the visual layout of your webpage to guide your story:

  • 0:00 - 0:20 (The Hook): "Every day, we scan items at the grocery store without thinking. But how does a machine read a piece of paper? Today, we are going to show you the invisible science behind the barcode."
  • 0:20 - 0:50 (The Mechanism): "A barcode scanner is just a light sensor. Black bars absorb light, and white gaps reflect it. On the left side of our screen, you can see the Input: the raw light level. As we slide our physical Micro:bit over a printed barcode, we are capturing that exact reflection."
  • 0:50 - 1:20 (The Demo): "Watch the middle section. This is the Process. The computer translates the analog light changes into digital binary 1s and 0s in real-time. It's translating physics into code."
  • 1:20 - 1:40 (The Aha Moment): "Finally, the Output. Once the computer recognizes the pattern, it reveals the price. The 'magic' is that the webpage is reacting in real-time to the physical world."
  • 1:40 - 2:00 (Conclusion): "By understanding these invisible mechanisms, we understand the technology we use every day. Thank you."

5 Connecting the Physical Micro:bit (The Bonus)

Your page works without the hardware. Now, let's make it work with the hardware. You will use MakeCode and the Web Serial feature.

  1. MakeCode Code: Write a simple program in MakeCode that continuously sends the light level to the serial port: serial.writeValue("light", input.lightLevel()).
  2. Plug it in: Connect the Micro:bit to the laptop via USB.
  3. Check the Port: You cannot just open the HTML file from your computer's hard drive for Web Serial to work. You must open the live GitHub Pages URL (the `https://...` link).
  4. The Integration: Modify the JavaScript in your index.html to listen for the serial data. Instead of `Math.random()`, use the actual light level from the Micro:bit to update the light meter and generate the binary.
