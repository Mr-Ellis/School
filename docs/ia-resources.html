Before You Start

A common mistake is believing that the highest-scoring IA is the most technically advanced.

It isn't.

The highest-scoring IA is usually the one that:

  • Solves a real problem
  • Uses appropriate complexity
  • Is well documented
  • Has strong testing evidence
  • Includes meaningful client feedback
  • Demonstrates good computational thinking

A well-designed Python application using OOP, SQLite and a professional GUI can easily outperform an overcomplicated web application that is poorly documented.

Criterion A

Problem Identification & Client Requirements
Microsoft Forms forms.office.com IA Rating Learning Curve: ⭐ Best For: Client interviews, Requirements gathering, Feedback collection, Success criteria evidence
Why It Is Recommended

Many students invent requirements. Strong students collect requirements directly from their client.

Forms provides: charts, statistics, screenshots, client evidence — which makes Criterion A significantly stronger.

Google Forms forms.google.com IA Rating Learning Curve: ⭐ Best For: Surveys, User feedback, Requirements gathering
Why It Is Recommended

An excellent alternative to Microsoft Forms. Particularly useful when collecting responses from multiple users.

Miro miro.com IA Rating Learning Curve: ⭐⭐ Best For: Brainstorming, Stakeholder mapping, Requirement analysis
Why It Is Recommended

Students can visually map: users, problems, workflows — which often leads to stronger project ideas.

Criterion B

Design
Draw.io (Diagrams.net) app.diagrams.net IA Rating Learning Curve: ⭐⭐ Best For: Flowcharts, UML diagrams, ERDs, System diagrams
Why It Is Recommended

This is probably the single most important design tool for the IA. It allows students to create professional UML diagrams, database designs, and flowcharts that directly support Criterion B.

Every student should learn this.

Excalidraw excalidraw.com IA Rating Learning Curve: ⭐ Best For: Rapid sketches, Early-stage planning, Interface ideas
Why It Is Recommended

Extremely simple and quick. Perfect for generating draft designs before producing formal diagrams.

Mermaid Live Editor mermaid.live IA Rating Learning Curve: ⭐⭐⭐ Best For: Diagram-as-code, Maintaining evolving designs
Why It Is Recommended

Students can generate diagrams from text. Excellent for stronger programmers.

Criterion C

System Overview · Algorithms & Flowcharts
PyFlow — Python to Flowchart Visualizer python2flow.html IA Rating Learning Curve: ⭐⭐ Best For: Generating flowcharts from Python code
Why It Is Recommended

Generate professional flowcharts directly from your Python code. Essential for Criterion C — use this tool to visualize your algorithms and logic, making your system overview much stronger.

Simply paste your Python code into the editor and the flowchart is generated automatically. Supports up to 30 lines of code.

Python Tutor pythontutor.com IA Rating Learning Curve: ⭐ Best For: Visualizing variables, Memory changes, Demonstrating loops and functions
Why I love it for IB
  • Visualizes variables step-by-step
  • Shows memory changes
  • Demonstrates loops and functions
  • Incredible evidence for explaining algorithms in Criterion C

Students can literally screenshot program execution and explain what is happening.

Draw.io app.diagrams.net IA Rating Learning Curve: ⭐⭐ Best For: Flowcharts, UML diagrams, System diagrams
Why It Is Recommended

Professional diagrams that support Criterion C. Essential for system modeling.

Learning Python

Core & OOP Fundamentals
Online Python (learn.online-python.com) learn.online-python.com IA Rating Learning Curve: ⭐ Best For: Core Python, Functions, Data structures, Practical programming
Why It Is Recommended

This is one of the most efficient Python resources available. Students learn concepts through direct practice rather than long theoretical lessons. Excellent preparation for IA development.

Online Python Console learn.online-python.com IA Rating Learning Curve: ⭐ Best For: Instant execution, Learning concepts, Quick testing
Why It Is Recommended

Instant execution with no installation. Excellent for learning concepts. Not ideal as the final development environment but brilliant for learning and quick testing.

Object-Oriented Programming object-programming IA Rating Learning Curve: ⭐⭐⭐ Best For: Classes, Objects, Methods, Inheritance, Encapsulation
Why It Is Recommended

This may be the highest-value resource in the entire guide.

Object-Oriented Programming allows students to demonstrate: abstraction, modularity, maintainability, complexity — which are all valuable when discussing development decisions.

A project built around classes is generally much easier to justify in Criterion C than one large script.

W3Schools Python w3schools.com/python IA Rating Learning Curve: ⭐ Best For: Quick reference, Syntax checking, Small examples
Why It Is Recommended

When students forget how something works, W3Schools is often the fastest place to find an answer.

Real Python realpython.com IA Rating Learning Curve: ⭐⭐⭐⭐ Best For: Intermediate development, SQLite, APIs, Classes, Advanced Python
Why It Is Recommended

Think of Real Python as a professional reference library. Students should not try to complete everything. Instead, use it when solving specific problems.

Replit replit.com IA Rating Learning Curve: ⭐⭐ Best For: Quick prototype testing, Easy sharing with clients
Why It Is Recommended
  • Runs Python in the browser
  • Quick prototype testing
  • Easy sharing with clients

Great for experimenting before moving into the final solution.

IDEs

Development Environment
VS Code code.visualstudio.com IA Rating Learning Curve: ⭐⭐⭐ Best For: Professional development, Debugging, GitHub integration
Why It Is Recommended

VS Code has become the standard coding environment for many developers.

Benefits include: IntelliSense, Extensions, Git integration, Debugging tools.

Students planning to study Computer Science later should strongly consider using VS Code.

Thonny thonny.org IA Rating Learning Curve: ⭐ Best For: Beginner Python programming, Debugging, Learning
Why It Is Recommended
  • Best debugger for beginners
  • Step through line-by-line
  • Variable viewer
  • Easy screenshots for Criterion C

Honestly, if a student struggles with debugging, I would move them from VS Code to Thonny immediately.

Recommended Learning Path

Follow these stages in order
1 Learn Python Fundamentals Online Python
2 Learn Object-Oriented Programming Object Programming (Online Python)
3 Learn Data Storage SQLite Tutorial · DB Browser
4 Build a GUI CustomTkinter
5 Design Documentation Draw.io
6 Development Tracking GitHub
7 Testing ShareX · Excel · OBS Studio

The "7-Friendly" IA Stack

If you are unsure which technologies to use, this is the safest high-scoring combination:
Python Object-Oriented Programming VS Code or Thonny CustomTkinter SQLite Draw.io GitHub Microsoft Forms OBS Studio
This combination provides enough complexity to demonstrate strong computational thinking while remaining achievable within the constraints of the IB Computer Science Internal Assessment.
