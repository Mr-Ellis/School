Before You Start
A common mistake is believing that the highest-scoring IA is the most technically advanced. It isn't.

The highest-scoring IA is usually the one that:

  • Solves a real problem
  • Uses appropriate complexity
  • Is well documented
  • Has strong testing evidence
  • Includes meaningful client feedback
  • Demonstrates good computational thinking

A well-designed Python application using OOP, SQLite and a professional GUI can easily outperform an overcomplicated web application that is poorly documented.

The "7-Friendly" IA Stack

⭐ If you are unsure which technologies to use, this is the safest high-scoring combination:

Python Object-Oriented Programming VS Code or Thonny CustomTkinter SQLite Draw.io GitHub Microsoft Forms OBS Studio
This combination provides enough complexity to demonstrate strong computational thinking while remaining achievable within the constraints of the IB Computer Science Internal Assessment.

Criterion A

Problem Identification & Client Requirements
Microsoft Forms forms.office.com ⭐ learning
Google Forms forms.google.com ⭐ learning
Miro miro.com ⭐⭐ learning

📋 Client requirements & feedback

  • Microsoft Forms — charts, statistics, screenshots, client evidence
  • Google Forms — excellent alternative, particularly for multi-user responses
  • Miro — visual mapping of users, problems and workflows
Why it matters: Many students invent requirements. Strong students collect requirements directly from their client. Forms provide charts, statistics and screenshots that make Criterion A significantly stronger.

Criterion C

System Overview · Algorithms & Flowcharts
PyFlow Visualizer python2flow.html ⭐⭐ learning
Python Tutor pythontutor.com ⭐ learning
Draw.io app.diagrams.net ⭐⭐ learning

🧩 System modeling & algorithm visualization

  • PyFlow Visualizer — generate flowcharts directly from your Python code (paste code → flowchart)
  • Python Tutor — step-by-step variable visualization, memory changes, loop demonstration
  • Draw.io — professional system diagrams
Why it matters: You can literally screenshot program execution (Python Tutor) or generate flowcharts (PyFlow) to explain your algorithms in Criterion C. Both provide incredible evidence.

Learning Python

Core & OOP Fundamentals
OOP (Online Python) object-programming ⭐⭐⭐ learning
Online Python learn.online-python.com ⭐ learning
Real Python realpython.com ⭐⭐⭐⭐ learning
W3Schools w3schools.com/python ⭐ learning
Replit replit.com ⭐⭐ learning

🐍 Core Python & OOP

  • OOP (Online Python) — highest-value resource. Classes, objects, inheritance, encapsulation
  • Online Python — learn through direct practice, not theory
  • Real Python — professional reference for SQLite, APIs, advanced topics
  • Replit — runs Python in the browser, quick prototyping, easy sharing
Why it matters: A project built around classes is generally much easier to justify in Criterion C than one large script. OOP allows you to demonstrate abstraction, modularity and maintainability.

IDEs

Development Environment
VS Code code.visualstudio.com ⭐⭐⭐ learning
Thonny thonny.org ⭐ learning

🖥️ Choose your IDE

  • VS Code — professional: IntelliSense, extensions, Git integration, debugging
  • Thonny — best debugger for beginners: step through line-by-line, variable viewer, easy screenshots for Criterion C
Why it matters: If you are planning to study Computer Science later, you should strongly consider using VS Code. If you struggle with debugging, I would suggest you move from VS Code to Thonny immediately.

GUI Development

Desktop Interfaces
CustomTkinter customtkinter ⭐⭐ learning
Flet flet.dev ⭐⭐⭐ learning
Tkinter docs.python.org ⭐⭐ learning

🖌️ Desktop interfaces

  • CustomTkinter — professional look, beginner-friendly, excellent mark-to-effort ratio
  • Flet — cross-platform (desktop, web, mobile) using only Python
  • Tkinter — reliable, widely documented, still fully acceptable
Why it matters: CustomTkinter is currently my recommended GUI framework — it produces attractive interfaces quickly and provides one of the best mark-to-effort ratios available.

Databases

Data Storage
SQLite sqlitetutorial.net ⭐⭐ learning
DB Browser sqlitebrowser.org ⭐ learning

🗄️ SQLite

  • SQLite — lightweight, easy to learn, included with Python
  • DB Browser — inspect databases, debug records, take screenshots for Criterion C
Why it matters: Adding a database immediately increases your project's sophistication. Perfect for IB projects.

Version Control

GitHub
GitHub github.com ⭐⭐⭐ learning
Why it matters: You gain: version history, recovery points, evidence of development. A GitHub repository is often useful long after the IA ends.
