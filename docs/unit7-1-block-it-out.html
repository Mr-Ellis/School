7.1 Block it out

Moving from blocks to text · Lessons 1–4
Lesson 1 · Intro to Python pages 8–18

Think of programming like using a super-smart calculator. You type instructions, and Python helps you get answers! We use IDLE — a notebook for writing, testing, and running Python programs.

Tip: Add comments with # — notes that help you (and others) understand your code.

🔢 Data Types in Python

  • Integers — whole numbers like 5
  • Floats — decimal numbers like 3.14
  • Strings — text like "Hello"

🖥️ Basic I/O

  • print() — shows messages on the screen
  • input() — asks the user for information
# Example: greet the user name = input("What's your name? ") print("Hi " + name + "!")

➕ Math & Debugging

  • + addition · - subtraction · * multiplication · / division
  • Errors are normal! They help you learn. Use comments to explain what each part does.
Lesson 2 · Plan Like a Detective pages 18–27

Before you code, plan! A flowchart is a treasure map for your program — it shows the steps the computer will follow.

🔵 Start/Stop — beginning and end
🟩 Process — actions like adding numbers
🟨 Input/Output — ask or show
🔶 Decision — choices (if/else)

Example: Add Two Numbers

# Flowchart → Python number1 = int(input("Enter first number: ")) number2 = int(input("Enter second number: ")) total = number1 + number2 print("The sum is:", total)
Predict before you test: If you enter 15 and 20, what will the program show? This checks if your plan makes sense.

💻 Your Challenge: Make a program that asks for two numbers, calculates their average, and shows the answer (even with decimals!).

Lesson 3 · BIDMAS & Decisions pages 28–35

🔢 BIDMAS — Order of Operations

  • Brackets · Indices (powers) · Division · Multiplication · Addition · Subtraction
# Python follows BIDMAS print(3 + 4 * 5) # 23 (4*5 first) print(5 * (8 + 6)) # 70 (brackets first)

🤔 Making Choices with if

score = int(input("Enter score: ")) if score > 100: print("Well done!") else: print("Try again!")

🧩 Sub‑routines (Functions)

Mini‑programs inside your main program — keep things neat and reusable.

def add(num1, num2): return num1 + num2 # Use it anywhere result = add(5, 3) print(result) # 8
Try it: Make a program that checks if a number squared is bigger than 100. Compare two numbers and show either the sum or the difference.
Lesson 4 · Sub‑routines & Challenge pages 36–39

Sub‑routines are like mini‑programs inside a bigger program. They break big tasks into smaller, easier parts.

  • Keep code neat — organised and readable
  • Reusable — write once, use many times
  • Easier to fix — find bugs faster

🧮 Example: Calculator with sub‑routines

def add(): total = number1 + number2 print("The total is:", total) def subtract(): diff = number1 - number2 print("The difference is:", diff)
