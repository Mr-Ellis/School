The Internet — Revision Guide IGCSE Computer Science

This guide teaches you the concepts you need to understand for The Internet unit. It explains key ideas, gives exam technique tips, and provides practice questions so you can test your understanding. Work through each section, then try the practice questions at the end without looking at the notes.

1. Network Hardware

What is a network?

A network is two or more computers connected together to share resources and data. The internet is a global network of networks.

Key network hardware

DeviceWhat it does
NIC (Network Interface Card)Allows a device to connect to a network. Wired NICs use Ethernet; wireless NICs use Wi-Fi. Each NIC has a unique MAC address.
RouterConnects different networks together and directs data packets between them. Home routers connect a LAN to the internet.
SwitchConnects devices within a single network (LAN). Forwards data only to the intended device using MAC addresses.
ModemConverts digital signals from a computer into signals that can travel over telephone, cable, or fibre lines.
Access PointAllows wireless devices to connect to a wired network using Wi-Fi.
Ethernet CablePhysical cable used for wired network connections (e.g., Cat5e, Cat6).
A router connects different networks, while a switch connects devices within the same network.

LAN vs WAN

LAN (Local Area Network)WAN (Wide Area Network)
Area coveredSmall — a home, school, or officeLarge — a country or the world
Owned byUsually the organisation itselfUsually telecom companies
ExamplesHome Wi-Fi, school networkThe internet, mobile networks, bank ATM networks

Connecting to the internet

  • ISP (Internet Service Provider) — a company that provides access to the internet (e.g., BT, Sky, Virgin Media).
  • IP address — a unique address for every device on a network (e.g., 192.168.1.1).
  • DNS (Domain Name System) — translates human-friendly domain names (e.g., google.com) into IP addresses.
Exam tip: If you're asked to identify a device from a scenario, check what it connects to. Same network → switch. Different networks → router. Wireless extension → access point. Signal conversion → modem.

2. MAC & IP Addresses

The two addresses every device has

Every device on a network has two important addresses: a MAC address (physical, permanent) and an IP address (logical, can change).

MAC addresses

  • A unique identifier assigned to a Network Interface Card (NIC) by the manufacturer.
  • Permanent — cannot be changed.
  • 48 bits long, written as 6 pairs of hexadecimal digits (e.g., 00:1A:2B:3C:4D:5E).
  • First 3 pairs = manufacturer ID (OUI). Last 3 pairs = device serial number.
  • Used within a LAN — a switch uses MAC addresses to forward data to the correct device.

IP addresses

  • A logical address assigned to a device when it joins a network.
  • Can change — depends on which network you connect to (dynamic or static).
  • IPv4: 32-bit, written as 4 decimal numbers 0–255 separated by dots (e.g., 192.168.1.1). About 4.3 billion addresses.
  • IPv6: 128-bit, written as 8 groups of hexadecimal. Almost unlimited addresses.
  • Used across networks — routers use IP addresses to forward data between networks, including the internet.

MAC vs IP — the key differences

MAC addressIP address
Physical addressLogical address
Permanent (burned into NIC)Can change (dynamic or static)
48 bits (hexadecimal)32 bits (IPv4) or 128 bits (IPv6)
Used within a LANUsed across networks
Assigned by manufacturerAssigned by network/router

How they work together

  1. Your device creates a data packet with the destination IP address.
  2. Your router uses the IP address to forward the packet across the internet.
  3. When the packet reaches the destination network, a switch uses the MAC address to deliver it to the correct device.
Analogy: An IP address is like your postal address (used to get a letter to your house). A MAC address is like your name (used to identify who the letter is for once it arrives).
Why IPv6? IPv4 only has about 4.3 billion addresses, and they have run out because of the huge number of internet-connected devices. IPv6 uses 128 bits, providing almost unlimited addresses.
Exam tip: Don't say a MAC address "can be changed". It can't — it's burned into the NIC. Only IP addresses change (when you move networks or your router reassigns one).

  • Why do we need both MAC and IP addresses?
  • What is the main difference between IPv4 and IPv6?

3. The Internet and the Web

Internet vs World Wide Web

The InternetThe World Wide Web
The physical infrastructure — a global network of interconnected computer networks (cables, routers, switches, satellites, data centres)A service that runs on the internet — a collection of linked documents (web pages) accessed via a browser
Established: 1960s (ARPANET)Invented: 1989 by Tim Berners-Lee at CERN
The Web needs the internet to work — but the internet does not need the Web. You can send an email, make a video call, or transfer a file without ever opening a web browser.

URLs — Uniform Resource Locators

A URL is the address of a resource on the Web. Every web page, image, or file has its own unique URL.

Example: https://www.bbc.co.uk/news/technology?id=123

PartExampleWhat it does
Protocolhttps://Tells the browser how to communicate. Common: HTTP, HTTPS, FTP.
SubdomainwwwOptional prefix. Other examples: mail, docs.
Domain namebbc.co.ukThe human-readable address of the server. Converted to an IP by DNS.
Top-Level Domain (TLD).ukThe last part of the domain. Examples: .com, .org, .edu, .gov, .uk.
Path/news/technologyThe location of the specific page on the server.
Query string?id=123Extra data sent to the server.
Exam tip: If asked to "identify the parts of a URL", label them clearly: protocol, domain name, path, query string. Don't confuse the domain name (bbc.co.uk) with the subdomain (www).

HTTP and HTTPS

HTTPHTTPS
The rules for how browsers and servers communicate.HTTP with encryption added using TLS/SSL.
Data is sent in plain text — anyone intercepting it can read it.Data is scrambled before it leaves your device.
Used for public pages with no sensitive information.Used for banking, shopping, login pages.
HTTPS ≠ safe website. HTTPS only means the connection is encrypted. A phishing site can still use HTTPS.

How a web page is loaded

  1. Your browser checks its cache — if it has the page, it loads instantly.
  2. If not, it sends a request to a DNS server to translate the domain name into an IP address.
  3. The browser sends an HTTP/HTTPS request to that IP address.
  4. The web server processes the request and returns the HTML, CSS, and images.
  5. The browser renders the page.

Web browsers

A web browser is software that requests, retrieves, and displays web pages (e.g., Chrome, Firefox, Safari, Edge).

Browser vs Search Engine: A browser is software that displays web pages. A search engine (Google) is a website you visit using a browser to find other pages.

DNS — The Domain Name System

Computers use IP addresses to find each other, but humans find it easier to remember names like bbc.co.uk. DNS is the system that translates between the two.

Takes a domain name → returns the IP address of the server that hosts it. DNS servers are maintained by ISPs and organisations.

4. Web Technologies & Cookies

What is a cookie?

A cookie is a small text file (usually under 4KB) that a website stores on your device when you visit it. It contains a name, a value, and metadata like an expiry date.

  • Stored locally in your web browser — not on the website's server.
  • Every time you request a page from the same website, your browser sends the cookie back with the request.
  • Cookies are per-site — a cookie created by amazon.co.uk is only sent back to amazon.co.uk.

Types of cookies

TypeWhat it doesExample
Session cookieTemporary — exists only while you're on the site. Deleted when you close the browser.Keeping you logged in while you browse
Persistent cookieStored for a set period (days, months, or years). Survives closing the browser."Remember me" login, saved preferences
Third-party cookieCreated by a different domain than the one you're visiting — usually advertisers or analytics trackers.Ads following you around the web

What cookies are used for

  • Authentication — keeping you logged in
  • Shopping carts — remembering items you've added
  • Preferences — language, theme, region
  • Analytics — tracking which pages are popular
  • Targeted advertising — showing ads based on your browsing
  • Security — detecting suspicious login attempts

Privacy concerns

  • Tracking across sites — third-party cookies can build a detailed profile of your browsing.
  • Targeted advertising — ads that follow you around can feel intrusive.
  • Data selling — some companies sell cookie data to third parties.
  • Security risks — if cookies aren't encrypted, attackers could steal session data.
The law: In the UK and EU, websites must ask for your consent before setting non-essential cookies (GDPR). That's why you see "Accept all / Manage preferences" banners.

Managing cookies

  • Browser settings — view, delete, and block cookies
  • Incognito / Private mode — cookies are deleted when you close the window
  • Cookie cleaners — extensions that automatically clear cookies after each session

Other web technologies

TechnologyWhat it does
JavaScriptRuns in the browser to make pages interactive — animations, form validation, live updates.
CSSCascading Style Sheets — controls the layout, colours, and fonts of a web page.
HTTPS / TLSEncrypts data between browser and server. Essential for logins and payments.
CDNContent Delivery Network — a network of servers around the world that deliver content from the closest location.
Responsive designWebsites that adapt their layout to fit any screen size.
Server-side scriptingCode like PHP, Python, or Node.js that runs on the web server to generate dynamic pages.
Check your understanding:
  • Where are cookies stored — on your device or on the website's server?
  • What is the difference between a session cookie and a persistent cookie?
  • Why do websites have to ask for your consent before setting non-essential cookies?

5. Cyber Security Threats

What are cyber security threats?

Cyber security threats are methods used by criminals to gain unauthorised access to computer systems, steal data, or disrupt services.

Malware — the six you must know

TypeWhat it does
VirusReplicates its code inside other programs. Harms the computer by deleting, corrupting, or modifying files.
WormReplicates itself to spread to other computers. May cause no damage, but slows down networks significantly.
Trojan horseHides malicious code inside a legitimate-looking program, game, or file. When the user opens it, the harmful code runs.
RansomwareEncrypts the hard drive so the user can't access files. A ransom (often cryptocurrency) is demanded to restore access.
SpywareSecretly finds information about the user, their computer, or their company. Sends it to a hacker for misuse.
AdwareDisplays large numbers of adverts, often in multiple windows.

Other types of attack

AttackWhat it does
Brute-force attackA hacker tries every possible combination of passwords until the correct one is found. A computer can try millions per second.
Data interceptionObtaining data, without permission, that is passing through a network (also called a man-in-the-middle / MITM attack).
DDoS (Distributed Denial of Service)Many computers flood a server with pointless requests, making it slow down or go offline. The computers used are often part of a botnet.
HackingActivities that misuse computer systems or networks.
PhishingEmails, texts, or calls pretending to be from a bank or trusted site, trying to get personal information.
PharmingCombines phishing and farming. The user's computer or a DNS server is altered so a domain name points to the hacker's fake website.
Social engineeringObtaining confidential information by asking people for it — usually with confidence tricks (e.g., phoning a receptionist pretending to be IT support).
Exam tip: Learn the distinguishing feature of each. A virus needs a host file. A worm self-replicates without a host. A Trojan hides inside something legitimate. Ransomware encrypts and demands payment.
Check your understanding:
  • What is the difference between a virus and a worm?
  • What does a DDoS attack do?
  • Why is phishing often described as "social engineering"?

6. Cyber Security Solutions

What are cyber security solutions?

Cyber security solutions are the tools, methods, and behaviours used to protect computer systems, networks, and data from cyber security threats.

Key solutions

SolutionWhat it does
Anti-malwareDetects and removes malware (viruses, worms, Trojans, spyware). Compares files against virus definitions and quarantines suspicious files.
EncryptionScrambles data so it can't be read without the encryption key. Used for stored passwords, hard drive storage, and website communications.
SSL / HTTPSEnsures cryptography is used when transmitting web pages. Shown by the padlock icon in your browser.
FirewallsSeparates a trusted network from an untrusted network (like the internet). Checks packets and drops those that don't match filtering rules — called packet filtering.
Access levelsDifferent users get different permissions. Files may be set as read (open), write (edit/delete), or execute (run). Limits who can do what.
Proxy serversMake requests on your behalf so your IP address is hidden. VPNs use proxy servers. Useful on public Wi-Fi.
Privacy settingsTurn off features to reduce risk: microphone, webcam, location data, website tracking, and cookies.
Strong passwordsMinimum length, mix of uppercase/lowercase/symbols/numbers, changed regularly. Not based on names, dictionary words, or holidays.
BiometricsMeasures physical characteristics to verify identity: fingerprint, facial recognition, retinal scan, palm vein, ear, voice.
Auto updatesAutomatically patches security holes as soon as they're found. Keeps anti-virus and operating systems up to date.
Two-step verificationAsks for a second form of verification (e.g., a code sent to your phone) in addition to your password.
Exam tip: Match the solution to the threat. Phishing → checking URL, tone of communications. Brute-force → strong passwords, account lockout. Malware → anti-malware, automatic updates. Data interception → encryption, HTTPS, proxy servers.
Check your understanding:
  • What does a firewall do?
  • What is the difference between "read", "write", and "execute" access?
  • Why should software updates be applied automatically?

7. Digital Currency

Why were cryptocurrencies invented?

Traditional currencies have weaknesses:

  • Counterfeiting — fake coins and notes can be created.
  • Hyperinflation — governments can print too much money, making each unit worth less.
  • Commission fees — currency exchange and international transfers often carry high fees.
  • Slow transfers — international bank transfers can take days.

How digital currencies work

KeyPurposeAnalogy
Public keyUsed to receive money. Contains the wallet's digital currency address. Can be shared freely.Like an account number
Private keyUsed to spend or transfer money. Must be kept secret.Like a PIN

Keys are stored in a wallet — a file or simple database. If the wallet is printed so it can't be digitally hacked, this is called cold storage.

To spend currency you provide the destination public key and an electronic signature created using your private key. Everyone on the network can verify the transaction as valid.

The blockchain

The blockchain is a distributed digital ledger — a public record of every transaction ever made.

What's in each block?

  • The two parties involved (sender and receiver)
  • A timestamp of when the transaction occurred
  • The amount of currency transferred
  • Its own hash (a unique identifier)
  • A reference to the previous block's hash

Why "distributed"?

  • The ledger is public — anyone can download and view it.
  • There are many copies — no central authority.
  • If one copy is altered, it disagrees with all the others, so fraud is spotted immediately.

How it prevents tampering

Each block links back to the previous block via its hash. If you try to change anything in an earlier block, its hash changes — and every following block's "previous hash" reference becomes wrong. The whole chain visibly breaks.

Uses & benefits

  • International transfers — take minutes instead of days
  • Paying for goods and services
  • Saving
  • Hard to counterfeit
  • Very low fees — no bank needed
  • Supply is tightly controlled by the protocol — no government can just print more
Is hyperinflation prevented? The supply of most cryptocurrencies is controlled, so printing-driven hyperinflation isn't possible. But if people lose trust, no one will want the currency, and its value can fall to zero — effectively the same outcome as hyperinflation. Prices can also be extremely volatile.
Check your understanding:
  • Why is the blockchain described as "distributed"?
  • What is the difference between a public key and a private key?
  • Why can't a government just print more bitcoin?

8. Exam Technique

Command words

  • State / Give / Name — a short answer, often one word or phrase. No explanation needed.
  • Describe — say what happens or what something is. More detail than "state," but no need to explain why.
  • Explain — say how or why. You need to give reasons and make connections.
  • Compare — give similarities and differences.
  • Discuss — give advantages and disadvantages.
Mark allocation: Look at the number of marks. A 2-mark question usually needs two distinct points. A 3-mark question might need three points, or one point with three stages. Don't write one sentence for a 4-mark question — you won't get full marks.

Common mistakes to avoid

  • Confusing the internet with the World Wide Web.
  • Saying a MAC address can be changed (it can't — it's burned into the NIC).
  • Confusing a router (different networks) with a switch (same network).
  • Thinking HTTPS makes a website "safe" — it just means the connection is encrypted.
  • Mixing up session cookies (deleted on browser close) with persistent cookies (stay for a set time).
  • Confusing a virus (needs a host) with a worm (self-replicating).
  • Forgetting that "lossy" data can't be restored — but that's for the Data Representation unit.

Question 1

State the purpose of the following network hardware devices: (3 marks)

(a) Router
(b) Switch
(c) Modem

(a) A router connects different networks together and directs data packets between them.

(b) A switch connects devices within a single network and forwards data only to the intended device using MAC addresses.

(c) A modem converts digital signals from a computer into signals that can travel over telephone, cable, or fibre lines.

(1 mark each.)

Question 2

Explain one difference between a MAC address and an IP address. (2 marks)

A MAC address is a physical address permanently burned into the NIC by the manufacturer, used within a LAN. An IP address is a logical address that can change depending on which network the device connects to, and is used across networks.

(1 mark for each correctly contrasted point.)

Question 3

Why was IPv6 introduced to replace IPv4? (2 marks)

IPv4 uses 32 bits, which provides about 4.3 billion unique addresses. This is not enough for the huge number of internet-connected devices, so the addresses have effectively run out. IPv6 uses 128 bits, providing almost unlimited addresses.

(1 mark for IPv4 running out, 1 mark for IPv6 providing more addresses.)

Question 4

Explain the difference between the internet and the World Wide Web. (2 marks)

The internet is the physical infrastructure — a global network of interconnected computer networks (cables, routers, switches). The World Wide Web is a service that runs on the internet — a collection of linked documents (web pages) accessed via a browser.

(1 mark for internet being infrastructure, 1 mark for WWW being a service on top of it.)

Question 5

Identify the parts of the following URL and explain the purpose of each: https://mail.google.com/inbox?user=anna (4 marks)

https:// — the protocol (secure HTTP)
mail — the subdomain
google.com — the domain name
/inbox — the path
?user=anna — the query string

(1 mark for any four correctly identified and explained.)

Question 6

A user is concerned about their privacy when browsing the web. Describe two privacy concerns related to cookies and explain one way the user can manage them. (3 marks)

Concerns: Third-party cookies can be used by advertisers to track browsing across many sites. Some companies sell cookie data to third parties. Cookies can feel intrusive when used for targeted advertising.

Management: The user can view, delete, or block cookies in their browser's privacy settings. They can also use Incognito / Private browsing mode, which deletes cookies when the window closes.

(1 mark per concern, 1 mark for management method.)

Question 7

Describe what a virus, a worm, and a Trojan horse have in common and how they differ. (3 marks)

Common: All three are types of malware — malicious software designed to harm a computer or steal data.

Differences: A virus replicates its code inside other programs and requires a host file to spread. A worm is self-replicating and can spread across networks without needing a host file. A Trojan horse hides malicious code inside what appears to be a legitimate program, so the user installs it willingly.

(1 mark for common feature, 1 mark for each distinction.)

Question 8

Explain how a firewall helps protect a network from cyber security threats. (2 marks)

A firewall sits between a trusted network (e.g., a school LAN) and an untrusted network (the internet). It examines each packet passing in or out and drops any that don't match its filtering rules (packet filtering), blocking unauthorised traffic.

(1 mark for where it sits, 1 mark for packet filtering / dropping packets.)

Question 9

Explain why the blockchain is described as a "distributed ledger" and why this makes it hard to alter. (3 marks)

The blockchain is a public record of every transaction ever made. It is distributed because there are many copies held on many different computers across the network — there is no central authority. If one copy is altered, it will disagree with all the other copies, so the fraud will be spotted immediately. Each block also links to the previous one via a hash, so changing an earlier block breaks the chain.

(1 mark for public record, 1 mark for distributed / no central authority, 1 mark for hashes linking blocks.)

Question 10

A user receives an email that looks like it's from their bank asking them to click a link and confirm their account details. The link goes to http://secure-bank-login.co/verify. Explain two reasons why this is likely to be a phishing email. (2 marks)

Reason 1: The domain name secure-bank-login.co is not the bank's real domain (e.g., halifax.co.uk). This is a common phishing tactic.

Reason 2: The URL uses http:// rather than https://, so there is no encryption — a legitimate bank would use HTTPS for login pages.

(1 mark per valid reason.)
