Lesson 2 · MAC & IP Addresses
Year 10 · Networks · Addressing & Routing

Learning Objectives

  • Describe what a MAC address is and where it is used
  • Describe what an IP address is and how it differs from a MAC address
  • Explain the purpose of IPv4 and IPv6
  • Understand how MAC and IP addresses work together to deliver data
💡 Key Fact: Every device on a network has two important addresses: a MAC address (physical, permanent) and an IP address (logical, can change). MAC addresses work within a LAN; IP addresses work across networks (including the internet).
🎯 Starter Activity – Think-Pair-Share

Think: How does data know where to go on a network? How does your computer find the right device when sending a message? Share your ideas with a partner.

Click to reveal discussion points
  • Every device needs a unique identifier so data can be delivered correctly.
  • On a local network, devices use MAC addresses (like a serial number).
  • Across the internet, devices use IP addresses (like a postal address).
  • Routers use IP addresses to forward data between networks.

🔖 MAC Addresses (Media Access Control)

📌 What is a MAC address?

A unique identifier assigned to a Network Interface Card (NIC) by the manufacturer. It is permanent and cannot be changed.

Example: 00:1A:2B:3C:4D:5E

🔢 Format

A MAC address is 48 bits long, written as 6 pairs of hexadecimal digits (e.g., 00:1A:2B:3C:4D:5E).

First 3 pairs = manufacturer ID (OUI). Last 3 pairs = device serial number.

📍 Where is it used?

MAC addresses are used within a local network (LAN). A switch uses MAC addresses to forward data to the correct device on the same network.

🧠 Important: MAC addresses operate at the data link layer and are used for communication within a single network. They do not change when you move networks.

🌍 IP Addresses (Internet Protocol)

📌 What is an IP address?

A logical address assigned to a device when it joins a network. It can change depending on which network you connect to.

Example (IPv4): 192.168.1.1

🔢 IPv4 vs IPv6

IPv4: 32-bit, written as 4 decimal numbers (0–255) separated by dots. ~4.3 billion addresses.

IPv6: 128-bit, written as 8 groups of hexadecimal. Almost unlimited addresses.

📍 Where is it used?

IP addresses are used across networks. Routers use IP addresses to forward data between different networks, including the internet.

⚠️ Note: IPv4 addresses have run out because of the huge number of internet-connected devices. IPv6 was created to provide many more addresses.

⚖️ MAC vs IP — Key Differences

🔖 MAC Address
  • Physical address
  • Permanent (burned into NIC)
  • 48 bits (hexadecimal)
  • Used within a LAN
  • Assigned by manufacturer
🌍 IP Address
  • Logical address
  • Can change (dynamic or static)
  • 32 bits (IPv4) or 128 bits (IPv6)
  • Used across networks
  • Assigned by network/router

🔗 How They Work Together

When you send data to a device on another network (e.g., a web server):

  1. Your device creates a data packet with the destination IP address.
  2. Your router uses the IP address to forward the packet across the internet.
  3. When the packet reaches the destination network, a switch uses the MAC address to deliver it to the correct device.
💡 Analogy: Think of an IP address as your postal address (used to get a letter to your house) and a MAC address as your name (used to identify who the letter is for once it arrives).

🔁 Plenary – Addressing Concepts

Discuss the answers to the following questions with a partner:

  1. What is the difference between a MAC address and an IP address?
  2. Why do we need both MAC and IP addresses?
  3. Explain why IPv6 was introduced.
Click to reveal suggested answers
  • MAC vs IP: A MAC address is a permanent physical address assigned by the manufacturer, used within a LAN. An IP address is a logical address that can change, used across networks including the internet.
  • Why both: IP addresses route data between networks. Once the data reaches the correct network, MAC addresses identify the exact device. They work together like a postal address (IP) and a name (MAC).
  • IPv6: IPv4 only has ~4.3 billion addresses, which have run out due to the huge number of internet-connected devices. IPv6 uses 128 bits, providing almost unlimited addresses.
