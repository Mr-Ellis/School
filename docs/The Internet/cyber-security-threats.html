What it does

Replicates itself to spread to other computers. May cause no damage, but slows down networks and computers significantly.

What it does

Hides malicious code inside a legitimate-looking program, game or file. When the user opens it, the harmful code runs.

What it does

Encrypts the hard drive so the user can't access files. A ransom (often cryptocurrency like Bitcoin) is demanded to restore access.

What it does

Secretly finds information about the user, their computer or their company. Sends it to a hacker for misuse.

🎯 Other Types of Attack

🔓 Brute-force attack
A hacker tries every possible combination of passwords until the correct one is found. A computer program can try millions of passwords per second. Protection: use a strong password; lock accounts after 3 failed attempts.
🕵️ Data interception
Obtaining data, without permission, that is passing through a network. Also known as a man-in-the-middle (MITM) attack. Protection: use encrypted connections (HTTPS); avoid unencrypted public Wi-Fi.
🌊 Distributed Denial of Service (DDoS)
Many computers flood a server with pointless requests, making it slow down or go offline. The computers used are often part of a botnet — their owners don't even know. Protection: firewalls, manual settings on switches and routers.
💻 Hacking
Activities that misuse computer systems or networks. People who do this are called hackers.
🎣 Phishing
Emails, texts or phone calls pretending to be from a bank or trusted website, trying to get personal information like usernames, passwords or credit card details.
🌾 Pharming
Combines phishing and farming. The user's computer or a DNS server is altered so that a domain name points to an incorrect IP address — the hacker's fake website.
🧠 Social engineering
Obtaining confidential information by asking people for it — often using confidence tricks. For example, phoning a receptionist, pretending to be IT support, and asking for their password.
