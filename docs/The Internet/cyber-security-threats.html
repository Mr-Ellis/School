🦠 What is Malware?

Malware comes from two words: Malicious + Software. It is any executable program designed to harm a computer, network or data.

There are six main types of malware you need to know:

Virus

Replicates its code in other programs, infects other computers, and harms the computer by deleting, corrupting or modifying files.

Worm

Replicates itself to spread to other computers. May cause no damage, but slows down networks and computers.

Trojan Horse

Hides malicious code inside a legitimate-looking program, game or file. When opened, the harmful code runs.

Ransomware

Encrypts the hard drive so the user can't access files. A ransom (often in cryptocurrency) is demanded to restore access.

Spyware

Finds information about users, their computers or company information. Sends it to a hacker for misuse.

Adware

Displays large numbers of adverts, often through multiple windows. Hacker makes money when users click.

🎯 Other Types of Attack

🔓 Brute-force attack

A hacker tries every possible combination of passwords until the correct one is found. A computer program can try millions of passwords per second.

Protection: Use a strong password. Systems should lock out users after 3 failed attempts.

🕵️ Data interception

Obtaining data, without permission, that is passing through a network. Also known as a man-in-the-middle (MITM) attack.

Protection: Use encrypted connections (HTTPS). Avoid unencrypted public Wi-Fi.

🌊 Distributed Denial of Service (DDoS)

Many computers flood a server with pointless requests, making it slow down or go offline. The computers used are often part of a botnet — their owners don't even know.

Protection: Firewalls, manual settings on switches and routers.

💻 Hacking

Activities that misuse computer systems or networks. People who do this are called hackers.

🎣 Phishing

Emails, texts or phone calls pretending to be from a bank or trusted website, trying to get personal information like usernames, passwords or credit card details.

Watch out for: No personalised greeting · Sender address looks slightly off · Links that don't match the text · Requests for personal info · Urgency · Poor spelling or grammar

🌾 Pharming

Combines phishing and farming. The user's computer or a DNS server is altered so that a domain name points to an incorrect IP address — the hacker's fake website.

🧠 Social engineering

Obtaining confidential information by asking people for it — often using confidence tricks. For example, phoning a receptionist, pretending to be IT support, and asking for their password.
