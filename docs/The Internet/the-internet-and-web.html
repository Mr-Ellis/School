Lesson 3 · The Internet and Web
Year 10 · Networks · Internet vs WWW, URLs, HTTP/HTTPS

Learning Objectives

  • Explain the difference between the Internet and the World Wide Web
  • Describe the structure of a URL and what each part does
  • Explain what HTTP and HTTPS are, and why HTTPS is more secure
  • Understand the role of web browsers and how they retrieve web pages
  • Describe the purpose of a web server and DNS
💡 Key Fact: The Internet is the physical infrastructure — the global network of cables, routers and servers. The World Wide Web is a service that runs on top of the Internet — a collection of linked documents (web pages) accessed via a browser.
🎯 Starter Activity – Think-Pair-Share

Think: What is the difference between "the Internet" and "the World Wide Web"? Are they the same thing? Share your ideas with a partner and be ready to explain your reasoning.

Click to reveal discussion points
  • The Internet is a global network of networks — physical hardware that connects devices worldwide.
  • The World Wide Web (WWW) is one service that uses the Internet — a system of interlinked hypertext documents.
  • Other services that run on the Internet include email (SMTP), file transfer (FTP), and video streaming (RTSP).
  • Analogy: the Internet is the road network; the Web is one type of vehicle that travels on it.

🌐 The Internet vs the World Wide Web

🌍 The Internet

The physical infrastructure — a global network of interconnected computer networks. It includes cables (fibre optic, copper), routers, switches, satellites, and data centres.

Established: 1960s (ARPANET)

🕸️ The World Wide Web

A service that runs on the Internet. It is a collection of linked documents (web pages) and resources, accessed using a web browser and identified by URLs.

Invented: 1989 by Tim Berners-Lee at CERN

🔗 Other Internet Services

The Internet also supports email (SMTP/IMAP), file transfer (FTP), video calls (VoIP), streaming, online gaming, and more.

The Web is just one of many services.

🧠 Remember: The Web needs the Internet to work — but the Internet does not need the Web. You can send an email or make a video call without ever opening a web browser.

🔗 URLs — Uniform Resource Locators

A URL is the address of a resource on the Web. Every web page, image, or file has its own unique URL that tells the browser what to fetch and where from.

📋 Example URL

https://www.bbc.co.uk/news/technology?id=123

🔍 The Parts of a URL

1️⃣ Protocol

https:// — tells the browser how to communicate with the server. Common protocols: HTTP, HTTPS, FTP.

2️⃣ Domain Name

www.bbc.co.uk — the human-readable address of the web server. Converted to an IP address by DNS.

3️⃣ Subdomain

www.bbc.co.uk — an optional prefix. Other examples: mail.google.com, docs.microsoft.com.

4️⃣ Top-Level Domain (TLD)

bbc.co.uk — the last part of the domain. Examples: .com, .org, .edu, .gov, .uk.

5️⃣ Path

/news/technology — the location of the specific file or page on the server, organised in folders.

6️⃣ Query String

?id=123 — extra data sent to the server, usually from a form or filter.

📝 Exam Tip: If asked to "identify the parts of a URL", label them clearly: protocol, domain name, path, query string. Don't confuse the domain name (bbc.co.uk) with the subdomain (www).

🔐 HTTP and HTTPS

📡 HTTP (HyperText Transfer Protocol)

The rules that govern how web browsers and web servers communicate. It defines how requests are made and how responses are returned.

Data is sent in plain text — anyone intercepting it can read it.

🔒 HTTPS (HTTP Secure)

HTTP with encryption added using TLS/SSL. Data is scrambled before it leaves your device and only unscrambled by the intended server.

Used for banking, shopping, login pages — anything sensitive.

✅ Why HTTPS Matters

HTTPS protects against eavesdropping, tampering, and man-in-the-middle attacks. Modern browsers warn you when a site uses plain HTTP.

Look for the padlock 🔒 in the address bar.

⚠️ Note: HTTPS does not make a website "safe" or "trustworthy" — it only means the connection is encrypted. A phishing site can still use HTTPS.

⚙️ How a Web Page is Loaded

When you type a URL into your browser and press Enter, a sequence of steps happens in a fraction of a second:

  1. Your browser checks its cache — if it already has the page, it loads instantly.
  2. If not, it sends a request to a DNS server to translate the domain name into an IP address.
  3. The browser sends an HTTP/HTTPS request to that IP address.
  4. The web server processes the request and returns the HTML, CSS, and images.
  5. The browser renders the page — interpreting HTML for structure, CSS for style, and JavaScript for interactivity.
💡 Analogy: A URL is like a postal address, DNS is like a phone book (name → number), HTTP is the language you write your letter in, and the web server is the person who reads it and replies.

🌐 Web Browsers

📌 What is a browser?

A web browser is software that requests, retrieves, and displays web pages. Examples: Chrome, Firefox, Safari, Edge.

🛠️ What does it do?
  • Sends HTTP/HTTPS requests
  • Renders HTML & CSS
  • Runs JavaScript
  • Manages cookies & cache
  • Stores bookmarks & history
🔧 Common Features
  • Address bar (URL input)
  • Tabs & windows
  • Back / forward buttons
  • Bookmarks / favourites
  • Extensions / add-ons
🧠 Browser vs Search Engine: A browser (Chrome) is software that displays web pages. A search engine (Google) is a website you visit using a browser to find other pages. They are not the same thing.

📖 DNS — The Domain Name System

Computers use IP addresses to find each other, but humans find it easier to remember names like bbc.co.uk. DNS is the system that translates between the two.

🔁 What DNS does

Takes a domain name (e.g. bbc.co.uk) and returns the IP address (e.g. 151.101.0.81) of the server that hosts it.

🏢 DNS Servers

Specialised servers maintained by ISPs and organisations. They store huge databases of domain names and their matching IP addresses.

⚡ Why it matters

Without DNS, you would have to type IP addresses for every website. DNS makes the Web usable for humans.

🔁 Plenary – Internet & Web Concepts

Discuss the answers to the following questions with a partner:

  1. What is the difference between the Internet and the World Wide Web?
  2. Why is HTTPS more secure than HTTP?
  3. What does DNS do, and why is it necessary?
  4. Name three parts of a URL and explain what each one does.
Click to reveal suggested answers
  • Internet vs WWW: The Internet is the global physical network of computers. The WWW is a service — a collection of linked web pages — that runs on top of the Internet.
  • HTTPS: HTTPS encrypts data using TLS/SSL, so anyone intercepting the traffic cannot read it. HTTP sends data in plain text.
  • DNS: The Domain Name System translates human-readable domain names (bbc.co.uk) into IP addresses (151.101.0.81) so browsers can find the right server.
  • Parts of a URL: Protocol (https), domain (bbc.co.uk), path (/news), query string (?id=123).
