Do not pad the list with basic syntax. Loops, print(), comments, and file names do not count as techniques. A technique earns a paragraph only when another programmer might have solved it differently.

2. How to Write Each Technique

Aim for 100 words per technique, using the same five-point structure:

  1. What the technique is
  2. Where in your code it appears
  3. Why you chose it
  4. What benefit it gives the user
  5. What limitation it has

Point five is what most students skip. It is also what turns a description into an evaluation, which is what the top band requires.

5. Required Code Changes

5.1 The program does not currently run

Two problems currently prevent the program from starting and from being demonstrated as a finished product:

  • ModuleNotFoundError: No module named 'recommendation_system' at startup
  • No standalone executable has been created, so the client cannot run the program without installing Python

Both must be fixed before the video can be recorded. Section 5.2 covers the ModuleNotFoundError and Section 5.3 covers the executable.

5.2 Fixing the ModuleNotFoundError

Python raises this error when it cannot find one of the modules imported at the top of program.py. The cause is almost always one of the following:

  • Files in different folders. program.py must be in the same directory as recommendation_system.py and validation.py. If they are in subfolders, move them into one folder.
  • Wrong working directory. If the program is run from an IDE, the working directory might not be the folder containing the source files. In VS Code, right-click the folder containing all three files and choose "Open in Integrated Terminal", then run python program.py.
  • Missing file. If recommendation_system.py was never created or has been deleted, the import will fail. Confirm the file exists.
  • Filename case mismatch. Filenames are case-sensitive on most systems. Recommendation_system.py is not the same as recommendation_system.py.

Once all three files sit in the same folder and the program is run from that folder, the error resolves. Verify by launching python program.py and confirming the window opens.

5.3 Building a standalone executable with PyInstaller

A distributable executable lets the client use the program without installing Python or any libraries, and it demonstrates that the product is a finished deliverable. The IA resource page has a tutorial for this. The standard tool is PyInstaller:

pip install pyinstaller
pyinstaller --onefile --windowed --name "IBUniversityRecommender" program.py

Notes:

  • --onefile produces a single .exe
  • --windowed hides the console, which is correct for a GUI-only app
  • Any data files (JSON files) that the program reads at runtime must be listed with --add-data, or the executable will fail when it cannot find them
  • The executable appears in the dist/ folder after the build
  • Test the executable on a machine that does not have Python installed — that is the only way to confirm it works for the client

Once the executable builds and runs, record it as a technique in the Criterion D write-up: "packaged the program into a standalone executable using PyInstaller so the client does not need to install Python". This supports SC9 (usability) and strengthens the "fully functional product" requirement.

5.4 SC2 — Route sidebar inputs through the validator

The data editor validates university fields, but the sidebar score and fees entries are only stripped. In run_recommendation_process(), pass the raw strings through self.validator first. If it returns an error, call self.show_error(error) and return before calling generate_recommendations(). This makes SC2 provable on the main screen, not just the editor.

5.5 SC9 — Client evidence and splash guidance

Send the client a Microsoft Forms survey with one Likert question per SC. Record the responses and reference them in the video. Add the splash dialog described in Section 7 so the interface is self-explanatory on first launch.

5.6 SC7 — Record the response time

The code already measures and displays response time in display_results(). Add a print() so the value appears in the console during the video, and pause on the summary line long enough for the viewer to read it.

5.7 Storage consistency

Criterion A mentions "JSON or SQLite". Criterion B mentions "JSON/SQLite". The implementation uses JSON. Either commit to JSON in Criterion B (recommended, since it already works) or refactor to SQLite. Do not leave the storage choice ambiguous between criteria.

5.8 University dictionary consistency

The result cards read university["ib_requirement"], university["fees"], and university["field_of_study"]. Confirm that recommendation_system.py returns exactly those keys. A single mismatch causes a KeyError at runtime that would fail SC6 in the video.

7. Splash Screen

A splash screen supports SC9 and provides a screenshot for the Criterion C wireframe. Keep it short.

7.1 Where to add it

In UniversityRecommenderApp.__init__, after create_layout(), call self.show_splash() once. Add a "How to use" button to the sidebar so it can be re-displayed at any time.

7.2 The splash function

def show_splash(self) -> None:
    splash = ctk.CTkToplevel(self)
    splash.title("Welcome")
    splash.geometry("460x340")
    splash.grab_set()

    ctk.CTkLabel(
        splash,
        text="Welcome to IB University Recommender",
        font=("Arial", 18, "bold")
    ).pack(padx=24, pady=(24, 10))

    ctk.CTkLabel(
        splash,
        text=(
            "Find universities that match your predicted IB score.\n\n"
            "QUICK START\n"
            "  1. Enter your predicted IB score.\n"
            "  2. Choose any filters you want.\n"
            "  3. Press 'Apply Filters & Show Recommendations'.\n\n"
            "Each result is classified as Reach, Match, or Safe.\n"
            "Your university data is saved locally."
        ),
        font=("Arial", 13),
        justify="left",
        wraplength=400
    ).pack(padx=24, pady=(0, 16), anchor="w")

    ctk.CTkButton(
        splash,
        text="Got it",
        command=splash.destroy
    ).pack(padx=24, pady=(0, 24), fill="x")
