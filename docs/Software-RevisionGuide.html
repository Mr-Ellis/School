This guide teaches you the concepts you need to understand for the Unit 6 Software exam. It explains key ideas, gives exam technique tips, and provides practice questions so you can test your understanding. Work through each section, then try the practice questions without looking at the notes.

1. Operating Systems

What is an operating system?

An operating system (OS) is system software that manages the computer's hardware and provides a platform for applications to run. Without an OS, a computer cannot function.

Key functions of an OS

You need to know these functions and be able to explain them:

  • Managing files — creating, deleting, organising files and folders; tracking where data is stored on secondary storage.
  • Providing a user interface — allowing the user to interact with the computer (e.g., GUI, command line).
  • Managing peripherals and drivers — communicating with hardware devices via device drivers.
  • Managing memory — allocating RAM to programs and ensuring they don't interfere with each other.
  • Multitasking — allowing multiple programs to run "at the same time" by rapidly switching between them (time slicing).
  • Providing a platform for running applications — giving applications access to services like file storage, networking, and input/output.
  • Managing user accounts and security — handling logins, access rights, permissions, and protecting data.
  • Handling interrupts — responding to signals from hardware or software (see Section 3).
📝 Exam tip: If a question asks you to "explain" a function, don't just name it — say what it does and why it matters. For example, "Managing memory" is a name; "Managing memory means allocating RAM to programs and preventing them from accessing each other's memory, which keeps the system stable and secure" is an explanation.

How multitasking works

A single CPU can only execute one instruction at a time. Multitasking creates the illusion that multiple programs are running simultaneously.

The OS uses a scheduler to give each process a small slice of CPU time (called a time slice or quantum). It rapidly switches between processes. Because the switches happen many times per second, it looks like everything is running at once.

When the OS switches from one process to another, it must:

  • Save the state of the current process (registers, program counter).
  • Load the saved state of the next process.

  • Can you explain why multitasking is an illusion?
  • What is a time slice?
  • Why does the OS need to save the state of a process?

2. Interrupts

What is an interrupt?

An interrupt is a signal sent to the CPU that tells it to pause what it's doing and deal with something more urgent. Without interrupts, the CPU would have to constantly check every device to see if it needed attention (called polling), which wastes time.

Types of interrupt

  • Hardware interrupt — generated by a hardware device, e.g., a key press on a keyboard, a mouse click, or a printer finishing a job.
  • Software interrupt — generated by a program, e.g., division by zero, two processes trying to access the same memory location, or a program requesting a service from the OS (system call).

What happens when an interrupt occurs?

  1. The CPU finishes the current instruction.
  2. It checks the interrupt and identifies its source.
  3. The current state of the process is saved (registers, program counter).
  4. The CPU runs the interrupt service routine (ISR) — a small piece of code that handles the interrupt.
  5. Once the ISR is finished, the saved state is restored, and the original process continues.
📝 Exam tip: If you're asked to "describe the actions of the OS as a result of an interrupt," don't just say "it handles it." Walk through the steps: save state → identify source → run ISR → restore state.

3. Utility Software

What is utility software?

Utility software is system software that helps maintain, manage, and optimise the computer. It is not essential for the computer to run, but it helps it run efficiently and safely.

Examples: disk defragmenter, disk clean-up, backup software, antivirus software.

Disk defragmenter

Over time, files on a magnetic hard drive become fragmented — split into pieces scattered across the disk. This happens because files are created, deleted, and resized, leaving gaps.

A defragmenter rearranges the pieces so each file is stored contiguously (together). It also consolidates free space. This reduces the movement of the read/write head, so files load faster.

📝 Exam tip: Know the difference between magnetic and solid-state drives:
  • Magnetic drives have moving parts (spinning platters, read/write head) and do benefit from defragmentation.
  • Solid-state drives (SSDs) have no moving parts and do not need defragmentation. In fact, defragmenting an SSD causes unnecessary writes, which reduces its lifespan.
✅ Check your understanding:
  • Why do magnetic drives need defragmentation but SSDs don't?
  • What is fragmentation, and how does it slow down a computer?

4. Firmware & Bootloader

What is firmware?

Firmware is software stored permanently on a hardware device, typically in ROM (read-only memory) or flash memory. It is non-volatile — it keeps its contents when the power is off.

Firmware provides low-level control for the device's hardware and acts as an intermediary between the hardware and higher-level software.

What is a bootloader?

The bootloader is the first program that runs when a computer is switched on. It is stored in firmware (ROM). Its job is to:

  1. Initialise the hardware (Power-On Self-Test, or POST).
  2. Locate the operating system on secondary storage.
  3. Load the OS into RAM.
  4. Transfer control to the OS so it can start.
📝 Exam tip: Don't confuse firmware with the OS. Firmware is stored in ROM and is non-volatile; the OS is stored on secondary storage (like a hard drive) and is loaded into RAM by the bootloader.

5. Programming Languages

Low-level vs high-level languages

Low-level languages are close to machine code. They are specific to a particular processor and give direct control over hardware.

  • Machine code — binary instructions (0s and 1s) that the CPU executes directly.
  • Assembly language — uses mnemonics (short codes like MOV, ADD) instead of binary. Each mnemonic corresponds to one machine code instruction.

High-level languages are closer to human language. They are portable (machine-independent), easier to read and write, and provide built-in functions and libraries.

Why use assembly language?

  • It gives direct control over hardware — useful for device drivers.
  • It produces very efficient (fast and small) code.
  • Sometimes it's the only way to access certain hardware features.

Why use a high-level language?

  • Easier and faster to write, read, and maintain.
  • Portable across different hardware.
  • Built-in functions and libraries speed up development.
📝 Exam tip: If a question asks why assembly is used for a device driver, the key reason is direct hardware control. If it asks why a high-level language is used for an application, the key reasons are easier to write and portable.

6. Translators

What is a translator?

A translator converts source code into machine code that the CPU can execute. There are three types you need to know:

Assembler

Translates assembly language into machine code. Each assembly mnemonic is converted into the corresponding binary instruction.

Compiler

Translates high-level source code into machine code all at once. It produces an executable file that can be run without the compiler or the source code.

Advantages: Fast execution, can distribute without source code.
Disadvantages: Takes time to compile, harder to debug (errors reported after compilation).

Interpreter

Translates and executes high-level source code line by line, every time the program is run. It does not produce a separate executable file.

Advantages: Easier to debug (stops at the error), no compilation step.
Disadvantages: Slower execution, requires source code to be present.

📝 Exam tip: When comparing compilers and interpreters, focus on: speed of execution, when translation happens, and whether source code is needed at runtime.
✅ Check your understanding:
  • Which translator is used for assembly language?
  • Why might a compiler be better than an interpreter for a complex application?
  • Why might an interpreter be better for debugging?

7. Integrated Development Environments (IDEs)

What is an IDE?

An IDE is a software application that provides comprehensive facilities for writing, testing, and debugging code. It combines several tools into one interface.

Common IDE features

  • Code editor — where you write your code.
  • Syntax highlighting — displays different parts of code in different colours (keywords, strings, comments) to improve readability.
  • Prettyprint — automatically formats code with consistent indentation and spacing.
  • Auto-completion — suggests code as you type (e.g., variable names, function names).
  • Auto-correction — inserts missing brackets or braces.
  • Error diagnostics — highlights syntax errors and warnings.
  • Breakpoints — pause execution at a specific line so you can inspect variables.
  • Variable watch / inspection — view the current values of variables while the program runs.
  • Run-time environment — allows you to run and test your code.
  • Translators — built-in compilers or interpreters.
📝 Exam tip: If you're asked about features that "change how the code appears," focus on syntax highlighting, prettyprint, line numbering, and code folding. If asked about debugging features, focus on error diagnostics, breakpoints, and variable watch.

8. Exam Technique

Command words

Pay attention to the command word — it tells you how much detail is needed:

  • State / Give / Name — a short answer, often one word or phrase. No explanation needed.
  • Describe — say what happens or what something is. More detail than "state," but no need to explain why.
  • Explain — say how or why. You need to give reasons and make connections.
  • Compare — give similarities and differences.
  • Discuss — give advantages and disadvantages.
📝 Mark allocation: Look at the number of marks. A 2-mark question usually needs two distinct points. A 3-mark question might need three points, or one point with three stages of development. Don't write one sentence for a 4-mark question — you won't get full marks.

Common mistakes to avoid

  • Confusing firmware with the operating system.
  • Saying SSDs need defragmentation (they don't).
  • Confusing a compiler with an interpreter.
  • Describing an interrupt without mentioning the ISR or saving state.
  • Writing vague answers like "it manages things" instead of being specific.

9. Practice Questions

Question 1

Explain what is meant by multitasking and describe how an operating system achieves it. (4 marks)

Multitasking is the ability of an operating system to run multiple programs seemingly at the same time.

The OS uses a scheduler to allocate a small amount of CPU time (a time slice) to each process in turn. When the time slice expires, the OS saves the state of the current process (registers, program counter), loads the saved state of the next process, and resumes it. Because the switching happens very quickly, it appears that all programs are running simultaneously.

(4 marks: 1 for definition, 1 for scheduler/time slice, 1 for saving/restoring state, 1 for the illusion of simultaneity.)

Question 2

Describe what happens when a hardware interrupt is generated, from the moment the signal is sent to the moment the original task resumes. (4 marks)

  1. The CPU finishes the current instruction and checks the interrupt.
  2. The current state of the process is saved (registers, program counter).
  3. The CPU identifies the source and runs the appropriate interrupt service routine (ISR).
  4. After the ISR completes, the saved state is restored, and the original task continues.

(4 marks: 1 for each correct stage.)

Question 3

A student says: "I defragment my SSD every week to keep it running fast." Explain why this is not a good idea. (2 marks)

Solid-state drives (SSDs) have no moving parts, so defragmentation does not improve their performance. In fact, defragmenting an SSD causes unnecessary write operations, which reduces the drive's lifespan because SSDs have a limited number of write cycles.

(2 marks: 1 for no moving parts / no benefit, 1 for reducing lifespan.)

Question 4

Explain the difference between a compiler and an interpreter, and give one advantage of each. (4 marks)

A compiler translates the entire source code into machine code all at once, producing an executable file. Advantage: the compiled program runs faster because translation is already done.

An interpreter translates and executes the source code line by line, every time the program is run. Advantage: it is easier to debug because it stops at the line where an error occurs.

(4 marks: 1 for compiler definition, 1 for compiler advantage, 1 for interpreter definition, 1 for interpreter advantage.)

Question 5

Describe two features of an IDE that help a programmer write code more efficiently. (4 marks)

  • Auto-completion — suggests variable names, function names, and other code as the programmer types, reducing typing and helping avoid spelling errors.
  • Syntax highlighting — displays different parts of the code in different colours, making it easier to read and spot syntax errors.
  • Prettyprint — automatically formats the code with consistent indentation, making it easier to read and follow the structure.
  • Error diagnostics — highlights syntax errors as the programmer types, allowing them to fix mistakes immediately.

(4 marks: 2 for each feature — 1 for naming it, 1 for explaining how it helps.)
