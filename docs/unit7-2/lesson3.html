🧩 What Are Data Types?

Data types are like labels that tell the computer what kind of information you're working with. Just like you wouldn't store soup in a pencil case, you need the right container for the right data!

String

Text — one or more characters, always in quotation marks.

"Hello!", "Game Over"

Integer

Whole numbers with no decimal point.

100, -5, 2025

Float

Numbers that contain a decimal point.

3.14, 0.5, 99.99

Boolean

True or False — used for decisions.

True, False
On the micro:bit: Sensor readings like sound or light are stored as integers. Messages and screen text are stored as strings. If you want to perform a calculation with a value, it must be an integer or float — you cannot do maths with a string!

🕹️ Variables: Your Data Containers

Imagine variables as named boxes that hold your data while the program runs. You can open the box, change what's inside, or check it later.

  • Use names that make sense: temperature, score, player_name, light_level.
  • Assign values using =: score = 100.
# Python examples
score = 100         # Integer
player_name = "Alex"   # String
game_over = False     # Boolean

🔍 Decisions & Comparison Operators

When your program needs to make a choice, it uses comparison operators to compare values. These are used in if statements, loops, and flowcharts.

OperatorMeaningExampleResult
==Equal toscore == 100True if score is 100
!=Not equal toscore != 100True if score is NOT 100
>Greater thanscore > 100True if score is more than 100
<Less thanscore < 100True if score is less than 100
>=Greater than or equal toscore >= 100True if score is 100 or more
<=Less than or equal toscore <= 100True if score is 100 or less
Watch out: Changing < to <= changes the meaning. If the light detected is less than or equal to 100, the value 100 is now included as part of the condition that switches the lights on. The comparison operator is a common place to look when debugging a program that isn't behaving as expected.

🧪 Algorithm Tracing: Test Your Program Like a Detective!

Algorithm tracing means walking through your code step-by-step to see what happens with different inputs. This helps you catch bugs and predict outcomes.

Example: A burglar alarm that sounds when the light level is <= 10.
  • If light_level = 9 → 9 <= 10 is True → Alarm turns on
  • If light_level = 15 → 15 <= 10 is False → Alarm stays off

Flowchart for the sound sensor program using selection.

Here is the MicroPython program that matches this flowchart. Notice how the comparison operator > is used:

from microbit import *

while True:
    if microphone.current_event() > SoundEvent.LOUD:
        display.show(Image.SURPRISED)
        sleep(200)
    if microphone.current_event() < SoundEvent.QUIET:
        display.show(Image.HAPPY)
        sleep(200)
Debugging challenge: The original SoundSensorProgram.py used == SoundEvent.LOUD instead of > SoundEvent.LOUD. Why might that cause a problem? The comparison operator should be > for a loud noise and < for a quiet noise. Using == only matches one exact value, so louder sounds might be missed. This is a logic error — the code runs but doesn't do what was intended.

Hands-On: Sensor Detective

Get a micro:bit and USB cable. You will write a short MicroPython program that reads a sensor, stores the value in a variable, and uses an if statement with a comparison operator to make a decision.

Step 1: Read and Display a Sensor Value

Open the MicroPython Editor and type this program. It reads the light level and scrolls the number on the display so you can see the actual integer value:

from microbit import *

while True:
    light_level = display.read_light_level()
    display.scroll(str(light_level))
    sleep(500)
Notice: display.read_light_level() returns an integer. We use str() to convert it to a string so display.scroll() can show it. This is a great example of why data types matter!

Step 2: Add a Decision

Now add an if statement. Cover the micro:bit with your hand (low light) and shine a torch on it (high light). Record the values you see in the table below.

from microbit import *

while True:
    light_level = display.read_light_level()
    if light_level < 50:
        display.show(Image.HAPPY)
    else:
        display.show(Image.SAD)
    sleep(200)
