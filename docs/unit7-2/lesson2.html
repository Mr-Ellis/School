🚀 Get Started: Sensors in Programming

Sensors are used to gather data from the environment around them and use that data to determine the output. For example, a light sensor in a room detects when the light level reduces, and the lights need to be switched on.

On the micro:bit, there are several built-in sensors you can use in your programs:

Input Sensors

  • Light sensor — detects light levels
  • Temperature sensor — detects how hot or cold it is
  • Accelerometer — detects movement and tilt
  • Compass — detects direction
  • Microphone — detects sound levels
  • Touch sensor — detects when the logo is touched
  • Buttons A and B — detect when pressed

Outputs

  • LED display (25 lights)
  • Buzzer / sound output
  • Radio (to send messages)
Think about it: How could you use the light sensor on the micro:bit to create a burglar alarm? What value would you set as the threshold for triggering the alarm?

🌡️ Example: Smart Thermostat

A smart thermostat uses a temperature sensor to gather data about the temperature in a room. It then uses this data to decide whether the heating should be on or off.

The flowchart for this system would look like this:

A simple flowchart for a smart thermostat using selection.

In MicroPython, the code for this would use an if statement:

from microbit import *

if temperature() < 18:
    display.show(Image.ARROW_N)
    pin0.write_digital(1)
else:
    display.show(Image.ARROW_S)
    pin0.write_digital(0)

💡 Using the Light Sensor

The micro:bit's LED display can also work as a light sensor. The code to read the light level is:

display.read_light_level()

You can use this in an if statement to make decisions based on light levels. For example:

from microbit import *

while True:
    if display.read_light_level() < 100:
        display.show(Image.CHESSBOARD)
        music.play(music.BA_DING)
    else:
        display.clear()
Debugging Challenge: If the light level is 67, the micro:bit would display a chessboard image and play the music 'Ba_ding'. If the light level is 130, the micro:bit will clear the screen. Can you spot the error if the code was showing > instead of <?

🐍 The micro:bit Python Environment

The micro:bit Python environment is a text-based programming tool. Unlike MakeCode, there is no simulator — you must download the program to a real micro:bit to run it.

When you open the online software, there is a default program loaded:

from microbit import *

display.scroll("Hello World!")
display.show(Image.HEART)

If downloaded, this program would display the words 'Hello, World!' followed by a heart.

Key difference from MakeCode: The syntax used is different from how you saw it when switching the view in MakeCode. There are no blocks to help start the program — you have to know and type the lines of code yourself.

🛠️ Correcting Errors Using a Flowchart

Flowcharts are important for planning a program as well as identifying and fixing errors.

Consider this program:

from microbit import *

while True:
    if button_a.is_pressed():
        display.scroll("Diamonds")
        sleep(1000)
        display.show(Image.DIAMOND)
        sleep(1000)
        display.show(Image.DIAMOND_SMALL)
        sleep(1000)

The flowchart for this program should look like this:

Start
↓
Is A
button
pressed?
↓ Yes
Display large diamond
↓
Delay 1 second
↓
Display "Hello"
↓
Delay 1 second
↓
Display small diamond
↓
Delay 1 second
↓
Stop
Flowchart for the Diamonds program.
Errors in the program code when comparing to the flowchart:
  • Both show the A button as an input.
  • There is not a delay between each output.
  • The text to be displayed is incorrect.
  • The sequence of the outputs is incorrect.

How to fix it: Read the flowchart from top to bottom, follow the flow, identify the inputs and outputs that are going to be used, and check the sequence they are placed in.
