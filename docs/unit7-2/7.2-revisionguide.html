1 Smart Devices & Sensors

A smart device uses sensors to gather data from its surroundings, then uses that data to decide the correct output — often automatically.

TermMeaning
Smart deviceA device that uses sensors and is connected to other devices.
SensorA device that gathers data from its surroundings to record or respond to.
InputPhysical hardware attached to a computing device, such as a keyboard, mouse, microphone, or button.
OutputA visible or audible outcome on the device, e.g. through the display, monitor, speakers, or headphones.
Remember: A sensor is an input — it brings data into the system. An LED display or speaker is an output — it sends information out to the user.

Q: Is a temperature sensor an input or an output?

A: An input — it gathers data from the surroundings.

2 Types of Software

Software is the programs that run on a computing device. There are three key types you need to know:

TypeWhat it doesExamples
Systems software Runs the hardware and software — the operating system (OS). Allows the computer's hardware to communicate with the software that is running. Windows, macOS, Linux, Android, iOS
Applications software Programs for general or specific tasks that help the user complete a task. Word processor, web browser, games, presentation software
Simulator Software to simulate a real-world application. Used for training and testing because it is safe, cheap, and repeatable. Flight simulator, medical simulator, military simulator
Watch out: The operating system is systems software, not applications software. It is the link between the hardware and the applications.

Q: What type of software is a flight simulator?

A: A simulator (a type of application software that copies a real-world situation).

3 Flowcharts & Selection

A flowchart shows the step-by-step sequence of actions in a program. A decision diamond asks a yes/no question — this is called selection.

SymbolNameWhat it shows
TerminatorStart or end
Input / OutputGetting data in or showing a result
ProcessAn instruction or calculation
DecisionA yes/no question (selection)
Selection logic: If a flowchart uses a decision diamond, the program follows different paths depending on the answer. In Python this is written as if ... else.

Q: Which flowchart symbol is used to check a condition and decide what to do?

A: The decision diamond.

4 Comparison Operators

Comparison operators are used in if statements and flowcharts to compare values and make decisions.

OperatorMeaning
<Less than
>Greater than
<=Less than or equal to
>=Greater than or equal to
==Equal to
!=Not equal to
Watch out: = means "assign a value" (e.g. score = 10), but == means "is equal to" (e.g. if score == 10:). They are not the same.

Q: Which operator means "not equal to"?

A: !=

5 MicroPython Output Commands

These commands control what the micro:bit shows or plays. They are all outputs.

CommandWhat it does
display.show(Image.HEART)Shows a single image (a heart) on the LED display.
display.scroll("Hello")Scrolls the text "Hello" across the LED display.
sleep(1000)Adds a delay of 1000 milliseconds (1 second).
music.play(music.BADDY)Plays a built-in tune.
Sequence matters: If you want an image to stay on screen for 1 second before the next output, you must put sleep(1000) after the display.show() line. 
display.show(Image.RABBIT)
sleep(1000)

This shows a rabbit, pauses for 1 second, then moves on to the next line.

Q: Which command adds a delay of 1 second?

A: sleep(1000) — 1000 milliseconds = 1 second.

6 MicroPython Inputs & Sensors

These commands read data from the micro:bit's sensors. They are all inputs.

CommandWhat it does
pin_logo.is_touched()Checks if the logo is touched.
temperature()Reads the temperature.
microphone.current_event() == SoundEvent.LOUDChecks if a loud sound was detected.
accelerometer.was_gesture('shake')Checks if the micro:bit was shaken.
display.read_light_level()Reads the light level using the LED display.
Input vs output: A sensor command reads data in. A display or music command sends data out. If a command starts with display.show or music.play, it's an output.

Q: Is temperature() an input or an output?

A: An input — it reads the temperature sensor.

7 IF Statements & Light Level Examples

An if statement uses a comparison operator to decide whether to run a block of code.

Example: light level is greater than 70

if display.read_light_level() > 70:
    display.show(Image.HAPPY)

Example: light level is equal to 50

if display.read_light_level() == 50:
    display.show(Image.SAD)
Watch out: > means "greater than". == means "equal to". Mixing these up is a very common error. If the condition is light_level < 60, then 60 itself is not included — the condition is false at exactly 60.

Q: Which operator would you use to check if the light level is exactly 50?

A: == (equal to).

8 Data Types

Every value in a program has a data type. Choosing the right one matters — you can't do maths with text!

Data typeWhat it storesExample
StringText — letters, numbers, or symbols in quotes."Hello", "Welcome to MicroPython"
IntegerWhole numbers (no decimal point).145, 100, -5
Float / RealNumbers with a decimal point.3.14, 1.75

Key rules to remember

  • "145" with quotes is a string — it is text, not a number.
  • 145 without quotes is an integer — it can be used in calculations.
  • "Hello" is a string.
  • "Welcome to MicroPython" is a string, not an integer.
  • The result of 100 + 50 is 150, which is an integer.
Why it matters: If a value is stored as a string, you cannot compare it to another number in the same way, or do arithmetic with it. You would need to convert it first using int() or float().

Q: What data type is "145" (with quotes)?

A: A string — the quotes make it text, not a number.

9 Testing & Test Plans

A test plan is a structured approach to determine whether your program works as expected. It lists inputs, expected outputs, and actual outputs.

TestInputExpected OutputActual OutputPass / Fail
NormalLight = 40Happy faceHappy facePass
BoundaryLight = 100Sad faceSad facePass
NormalLight = 180Sad faceSad facePass
Boundary values matter: If the condition is light_level < 100, then 100 is a boundary. At exactly 100, the condition is false. Test it to make sure your program behaves correctly.

Q: What is a test plan used for?

A: To check a program gives the correct output for a range of inputs.

10 Debugging: Flowchart vs Code

Flowcharts are used to plan a program and to identify and fix errors. Read the flowchart top to bottom and compare each step to the code.

Typical errors to look for

  • The input is wrong (e.g. using a button when it should be a light sensor).
  • The sequence of outputs is wrong.
  • A delay (sleep()) is missing between outputs.
  • The text or image displayed does not match the flowchart.

Example: light level flowchart

If a flowchart says: "If light level is greater than 60 → display 'Bright'; otherwise → clear screen", then:

  • At light level 70, the output is "Bright".
  • At light level 60, the condition > 60 is false, so the screen clears (60 is not greater than 60).
Check the boundary: > does not include the value itself. >= does. Always check which one the flowchart uses.

Q: If the condition is light_level > 60, what happens at exactly 60?

A: The condition is false — the program follows the "No" path.

12 Summary — Common Errors Checklist

When reading or writing MicroPython code for the micro:bit, run through this checklist:

Input & output checks

  • Sensor commands (e.g. temperature()) are inputs.
  • Display and music commands are outputs.
  • display.read_light_level() is an input, not an output.
  • display.show() is an output, not an input.

Logic & data checks

  • Used == for "equal to", not =.
  • Used > / < correctly — boundaries matter.
  • Text is in quotes (String), whole numbers are not (Integer).
  • Added sleep() when a delay is needed.
  • The sequence of outputs matches the flowchart.
Reminder: Reading code carefully is a skill. Slow down, trace each line, and check the checklist.
