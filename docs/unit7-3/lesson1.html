There are many different methods of connecting to networks and the internet, such as using wires or wireless transmission methods to send and receive data. Bluetooth, Wi‑Fi and cellular data are always improving, so it's important to know the key differences.

Data can be transferred from one device to another wirelessly using radio waves. The most popular methods of wireless data transfer are Wi‑Fi, Bluetooth and cellular data.

Think about it: What was the last thing that you did online? How many devices that connect to the internet are in your home? What's the most unusual device that you know can connect to the internet?

📡 Transmission Methods

For each wireless transmission method, it is important to consider these characteristics:

  • Bandwidth — the amount of data that can be transmitted within a certain amount of time.
  • Transmission distance — how far a signal can be sent using the transmission method.
  • Security — how easily the transmission can be hacked.
  • Interference — what can interrupt the signal (walls, microwaves, other radio waves).

Wi‑Fi

  • Wireless connection using a router or access point.
  • High bandwidth (fast data transfer).
  • Works well in homes, schools, cafes.
  • Can suffer from interference (walls, other devices).
  • Needs security (passwords).

Bluetooth

  • Short‑range wireless connection between devices.
  • Good for connecting accessories (keyboard, mouse, headphones).
  • Secure because of short distance.
  • Slower than Wi‑Fi or cellular.
  • Only works over a few metres.

Cellular Data (4G/5G)

  • Uses mobile phone masts to connect devices outdoors.
  • Works over long distances.
  • Useful when away from Wi‑Fi.
  • Can be affected by distance from mast or obstacles.
  • Bandwidth lower than Wi‑Fi in some cases.
Key comparisons: Highest bandwidth → Wi‑Fi · Longest distance → Cellular data · Most secure → Bluetooth (short range) or cellular (encrypted).

🔍 Transmission Characteristics

Wireless transmission = convenient, portable, but can be blocked by interference.

Wired transmission = stable, but not portable.

Devices can connect using Wi‑Fi, Bluetooth, or cellular networks. Wi‑Fi signals can be affected by interference, which causes problems with data transmission.

  • Scenario 3: Adam connects Bluetooth headphones to his PC, but they stop working when he goes downstairs. → Transmission distance

🌐 Accessing Web Pages: IP Addresses & URLs

IP Address (Internet Protocol Address)

  • A unique number given to each device on a network.
  • Format: four numbers separated by dots (e.g. 192.168.1.20).
  • Each number must be between 0 and 255.
  • Example of valid IP: 199.59.149.230
  • Invalid examples:
    • 69.171.224 (only 3 numbers)
    • 74.125.6556.91 (6556 > 255)

URL (Uniform Resource Locator)

  • The "web address" we type into a browser (e.g. www.google.com).
  • A URL matches to an IP address using the Domain Name System (DNS).
  • Valid URLs must have a domain name and extension (e.g. .com, .org, .co.uk).
  • Invalid examples: www.google or www.com.

⚡ Quick Recap

  • Wi‑Fi = fast, medium distance, needs passwords.
  • Bluetooth = short distance, slower, secure.
  • Cellular = long distance, outdoors, depends on mast.
  • IP address = unique number (0–255, four parts).
  • URL = human‑friendly web address that links to an IP.
