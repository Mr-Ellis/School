🧭 DNS: From Domain to IP Address

Every device online has a unique IP address (e.g., 142.250.80.110). URLs (e.g., google.com) are easier to remember. DNS (Domain Name System) works like a phonebook for the internet.

How DNS Works — Step by Step:
  1. You type a URL into your browser (e.g., google.com).
  2. Your browser asks a DNS server for the matching IP address.
  3. The DNS server looks up the URL in its database.
  4. The DNS server returns the IP address (e.g., 142.250.80.110).
  5. Your browser uses that IP address to contact the web server and load the website.
  6. If there is no match, you get a 404 error (page not found).

🔒 Secure Websites & SSL/TLS

SSL/TLS encryption protects your connection by providing three key things:

  • Confidentiality — keeps data private (no one can read it).
  • Integrity — prevents tampering (data can't be changed in transit).
  • Authentication — verifies the website is real (not a fake).
How to Spot a Secure Website:
  • Padlock icon in the address bar.
  • https:// at the start of the URL (the 's' stands for secure).
  • Click the padlock to see the certificate information.

Insecure Websites

  • Missing padlock or http:// = Not Secure.
  • Risks: Data theft (passwords, credit card numbers) and malware injection.
  • Always check for HTTPS before entering personal information.
Why it matters: SSL/TLS protects passwords, credit cards, and personal information from being intercepted by hackers.

⚡ Quick Recap

  • DNS = translates URLs into IP addresses (like a phonebook).
  • IP2Location = tool to find the domain and location of an IP address.
  • Browser parts = address bar, back/forward, refresh, padlock, HTTPS.
  • SSL/TLS = provides confidentiality, integrity, and authentication.
  • Secure websites = have a padlock and https://.
  • Insecure websites = have no padlock or use http:// — avoid entering personal info.
