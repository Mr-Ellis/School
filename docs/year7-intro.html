Course Overview

This course focuses on the foundational principles of computing, exploring topics such as computational thinking, programming, data management, networks and digital communication, and computer systems. Throughout the year, students will investigate core computing areas including algorithm design, flowcharts, physical computing with micro:bit, data modeling, and the ethical use of technology.

Emphasis is placed on developing problem-solving strategies, logical reasoning, and digital fluency. Students engage in hands-on activities, including programming in Python and MicroPython, designing smart solutions, and modeling real-world scenarios using simulations and data tools. They will also explore how AI and automation are integrated into modern computing systems.

By the end of the course students will have strengthened analytical thinking, engaged in practical computing tasks, and deepened their understanding of algorithmic logic, data representation, digital communication, and the role of computing in society.

Course Topics & Units

Unit 1 · Block it out: Moving from blocks to text
  • Introduction to block-based programming
  • Transitioning to text-based programming languages
  • Understanding syntax and structure in text-based coding
  • Writing simple programs using Python
  • Debugging and troubleshooting basic errors
Unit 2 · Decomposing problems: Creating a smart solution
  • Understanding decomposition in problem-solving
  • Breaking down complex tasks into smaller steps
  • Algorithm design and flowcharts
  • Using logical reasoning in programming
  • Creating efficient solutions with structured programming
Unit 3 · Connections are made: Accessing the internet
  • How the internet works (IP, DNS, packets)
  • Network types: LAN, WAN, Wi‑Fi, cellular
  • Security: encryption, HTTPS, secure browsing
  • Digital communication and protocols
Unit 4 · The power of data: Using data modelling
  • Data representation: types, collection, and organisation
  • Creating and interpreting graphs and charts
  • Using spreadsheets and databases for analysis
  • Conditional formatting and primary keys
Unit 5 · Living with AI: Digital data
  • Fundamentals of artificial intelligence
  • Machine learning and pattern recognition
  • Ethical considerations and data privacy
  • Real-world AI applications and societal impact
Unit 6 · Sequencing & pattern recognition: Getting the message across
  • Understanding sequencing in computing
  • Recognising and applying patterns in programming
  • Binary and ASCII encoding for text communication
  • Cryptography and secure messaging
  • Signal processing and multimedia data
