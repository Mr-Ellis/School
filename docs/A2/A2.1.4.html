A2.1.4 – Network Protocols

📌 Learning Objective

By the end of this lesson, you will be able to:

  • Describe the function of the following network protocols: TCP, UDP, HTTP, HTTPS, and DHCP.
  • Explain the difference between transport-layer protocols and application-layer protocols.
  • Select the appropriate protocol for a given network scenario.

🎯 IB Command Term: Describe

Describe – "Give a detailed account. For each protocol: state what it is, what layer it operates at, what function it performs, and a typical use case."

🔑 Key Terms

ProtocolLayerFunction
TCPTransportConnection-oriented protocol that guarantees in-order, loss-free delivery using sequence numbers and acknowledgements. Uses the three-way handshake (SYN → SYN-ACK → ACK).
UDPTransportConnection-less protocol that sends independent datagrams. Best-effort delivery with no retransmission or ordering — trades reliability for low latency and minimal overhead.
HTTPApplicationStateless request–response protocol for fetching web resources. Runs over TCP (HTTP/1.1 & 2) or QUIC/UDP (HTTP/3). Default port 80.
HTTPSApplicationHTTP wrapped in TLS. Provides the same semantics as HTTP but with encryption and authentication. Default port 443.
DHCPApplicationAutomatically assigns IP addresses and network configuration using the DORA cycle (Discover → Offer → Request → Acknowledge). Runs over UDP, ports 67/68.
📌 EXAM TIP: Keep transport and application protocols separate in your answers. Transport protocols (TCP, UDP) create the end-to-end pipe; application protocols (HTTP, HTTPS, DHCP) define what travels through it. A common mistake is describing HTTP as "reliable" — reliability comes from TCP underneath, not from HTTP itself.

🕹️ Interactive Task 3: Choose the Right Protocol for the Scenario

Each scenario needs a specific protocol. Select the best choice from the dropdown for each one, then click Check Answers.

🎥 Live Video Call

A video-conferencing app needs minimal latency and can tolerate occasional dropped frames. It should not wait for retransmissions.

📧 Sending an Email

An email client needs every byte of the message to arrive intact and in the correct order.

🔒 Online Banking

A user logs into their bank's website. The traffic must be encrypted and the server authenticated.

💻 Joining a New Network

A laptop connects to a new office network and needs to be assigned an IP address, subnet mask, gateway, and DNS servers automatically.

🌐 Browsing a Website

A browser requests a web page from a server using a stateless request–response protocol over port 80.

🎮 Online Gaming

A fast-paced multiplayer game needs the lowest possible latency and can tolerate occasional packet loss.

⭐ Extension Activities

After completing all Core Tasks, choose one or more of these activities to deepen your understanding:

1. Protocol Comparison Table — Create a table comparing TCP and UDP. Include connection model, reliability, ordering, flow control, and two example use cases for each.
2. The DORA Cycle — Draw a diagram of the four DHCP messages (Discover, Offer, Request, Acknowledge) showing which side (client/server) sends each and which ports are used.
3. HTTP vs HTTPS — Write a short paragraph explaining what TLS adds to HTTP and why HTTPS matters for online banking and e-commerce.
4. Wireshark Capture — Use Wireshark to capture a simple web request. Identify the TCP handshake, the HTTP request, and (if HTTPS) the TLS handshake. Note which protocols appear in sequence.

"Transport protocols (TCP, UDP) build the pipe; application protocols (HTTP, HTTPS, DHCP) define what travels through it. Together they turn raw bits on a wire into a secure page load on your screen."
