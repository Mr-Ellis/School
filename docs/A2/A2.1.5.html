A2.1.5 – The TCP/IP Model HL ONLY

📌 Learning Objective

By the end of this lesson, you will be able to:

  • Describe the function of the four layers of the TCP/IP model: Application, Transport, Internet, and Network Interface.
  • Explain the role of each layer and how they interact to ensure reliable data transmission over a network.
  • Identify which layer a given protocol (e.g., HTTP, TCP, IP, Ethernet) belongs to.

🎯 IB Command Term: Describe

🔑 Key Terms: The Four Layers

LayerPrimary FunctionKey Protocols / TechnologiesReliability Contribution
ApplicationDefines the semantics and syntax of the actual user data exchanged. Provides network services to applications and interacts with the user.[reference:0]HTTP/HTTPS, SMTP, DNS, SSH, DHCP, FTP, RTP/RTCP[reference:1]Uses transport guarantees or adds its own (e.g., application-layer retries, checksums inside payloads).[reference:2]
TransportCreates a logical end-to-end channel between two host processes, adding ports for multiplexing. Ensures reliable data delivery between applications.[reference:3]TCP (connection-oriented, in-order, loss-free), UDP (connection-less), QUIC (stream-multiplexed)[reference:4]TCP/QUIC masks loss and reordering, ensures data integrity with checksums, throttles transmissions to avoid congestion collapse.[reference:5]
InternetDelivers variable-length packets across multiple interconnected links and networks. Provides global addressing, fragmentation, and routing.[reference:6]IP (IPv4, IPv6), ICMP, IGMP/MLD, routing protocols (OSPF, BGP)[reference:7]Best-effort delivery without guarantees; however, it reports problems via ICMP so higher layers can recover.[reference:8]
Network Interface (Link)Moves raw frames between directly connected nodes and detects corruption on the local medium.[reference:9]Ethernet (IEEE 802.3), Wi-Fi (802.11), fibre-channel, DSL, cellular[reference:10]Link-level CRC/CRC32 checksums, optional automatic repeat requests (ARQ) in Wi-Fi, collision/back-off logic.[reference:11]
📌 EXAM TIP: The TCP/IP model is often called the Internet Protocol Suite. Remember the order: Application → Transport → Internet → Network Interface (ATIN). Each layer only communicates with the adjacent layers above and below it.[reference:12]

"The TCP/IP model decomposes internetworking into four ordered layers: Application, Transport, Internet, and Network Interface. Each layer solves one well-defined subset of the end-to-end communication problem and exposes a clean service interface to the layer above. Because the layers are independent yet complementary, engineers can innovate or replace any one of them without rewriting the whole stack."[reference:13]
