A2.1 Revision Guide: Network Fundamentals

This revision guide covers the core principles of how networks operate: the types of networks and their characteristics, the modern infrastructure that supports them, the hardware that connects them, the protocols that define communication, and the four-layer TCP/IP model. Use the command-term boxes to understand exactly what the examiner wants, and test yourself with the hidden practice questions at the end of each section.

1. Network Types, Characteristics & Models (A2.1.1)

🎯 IB Command Term: Explain
"Give a detailed account including reasons or causes. For each network type: state what it is, its primary purpose, and provide specific reasons for its design characteristics (e.g., why a LAN uses specific hardware compared to a WAN)."

Network Types

TypeScopeKey Characteristic
PAN (Personal Area Network)Immediate vicinity of a person.Bluetooth earphones to a phone; smartwatch to a phone.
LAN (Local Area Network)Small geographic area (home, office, school).High speed; owned by a single entity.
WAN (Wide Area Network)Large geographic area; connects multiple LANs.Uses external infrastructure (telecom lines); the Internet is the largest WAN.
VPN (Virtual Private Network)Logical network over an untrusted network (the Internet).Creates a secure, encrypted tunnel for privacy and anonymity.
⚠️ Exam Tip — Comparing LAN and WAN: Focus on three things: geographic scale (small vs. large), ownership (private vs. third-party), and transmission media (owned cables vs. leased telecom lines).

Key Characteristics

CharacteristicDefinition
BandwidthThe maximum rate of data transfer across a given path, usually measured in Mbps.
LatencyThe time delay taken for a data packet to travel from source to destination.
TopologyThe physical or logical arrangement of devices in a network (e.g., Star, Bus, Mesh).

Network Models

ModelHow It Works
Client/ServerOne central computer (server) provides resources and services to other computers (clients).
Peer-to-Peer (P2P)All computers have equal status and can act as both client and server, sharing resources directly.

Practice Question

Question: A multinational company needs to connect its offices in London, New York, and Tokyo. Explain which network type would be most appropriate and why. (3 marks)

Answer: A WAN (Wide Area Network) is most appropriate. It covers a large geographic area and connects multiple LANs (one per office). A WAN uses external infrastructure (such as leased telecom lines) provided by third parties, which is necessary because the company does not own the cables between London, New York, and Tokyo. A LAN would not work because it is limited to a small geographic area.

2. Modern Digital Infrastructures (A2.1.2)

🎯 IB Command Term: Identify
"Recognize and state the name of the infrastructure from a given description, scenario, or set of characteristics."

Modern computing relies on several interconnected infrastructures. You must be able to identify which one is at play in a given scenario.

InfrastructureWhat It IsKey BenefitKey Limitation

Cloud ComputingUsing someone else’s powerful computers over the internet (e.g., Google Drive, AWS).Scalable resources; no need to buy local hardware.Needs internet; less direct control; privacy concerns.

⚠️ Exam Tip — Edge vs. Cloud: If a scenario emphasises speed or poor connectivity, the answer is likely Edge Computing. If it emphasises sharing resources or scaling, it is likely Cloud Computing.

Case Study: Rescue Robots & Disaster Recovery

Rescue robots (e.g., in collapsed buildings after earthquakes) use edge computing because they cannot rely on a distant cloud. If a robot sends camera footage to a data centre to decide whether a shape is a survivor or rubble, the delay (latency) could cost lives. By processing data locally on the robot, it can make split-second decisions even when network connectivity is poor or completely lost.

Why this matters for disaster recovery: Disaster recovery is not just about backing up data; it is about keeping critical systems running when infrastructure fails. Edge computing provides resilience: if the central network goes down, edge devices (like rescue robots or local emergency servers) can continue to operate independently.

Practice Question

Question: A rescue robot searching a collapsed building must identify survivors quickly. Explain why edge computing is essential for this scenario. (3 marks)

Answer: Edge computing processes data locally on the robot itself, rather than sending it to a distant cloud. This provides very low latency, allowing the robot to make split-second decisions (e.g., distinguishing a survivor from rubble). In a collapsed building, network connectivity may be unreliable or absent, so a cloud-only approach would fail. Edge computing provides resilience by allowing the robot to continue operating independently of central systems.

3. Network Devices (A2.1.3)

🎯 IB Command Term: Describe
"Give a detailed account. For each network device: state what it is, what function it performs, and how it connects to other devices in the network."

Each device performs a specific job at a specific layer of the network.

DeviceFunction
HubConnects multiple devices in a LAN. Broadcasts incoming data to all connected devices. Operates at the physical layer. Largely obsolete.
SwitchConnects devices in a LAN. Uses MAC addresses to forward data only to the intended device. Operates at the data link layer.
RouterConnects different networks (e.g., a LAN to the internet). Uses IP addresses to route data packets between networks. Operates at the network layer.
ModemModulates and demodulates signals to convert digital data to analogue (and back) for transmission over phone/cable lines.
BridgeConnects two LAN segments. Filters traffic using MAC addresses to reduce collisions.
GatewayConnects networks that use different protocols. Acts as a translator between systems.
FirewallMonitors and filters incoming/outgoing network traffic based on security rules. Blocks unauthorised access.
Proxy ServerActs as an intermediary between clients and servers. Can cache content, filter requests, and improve security/anonymity.
NIC (Network Interface Card)Hardware that allows a device to connect to a network (wired or wireless). Contains a unique MAC address.
WAP (Wireless Access Point)Connects wireless devices to a wired network. Provides Wi-Fi connectivity.
RepeaterRegenerates and retransmits signals to extend the range of a network over long distances.
⚠️ Exam Tip — Switch vs. Router: A common mistake is confusing these two. Remember: a switch connects devices within one network and uses MAC addresses. A router connects different networks together and uses IP addresses.

Practice Question

Question: A small business has a local network but needs to connect it to the internet. Describe the role of the router in this scenario. (2 marks)

Answer: The router connects the local network (LAN) to the internet (a different network). It uses IP addresses to route data packets between the two networks, ensuring that data from the business's computers reaches the correct destination on the internet and vice versa.

4. Network Protocols (A2.1.4)

🎯 IB Command Term: Describe
"Give a detailed account. For each protocol: state what it is, what layer it operates at, what function it performs, and a typical use case."

A protocol is an agreed set of rules for communication. You must know which layer each protocol operates at.

ProtocolLayerFunction
TCPTransportConnection-oriented protocol that guarantees in-order, loss-free delivery using sequence numbers and acknowledgements. Uses the three-way handshake (SYN → SYN-ACK → ACK).
UDPTransportConnection-less protocol that sends independent datagrams. Best-effort delivery with no retransmission or ordering — trades reliability for low latency and minimal overhead.
HTTPApplicationStateless request–response protocol for fetching web resources. Runs over TCP (HTTP/1.1 & 2) or QUIC/UDP (HTTP/3). Default port 80.
HTTPSApplicationHTTP wrapped in TLS. Provides the same semantics as HTTP but with encryption and authentication. Default port 443.
DHCPApplicationAutomatically assigns IP addresses and network configuration using the DORA cycle (Discover → Offer → Request → Acknowledge). Runs over UDP, ports 67/68.
⚠️ Exam Tip — Transport vs. Application: Keep these separate in your answers. Transport protocols (TCP, UDP) create the end-to-end pipe. Application protocols (HTTP, HTTPS, DHCP) define what travels through it. A common mistake is describing HTTP as "reliable" — reliability comes from TCP underneath, not from HTTP itself.

Choosing the Right Protocol

ScenarioBest ProtocolReason
Live video callUDPNeeds minimal latency; can tolerate occasional dropped frames; must not wait for retransmissions.
Sending an emailTCPEvery byte must arrive intact and in the correct order.
Online banking loginHTTPSTraffic must be encrypted and the server authenticated.
Joining a new networkDHCPNeeds an IP address, subnet mask, gateway, and DNS servers assigned automatically.
Browsing a websiteHTTPStateless request–response protocol over port 80.
Online gamingUDPFast-paced action cannot wait for lost packets to be re-sent.

Practice Question

Question: A live video call application needs to minimise delay and can tolerate occasional dropped frames. State the most appropriate transport protocol and explain why. (3 marks)

Answer: UDP is the most appropriate. It is a connection-less protocol that sends independent datagrams with no retransmission or ordering. This reduces overhead and latency, which is critical for a live call. Occasional dropped frames are acceptable because the video can continue playing; waiting for retransmissions (as TCP would) would cause noticeable delay.

5. The TCP/IP Model (A2.1.5 HL)

🎯 IB Command Term: Describe
"Give a detailed account. For each layer of the TCP/IP model: state its name, its primary function, the protocols it uses, and how it contributes to end-to-end communication."

The TCP/IP model (also called the Internet Protocol Suite) is the foundational framework the Internet uses. It has four layers, often remembered by the acronym ATIN (Application → Transport → Internet → Network Interface).

LayerPrimary FunctionKey Protocols / TechnologiesReliability Contribution
ApplicationDefines the semantics and syntax of the user data exchanged. Provides network services to applications.HTTP/HTTPS, SMTP, DNS, SSH, DHCP, FTP, RTP/RTCPUses transport guarantees or adds its own (e.g., application-layer retries).
TransportCreates a logical end-to-end channel between two host processes, adding ports for multiplexing. Ensures reliable data delivery between applications.TCP (connection-oriented, in-order, loss-free), UDP (connection-less), QUICTCP/QUIC masks loss and reordering, ensures integrity with checksums, throttles transmissions.
InternetDelivers variable-length packets across multiple interconnected links and networks. Provides global addressing, fragmentation, and routing.IP (IPv4, IPv6), ICMP, IGMP/MLD, routing protocols (OSPF, BGP)Best-effort delivery without guarantees; reports problems via ICMP so higher layers can recover.
Network Interface (Link)Moves raw frames between directly connected nodes and detects corruption on the local medium.Ethernet (IEEE 802.3), Wi-Fi (802.11), fibre-channel, DSL, cellularLink-level CRC/CRC32 checksums, optional ARQ in Wi-Fi, collision/back-off logic.
⚠️ Exam Tip — The ATIN Acronym: Remember the order: Application → Transport → Internet → Network Interface. Each layer only communicates with the adjacent layers above and below it. When describing a protocol, always state its layer first — this earns marks immediately.

Practice Question

Question: Explain how the Transport layer contributes to reliable data delivery. (2 marks)

Answer: The Transport layer uses protocols like TCP to ensure reliable delivery. TCP uses sequence numbers and acknowledgements to guarantee that data arrives in order and without loss. It also uses checksums to detect corruption and flow control to avoid overwhelming the receiver.

Quick Definitions to Memorise

• Bandwidth: Maximum data transfer rate of a path.
• Latency: Time delay for a packet to travel from source to destination.
• MAC address: Unique hardware identifier used by switches.
• IP address: Logical address used by routers to route packets between networks.
• TCP: Reliable, connection-oriented transport protocol.
• UDP: Fast, connection-less transport protocol.
• DORA: Discover → Offer → Request → Acknowledge (the DHCP process).
• ATIN: Application → Transport → Internet → Network Interface (the TCP/IP layers).
