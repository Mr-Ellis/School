A2.2.2 – Explain the Function of Servers (HL)

📌 Learning Objective

By the end of this lesson, you will be able to:

  • Explain the role of a server in a client-server network model
  • Explain the specific function of six key server types: DNS, DHCP, File, Mail, Proxy, and Web
  • Distinguish between servers that perform similar-sounding tasks (e.g., DNS vs. DHCP)
  • Match a server type to a real-world scenario and justify the choice

🎯 IB Command Term: Explain

Explain – “Give a detailed account including reasons or causes.”

Naming a server is not explaining it. This lesson builds the skill of explaining what problem the server solves, how it solves it, and why a network needs it.

🔑 Key Terms

TermDefinition
ServerA computer or program that provides a service or resource to other computers (clients) across a network.
ClientA computer or program that requests a service or resource from a server.
Client-Server ModelA network architecture where one central server (or a cluster of servers) provides resources to multiple client devices.
ProtocolAn agreed set of rules for communication between devices (e.g., HTTP, SMTP, DNS).
IP AddressA unique numerical address assigned to a device on a network.
Domain NameA human-readable name for a website (e.g., google.com) that must be translated into an IP address.
CacheA temporary storage area that keeps frequently accessed data close at hand to speed up future requests.

💡 The Big Idea: Servers Solve Problems

A server is not just a "powerful computer." It is a solution to a specific problem. If you can explain what problem the server solves, you can explain the server.

In the client-server model, servers have a one-to-many relationship with clients: a single server can provide resources to many clients at once [citation:7]. The server listens for requests, processes them, and sends back a response.

The one rule you must never break

A server is defined by its software, not its hardware. A regular desktop computer can become a file server simply by installing file-sharing software [citation:7]. What makes it a "file server" is the service it provides, not the size of the box.

🔌 The Six Key Servers (HL)

The IB syllabus requires you to know these six server types. For each one, you must explain what it does and why it is needed.

DNS

DNS Server

Function: Converts a human-readable domain name (like google.com) into the numerical IP address that computers use to find each other [citation:9].

Why it is needed: Humans are good at remembering names, but computers need numbers. DNS is the translator that bridges the gap.

Analogy: A phone book. You know the name, DNS gives you the number.
DHCP

DHCP Server

Function: Automatically assigns network settings to a device when it joins a network: an IP address, subnet mask, default gateway, and DNS server address [citation:9].

Why it is needed: Manually configuring every device on a network would be impossible. DHCP handles it automatically, usually for a lease period.

Analogy: A hotel receptionist. When you arrive, they give you a room key (IP address) for your stay.
File

File Server

Function: Centrally stores and manages shared files. It controls access permissions and handles backups for authorized users [citation:9].

Why it is needed: Instead of everyone having their own copy of a file, the file lives in one place. This prevents version confusion and makes backups simple.

Analogy: A shared filing cabinet in an office. Everyone can access the files they are allowed to see.
Mail

Mail Server

Function: Sends, receives, stores, and forwards email. It uses SMTP to send or relay messages, and IMAP or POP3 to retrieve them [citation:9].

Why it is needed: Email needs a central hub. Your mail server holds your inbox until you log in, and handles delivery to other mail servers across the internet.

Analogy: A post office. It receives your letters, sorts them, and delivers them to the right address.
Proxy

Proxy Server

Function: Acts as an intermediary between clients and external servers. It can filter requests, restrict access, cache resources, log activity, and hide internal client IP addresses [citation:9].

Why it is needed: It provides security and control. A school can use a proxy to block inappropriate websites, or a company can use one to monitor traffic.

Analogy: A receptionist who screens your calls. They decide what gets through and what does not.
Web

Web Server

Function: Responds to HTTP or HTTPS requests from browsers by sending or generating resources such as HTML, CSS, JavaScript, and images [citation:9].

Why it is needed: Every website you visit lives on a web server. The browser sends a request, and the web server sends back the page.

Analogy: A library desk. You ask for a book (page), and the librarian (web server) fetches it for you.

⚠️ The Most Common Mistake: DNS vs. DHCP

These two servers are often confused because they both deal with IP addresses. They do completely different jobs.

ServerWhat It DoesWhen It Acts
DHCPGives a device its IP address and network settings.When the device first joins the network (like when you connect to Wi-Fi).
DNSTranslates a domain name into an IP address.Every time you type a web address or click a link.
Remember it this way

DHCP gives you your address. It is how your device gets an identity on the network.
DNS tells you someone else's address. It is how your device finds the server it wants to talk to.
