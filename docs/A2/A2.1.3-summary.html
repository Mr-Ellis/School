A2.1.3 – Network Devices

📌 Learning Objective

By the end of this lesson, you will be able to:

  • Describe the function of the following network devices: hub, switch, router, modem, bridge, gateway, firewall, proxy server, NIC, WAP, and repeater.
  • Explain how devices on a network interact to transmit data.
  • Select appropriate devices for given network scenarios.

🎯 IB Command Term: Describe

Describe – "Give a detailed account. For each network device: state what it is, what function it performs, and how it connects to other devices in the network."

🔑 Key Terms

DeviceFunction
HubConnects multiple devices in a LAN. Broadcasts incoming data to all connected devices. Operates at the physical layer. Largely obsolete.
SwitchConnects devices in a LAN. Uses MAC addresses to forward data only to the intended device. Operates at the data link layer.
RouterConnects different networks (e.g., a LAN to the internet). Uses IP addresses to route data packets between networks. Operates at the network layer.
ModemModulates and demodulates signals to convert digital data to analog (and back) for transmission over phone/cable lines.
BridgeConnects two LAN segments. Filters traffic using MAC addresses to reduce collisions.
GatewayConnects networks that use different protocols. Acts as a translator between systems.
FirewallMonitors and filters incoming/outgoing network traffic based on security rules. Blocks unauthorized access.
Proxy ServerActs as an intermediary between clients and servers. Can cache content, filter requests, and improve security/anonymity.
Network Interface Card (NIC)Hardware that allows a device to connect to a network (wired or wireless). Contains a unique MAC address.
Wireless Access Point (WAP)Connects wireless devices to a wired network. Provides Wi-Fi connectivity.
RepeaterRegenerates and retransmits signals to extend the range of a network over long distances.
📌 EXAM TIP: A common mistake is confusing a switch and a router. Remember: a switch connects devices within one network; a router connects different networks together. A switch uses MAC addresses; a router uses IP addresses.

⭐ Extension Activities

After completing all Core Tasks, choose one or more of these activities to deepen your understanding:

1. Network Diagram — Draw a diagram of a home network showing the modem, router, switch, WAP, and connected devices. Annotate each device with its function.
2. Device Comparison — Create a table comparing a hub, switch, and router. Include the layer they operate at, the addressing they use, and a scenario where each is appropriate.
3. Research — Research the role of a proxy server in a school or corporate network. Write a short paragraph explaining what it does and why it is used.
4. Packet Tracer — Use Cisco Packet Tracer (or a similar simulator) to build a simple network with a switch, router, and two PCs. Verify that the PCs can communicate.

"Network devices each have a specific role: hubs broadcast, switches direct by MAC address, routers route by IP address, and firewalls protect. Understanding their functions is essential for designing and troubleshooting networks."
