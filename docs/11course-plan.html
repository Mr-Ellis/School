Term 1 — B2 Programming

B2 Programming Core

Students learn core programming skills by designing, writing, and testing code using structured techniques. They develop confidence with sequence, selection, iteration, arrays, functions, and basic algorithms.

Week Dates Topic / Lesson Content 1 Aug 26–30 Hello World & Setup Environment setup, first program 2 Sep 2–6 Numeric Types & Operations Data types, arithmetic operations 3 Sep 9–13 Strings & Substrings String manipulation, substring extraction 4 Sep 16–20 Static vs Dynamic Data Structures 1D/2D arrays/lists, traversal 4 Sep 16–20 Arrays & Lists 1D/2D arrays/lists, traversal 5 Sep 23–27 Sequence Instruction order 5 Sep 23–27 Selection Conditionals 6 Sep 30 – Oct 4 Iteration Counted/conditional loops 7 Oct 7–11 Functions & Modularisation Functions, parameters, return values 8 Oct 14–18 Exception Handling & Debugging try/except, debugging techniques 🍂 Autumn Break: Oct 19–23

Term 2 — B3 OOP & B4 ADTs

B3 Object-Oriented Programming Core

Students learn object-oriented programming principles including classes, objects, encapsulation, inheritance, and polymorphism.

Week Dates Topic / Lesson Content 14 Dec 1–5 Intro to OOP Classes, objects, encapsulation 14 Dec 1–5 Inheritance (HL) Parent/child classes, reusability 15 Dec 8–12 Designing Classes UML class diagrams, attributes, methods 15 Dec 8–12 Polymorphism (HL) Overriding, dynamic dispatch 16 Dec 15–19 Instantiating Objects Constructors, object state 16 Dec 15–19 Abstraction (HL) Abstraction HL ❄️ Winter Break: Dec 21 – Jan 1 17 Jan 4–8 Encapsulation Access modifiers, information hiding 17 Jan 4–8 Composition & Aggregation (HL) Composition and aggregation 18 Jan 11–15 Static vs Non-Static Class vs instance variables/methods 18 Jan 11–15 Design Patterns in OOP (HL) Design patterns in OOP HL

B4 Abstract Data Types HL

Students explore abstract data types and their implementations, including linked lists and other HL structures. Emphasis is placed on abstraction, structure, and algorithmic manipulation.

Week Dates Topic / Lesson Content 19 Jan 18–22 Intro to ADTs Purpose, abstraction of data structures 19 Jan 18–22 Linked Lists (HL) Singly/doubly/circular lists, insertion/deletion/traversal 19 Jan 18–22 Linked Lists (HL) Construct and apply linked lists 20 Jan 25–29 Sets (HL) Construct and apply Sets 20 Jan 25–29 Hash Table/Maps (HL) Construct and apply HashTables 21 Feb 1–7 Revision Review and consolidation ❄️ Winter Break: Feb 8–12
