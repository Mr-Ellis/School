Using py -m pip guarantees you're installing into the same Python that py runs. Using just pip can install to a different Python by mistake — a common beginner trap.

❓ Your Turn

What happens if you write command=on_click() with brackets instead of command=on_click?

Answer: With brackets, Python calls the function immediately when the button is created — not when it's clicked. The button would do nothing when clicked, and the label would change before you even press it. The brackets mean "call this now"; no brackets means "remember this for later."

The Task Class
SC4 — Auto priority

Now we build the engine. A Task class stores everything about one homework task and knows how to calculate its own priority.

Create these files:

Folder structure 
models\
├── __init__.py     (empty file)
└── task.py
⚠️ Important

The __init__.py file must exist even if empty. It tells Python to treat models as a package so you can import from it.

models/task.py 
from datetime import datetime, date

class Task:
    def __init__(self, task_id, title, subject, due_date):
        self.task_id = task_id
        self.title = title
        self.subject = subject
        self.due_date = due_date
        self.priority = self.calculate_priority()

    def calculate_priority(self):
        due = datetime.strptime(self.due_date, "%Y-%m-%d").date()
        days_left = (due - date.today()).days

        if days_left < 0:
            return "Overdue"
        elif days_left <= 2:
            return "High"
        elif days_left <= 7:
            return "Medium"
        else:
            return "Low"

    def days_left(self):
        due = datetime.strptime(self.due_date, "%Y-%m-%d").date()
        return (due - date.today()).days

    def to_dict(self):
        return {
            "id": self.task_id,
            "title": self.title,
            "subject": self.subject,
            "due_date": self.due_date,
            "priority": self.priority
        }

Saving to a File
SC7 — JSON persistence

If your program closes, you don't want to lose all your tasks. We save them to a JSON file — a simple text format that stores structured data.

Create these files:

Folder structure 
HomeworkManager\
├── tasks.json          (contains just: [])
└── managers\
    ├── __init__.py     (empty)
    └── storage_manager.py
tasks.json 
[]
managers/storage_manager.py 
import json
import os

class StorageManager:
    FILE_PATH = "tasks.json"

    @staticmethod
    def load_tasks():
        if not os.path.exists(StorageManager.FILE_PATH):
            return []
        with open(StorageManager.FILE_PATH, "r", encoding="utf-8") as file:
            return json.load(file)

    @staticmethod
    def save_tasks(tasks):
        with open(StorageManager.FILE_PATH, "w", encoding="utf-8") as file:
            json.dump(tasks, file, indent=4)
❓ Your Turn

Why JSON instead of a plain .txt file?

Answer: JSON understands structure (lists, dictionaries, numbers, strings). A plain text file only stores raw characters. With JSON, we can save a whole list of task dictionaries and load them back as real Python objects, without writing our own parser.

Rejecting Bad Input
SC8 — Validation

Users make mistakes. Your program should catch them before saving garbage data.

├── __init__.py     (empty)
└── validation.py
utilities/validation.py 
from datetime import datetime

class Validation:
    @staticmethod
    def validate_title(title):
        return title.strip() != ""

    @staticmethod
    def validate_subject(subject):
        return subject.strip() != ""

    @staticmethod
    def validate_date(date_text):
        try:
            datetime.strptime(date_text, "%Y-%m-%d")
            return True
        except ValueError:
            return False
❓ Your Turn

Why validate before saving rather than after?

Answer: If you save first, invalid data ends up in your JSON file, and you'll have to detect and clean it later — sometimes after it's caused crashes. Validating first prevents bad data from ever entering the system.

The Task Manager
SC1–SC3, SC5–SC6

The TaskManager is the brain. It ties together the Task model, the storage, and the sorting logic.

managers/task_manager.py 
from models.task import Task
from managers.storage_manager import StorageManager

class TaskManager:
    def __init__(self):
        self.tasks = []
        self.load_tasks()

    def add_task(self, title, subject, due_date):
        task_id = self.get_next_id()
        task = Task(task_id, title, subject, due_date)
        self.tasks.append(task)
        self.sort_tasks()
        self.save_tasks()

    def edit_task(self, task_id, title, subject, due_date):
        for task in self.tasks:
            if task.task_id == task_id:
                task.title = title
                task.subject = subject
                task.due_date = due_date
                task.priority = task.calculate_priority()
                break
        self.sort_tasks()
        .save_tasks()

    def delete_task(self, task_id):
        self.tasks = [t for t in self.tasks if t.task_id != task_id]
        self.save_tasks()

    def sort_tasks(self):
        priority_order = {"Overdue": 0, "High": 1, "Medium": 2, "Low": 3}
        self.tasks.sort(key=lambda t: (priority_order[t.priority], t.due_date))

    def get_next_id(self):
        if not self.tasks:
            return 1
        return max(t.task_id for t in self.tasks) + 1

    def save_tasks(self):
        StorageManager.save_tasks([t.to_dict() for t in self.tasks])

    def load_tasks(self):
        self.tasks.clear()
        for item in StorageManager.load_tasks():
            self.tasks.append(Task(item["id"], item["title"],
                                   item["subject"], item["due_date"]))
        self.sort_tasks()
❓ Your Turn

Which task appears first in the output, and why?

Answer: The task with the highest priority (Overdue > High > Medium > Low). If two tasks share the same priority, the one with the earlier due date comes first.

gui/main_window.py 
import tkinter as tk
from tkinter import ttk, messagebox
import customtkinter as ctk
from gui.task_dialog import TaskDialog
from managers.task_manager import TaskManager
from utilities.validation import Validation

class MainWindow(ctk.CTk):
    def __init__(self):
        super().__init__()
        self.title("Homework Task Manager")
        self.geometry("900x600")
        self.manager = TaskManager()
        self.create_widgets()
        self.refresh_table()

    def create_widgets(self):
        ctk.CTkLabel(self, text="Homework Task Manager",
                     font=("Arial", 24, "bold")).pack(pady=10)

        btn_frame = ctk.CTkFrame(self)
        btn_frame.pack(fill="x", padx=20)
        ctk.CTkButton(btn_frame, text="Add", command=self.add_task).pack(side="left", padx=5, pady=10)
        ctk.CTkButton(btn_frame, text="Edit", command=self.edit_task).pack(side="left", padx=5)
        ctk.CTkButton(btn_frame, text="Delete", command=self.delete_task).pack(side="left", padx=5)

        columns = ("Title", "Subject", "Due Date", "Priority", "Days Left")
        self.tree = ttk.Treeview(self, columns=columns, show="headings")
        for col in columns:
            self.tree.heading(col, text=col)
            self.tree.column(col, width=150)
        self.tree.pack(fill="both", expand=True, padx=20, pady=20)

        self.status = ctk.CTkLabel(self, text="")
        self.status.pack(pady=5)

    def refresh_table(self):
        for row in self.tree.get_children():
            self.tree.delete(row)
        for t in self.manager.tasks:
            self.tree.insert("", tk.END, iid=t.task_id,
                             values=(t.title, t.subject, t.due_date,
                                     t.priority, t.days_left()))
        self.status.configure(text=f"{len(self.manager.tasks)} tasks loaded")

    def add_task(self):
        dialog = TaskDialog(self, "Add Task")
        self.wait_window(dialog)
        if not dialog.result:
            return
        title, subject, due_date = dialog.result

        if not Validation.validate_title(title):
            messagebox.showerror("Error", "Title cannot be empty."); return
        if not Validation.validate_subject(subject):
            messagebox.showerror("Error", "Subject cannot be empty."); return
        if not Validation.validate_date(due_date):
            messagebox.showerror("Error", "Date must be YYYY-MM-DD."); return

        self.manager.add_task(title, subject, due_date)
        self.refresh_table()
        messagebox.showinfo("Success", "Task added!")

    def edit_task(self):
        sel = self.tree.selection()
        if not sel:
            messagebox.showwarning("Warning", "Select a task first."); return
        task_id = int(sel[0])
        task = next(t for t in self.manager.tasks if t.task_id == task_id)

        dialog = TaskDialog(self, "Edit Task", task)
        self.wait_window(dialog)
        if not dialog.result:
            return
        title, subject, due_date = dialog.result

        if not (Validation.validate_title(title)
                and Validation.validate_subject(subject)
                and Validation.validate_date(due_date)):
            messagebox.showerror("Error", "Invalid input."); return

        self.manager.edit_task(task_id, title, subject, due_date)
        self.refresh_table()
        messagebox.showinfo("Success", "Task updated!")

    def delete_task(self):
        sel = self.tree.selection()
        if not sel:
            messagebox.showwarning("Warning", "Select a task first."); return
        task_id = int(sel[0])
        if messagebox.askyesno("Delete", "Delete selected task?"):
            self.manager.delete_task(task_id)
            self.refresh_table()
            messagebox.showinfo("Deleted", "Task removed.")

Weighted Priority Algorithm
Final upgrade
🎯 Why We're Doing This

Your current priority uses a simple if/elif chain. It ignores difficulty and time estimates. A 30-minute quiz and a 4-hour essay due on the same day get the same priority.

We're replacing it with a weighted scoring algorithm — a real algorithmic approach that IB moderators reward in Criterion C.

The formula:

Formula 
score = (urgency × 0.5) + (difficulty × 2) + (estimated_hours × 0.8)
  • Urgency = max(0, 10 - days_left) → 10 for due today, 0 for 10+ days away
  • Difficulty = 1 (Easy), 2 (Medium), 3 (Hard) — user picks
  • Estimated hours = user input
📝 Design Justification — Read This Before Coding

This is the part that earns IB marks. Understand why these numbers:

  • Urgency × 0.5 — ranges 0–5 points. Matters, but not alone.
  • Difficulty × 2 — heaviest weight. Hard (3) adds 6 points, easy (1) adds 2. The 4-point gap can bump a task up a full band.
  • Estimated hours × 0.8 — a 3-hour task adds 2.4 points; a 0.5-hour task adds 0.4. Distinguishes quick revision from big projects.

Why these weights? After discussion with the client, difficulty and time commitment mattered more than raw due date — students underestimate long tasks. Urgency is included because procrastinating is also bad.

Add this sentence to your IB documentation:

I found that weighted scoring models — commonly used in project management and recommendation systems — provide a more flexible and justified approach. Step 1 — Replace models/task.py

models/task.py 
from datetime import datetime, date


class Task:
    def __init__(self, task_id, title, subject, due_date,
                 difficulty=2, estimated_hours=1.0):
        self.task_id = task_id
        self.title = title
        self.subject = subject
        self.due_date = due_date
        self.difficulty = int(difficulty)
        self.estimated_hours = float(estimated_hours)
        self.priority_score = self.calculate_priority_score()
        self.priority = self.score_to_label(self.priority_score)

    def days_left(self):
        due = datetime.strptime(self.due_date, "%Y-%m-%d").date()
        return (due - date.today()).days

    def calculate_priority_score(self):
        days = self.days_left()
        urgency = max(0, 10 - days)
        score = (urgency * 0.5) + (self.difficulty * 2) + (self.estimated_hours * 0.8)
        return round(score, 2)

    def score_to_label(self, score):
        if self.days_left() < 0:
            return "Overdue"
        elif score >= 9:
            return "High"
        elif score >= 6:
            return "Medium"
        else:
            return "Low"

    def to_dict(self):
        return {
            "id": self.task_id,
            "title": self.title,
            "subject": self.subject,
            "due_date": self.due_date,
            "difficulty": self.difficulty,
            "estimated_hours": self.estimated_hours,
            "priority_score": self.priority_score,
            "priority": self.priority
        }

gui/main_window.py 
import tkinter as tk
from tkinter import ttk, messagebox
import customtkinter as ctk
from gui.task_dialog import TaskDialog
from managers.task_manager import TaskManager
from utilities.validation import Validation


class MainWindow(ctk.CTk):
    def __init__(self):
        super().__init__()
        self.title("Homework Task Manager")
        self.geometry("1000x600")
        self.manager = TaskManager()
        self.create_widgets()
        self.refresh_table()

    def create_widgets(self):
        ctk.CTkLabel(self, text="Homework Task Manager",
                     font=("Arial", 24, "bold")).pack(pady=10)

        btn_frame = ctk.CTkFrame(self)
        btn_frame.pack(fill="x", padx=20)
        ctk.CTkButton(btn_frame, text="Add", command=self.add_task).pack(side="left", padx=5, pady=10)
        ctk.CTkButton(btn_frame, text="Edit", command=self.edit_task).pack(side="left", padx=5)
        ctk.CTkButton(btn_frame, text="Delete", command=self.delete_task).pack(side="left", padx=5)

        columns = ("Title", "Subject", "Due Date", "Priority", "Score", "Days Left")
        self.tree = ttk.Treeview(self, columns=columns, show="headings")
        for col in columns:
            self.tree.heading(col, text=col)
            self.tree.column(col, width=140)
        self.tree.pack(fill="both", expand=True, padx=20, pady=20)

        self.tree.tag_configure("Overdue", background="#8B0000", foreground="white")
        self.tree.tag_configure("High",    background="#B22222", foreground="white")
        self.tree.tag_configure("Medium",  background="#DAA520", foreground="black")
        self.tree.tag_configure("Low",     background="#2E8B57", foreground="white")

        self.status = ctk.CTkLabel(self, text="")
        self.status.pack(pady=5)

    def refresh_table(self):
        for row in self.tree.get_children():
            self.tree.delete(row)

        for t in self.manager.tasks:
            self.tree.insert("", tk.END, iid=t.task_id,
                             values=(t.title, t.subject, t.due_date,
                                     t.priority, t.priority_score,
                                     t.days_left()),
                             tags=(t.priority,))

        overdue = sum(1 for t in self.manager.tasks if t.priority == "Overdue")
        high    = sum(1 for t in self.manager.tasks if t.priority == "High")
        self.status.configure(
            text=f"Total: {len(self.manager.tasks)}   "
                 f"Overdue: {overdue}   High: {high}"
        )

    def add_task(self):
        dialog = TaskDialog(self, "Add Task")
        self.wait_window(dialog)
        if not dialog.result:
            return

        title, subject, due_date, difficulty, hours_text = dialog.result

        if not Validation.validate_title(title):
            messagebox.showerror("Error", "Title cannot be empty."); return
        if not Validation.validate_subject(subject):
            messagebox.showerror("Error", "Subject cannot be empty."); return
        if not Validation.validate_date(due_date):
            messagebox.showerror("Error", "Date must be YYYY-MM-DD."); return

        try:
            estimated_hours = float(hours_text)
            if estimated_hours < 0:
                raise ValueError
        except ValueError:
            messagebox.showerror("Error", "Estimated hours must be a positive number.")
            return

        self.manager.add_task(title, subject, due_date, difficulty, estimated_hours)
        self.refresh_table()
        messagebox.showinfo("Success", "Task added!")

    def edit_task(self):
        sel = self.tree.selection()
        if not sel:
            messagebox.showwarning("Warning", "Select a task first."); return

        task_id = int(sel[0])
        task = next(t for t in self.manager.tasks if t.task_id == task_id)

        dialog = TaskDialog(self, "Edit Task", task)
        self.wait_window(dialog)
        if not dialog.result:
            return

        title, subject, due_date, difficulty, hours_text = dialog.result

        if not (Validation.validate_title(title)
                and Validation.validate_subject(subject)
                and Validation.validate_date(due_date)):
            messagebox.showerror("Error", "Invalid input."); return

        try:
            estimated_hours = float(hours_text)
            if estimated_hours < 0:
                raise ValueError
        except ValueError:
            messagebox.showerror("Error", "Estimated hours must be a positive number.")
            return

        self.manager.edit_task(task_id, title, subject, due_date,
                               difficulty, estimated_hours)
        self.refresh_table()
        messagebox.showinfo("Success", "Task updated!")

    def delete_task(self):
        sel = self.tree.selection()
        if not sel:
            messagebox.showwarning("Warning", "Select a task first."); return

        task_id = int(sel[0])
        if messagebox.askyesno("Delete", "Delete selected task?"):
            self.manager.delete_task(task_id)
            .refresh_table()
            messagebox.showinfo("Deleted", "Task removed.")

Answer: It depends on the tasks. If several tasks are due soon, their scores all rise together, so the order stays the same.
