🔁 Quick Recap: What is Pseudocode?

In Lesson 1, we learned that pseudocode is a text version of an algorithm that looks similar to code but isn't tied to any one programming language.

Good pseudocode should be:

  • Short — only the essential steps
  • Clear — easy to read and understand
  • Precise — no vague instructions
  • Started with START and ended with STOP — always uppercase

🔀 What are Conditional Statements?

A conditional statement lets a program make a decision. It checks a condition and then chooses one path or another based on whether the condition is true or false.

In pseudocode, conditional statements use the keywords IF, THEN, ELSE and ENDIF.

The structure of a conditional statement:
IF condition THEN instructions to run if the condition is true ELSE instructions to run if the condition is false ENDIF

📝 Worked Example: Capital of England Quiz

Let's look at the pseudocode from Worksheet 1 and work through it together:

START answer = "London" OUTPUT "What is the capital of England?" userInput = INPUT IF answer == userInput THEN OUTPUT "Correct" ELSE OUTPUT "Incorrect" ENDIF STOP

Step-by-step trace

  1. START — the program begins.
  2. answer = "London" — the variable answer is set to the string "London".
  3. OUTPUT "What is the capital of England?" — the question is displayed to the user.
  4. userInput = INPUT — the program waits for the user to type something. Whatever they type is stored in userInput.
  5. IF answer == userInput THEN — the program checks: is the value of answer equal to the value of userInput?
  6. If true (they typed "London") → OUTPUT "Correct"
  7. If false (they typed anything else) → OUTPUT "Incorrect"
  8. ENDIF — the conditional block ends.
  9. STOP — the program ends.
Predict the output: If the user types "London", the output is "Correct". If the user types "Paris", the output is "Incorrect".

✏️ Practice 2: Light Level Challenges

Here is a MicroPython program that uses a conditional statement with the micro:bit's light sensor:

from microbit import *

while True:
    if display.read_light_level() > 50:
        display.show(Image.HEART)

This program checks if the light level is greater than 50. If it is, it displays a heart.

  3. IF light level < 100 THEN display a heart ENDIF
  4. IF light level > 60 THEN display a heart ENDIF
  5. IF light level == 200 THEN display a heart ENDIF

✏️ Practice 3: Wireless Messaging with Micro:bits

In this activity, you'll send and receive secret messages between two micro:bits using wireless communication and alphabet position encoding.

🔧 Step 1: Setup

  • Connect two micro:bits to your computer.
  • Label them Micro:bit 1 and Micro:bit 2.
  • Save your programs as microbit1.py and microbit2.py.

💻 Step 2: Micro:bit 1 — Sends HELLO

from microbit import *
import radio

radio.config(group=42)
radio.on()

while True:
    message = radio.receive()
    if message:
        display.scroll("8, 5, 12, 12, 15") # HELLO
    if button_a.is_pressed():
        display.clear()
        radio.send('message')

✅ Step 3: Micro:bit 2 — Sends MICROBIT

from microbit import *
import radio

radio.config(group=42)
radio.on()

while True:
    message = radio.receive()
    if message:
        display.scroll("13, 9, 3, 18, 15, 2, 9, 20") # MICROBIT
    if button_a.is_pressed():
        display.clear()
        radio.send('message')

🔍 Step 4: Decode the Message

Use the alphabet position table to decode:

  • 13, 9, 3, 18, 15, 2, 9, 20 → M, I, C, R, O, B, I, T → MICROBIT
