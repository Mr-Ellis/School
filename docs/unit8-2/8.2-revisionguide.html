1 The Rules of Pseudocode

Pseudocode is a text representation of an algorithm. It sits between human language and programming code, making it the perfect planning tool.

Test your knowledge

  • Should pseudocode be written as long paragraphs or short, precise instructions?
  • What case (upper/lower) should keywords like START and STOP be in?
  • Do you need to indent code inside an IF statement?
Remember: You cannot just write pseudocode "any way you like." It has strict rules so that other programmers can read and understand your plan without confusion.

Rule 1: Short and precise (one instruction per line).

Rule 2: Capitalised keywords (START, STOP, INPUT, OUTPUT, IF, THEN).

Rule 3: Must begin with START and end with STOP.

Rule 4: Indentation matters for conditional blocks.

3 Pseudocode vs. MicroPython

It is important to know which tool you are using. Here is how they compare:

ToolWhat it is used for
PseudocodeUsed to plan the algorithm and the logical/conditional statements before you write any code.
MicroPythonThe actual code that runs on the micro:bit. Used to write the program for the device.
Test PlanUsed to check the outputs are as expected, and to find errors that need fixing.

Spotting the difference

  • If you see OUTPUT "Hello", that is Pseudocode.
  • If you see display.scroll("Hello"), that is MicroPython.

4 Variables & Data Types

A variable is a named container that holds a value. In algorithms, variables can hold different data types:

Data TypeWhat it stores
IntegerA whole number (e.g. 5, 42, 100).
BooleanOnly two possible states: TRUE or FALSE.
StringText (e.g. "Hello", "Password").

What data type is a sensor reading?

When you store a sensor reading (like the light level) in a variable, it is stored as an integer because it is a whole number.

Think about it: The output of a conditional statement is a Boolean, because it can only be one of two states: TRUE or FALSE.

5 Logical Operators (AND / OR)

Logical operators combine inputs to generate an output based on rules. The two you need to know are AND and OR.

How they work

  • AND: Activates the output only when both inputs are TRUE.
  • OR: Activates the output when either or both inputs are TRUE.

8 Linear Search

A linear search is an algorithm that finds an item in a list by checking each item in turn, one by one, until it finds the target.

Are these statements True or False?

  • It requires the list to be ordered alphabetically or numerically.
  • It always searches a list from left to right.
  • A computer can do it without a program.

1. False: The list does not need to be ordered. It can be completely random.

2. True: It starts at the first item and moves to the next (usually left to right).

3. False: A computer needs an algorithm/program to tell it exactly how to search.

9 Using Test Plans

A test plan is used to make sure the program works as expected and to find errors that need fixing (like spelling mistakes or logic errors).

Test your knowledge

  • Do you only need to test one possible input?
  • Can you use a test plan more than once?
  • If you use AND/OR, do you need to test every combination?

1. No: You must test multiple possible inputs.

2. Yes: You can use it as many times as necessary as you fix errors.

3. Yes: You must test all combinations of inputs when using logical operators.

10 Debugging

Debugging is the process of finding and fixing errors in your code.

Common MicroPython errors to look for:

  • Missing colons: if button_a.is_pressed() needs a : at the end.
  • Missing brackets: Check that every ( has a matching ).
  • Case sensitivity: Image.HAPPY is correct, image.happy will cause an error.
  • Spelling: display not diplay.

Q: What is the process of finding and fixing code errors called?

A: Debugging.
