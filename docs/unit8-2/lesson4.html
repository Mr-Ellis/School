💻 How Computers Store Letters: Binary & ASCII

Computers are made of millions of tiny switches that can only ever be ON (1) or OFF (0). That is why computers "speak" in binary — a series of 0s and 1s.

Every letter, number and symbol on a keyboard has its own unique 8-bit binary code. This is called the ASCII code.

📡 Sending a Message Between Two micro:bits

The micro:bit has a built-in radio that lets two devices talk to each other without any wires. Two functions do the work:

  • radio.send() — sends data from one micro:bit to another.
  • radio.receive() — reads any message that has arrived.
Critical rule: both micro:bits must be on the same radio group to communicate. The group is a number from 0 to 255. Choose a group that is unique to your pair — if another pair uses the same group, your messages will be mixed up with theirs.
Main Activity · Micro:bit Pair Work

Send the Hidden Word Between Two micro:bits

In pairs, you will program two micro:bits to talk to each other over the radio. One micro:bit sends a message; the other receives it and scrolls a sequence of binary numbers. You decode the numbers to reveal a hidden three-letter word.

What you need

  • Two micro:bits and two USB cables
  • The MicroPython editor open on your device: https://python.microbit.org/v/2
  • The program below (this is HiddenWord.py)
  • Pen and paper (you must write down each binary number as it scrolls)

The program: HiddenWord.py

from microbit import *
import radio
import music

radio.on()
radio.config(group=65)

while True:
    message = radio.receive()
    if button_a.was_pressed():
        radio.send('message')
    if message:
        display.scroll('01100010')
        sleep(1000)
        music.play('c')
        display.scroll('01111001')
        sleep(1000)
        music.play('c')
        display.scroll('01100101')
        music.play(music.POWER_DOWN)

Step-by-step

  1. Agree a radio group with your partner. Pick a number between 0 and 255 that no other pair is using. Write it down: group ______
  2. Open https://python.microbit.org/v/2 and type in the program above, changing the line radio.config(group=65) so the number matches your group.
  3. Download the program to BOTH micro:bits. Both must run the same program with the same group number.
  4. Press button A on one micro:bit. The other micro:bit should beep and scroll the first binary number.
  5. Write down each binary number as it appears. There are three numbers in total — one for each letter of the hidden word.
  6. Use the ASCII mini-table to decode the three letters and work out the hidden word.
Check your answer: the hidden word is "bye" — 01100010 = b, 01111001 = y, 01100101 = e.
Then extend it (10 mins): add sound and a final image so the receiver knows when each letter starts and ends, and when the whole message is complete.
  • Add music.play('c') after each letter so there is a beep between numbers.
  • Add display.show(Image.YES) at the end so the receiver knows the message has finished.
  • Test again with your partner. Which version is easier to decode — with or without the beeps and final image?

🛠️ Debugging: Finding and Fixing Errors

If your radio message does not arrive, the problem is often an error in the code. When a program has a syntax error, it will not run: the micro:bit displays a sad face and the line number where it found the problem. Use that line number to find and fix the mistake.

Common mistakes

MistakeWhat to check
Missing colon :Every if, else, while and for line needs a colon at the end.
Spelling errorsDisplay instead of display, image.heart instead of Image.HEART. Python is case-sensitive.
Missing bracketsEvery opening ( needs a closing ).
Missing quotation marksStrings (text) must be wrapped in " " or ' '.
Wrong radio groupBoth micro:bits must use the same group number.
Missing indentationLines inside an if block must be indented.

🧪 Test Plan: Did Your Message Arrive?

A test plan is a table that tells you what to test, what you expect to happen, and what actually happened. Fill in the expected outcome before you test, then run the program and record the actual result. Fix one error at a time — this is an iterative process.

Tip: Testing early saves time! Fix small errors before they become big problems. Every error you find and fix is one iteration of the development cycle.

🚀 Challenge Yourself: Change the Input

Open the file ChallengeYourself.py. The program currently sends a message when the A button is pressed. Your challenge: replace the A button with the shake gesture.

from microbit import *
import radio

radio.config(group=42)
radio.on()

while True:
    message = radio.receive()
    if message:
        display.scroll("8, 5, 12, 12, 15")
    if accelerometer.was_gesture('shake'):
        display.clear()
        radio.send('message')
Think about it: A conditional statement can have only one of two outputs: TRUE or FALSE. This is a Boolean output. When you shake the micro:bit, accelerometer.was_gesture('shake') returns TRUE; otherwise it returns FALSE. Which lines run when it is TRUE? Which are skipped when it is FALSE? Test it with your partner.
