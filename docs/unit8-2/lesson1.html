📝 What is Pseudocode?

An algorithm is a set of step-by-step instructions that can be followed to solve a problem. An algorithm can be shown in two main ways:

  • Flowchart — a visual diagram using shapes and arrows.
  • Pseudocode — a text version of the algorithm that looks similar to code, but isn't tied to any one programming language.

Pseudocode is the link between our spoken words and the programming language. It has rules (like grammar in English), but no fixed syntax — so it's easier to edit than a flowchart.

⭐ Key Characteristics of Pseudocode

Good pseudocode should be:

  • Short — only the essential steps
  • Clear — easy to read and understand
  • Precise — no vague instructions
  • One instruction per line
  • Started with START and ended with STOP — always uppercase
  • Using uppercase keywords like INPUT, OUTPUT, IF, THEN, ELSE, ENDIF
Watch out: start is not the same as START. enter is not the same as INPUT. display is not the same as OUTPUT.

🧮 Example: Calculate the Area of a Square

Here is a simple algorithm to work out the area of a square. First, plan the steps:

  1. Get the length of one side from the user → store it in a variable called length.
  2. Multiply length by itself → store the answer in a new variable called area.
  3. Output the value stored in area.

Now write it as pseudocode:

START length = INPUT area = length * length OUTPUT area STOP

📦 Variables

A variable is a named temporary storage location. It can hold one value at a time, and that value can be changed during the program.

  • Name well: salary, area, userInput
  • Assign values with the = symbol: number = 6
  • Reassign at any time: number = number + 4

❓ Practise: Quiz Question

Look at the flowchart and pseudocode below for a quiz question. It asks the user "Who invented the World Wide Web?" and checks their answer.

Pseudocode

START answer = "Tim Berners Lee" OUTPUT "Who invented the World Wide Web?" userInput = INPUT IF answer == userInput THEN OUTPUT "Correct" ELSE OUTPUT "Incorrect" ENDIF STOP

Decompose it

  1. Annotate the variables — which lines set up the variables?
  2. Annotate the selection — where is the decision being made, and what are the two outputs?
  3. List the variables and their data types:
    • answer is a string (text)
    • userInput is a string (text — because it comes from the user typing)
