🧠 Stored Program Concept & Von Neumann Architecture

Before 1943, computers stored only data in memory. Programs were input one instruction at a time using switches or punch cards. Mathematician John von Neumann introduced the idea of storing both program instructions and data in the same memory. This is still how computers work today!

  • Von Neumann architecture: Program instructions and data share a common memory (RAM)
  • The CPU accesses both instructions and data from the same RAM
  • Memory addresses 0-7 might store a mix of program instructions and data

🔧 Components of the CPU

Control Unit (CU)

Coordinates and controls all activities in the CPU. Decodes instructions and sends control signals. Receives signals from the system clock.

Arithmetic Logic Unit (ALU)

Carries out arithmetic operations (add, subtract) and logical operations (AND, OR, NOT).

Very fast memory locations inside the CPU. Each has a specific job during the fetch-execute cycle.
